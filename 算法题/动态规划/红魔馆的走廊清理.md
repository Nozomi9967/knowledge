### **红魔馆的走廊清理 — 网格最小转向次数 DP**

核心思路是**三维 DP 记录到达方向**：`dp[i][j][k]` 表示到达 $(i,j)$ 时的最少转向次数，$k=0$ 表示从上方下来（向下移动），$k=1$ 表示从左方过来（向右移动）。从上方来若上一步也是向下则无转向，若上一步是向右则转向+1。时间复杂度 $O(mn)$，空间 $O(mn)$。

---

### **一、题目概述**

- **背景**：十六夜咲夜需要从厨房 $(0,0)$ 送红茶到蕾米莉亚的房间 $(m-1, n-1)$。
- **地图**：$m \times n$ 的网格。
- **移动规则**：只能向**右**或向**下**移动。
- **障碍物**：数值为 $1, 2, 3, 4$ 的格点不可通行，只有 $0$ 可通行。
- **目标**：找到从起点到终点**转向次数最少**的路径。
- **转向定义**：从"向右"变为"向下"或从"向下"变为"向右"。
- **输出**：最少转向次数。若无法到达或输入无效，输出 $-1$。

---

### **二、输入输出与数据范围**

- **输入**：第一行 $m, n$，后续 $m$ 行为网格数据。
- **约束**：$1 \le m, n \le 100$。若超出范围输出 $-1$。
- **输出**：一个整数（最少转向次数或 $-1$）。

---

### **三、解题思路：动态规划 (DP)**

#### **3.1 状态定义**

由于转向与否取决于**上一步的方向**，需要在 DP 状态中记录方向。

定义 `dp[i][j][k]` 表示到达坐标 $(i, j)$ 时的最少转向次数：
- `k = 0`：表示**向下**移动到达 $(i, j)$（即上一步在 $(i-1, j)$）。
- `k = 1`：表示**向右**移动到达 $(i, j)$（即上一步在 $(i, j-1)$）。

#### **3.2 状态转移方程**

对于任意可通行格点 $(i, j)$（即数值为 $0$）：

1. **从上方 $(i-1, j)$ 向下移动到达 $(i, j)$**：
   - 上一步也是向下（`k=0`）：方向未变，转向次数不变。
   - 上一步是向右（`k=1`）：发生转向（右→下），转向次数 $+1$。
   - `dp[i][j][0] = min(dp[i-1][j][0], dp[i-1][j][1] + 1)`

2. **从左方 $(i, j-1)$ 向右移动到达 $(i, j)$**：
   - 上一步也是向右（`k=1`）：方向未变，转向次数不变。
   - 上一步是向下（`k=0`）：发生转向（下→右），转向次数 $+1$。
   - `dp[i][j][1] = min(dp[i][j-1][1], dp[i][j-1][0] + 1)`

#### **3.3 初始化与边界条件**

- **无效输入检查**：若 $m, n$ 不在 $[1, 100]$ 范围内，直接输出 $-1$。
- **起点**：$(0, 0)$ 作为起点，转向次数为 $0$。
- **第一行**（坐标 $(0, j)$）：只能通过**向右**移动到达。
  - 若中途无障碍，`dp[0][j][1] = 0`。
  - `dp[0][j][0]` 初始化为 $1$：若从第一行某点向下走，相当于发生了一次转向（右→下），这一设计预算了从边界出发转向的代价。
- **第一列**（坐标 $(i, 0)$）：只能通过**向下**移动到达。
  - 若中途无障碍，`dp[i][0][0] = 0`。
  - `dp[i][0][1]` 初始化为 $1$：若从第一列向右走，相当于一次转向（下→右）。
- **障碍物处理**：若当前格点数值不为 $0$，将其状态设为 `INF`（不可达）。

### **四、代码实现解析**

```java
import java.util.*;

public class Main {
    static final int INF = Integer.MAX_VALUE / 2;

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int m = in.nextInt(), n = in.nextInt();

        // 输入合法性检查
        if (m <= 0 || n <= 0 || m > 100 || n > 100) {
            System.out.print(-1);
            return;
        }

        int[][] a = new int[m][n];
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                a[i][j] = in.nextInt();

        if (a[0][0] != 0 || a[m-1][n-1] != 0) {
            System.out.print(-1);
            return;
        }

        // dp[i][j][0] = 从上方下来（向下），dp[i][j][1] = 从左方过来（向右）
        int[][][] dp = new int[m][n][2];
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                for (int k = 0; k < 2; k++)
                    dp[i][j][k] = INF;

        // 起点
        dp[0][0][0] = dp[0][0][1] = 0;

        // 第一行初始化：只能向右走
        boolean f = false;
        for (int j = 1; j < n; j++) {
            if (a[0][j] != 0) f = true;
            if (!f) {
                dp[0][j][1] = 0;   // 保持向右，转向 0 次
                dp[0][j][0] = 1;   // 若从此处向下，预算一次转向
            }
        }

        // 第一列初始化：只能向下走
        f = false;
        for (int i = 1; i < m; i++) {
            if (a[i][0] != 0) f = true;
            if (!f) {
                dp[i][0][0] = 0;   // 保持向下，转向 0 次
                dp[i][0][1] = 1;   // 若从此处向右，预算一次转向
            }
        }

        // DP 主循环
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (a[i][j] != 0) continue; // 障碍物不可达

                // 从上方来（向下移动）
                dp[i][j][0] = Math.min(dp[i-1][j][0], dp[i-1][j][1] + 1);

                // 从左方来（向右移动）
                dp[i][j][1] = Math.min(dp[i][j-1][1], dp[i][j-1][0] + 1);
            }
        }

        // 终点取两种方向的最小值
        int ans = Math.min(dp[m-1][n-1][0], dp[m-1][n-1][1]);
        if (ans >= INF) System.out.print(-1);
        else System.out.print(ans);
    }
}
```

### **五、复杂度分析**

- **时间复杂度**：$O(m \times n)$。只需遍历一次网格。
- **空间复杂度**：$O(m \times n)$。$m, n \le 100$ 时空间占用极小。

---

### **六、关键设计点详解**

#### **边界初始化为 1 的含义**

第一行中 `dp[0][j][0] = 1` 的语义不是"已发生转向"，而是"如果从第 j 列向下走，需要付出 1 次转向代价"。同理第一列中 `dp[i][0][1] = 1` 预算是"从第 i 行向右走需要 1 次转向"。

这样设计的妙处在于：**终点的 `min(dp[m-1][n-1][0], dp[m-1][n-1][1])` 天然包含了从边界转向的代价**。如果终点恰好是"最后一行的最后一列"（即右下角），最后一步必然同时面临"从上方下来"和"从左方过来"两种选择，取 min 即可。

#### **为什么不用 BFS**

BFS（0-1 BFS）也可以：把"方向不变"的边权设为 0，"转向"的边权设为 1，跑 0-1 BFS。但 DP 更直观，且网格只有 100×100，DP 足够快。

---

### **七、面试话术**

1. **为什么需要三维 DP？** — 转向次数的计算依赖于上一步的方向。二维 DP（只存最小转向次数）丢失了方向信息，无法判断当前步是否发生了转向。三维 DP 的第三维只有 2 个值，空间代价很小。
2. **边界初始化为 1 的设计意图？** — 第一行只能向右走，但如果在第一行某点转向向下，这本身就是一次转向。把 `dp[0][j][0]` 初始化为 1 而不是 INF，表示"虽然没走过，但如果从这条路径往下走的代价是 1"。
3. **与普通最短路 BFS 的区别？** — BFS 求的是最少步数，本题求的是最少转向次数。转向是一种"代价"而非"步数"，且边权只有 0（不转向）和 1（转向），0-1 BFS 也可以，但 DP 更简洁。
4. **如果允许四个方向呢？** — 三维 DP 仍可扩展：$k=0,1,2,3$ 对应上下左右。转移方程变为 $dp[i][j][k] = \min(dp[ni][nj][k], dp[ni][nj][other] + 1)$，其中 other 是与 k 不同的方向。

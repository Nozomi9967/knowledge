### **LeetCode 62「不同路径」是最标准的网格 DP：`dp[i][j] = dp[i-1][j] + dp[i][j-1]`（只能往下或往右来），边界是第一行和第一列全为 1。二维可以滚动成一维。**

### **一、问题本身**

`m × n` 的网格，从左上角 `(0,0)` 走到右下角 `(m-1, n-1)`，每步只能向右或向下，问有多少条不同路径。

```
m = 3, n = 7  →  28
```

---

### **二、状态定义与转移**

**状态**：`dp[i][j]` = 走到格子 `(i,j)` 的路径数。

**转移**：到达 `(i,j)` 只有两个入口——从上面 `(i-1,j)` 下来，或从左边 `(i,j-1)` 过来。

```
dp[i][j] = dp[i-1][j] + dp[i][j-1]
```

**边界**：第一行 `dp[0][j] = 1`（只能一路向右）、第一列 `dp[i][0] = 1`（只能一路向下）。这两条边界的值是 1，不是 0，写错会全盘皆错。

---

### **三、代码（二维）**

```java
class Solution {
    public int uniquePaths(int m, int n) {
        int[][] dp = new int[m][n];
        for (int i = 0; i < m; i++) dp[i][0] = 1;
        for (int j = 0; j < n; j++) dp[0][j] = 1;
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
            }
        }
        return dp[m - 1][n - 1];
    }
}
```

### **四、滚动数组优化到一维**

观察转移式：`dp[i][j]` 只依赖「上一行的同一列」和「本行的左一格」。所以只要一行数组，从左往右更新即可——`dp[j]` 在更新前存的就是上一行的值（相当于 `dp[i-1][j]`），更新后变成当前行。

```java
class Solution {
    public int uniquePaths(int m, int n) {
        int[] dp = new int[n];
        Arrays.fill(dp, 1);           // 第一行全 1
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[j] = dp[j] + dp[j - 1];
                //    ↑上一行同列   ↑本行左一格（已更新）
            }
        }
        return dp[n - 1];
    }
}
```

**关键点**：`dp[j]` 在赋值号右边出现两次，左边的含义是"当前行"，右边的含义是"上一行"——这个覆盖是滚动数组的核心技巧。`dp[0]` 始终为 1（第一列），不用动。

---

### **五、数学解法：组合数**

从 `(0,0)` 到 `(m-1,n-1)` 一共要走 `(m-1) + (n-1)` 步，其中 `m-1` 步向下、`n-1` 步向右。所以路径数等于从总步数里选 `m-1` 步向下的组合数：

```
C(m+n-2, m-1)
```

```java
class Solution {
    public int uniquePaths(int m, int n) {
        long ans = 1;
        for (int i = 1; i <= m - 1; i++) {
            ans = ans * (n - 1 + i) / i;   // 边乘边除，避免阶乘溢出
        }
        return (int) ans;
    }
}
```

注意必须**边乘边除**，如果先算完整阶乘再除，`m=20` 就会溢出 long。

---

### **六、复杂度与易错点**

| 解法 | 时间 | 空间 |
|---|---|---|
| 二维 DP | O(m·n) | O(m·n) |
| 一维滚动 | O(m·n) | O(n) |
| 组合数 | O(m) | O(1) |

**易错点**：

1. **边界写成 0**：第一行/第一列必须是 1
2. **滚动时从右往左**：一维滚动必须**从左往右**遍历（因为依赖本行左边），这点和 01 背包的倒序正好相反，别记混
3. **组合数溢**：先乘后除必炸，要边乘边除
4. 有障碍物的版本是 63 题，转移不变，只是障碍格置 0、且第一行/列遇到障碍后全为 0

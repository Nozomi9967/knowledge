### **LeetCode 70「爬楼梯」本质就是斐波那契数列：`dp[i] = dp[i-1] + dp[i-2]`，因为到第 i 阶只能从 i-1 跨一步或从 i-2 跨两步来。**

### **一、问题本身**

一次可以爬 1 或 2 个台阶，问爬到第 `n` 阶有多少种不同的方法。

```
n = 3
1+1+1 / 1+2 / 2+1  →  3 种
```

---

### **二、状态定义与转移**

**状态**：`dp[i]` = 爬到第 `i` 阶的方法数。

**转移**：最后一步只有两种可能——从 `i-1` 跨 1 阶，或从 `i-2` 跨 2 阶。所以

```
dp[i] = dp[i-1] + dp[i-2]
```

**边界**：`dp[0] = 1`（站在地面，一种"什么都不做"的方案）、`dp[1] = 1`。

**这个 dp[0]=1 是最容易纠结的点**：它不是"爬 0 阶有 1 种方法"这种字面理解，而是为了让 `dp[2] = dp[1] + dp[0] = 2` 成立而设的哨兵值。也可以直接写 `dp[1]=1, dp[2]=2` 从 3 开始循环，避开这个讨论。

---

### **三、代码（滚动变量，O(1) 空间）**

```java
class Solution {
    public int climbStairs(int n) {
        if (n <= 2) return n;
        int prev2 = 1;   // dp[i-2]
        int prev1 = 2;   // dp[i-1]
        for (int i = 3; i <= n; i++) {
            int cur = prev1 + prev2;
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }
}
```

只保留最近两个状态，空间从 O(n) 降到 O(1)。这也是斐波那契的标准写法。

---

### **四、进阶：n 很大时用矩阵快速幂**

如果 `n` 到 10^18（某些变体题会这么出），O(n) 也过不了，要用矩阵快速幂做到 O(log n)：

```java
// [f(n)  ]   [1 1]^(n-1)   [f(1)]
// [f(n-1)] = [1 0]       * [f(0)]
```

面试里如果被追问"n 特别大怎么办"，答出矩阵快速幂就够了，不必现场写完。

---

### **五、复杂度与易错点**

| 项 | 复杂度 |
|---|---|
| 时间 | O(n) |
| 空间 | O(1)（滚动变量） |

**易错点**：

1. `n = 1` 时直接返回 1，别进循环
2. 别把 `dp[0]` 设成 0——那样 `dp[2]` 会算成 1，答案错
3. 这题和「斐波那契数」（509）是同一道题，只是起点差一位，注意别把边界搞混

---

### **六、变体：每次可以爬 1..m 阶**

如果一次能爬 1 到 m 阶，转移变成 `dp[i] = sum(dp[i-1] ... dp[i-m])`，用滑动窗口维护前缀和可以做到 O(n)。这是「组合总和 IV」的原始模型。

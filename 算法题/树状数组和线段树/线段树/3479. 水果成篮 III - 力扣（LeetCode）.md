提示

给你两个长度为 `n` 的整数数组， `fruits` 和 `baskets` ，其中 `fruits[i]` 表示第 `i` 种水果的 **数量** ， `baskets[j]` 表示第 `j` 个篮子的 **容量** 。

你需要对 `fruits` 数组从左到右按照以下规则放置水果：

- 每种水果必须放入第一个 **容量大于等于** 该水果数量的 **最左侧可用篮子** 中。
- 每个篮子只能装 **一种** 水果。
- 如果一种水果 **无法放入** 任何篮子，它将保持 **未放置** 。

返回所有可能分配完成后，剩余未放置的水果种类的数量。

**示例 1**

**输入：** fruits = \[4,2,5\], baskets = \[3,5,4\]

**输出：** 1

**解释：**

- `fruits[0] = 4` 放入 `baskets[1] = 5` 。
- `fruits[1] = 2` 放入 `baskets[0] = 3` 。
- `fruits[2] = 5` 无法放入 `baskets[2] = 4` 。

由于有一种水果未放置，我们返回 1。

**示例 2**

**输入：** fruits = \[3,6,1\], baskets = \[6,4,7\]

**输出：** 0

**解释：**

- `fruits[0] = 3` 放入 `baskets[0] = 6` 。
- `fruits[1] = 6` 无法放入 `baskets[1] = 4` （容量不足），但可以放入下一个可用的篮子 `baskets[2] = 7` 。
- `fruits[2] = 1` 放入 `baskets[1] = 4` 。

由于所有水果都已成功放置，我们返回 0。

**提示：**

- `n == fruits.length == baskets.length`
- `1 <= n <= 10^5`
- `1 <= fruits[i], baskets[i] <= 10^9`

---



```java
class Solution {

  

    int[] tree;

  

    void build(int node, int l, int r, int[] b) {

        if (l == r) {

            tree[node] = b[l];

            return;

        }

  

        int m = (l + r) >> 1;

  

        build(node * 2, l, m, b);

        build(node * 2 + 1, m + 1, r, b);

  

        tree[node] = Math.max(tree[node * 2], tree[node * 2 + 1]);

    }

  

    // 找第一个 >= x 的 basket

    int find(int node, int l, int r, int x) {

  

        if (tree[node] < x) return -1; // 整段都不行

  

        if (l == r) return l;

  

        int m = (l + r) >> 1;

  

        if (tree[node * 2] >= x) {

            return find(node * 2, l, m, x);

        } else {

            return find(node * 2 + 1, m + 1, r, x);

        }

    }

  

    void update(int node, int l, int r, int idx, int val) {

        if (l == r) {

            tree[node] = val;

            return;

        }

  

        int m = (l + r) >> 1;

  

        if (idx <= m) update(node * 2, l, m, idx, val);

        else update(node * 2 + 1, m + 1, r, idx, val);

  

        tree[node] = Math.max(tree[node * 2], tree[node * 2 + 1]);

    }

  

    public int numOfUnplacedFruits(int[] fruits, int[] baskets) {

  

        int n = baskets.length;

        tree = new int[4 * n];

  

        build(1, 0, n - 1, baskets);

  

        int unplaced = 0;

  

        for (int f : fruits) {

  

            int idx = find(1, 0, n - 1, f);

  

            if (idx == -1) {

                unplaced++;

            } else {

                update(1, 0, n - 1, idx, 0); // 删除这个 basket

            }

        }

  

        return unplaced;

    }

}
```

# 📘 线段树完整学习笔记（Build / Query / Update / Node vs IDX）

---

# 一、线段树核心概念

线段树是一种用于**区间查询 + 单点/区间更新**的数据结构。

核心思想：

> 用一棵二叉树，把数组的每个区间拆开存储信息（如 sum / max / min）。

---

# 二、Node 和 IDX 的关系（核心重点）

## 1️⃣ idx（数组下标）

```text
nums[idx]
```

- 表示真实数组位置
    
- 是“数据本身”
    

例：

```text
nums = [1, 3, 5, 7]
index   0  1  2  3
```

---

## 2️⃣ node（线段树节点编号）

```text
tree[node]
```

- 表示一个区间的信息
    
- 不是数组下标
    
- 是“区间管理节点”
    

---

## 3️⃣ 本质区别

|类型|含义|
|---|---|
|idx|数组的真实点|
|node|覆盖一段区间的节点|

---

## 4️⃣ 核心结论

> node 和 idx 没有直接关系  
> idx 会被多个 node（从叶子到根）覆盖

---

## 5️⃣ 结构理解图

```text
                [0,3] node1
               /            \
         [0,1] node2      [2,3] node3
          /     \          /     \
     [0,0]    [1,1]    [2,2]   [3,3]
```

---

# 三、build 方法（建树）

## 1️⃣ 作用

> 把数组递归拆分，并构建线段树

---

## 2️⃣ 代码

```java
void build(int node, int l, int r, int[] nums) {

    if (l == r) {
        tree[node] = nums[l];
        return;
    }

    int mid = (l + r) >> 1;

    build(node * 2, l, mid, nums);
    build(node * 2 + 1, mid + 1, r, nums);

    tree[node] = Math.max(tree[node * 2], tree[node * 2 + 1]);
}
```

---

## 3️⃣ build 做了三件事

1. 拆区间
    
2. 到叶子赋值
    
3. 回溯合并
    

---

## 4️⃣ 本质

> DFS + 回溯构建区间信息

---

# 四、query 方法（区间查询）

## 1️⃣ 作用

> 查询区间 [L, R] 的结果

---

## 2️⃣ 核心代码

```java
int query(int node, int l, int r, int L, int R) {

    if (R < l || r < L) return 0; // 无交集

    if (L <= l && r <= R) return tree[node]; // 完全覆盖

    int mid = (l + r) >> 1;

    return query(node * 2, l, mid, L, R)
         + query(node * 2 + 1, mid + 1, r, L, R);
}
```

---

## 3️⃣ 三种情况

### ❌ 无交集

```text
直接返回 0
```

---

### ✅ 完全覆盖

```text
直接用 tree[node]
```

---

### 🔁 部分重叠

```text
继续拆左右子树
```

---

## 4️⃣ 本质

> “剪枝 + 区间复用 + 递归拆分”

---

# 五、update 方法（单点更新）

## 1️⃣ 作用

> 修改 nums[idx] 并更新线段树

---

## 2️⃣ 核心代码

```java
void update(int node, int l, int r, int idx, int val) {

    if (l == r) {
        tree[node] = val;
        return;
    }

    int mid = (l + r) >> 1;

    if (idx <= mid)
        update(node * 2, l, mid, idx, val);
    else
        update(node * 2 + 1, mid + 1, r, idx, val);

    tree[node] = Math.max(tree[node * 2], tree[node * 2 + 1]);
}
```

---

## 3️⃣ update 做了两件事

### ① 找到 idx 对应的叶子节点

```text
root → 一路递归 → leaf
```

---

### ② 回溯更新所有 node

```text
leaf → root
```

---

## 4️⃣ 本质

> 修改一个点 + 更新所有受影响区间

---

# 六、node vs idx 关系总结

## 1️⃣ 错误理解

❌ node = idx

---

## 2️⃣ 正确理解

✔ idx 是点  
✔ node 是区间  
✔ 一个 idx 被多个 node 覆盖

---

## 3️⃣ update 路径

```text
idx = 2
↓
node1 → node3 → node6
```

---

## 4️⃣ 类比理解

|概念|类比|
|---|---|
|idx|员工|
|node|各级主管|
|update|员工改数据|
|回溯|主管更新统计|

# 七、LeetCode 3479（Fruits into Baskets III）

---

## 1️⃣ 问题本质

每个 fruit：

> 找第一个 ≥ fruit 的 basket，并删除它

---

## 2️⃣ 线段树维护

```text
区间最大值
```

---

## 3️⃣ 关键操作

### find（找可用 basket）

```java
if (tree[node] < x) return -1;

if (l == r) return l;

if (left child >= x)
    go left
else
    go right
```

---

### update（删除 basket）

```java
update(idx, 0)
```

---

## 4️⃣ 本质

> max + 剪枝 + 单点删除

---

# 八、线段树三大核心总结

|操作|本质|
|---|---|
|build|构建区间信息|
|query|剪枝查询|
|update|单点修改 + 回溯|

---

# 九、时间复杂度

|操作|复杂度|
|---|---|
|build|O(n)|
|query|O(log n)|
|update|O(log n)|

---

# 十、一句话总总结

> 线段树 = 用树结构维护区间信息，通过递归拆分 + 回溯更新，实现 O(log n) 的区间操作。

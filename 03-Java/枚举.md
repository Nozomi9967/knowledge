# Java 枚举（Enum）全解

## 一、枚举是什么

本质上，`enum` 是一个**特殊的类**，编译器会把它翻译成继承 `java.lang.Enum` 的 final 类，每个枚举常量都是该类的一个 `public static final` 实例。

```java
enum Season { SPRING, SUMMER, AUTUMN, WINTER }

// 编译器实际生成的等价代码（简化版）：
final class Season extends Enum<Season> {
    public static final Season SPRING = new Season("SPRING", 0);
    public static final Season SUMMER = new Season("SUMMER", 1);
    public static final Season AUTUMN = new Season("AUTUMN", 2);
    public static final Season WINTER = new Season("WINTER", 3);
    // ...
}
```

------

## 二、基础用法

```java
enum Direction { UP, DOWN, LEFT, RIGHT }

Direction d = Direction.UP;
System.out.println(d);          // UP
System.out.println(d.name());   // UP（常量名字符串）
System.out.println(d.ordinal()); // 0（从0开始的序号）

// 字符串转枚举
Direction d2 = Direction.valueOf("DOWN"); // Direction.DOWN

// 遍历所有常量
for (Direction dir : Direction.values()) {
    System.out.println(dir.ordinal() + " -> " + dir);
}
```

## 三、枚举 + 属性和方法（最常用）

枚举可以有**字段、构造器、方法**，构造器必须是 private。

```java
enum Planet {
    MERCURY(3.303e+23, 2.4397e6),
    VENUS  (4.869e+24, 6.0518e6),
    EARTH  (5.976e+24, 6.37814e6);

    private final double mass;   // 质量
    private final double radius; // 半径

    // 构造器必须 private
    Planet(double mass, double radius) {
        this.mass = mass;
        this.radius = radius;
    }

    // 普通方法
    public double surfaceGravity() {
        final double G = 6.67300E-11;
        return G * mass / (radius * radius);
    }
}

System.out.println(Planet.EARTH.surfaceGravity()); // 9.80...
```

## 四、枚举 + 抽象方法（每个常量有不同行为）

```java
enum Operation {
    PLUS("+") {
        @Override
        public double apply(double x, double y) { return x + y; }
    },
    MINUS("-") {
        @Override
        public double apply(double x, double y) { return x - y; }
    },
    TIMES("*") {
        @Override
        public double apply(double x, double y) { return x * y; }
    };

    private final String symbol;

    Operation(String symbol) { this.symbol = symbol; }

    // 抽象方法，每个常量必须实现
    public abstract double apply(double x, double y);

    @Override
    public String toString() { return symbol; }
}

// 使用
for (Operation op : Operation.values()) {
    System.out.printf("3 %s 2 = %.1f%n", op, op.apply(3, 2));
}
// 3 + 2 = 5.0
// 3 - 2 = 1.0
// 3 * 2 = 6.0
```

## 五、switch 中使用枚举

```java
enum Status { PENDING, RUNNING, SUCCESS, FAILED }

Status s = Status.RUNNING;

// 传统 switch
switch (s) {
    case PENDING:  System.out.println("等待中"); break;
    case RUNNING:  System.out.println("运行中"); break;
    case SUCCESS:  System.out.println("成功");   break;
    case FAILED:   System.out.println("失败");   break;
}

// Java 14+ switch 表达式（更简洁）
String msg = switch (s) {
    case PENDING  -> "等待中";
    case RUNNING  -> "运行中";
    case SUCCESS  -> "成功";
    case FAILED   -> "失败";
};
```

## 六、EnumSet 和 EnumMap

专为枚举设计，**性能远优于** HashSet/HashMap（底层用位向量实现）。

```java
enum Day { MON, TUE, WED, THU, FRI, SAT, SUN }

// EnumSet
EnumSet<Day> weekdays  = EnumSet.range(Day.MON, Day.FRI);
EnumSet<Day> weekends  = EnumSet.of(Day.SAT, Day.SUN);
EnumSet<Day> all       = EnumSet.allOf(Day.class);

System.out.println(weekdays.contains(Day.MON)); // true

// EnumMap
EnumMap<Day, String> schedule = new EnumMap<>(Day.class);
schedule.put(Day.MON, "周会");
schedule.put(Day.FRI, "代码审查");
System.out.println(schedule.get(Day.MON)); // 周会
```

## 七、枚举实现接口

```java
interface Printable {
    void print();
}

enum Color implements Printable {
    RED, GREEN, BLUE;

    @Override
    public void print() {
        System.out.println("Color: " + this.name());
    }
}

Color.RED.print(); // Color: RED
```

## 八、枚举与单例模式

枚举是实现单例的**最佳方式**（Effective Java 推荐），其安全性由 JVM 规范在三个层面保证：

1. **天然线程安全**：枚举实例在类加载时由 `<clinit>()` 创建，类加载过程由 JVM 加锁保证，无需手动编写 `synchronized` 或双重检查锁。
2. **防反射攻击**：JVM 禁止通过反射创建枚举实例，调用枚举构造器的 `newInstance()` 会直接抛出 `IllegalArgumentException`（"Cannot reflectively create enum objects"）。
3. **防反序列化**：枚举的反序列化不是通过反射创建新对象，而是直接返回已有的枚举实例，`readResolve()` 由 JVM 自动保障，确保反序列化后仍是同一个实例。

普通单例的三层防护都需要手动实现，且容易遗漏；枚举则全部由 JVM 在语言层面强制保证。

```java
enum Singleton {
    INSTANCE;

    private int count = 0;

    public void increment() { count++; }
    public int getCount()   { return count; }
}

// 使用
Singleton.INSTANCE.increment();
Singleton.INSTANCE.increment();
System.out.println(Singleton.INSTANCE.getCount()); // 2
```

## 九、常用 API 汇总

| 方法              | 说明                       |
| ----------------- | -------------------------- |
| `name()`          | 返回常量名字符串           |
| `ordinal()`       | 返回序号（从 0 开始）      |
| `valueOf(String)` | 字符串转枚举，找不到抛异常 |
| `values()`        | 返回所有常量数组           |
| `compareTo(E)`    | 按 ordinal 比较大小        |
| `toString()`      | 默认返回 name()，可重写    |

## 十、注意事项

**不要依赖 `ordinal()`** 存储业务含义，因为增减常量会导致序号变化，应该用显式字段：

```java
// ❌ 错误做法
enum Type { A, B, C }
int code = type.ordinal(); // 脆弱！

// ✅ 正确做法
enum Type {
    A(1), B(2), C(3);
    private final int code;
    Type(int code) { this.code = code; }
    public int getCode() { return code; }
}
```

**`valueOf` 找不到会抛 `IllegalArgumentException`**，需要容错时自己封装：

```java
public static Type fromCode(int code) {
    for (Type t : values()) {
        if (t.code == code) return t;
    }
    throw new IllegalArgumentException("未知 code: " + code);
}
```

# 🎯 面试题 · 2026-07-13（基于《枚举》）

> [!question]- 面试题 1：枚举本质上是什么？编译器如何处理？
> **口述参考答案：**
> 枚举本质上是一个特殊的类，编译器会将其翻译为继承 `java.lang.Enum` 的 `final` 类。每个枚举常量是该类的一个 `public static final` 实例，在类的 `<clinit>()` 方法中完成初始化。以 `enum Season { SPRING, SUMMER, AUTUMN, WINTER }` 为例，编译器实际会生成四个 `public static final Season` 字段，通过私有构造器创建实例并赋值。这意味着枚举常量是单例的——JVM 保证每个常量只被实例化一次。

> [!question]- 面试题 2：枚举可以包含哪些成员？构造器有什么权限限制？
> **口述参考答案：**
> 枚举可以包含字段、构造器、普通方法，但构造器必须是 `private` 的，因为枚举实例由编译器生成，不允许外部通过 `new` 创建。以 Planet 枚举为例，每个星球常量绑定了质量和半径两个属性，通过构造器赋值，并提供了 `surfaceGravity()` 方法计算表面重力。调用方式与普通类无异：`Planet.EARTH.surfaceGravity()` 即可获得地球表面重力。这种设计将常量与业务逻辑封装在一起，是枚举最常用的场景。

> [!question]- 面试题 3：枚举如何实现不同常量拥有不同的行为？
> **口述参考答案：**
> 通过抽象方法实现。在枚举中定义一个抽象方法，每个枚举常量在声明时用大括号单独重写该方法。以 Operation 枚举为例，定义抽象方法 `apply(double x, double y)`，PLUS 返回 `x + y`，MINUS 返回 `x - y`，TIMES 返回 `x * y`。调用时直接 `Operation.PLUS.apply(3, 2)` 即可，无需编写 `if-else` 或 `switch` 判断操作类型。这种方式将行为直接绑定到枚举常量上，是策略模式在枚举中的典型应用。

> [!question]- 面试题 4：EnumSet 和 EnumMap 相比普通集合有什么优势？
> **口述参考答案：**
> EnumSet 和 EnumMap 是 Java 专门为枚举设计的集合实现，底层用位向量（bit vector）存储，性能远优于 HashSet 和 HashMap。以 Day 枚举为例，`EnumSet.range(Day.MON, Day.FRI)` 即可获取工作日集合，`EnumSet.of(Day.SAT, Day.SUN)` 获取周末集合。EnumMap 构造时传入 `Day.class` 指定 key 类型，如 `schedule.put(Day.MON, "周会")`，比 HashMap 效率更高且类型安全。建议在 key 为枚举的场景优先使用 EnumMap。

> [!question]- 面试题 5：用枚举实现单例有什么优势？使用时需要注意哪些问题？
> **口述参考答案：**
> 枚举是实现单例的最佳方式，安全性由 JVM 规范在三个层面强制保证。第一，**天然线程安全**——实例在类加载时由 `<clinit>()` 创建，类加载过程由 JVM 加锁，无需手动编写同步代码。第二，**防反射攻击**——JVM 禁止通过反射创建枚举实例，调用构造器 `newInstance()` 会抛出 `IllegalArgumentException`。第三，**防反序列化**——枚举反序列化时 JVM 直接返回已有实例，不会创建新对象。
>
> 使用时有两个注意点。其一，**不要依赖 `ordinal()` 存储业务含义**，因为增减枚举常量会导致序号变化，应使用显式字段，如每个常量绑定一个 code 值。其二，`valueOf()` 找不到对应字符串时会抛出 `IllegalArgumentException`，需要容错时应自行封装方法，遍历 `values()` 匹配。

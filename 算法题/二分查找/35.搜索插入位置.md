## 题解

```java
class Solution {
    public int searchInsert(int[] nums, int target) {
        int left=0,right=nums.length-1;
        int mid=0;
        while(left<=right){
            mid=(left+right)/2;
            if(target>nums[mid]) left=mid+1;
            else right=mid-1;
        }
        return left;
    }
}
```

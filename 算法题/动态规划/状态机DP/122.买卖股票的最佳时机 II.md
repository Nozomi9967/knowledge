# LeetCode 122「买卖股票的最佳时机 II」— 无限次交易

题目：给定 `prices`，**可以多次交易**（买入前必须已卖出，任意时刻最多持有一股），求最大收益。与 123 题的区别是**交易次数不设上限**。

---

## 一、我的写法：划分 DP（$O(n^2)$）

```java
class Solution {
    public int maxProfit(int[] prices) {
        int n=prices.length;
        // d[i]:前i天能获得的最大利润
        int[] d=new int[n+1];
        // 直接从第二天开始: i+1=2
        for(int i=1;i<n;i++){
            d[i+1]=d[i];
            for(int j=i-1;j>=0;j--){
                if(prices[j]>=prices[i]) continue;
                d[i+1]= Math.max(d[i+1],prices[i]-prices[j] + d[j+1]);
                // System.out.println("d["+(i+1)+"]:"+d[i+1]);
            }
        }

        return d[n];
    }
}
```

### 状态定义

`d[i]`：前 `i` 天（第 `0..i-1` 天）能获得的最大利润，`d[0]=0`。

### 状态转移

枚举「最后一笔交易」：第 `i+1` 天卖出，枚举买入日 `j`（`0 ≤ j < i`），若 `prices[j] < prices[i]` 有差价可赚：

```
d[i+1] = max( d[i],   max over j ( prices[i]-prices[j] + d[j+1] ) )
```

- `d[i]`：第 `i+1` 天什么都不做，继承前一天的利润
- `prices[i]-prices[j]`：最后这笔交易的利润
- `d[j+1]`：这笔交易之前的累积利润（前 `j+1` 天，即第 `0..j` 天）

> [!info] 为什么是 `d[j+1]` 而不是 `d[j]`？
> 买在 `j` 天，之前的交易按理应在 `j` 天之前结束。但本题**允许同一天先卖后买**（卖出价 = 买入价、净收益 0，等价于不动），所以前 `j+1` 天（含第 `j` 天）的利润可以照常计入，不会产生非法叠加。这就是无限次交易与 121（只能 1 次，此处用 `d[j]`）的状态语义差别。

### 复杂度

- 时间 $O(n^2)$：本题 `n ≤ 3×10^4`，内层枚举买入日使总运算量逼近 $9×10^8$，大样例**超时风险高**——只适合理解"枚举最后一笔交易"的转移思路，AC / 面试用下面的 $O(n)$ 解法
- 空间 $O(n)$

## 二、贪心（$O(n)$，最推荐口述）

**只要 `prices[i] > prices[i-1]` 就把差额累加进去。**

```java
class Solution {
    public int maxProfit(int[] prices) {
        int profit = 0;
        for (int i = 1; i < prices.length; i++) {
            if (prices[i] > prices[i - 1]) {
                profit += prices[i] - prices[i - 1];
            }
        }
        return profit;
    }
}
```

**为什么对：** 任一笔交易（`buy` 天买、`sell` 天卖）的利润 `prices[sell] - prices[buy]` 都能拆成**相邻天差的累加**（差分数列）：

$$prices[buy+1]-prices[buy] + \cdots + prices[sell]-prices[sell-1]$$

交易次数无限 ⟹ 每一天的上涨都可以单独收割、下跌段的负差可以全部跳过。所以答案 = 所有正相邻差之和，贪心成立。

## 三、状态机 DP（$O(n)$ 时间，$O(1)$ 空间）

两个状态：

- `cash`：今天手里**没股票**的最大收益
- `hold`：今天手里**有股票**的最大收益

```java
class Solution {
    public int maxProfit(int[] prices) {
        int cash = 0;
        int hold = -prices[0]; // 第 0 天买入后的收益
        for (int i = 1; i < prices.length; i++) {
            cash = Math.max(cash, hold + prices[i]); // 今天卖出 or 不动
            hold = Math.max(hold, cash - prices[i]); // 今天买入 or 不动
        }
        return cash;
    }
}
```

> [!info] `hold` 更新为什么能用「当天刚更新过的 `cash`」？
> 表示**同一天先卖后买**（`cash` 先算出卖出，`hold` 再用新现金买入）。本题交易次数无限，同一天卖出再买入净收益为 0、等价于不动，不会污染答案；这也让状态机天然支持连续多段交易。

| 状态 | 含义 | 转移 |
|------|------|------|
| `cash` | 空仓（没股票） | `max(cash, hold + price)` — 卖出或不动 |
| `hold` | 持仓（有股票） | `max(hold, cash - price)` — 买入或不动 |

**和 123 的关系：** 123 限定了「最多 2 笔」，必须拆成 4 个变量 `buy1/sell1/buy2/sell2`；本题不限次数，两个变量就够。122 是 123 状态机去掉了交易次数维度。

---

## 四、与 121 / 123 的区别

| 题目 | 交易次数 | 状态数 | 核心思路 |
|------|---------|--------|----------|
| 121 | 至多 1 次 | 1 个前缀最小值 | 扫一遍维护最低买入价 |
| 122 | 无限次 | `cash/hold` 两状态 | 贪心吃所有正差 / 状态机 |
| 123 | 至多 2 次 | 4 变量 | 状态机 + 交易次数维度 |

> 121 → 122 → 123 → 188 是一条经典递进线：只能 1 次 → 不限次数（两状态）→ 至多 2 笔（4 变量）→ 至多 k 笔（循环交易次数维度）。

## 五、面试话术

1. **先说结论再讲机制**：无限次交易 → 每次上涨都收割，答案 = 所有 `prices[i] - prices[i-1]` 正数之和，O(n)。
2. **证明贪心成立**：任一段交易的利润 = 段内相邻差之和（差分数列视角），把每一段的正差分别取到、负差全部跳过，就是能拿到的最大收益。
3. **状态机一句话版**：维护 `cash`（空仓）、`hold`（持仓）两个状态，每天要么不动、要么卖掉更新 `cash`、要么买入更新 `hold`，O(n) 时间 O(1) 空间。
4. **被追问 O(n²) 划分 DP**：能——`d[i+1] = max(d[i], prices[i]-prices[j]+d[j+1])`，枚举最后一笔交易的买入日 `j`，`d[j+1]` 用前 `j+1` 天利润是因为允许同一天先卖后买；但大数据集会超时，AC 用贪心 / 状态机。

### **LeetCode 459「重复的子字符串」有两条路：直观解法是「枚举周期长度，逐个验证，O(n²)」；最优解用 KMP 的 next 数组——**如果 `n % (n - next[n-1]) == 0` 且 `next[n-1] > 0`，则说明整串由一个更短的周期重复而成**。**

### **一、问题本身**

判断字符串能否由它的某个子串重复多次构成。

```
"abab"   → true（"ab" × 2）
"abcabcabc" → true（"abc" × 3）
"aba"    → false
"a"      → false（重复必须 ≥ 2 次）
```

---

### **二、思路一：枚举周期（直观，O(n²)）**

如果整串由长度 `len` 的周期重复而成，那么 `len` 必须能整除 `n`（`n % len == 0`），且对每个位置 `i`，都有 `s[i] == s[i % len]`。

```java
class Solution {
    public boolean repeatedSubstringPattern(String s) {
        int n = s.length();
        for (int len = 1; len <= n / 2; len++) {   // 周期最多到 n/2
            if (n % len != 0) continue;            // 必须整除
            boolean ok = true;
            for (int i = len; i < n; i++) {
                if (s.charAt(i) != s.charAt(i - len)) { ok = false; break; }
            }
            if (ok) return true;
        }
        return false;
    }
}
```

- 时间 O(n²)（最坏情况每个 `len` 都验证一遍）
- 空间 O(1)

这写法正确且好懂，n ≤ 10^4 时能过。**面试先说这个，再给 KMP 优化，逻辑层次更清楚。**

### **三、思路二：KMP 的 next 数组（O(n)）**

**核心结论**：设 `next[n-1]` 是整串的"最长相等前后缀长度"，那么 `n - next[n-1]` 就是"最小可能的周期长度"。

判断条件：

```
next[n-1] > 0  &&  n % (n - next[n-1]) == 0
```

**为什么成立**：如果整串有长度为 `p = n - next[n-1]` 的周期，那整串就是"前 n-p 个字符"和"后 n-p 个字符"完全相等——这正是 `next[n-1] = n - p` 的含义。反过来，`n` 能被 `p` 整除说明整串恰好由整数个周期拼成。

**`next[n-1] > 0` 必须单独判**：`n=1` 时 `next[0]=0`，`p = 1 - 0 = 1`，`1 % 1 == 0`，会误判为 true。而长度为 1 的串不能算"重复构成"。

---

### **四、KMP next 数组的构造**

`next[i]` 表示 `s[0..i]` 的**最长相等前后缀长度**（前缀不含末尾、后缀不含开头）。

```java
int[] buildNext(String s) {
    int n = s.length();
    int[] next = new int[n];
    int j = 0;                        // j 是当前匹配到的前缀长度
    for (int i = 1; i < n; i++) {
        while (j > 0 && s.charAt(i) != s.charAt(j)) {
            j = next[j - 1];          // 失配，回退到次长前后缀
        }
        if (s.charAt(i) == s.charAt(j)) {
            j++;
        }
        next[i] = j;
    }
    return next;
}
```

**这一步是 KMP 的核心**：`j = next[j-1]` 的失配回退让整体复杂度保持 O(n)（`j` 只增不减地回退，均摊 O(1)）。

### **五、完整代码**

```java
class Solution {
    public boolean repeatedSubstringPattern(String s) {
        int n = s.length();
        if (n <= 1) return false;

        int[] next = new int[n];
        int j = 0;
        for (int i = 1; i < n; i++) {
            while (j > 0 && s.charAt(i) != s.charAt(j)) j = next[j - 1];
            if (s.charAt(i) == s.charAt(j)) j++;
            next[i] = j;
        }

        int p = n - next[n - 1];       // 最小周期长度
        return next[n - 1] > 0 && n % p == 0;
    }
}
```

### **七、思路三：字符串拼接技巧（最取巧）**

把 `s` 拼成 `s + s`，去掉首尾各一个字符，如果剩下的串里还能找到 `s`，说明 `s` 是周期串。

```java
return (s + s).substring(1, 2 * s.length() - 1).contains(s);
```

**原理**：`s+s` 包含了 `s` 的所有循环移位。去掉首尾各一个字符，是为了排除"在原位置匹配到原始 s"这种情况——剩下还能匹配，就说明存在非平凡的周期。

**注意**：`String.contains` 的底层是朴素匹配，最坏 O(n²)，所以这招虽然代码一行，复杂度并不优。面试可以提一句作为"巧解"，但要说明它不是最优。

### **八、复杂度与易错点**

| 解法 | 时间 | 空间 |
|---|---|---|
| 枚举周期 | O(n²) | O(1) |
| KMP next | O(n) | O(n) |
| 拼接技巧 | O(n²) 最坏 | O(n) |

**易错点**：

1. **忘记 `next[n-1] > 0`**：`"a"` 会误判为 true
2. **`n % p` 写成 `p % n`**：方向反了
3. **next 数组的失配回退写成 `j--`**：必须是 `j = next[j-1]`，否则退化成 O(n²)
4. **`while (j > 0 && ...)` 漏了 `j > 0`**：数组越界
5. **周期长度的理解**：`n - next[n-1]` 是**最小**周期，不是任意周期；如果最小周期不整除 n，更长周期也不会整除（这一点可以数学证明）
6. **空串**：`n=0` 时返回 false（本题约束 n ≥ 1，但工程代码要判）

### **九、KMP next 数组的其他用途**

`next` 数组（有些资料叫 `π` 数组或前缀函数）不止能判周期：

- **字符串匹配**：`next` 让主串指针不回退，做到 O(n+m)
- **最短回文串**（214）：`s + "#" + reverse(s)` 求 next
- **字符串的周期**（本题）
- **统计每个前缀出现的次数**：利用 next 链

**一句话**：`next[i]` 蕴含了"这个前缀的自相似结构"，凡是涉及字符串周期性、自相似的问题都该想到它。

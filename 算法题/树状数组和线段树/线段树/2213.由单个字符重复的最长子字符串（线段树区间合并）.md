# 2213. 由单个字符重复的最长子字符串（线段树区间合并）

## 题目描述

给你一个下标从 0 开始的字符串 `s`。另给你一个下标从 0 开始、长度为 `k` 的字符串 `queryCharacters`，一个下标从 0 开始、长度也是 `k` 的整数下标数组 `queryIndices`，这两个都用来描述 `k` 个查询。

第 `i` 个查询会将 `s` 中位于下标 `queryIndices[i]` 的字符更新为 `queryCharacters[i]`。

返回一个长度为 `k` 的数组 `lengths`，其中 `lengths[i]` 是在执行第 `i` 个查询**之后** `s` 中仅由单个字符重复组成的**最长子字符串**的长度。

### 示例 1

```
输入：s = "babacc", queryCharacters = "bcb", queryIndices = [1,3,3]
输出：[3,3,4]
解释：
- 第 1 次查询更新后 s = "bbbacc" → 最长 "bbb"，长度 3
- 第 2 次查询更新后 s = "bbbccc" → 最长 "bbb" 或 "ccc"，长度 3
- 第 3 次查询更新后 s = "bbbbcc" → 最长 "bbbb"，长度 4
```

### 示例 2

```
输入：s = "abyzz", queryCharacters = "aa", queryIndices = [2,1]
输出：[2,3]
```

### 提示

- `1 <= s.length <= 10^5`
- `s` 由小写英文字母组成
- `k == queryCharacters.length == queryIndices.length`
- `1 <= k <= 10^5`
- `queryCharacters` 由小写英文字母组成
- `0 <= queryIndices[i] < s.length`

---

## 核心思路

**问题形态**：单点更新（改一个字符）+ 全局查询（整串最长重复子串长度），$n, k \le 10^5$，暴力每次重建 $O(nk)$ 必超时 → **线段树区间合并**。

每个区间节点只需记录 5 个字段，就能把两个子区间"拼"出父区间的答案：

| 字段 | 含义 |
|------|------|
| `mx` | 区间内最长连续相同子串长度 |
| `l` / `lc` | 区间**左边界**起的连续相同长度 / 该字符 |
| `r` / `rc` | 区间**右边界**结束的连续相同长度 / 该字符 |
| `f` | 该区间是否**整个全为同一字符** |

**区间合并（pull）关键规则**：

1. `mx = max(L.mx, R.mx)`，若 `L.rc == R.lc` 则可能跨边界连起来：`mx = max(mx, L.r + R.l)`
2. 全同判断 `f = L.f && R.f && L.rc == R.lc`；全同时 `l = r = mx = L.mx + R.mx`
3. 左边界长度 `l`：若左孩子全同且 `L.rc == R.lc`，`l` 可延伸到 `L.r + R.l`（否则保持 `L.l`）
4. 右边界长度 `r`：对称，右孩子全同且边界字符相接时 `r = L.r + R.l`

**复杂度**：build $O(n)$，每次查询一次单点更新 $O(\log n)$，总 $O((n + k)\log n)$。

## 完整代码

```java
class Solution {

    private Node[] tree;
    private char[] a;

    class Node {
        // l,r内最长子字符串长度
        public int mx;
        public int l;
        public char lc;
        public int r;
        public char rc;
        public boolean f;

        Node() {}

        Node(int mx, int l, char lc, int r, char rc) {
            this.mx = mx;
            this.l = l;
            this.lc = lc;
            this.r = r;
            this.rc = rc;
            this.f = true;
        }
    }

    public void build(int node, int l, int r) {
        if (l == r) {
            tree[node] = new Node(1, 1, a[l], 1, a[l]);
            return;
        }

        int m = (r - l) / 2 + l;
        build(node * 2, l, m);
        build(node * 2 + 1, m + 1, r);

        Node cur = new Node();
        Node L = tree[node * 2];
        Node R = tree[node * 2 + 1];
        // 正常：aabb ccdd
        cur.mx = Math.max(L.mx, R.mx);
        cur.f = false;
        cur.l = L.l; cur.r = R.r; cur.lc = L.lc; cur.rc = R.rc;
        // aabb bbdd
        if (L.rc == R.lc) {
            cur.mx = Math.max(cur.mx, L.r + R.l);
        }
        if (L.f && R.f && L.rc == R.lc) { // aa a
            cur.f = true;
            cur.l = cur.r = cur.mx = (L.mx + R.mx);
        }
        if (L.f && L.rc == R.lc) { // aa ab
            cur.mx = Math.max(cur.mx, L.r + R.l);
            cur.l = (L.r + R.l);
        }
        if (R.f && L.rc == R.lc) { // ab bb
            cur.mx = Math.max(cur.mx, L.r + R.l);
            cur.r = (L.r + R.l);
        }
        tree[node] = cur;
    }

    void update(int node, int l, int r, int i, char c) {
        if (l == r && l == i) {
            a[i] = c;
            tree[node].lc = tree[node].rc = c;
            return;
        }

        int m = (r - l) / 2 + l;
        if (i <= m) update(node * 2, l, m, i, c);
        else update(node * 2 + 1, m + 1, r, i, c);

        Node cur = tree[node];
        Node L = tree[node * 2];
        Node R = tree[node * 2 + 1];
        // 正常：aabb ccdd
        cur.mx = Math.max(L.mx, R.mx);
        cur.f = false;
        cur.l = L.l; cur.r = R.r; cur.lc = L.lc; cur.rc = R.rc;
        // aabb bbdd
        if (L.rc == R.lc) {
            cur.mx = Math.max(cur.mx, L.r + R.l);
        }
        if (L.f && R.f && L.rc == R.lc) { // aa a
            cur.f = true;
            cur.l = cur.r = cur.mx = (L.mx + R.mx);
        }
        if (L.f && L.rc == R.lc) { // aa ab
            cur.mx = Math.max(cur.mx, L.r + R.l);
            cur.l = (L.r + R.l);
        }
        if (R.f && L.rc == R.lc) { // ab bb
            cur.mx = Math.max(cur.mx, L.r + R.l);
            cur.r = (L.r + R.l);
        }
    }

    public int[] longestRepeating(String s, String queryCharacters, int[] queryIndices) {
        int n = s.length();
        a = s.toCharArray();
        tree = new Node[n * 4];
        build(1, 0, n - 1);
        int m = queryIndices.length;
        int[] ans = new int[m];
        for (int i = 0; i < m; i++) {
            update(1, 0, n - 1, queryIndices[i], queryCharacters.charAt(i));
            ans[i] = tree[1].mx;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：build $O(n)$，单次查询单点更新 $O(\log n)$，总 $O((n + k)\log n)$
- **空间复杂度**：$O(n)$（4 倍数组线段树）

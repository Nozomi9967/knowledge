# 32.最长有效括号（DP 解法）

> [!abstract] 题目
> 给定一个仅由 `(` 和 `)` 构成的字符串，求其中最长的连续且括号匹配正确的子串长度。有效括号串要求每个左括号都能被相应的右括号闭合，例如 `(()())`。

| 参数 | 范围 |
|-----|------|
| s.length | 0 ~ 3×10⁴ |
| s[i] | `(` 或 `)` |

**示例 1：**
```
输入：s = "(()"
输出：2
解释：最长有效子串为 "()"
```

**示例 2：**
```
输入：s = ")()())"
输出：4
解释：最长有效子串为 "()()"
```

**示例 3：**
```
输入：s = ""
输出：0
```

---

## 核心思路：DP

### 状态定义

`d[i]` = **以 a[i] 结尾**的最长有效括号子串长度。只统计 `)` 结尾的位置——`(` 结尾不可能有效，直接跳过。

最终答案为所有 `d[i]` 的最大值。

### 递推关系（分两类）

`a[i]` 是 `')'` 时，看 `a[i-1]`：

**情况 1：`a[i-1] == '('`** — 形如 `...()` 配对

```
d[i] = d[i-2] + 2   （若 i-2 ≥ 0），否则 d[i] = 2
```

`()` 直接配对，长度为 2，再加上 i-2 之前已经匹配好的长度 `d[i-2]`。

**情况 2：`a[i-1] == ')'`** — 形如 `...((...))` 嵌套

设 `j = i - d[i-1] - 1`，即跳过 i-1 结尾的那个有效段后，j 是段前一个字符的位置。

```
若 j >= 0 且 a[j] == '('：
    d[i] = 2 + d[i-1] + d[j-1]   （j-1 ≥ 0 时才有 d[j-1]，否则加 0）
```

`a[j]` 与 `a[i]` 配对：内部有效段长度 `d[i-1]`，加上这对 `()` 的 2，再加上 j-1 之前已经匹配好的长度 `d[j-1]`。

### 关键点

- **`(` 结尾直接 continue**——有效串必须以 `)` 结尾。
- 答案 = max(d[i])，不是 d[n-1]（最长有效子串不一定贯穿到末尾）。
- 时间 O(n)，空间 O(n)。

## 完整 Java 代码

```java
class Solution {
    public int longestValidParentheses(String s) {
        char[] a = s.toCharArray();
        int n = a.length;
        int[] d = new int[n];   // d[i]: 以 a[i] 结尾的最长有效括号长度
        int ans = 0;
        for (int i = 1; i < n; i++) {
            if (a[i] == '(') continue;

            if (a[i - 1] == '(') {
                d[i] = Math.max(d[i], i - 2 >= 0 ? d[i - 2] + 2 : 2);
            } else {
                int j = i - d[i - 1] - 1;   // 跳过前一个有效段，j 是段前位置
                if (j >= 0 && a[j] == '(') {
                    d[i] = Math.max(d[i], 2 + d[i - 1] + (j - 1 >= 0 ? d[j - 1] : 0));
                }
            }
            ans = Math.max(ans, d[i]);
        }
        return ans;
    }
}
```

## 逐例走查

以 `s = ")()())"` 为例：

| i | a[i] | 情况 | 计算 | d[i] | ans |
|---|---|---|---|---|------|
| 0 | ) | 起点，无前置 | — | 0 | 0 |
| 1 | ( | 是 `(`，跳过 | — | 0 | 0 |
| 2 | ) | a[1]=='(' | d[0]+2=2 | 2 | 2 |
| 3 | ( | 是 `(`，跳过 | — | 0 | 2 |
| 4 | ) | a[3]=='(' | d[2]+2=4 | 4 | 4 |
| 5 | ) | a[4]==')'，j=5-d[4]-1=0，a[0]==')' | 不满足 | 0 | 4 |

答案 4，对应 `()()`。

## 面试话术

1. **为什么只统计 `)` 结尾？** → 有效括号串的最后一个字符必然是 `)`，`(` 结尾直接跳过，剪掉一半计算量。
2. **情况 2 的 j 是怎么推出来的？** → `d[i-1]` 是 i-1 结尾的有效段长度，跳过它就到达段前位置 j = i - d[i-1] - 1；a[j] 若能与 a[i] 配对，则内部段 + 这对外层括号 + j 前的段三段拼接。
3. **为什么答案要取 max 而不是 d[n-1]？** → 最长有效子串不一定贯穿到字符串末尾，比如 `")()())"` 的 d[5]=0 但答案是 4。
4. **和栈解法怎么选？** → DP 一次遍历直观、状态可复用；栈解法（压左括号下标、`)` 弹栈）空间也是 O(n) 但不需要 DP 数组那么多个转移分支。两者面试都常考，DP 思路更偏"推导"，栈更偏"模拟"。

栈解法
```java
class Solution {
    public int longestValidParentheses(String s) {
        int n = s.length();
        boolean[] isValid = new boolean[n];
        // ArrayDeque 比较慢，更快的写法见【Java 数组】
        Deque<Integer> st = new ArrayDeque<>(); // 未配对的左括号的下标

        // 标记哪些括号是配对的
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == '(') {
                st.push(i); // 保存左括号的下标
            } else if (!st.isEmpty()) { // 右括号与栈顶的左括号配对
                isValid[i] = isValid[st.pop()] = true;
            }
        }

        // 最长有效括号即为 isValid 中的最长连续 true
        int ans = 0;
        int cnt = 0;
        for (boolean b : isValid) {
            if (b) {
                cnt++; // 连续 true 的个数
                ans = Math.max(ans, cnt);
            } else {
                cnt = 0; // 重置计数器
            }
        }
        return ans;
    }
}
```

### **长度为 k 的子串中恰好有一对字符重复 — 滑动窗口解法**

核心思路是**滑动窗口 + 频率统计**：用固定长度为 k 的窗口遍历字符串，维护窗口内每个字符的出现次数，检查是否恰好有一个字符出现 2 次（其余都出现 1 次）。时间复杂度 $O(n)$，空间 $O(1)$（固定 26 个字母）。

---

### **一、问题本身**

给定字符串 `s` 和整数 `k`，求 `s` 中有多少个长度为 `k` 的子串满足：**恰好有一对字符重复，其余字符都不重复**。

即子串中：
- 有一个字符恰好出现 2 次
- 其余字符各出现 1 次
- 没有字符出现超过 2 次

> 例如 `s = "aabab"`，`k = 3`
> - `"aab"` → 'a' 出现 2 次，'b' 出现 1 次 ✓
> - `"aba"` → 'a' 出现 2 次，'b' 出现 1 次 ✓
> - `"bab"` → 'b' 出现 2 次，'a' 出现 1 次 ✓
> 共 3 个

---

### **二、错误解法分析**

原代码试图用 Map 记录每个字符的位置，但有根本缺陷：

1. **只记录单个位置，无法处理重复** — Map 的 value 只能存一个位置，子串中同一字符出现多次时信息丢失
2. **计算逻辑无数学依据** — `(r-l-(k-2))` 这个公式没有正确推导
3. **无法处理三次及以上重复** — 子串 `"aaa"` 中 'a' 出现 3 次，代码无法正确判断

---

### **三、正确解法：滑动窗口**

```java
public int numKLenSubstrRepeats(String s, int k) {
    if (k > s.length()) return 0;

    int ans = 0;
    int[] freq = new int[26];

    // 初始化第一个窗口
    for (int i = 0; i < k; i++) {
        freq[s.charAt(i) - 'a']++;
    }

    if (isValid(freq)) ans++;

    // 滑动窗口
    for (int i = k; i < s.length(); i++) {
        freq[s.charAt(i - k) - 'a']--;       // 移除左边字符
        freq[s.charAt(i) - 'a']++;           // 添加右边字符
        if (isValid(freq)) ans++;
    }

    return ans;
}

private boolean isValid(int[] freq) {
    int repeatCount = 0;
    for (int count : freq) {
        if (count == 2) {
            repeatCount++;
        } else if (count > 2) {
            return false;  // 有字符出现超过 2 次，不合法
        }
    }
    return repeatCount == 1;  // 恰好有一对重复
}
```

#### **`isValid` 的判断逻辑**

遍历 freq 数组，统计：
- `count == 2` 的字符个数（重复对的数量）
- `count > 2` 的字符（直接返回 false，不符合条件）

合法条件：`repeatCount == 1`（恰好一对重复，其余都是 1）。

---

### **四、复杂度分析**

- **时间复杂度**：$O(n \times 26) = O(n)$。每次窗口移动做两次 freq 更新（$O(1)$）和一次 isValid 检查（$O(26)$）。
- **空间复杂度**：$O(26) = O(1)$。固定大小的频率数组。

### **五、与同类滑动窗口题的对比**

| 题目 | 条件 | 窗口策略 |
|------|------|---------|
| LC 1100 无重复字符的子串 | 恰好 0 个重复 | 窗口收缩直到无重复 |
| 本题 | 恰好 1 对重复 | 固定长度 k，检查窗口内重复数 |
| LC 992 K 个不同整数的子数组 | 恰好 k 个不同值 | 至少 k 个 - 至少 k-1 个 |
| LC 340 至多 K 个不同字符 | 至多 k 个不同 | 窗口收缩直到不同数 ≤ k |

**本题的核心特点**：窗口长度固定为 k，不需要动态收缩。只需在每次移动时检查频率数组是否满足"恰好一对重复"的条件。

---

### **六、面试话术**

1. **为什么用滑动窗口？** — 窗口长度固定为 k，每次右移一位，只需要更新两端各一个字符的频率，$O(1)$ 维护。
2. **为什么用数组而非 Map？** — 字符集是 'a'-'z'，固定 26 个，用数组比 Map 更快且无需哈希开销。
3. **`isValid` 的判断依据** — 恰好一对重复意味着：一个字符出现 2 次、其余 k-2 个字符各出现 1 次、没有字符出现超过 2 次。总字符数 = 2 + (k-2)×1 = k，符合窗口长度。
4. **与 LC 1100 的区别** — 1100 要求"无重复"（窗口内不同字符数 = k），本题要求"恰好一对重复"（不同字符数 = k-1，且无字符出现超过 2 次）。

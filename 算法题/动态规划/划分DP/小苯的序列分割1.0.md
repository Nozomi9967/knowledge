# 小苯的序列分割 1.0（划分 DP + 奇偶权重）

## 题目描述

小苯有一个长度为 $n$ 的序列 $a$，希望将 $a$ 划分为**恰好 $m$ 个非空的连续段**，并将其中每一段中的数字求和，组成一个长度恰好 $m$ 的新序列 $b$。接着，最大化以下式子：

$$b_1 + b_2 \times 2 + b_3 + b_4 \times 2 \ldots$$

即：$b$ 中**奇数位置**的数字之和，加上**偶数位置**的数字之和 $\times 2$。

- **时间限制**：C/C++ 1 秒，其他语言 2 秒
- **空间限制**：C/C++ 256M，其他语言 512M

### 输入描述

本题有多组测试数据。第一行一个正整数 $T\ (1 \le T \le 100)$ 表示数据组数。每组数据：

- 第一行两个正整数 $n, m\ (1 \le m \le n \le 3000)$
- 第二行 $n$ 个整数 $a_i\ (-10^9 \le a_i \le 10^9)$

保证同一测试文件所有数据中 $n$ 的总和不超过 3000。

### 输出描述

每组数据输出一行一个整数，表示所求式子的最大值。

### 示例

```
输入：              输出：
2
5 4                23
1 3 2 4 3          7
5 1
1 3 2 4 -3
```

**说明**：第一组划分为 `[1,1] [2,2] [3,3] [4,5]` 最优，$b=\{1,3,2,7\}$，最大和为 $1 + 3 \times 2 + 2 + 7 \times 2 = 23$。

## 核心思路

**状态定义**：`d[i][j]` = 前 $i$ 个元素划分成恰好 $j$ 段时，式子的最大值。

**关键洞察**：$a_i$ 的贡献权重只取决于**它所在段的段号奇偶性**——第 $j$ 段是奇数段就 $\times 1$，偶数段就 $\times 2$。所以 DP 只需要按 $j$ 的奇偶决定当前元素乘几倍，不需要额外的状态维。

**两种转移**（决策：$a_i$ 是接在第 $j$ 段末尾，还是自己另起第 $j+1$ 段）：

| 决策 | 转移 | 权重来源 |
|------|------|---------|
| **加入**当前第 $j$ 段 | `d[i][j] = max(d[i][j], d[i-1][j] + a[i-1] × w(j))` | 按 $j$ 的奇偶 |
| **另起**第 $j+1$ 段 | `d[i][j+1] = d[i-1][j] + a[i-1] × w(j+1)` | 按 $j+1$ 的奇偶（与 $j$ 相反） |

其中 $w(j) = 1$（$j$ 奇）或 $2$（$j$ 偶）。

**初始状态**：`d[1][1] = a[0]`（第一个元素必然独占第 1 段，段号 1 为奇数，权重 1）。

**答案**：`d[n][m]`。

## 四个卡点（自己没绕过去的地方）

### 卡点 1：为什么"另起新段"是**直接赋值**，"加入当前段"要 **max 比较**

```java
// 加入 —— 要 max
if (i > j) d[i][j] = Math.max(d[i][j], d[i-1][j] + a[i-1]*2);
// 不加（另起新段）—— 直接赋值
if (j+1 <= i && j+1 <= m) {
    d[i][j+1] = d[i-1][j] + a[i-1];
}
```

**原因在于循环顺序造成的"先播种、后精修"**：

- `d[i][j+1]` 这一格，在内层循环跑到 $j$ 时被**首次写入**（此时它还是初始的 `MIN`，没有任何有效值，所以直接赋值等价于 max）——这是它唯一的"另起新段"来源，第 $i$ 个元素独占第 $j+1$ 段只能从 `d[i-1][j]` 来。
- 等内层循环推进到 $j+1$ 时，`d[i][j+1]` 已经有值了（上一轮播下的种），此时"加入"分支要拿 `d[i-1][j+1] + ...` 跟它比 max，才不会覆盖掉更优解。

一句话：**每格恰好被"另起新段"播种一次（赋值），再被"加入当前段"精修一次（max）**。

### 卡点 2：初始化不能用 0

题目数据范围 $-10^9 \le a_i \le 10^9$，**存在负数**。把 `d` 默认初始化为 0，等价于把"不可达状态"标记成了 0；但真实的合法答案完全可能是负的（比如全负数组），此时 max 会错误地选中那个虚假的 0。

**0 不是最小值** —— 有负数的题里，初始化必须用一个远低于任何合法值的哨兵。

### 卡点 3：`if (i > j)` 不能漏

```java
// 加入当前段
if (i > j) d[i][j] = Math.max(d[i][j], d[i-1][j] + a[i-1]*2);
```

这个转移是**往前看**的：从 `d[i-1][j]` 转移过来，意味着前 $i-1$ 个元素已经分成了 $j$ 段。

如果 $i == j$（比如 2 个元素分 2 段），那前驱状态是 `d[i-1][j] = d[1][2]`——1 个元素分 2 段，**不可能**。所以"加入当前段"这个分支必须保证**元素数严格大于段数**（$i > j$），因为你要给第 $i$ 个元素"蹭进已有的段"，前面就必须有富余的元素撑起那 $j$ 段。

> 直观理解：两个元素想分两段，就只能是「各占一段」，不存在"第二个元素加入前面的段"这种走法。

### 卡点 4：为什么 `Integer.MIN_VALUE` 不行，`Long.MIN_VALUE / 2` 才行

这是最容易踩的一个坑，两层原因叠加：

**① `Integer.MIN_VALUE` 数量级太小，压不住合法值**

- `Integer.MIN_VALUE` ≈ $-2.1 \times 10^9$
- 而合法答案的下界能到 $n \times \max|a_i| \times 1 \approx 3000 \times 10^9 = -3 \times 10^{12}$

也就是说，一个"不可达"状态被标成 $-2.1 \times 10^9$，反而**比真实的负数答案 $-3 \times 10^{12}$ 大得多**，会在 max 里胜出 → 输出一个根本不存在的划分方案的值。**哨兵必须比所有合法值都小。**

**② 为什么要 `/2` —— 防加法溢出**

如果直接用 `Long.MIN_VALUE`（$\approx -9.22 \times 10^{18}$），那么 `d[i-1][j] + a[i-1]*2` 在 `d[i-1][j]` 是哨兵时会变成 $-9.22 \times 10^{18} + 2 \times 10^9$……这个方向不会溢出。但反过来，如果哨兵参与了任何**减法**或多次累加，就会向下溢出成正数（long 回绕），那个虚假的巨大正数会直接毁掉答案。

`Long.MIN_VALUE / 2` ≈ $-4.6 \times 10^{18}$ 留了一半的安全余量，加减若干次 $10^9$ 量级的数都不会回绕，同时又远低于合法值下界 $-3 \times 10^{12}$。

**结论：哨兵取值的两个约束** —— 比所有合法值小（够小），且加上若干次数据后不溢出（别太小）。`Long.MIN_VALUE / 2` 或 `Long.MIN_VALUE / 4` 是这类 DP 的标准写法。

## AC 代码

```java
import java.util.*;

// 注意类名必须为 Main, 不要有任何 package xxx 信息
public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int t=in.nextInt();
        while(t-->0){
            int n=in.nextInt(),m=in.nextInt();
            int[] a=new int[n];
            for(int i=0;i<n;i++) a[i]=in.nextInt();
            long[][] d=new long[n+1][m+1];
            for(int i=0;i<=n;i++) Arrays.fill(d[i],Long.MIN_VALUE/2);
            d[1][1]=a[0];// 前1个元素1段时，式子最大值
            for(int i=2;i<=n;i++){
                // 加入/不加入

                for(int j=1;j<=i&&j<=m;j++){
                    if(j%2==0){
                        // 加入
                         if(i>j) d[i][j]=Math.max(d[i][j],(d[i-1][j]+a[i-1]*2));
                        // 不加
                        if(j+1<=i&&j+1<=m){
                            d[i][j+1]=d[i-1][j]+a[i-1];
                        }
                    }
                    else{
                        if(i>j)  d[i][j]=Math.max(d[i][j],(d[i-1][j]+a[i-1]));
                        // 不加
                        if(j+1<=i&&j+1<=m){
                            d[i][j+1]=d[i-1][j]+a[i-1]*2;
                        }
                    }
                    // System.out.println(i+" "+j+" "+d[i][j]);
                }
            }
            System.out.println(d[n][m]);

        }
    }
}
```

## 复杂度

- **时间复杂度**：$O(n \times m)$ 每组，$\sum n \le 3000$ 所以总量极小
- **空间复杂度**：$O(n \times m)$，可用滚动数组降到 $O(m)$（只依赖 `d[i-1][*]`）

## 可迁移经验

| 教训 | 通用做法 |
|------|---------|
| 有负数就别用 0 当初始值 | 哨兵取 `Long.MIN_VALUE / 2`（求最大）或 `Long.MAX_VALUE / 2`（求最小） |
| 哨兵数量级要对得上数据范围 | 先估算「合法值的最坏取值」，哨兵必须再低一个量级 |
| 划分 DP 的段数约束 | 「元素数 ≥ 段数」是硬约束，转移前先卡 `i > j` 或 `i >= j` |
| 一格被多路转移写入 | 分清"唯一来源"（可直接赋值）和"多来源"（必须 max/min） |

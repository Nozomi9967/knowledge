### **时空漫游者的能量跳跃 — 单调队列优化 DP**

核心思路是**线性 DP + 单调队列优化**：`d[i] = a[i] + max(d[i-k .. i-1])`，朴素枚举前驱是 $O(nk)$，但"窗口内最大值"正好是滑动窗口求最大值问题，用单调递减队列维护 $O(1)$ 取最大。总复杂度 $O(n)$。时间复杂度 $O(n)$，空间 $O(n)$。

---

### **一、题目概述**

n 个能量信标排成线性路径，起点信标 0，终点信标 n−1。每个信标 i 有能量值 $E_i$（可为负）。

位于信标 i 时，下一步可跳到 $[i+1, \min(n-1, i+k)]$ 内任意信标，k 是单次最大跳跃距离。

求从 0 到 n−1 收集到的最大总能量。

- $1 \le n, k \le 10^5$
- $-10^4 \le E_i \le 10^4$

> **示例1**：`k=2, E=[3,-5,-10,2,-1,5,-6,-5]` → 路径 `[3,-5,2,5,-5]`，总能量 `0`

> **示例2**：`k=3, E=[1,-5,-2,4,0,7]` → 路径 `[1,4,7]`，总能量 `12`

> **示例3**：`k=2, E=[1,-3,-2,4,-7,5]` → 路径 `[1,-2,4,5]`，总能量 `8`

---

### **二、核心思路**

#### **2.1 朴素 DP（$O(nk)$，超时）**

设 `d[i]` 为到达信标 i 能收集的最大总能量：

$$d[i] = E_i + \max_{j \in [i-k,\ i-1]} d[j]$$

初始化 `d[0] = E[0]`。枚举每个 i 的所有可达前驱 j，$O(nk)$，$n,k$ 都是 $10^5$ 时不可行。

#### **2.2 关键观察：转移需要的就是"滑动窗口最大值"**

`max(d[i-k .. i-1])` 恰好是长度 k 的窗口在 d 数组上滑动时的最大值。窗口每次右移一格（加入 `d[i]`，弹出 `d[i-k]`），这是标准的**单调队列**适用场景。

#### **2.3 单调递减队列维护窗口最大值**

队列存**下标**，保证队列中下标对应的 d 值**单调递减**：

1. **踢过期**：队首下标 `< i-k` 说明已跳出窗口 `[i-k, i-1]`，弹出。
2. **取队首**：队首即窗口内最大 d 值，`d[i] = E[i] + d[队首]`。
3. **维护单调性**：队尾 d 值 `<= d[i]` 的元素全部弹出——因为 d[i] 更靠右（存活更久）且值更大，永远优于它们。然后把 i 入队。

为什么队尾可以放心丢？—— 新元素 i 下标更大，在窗口里待的时间比旧元素更长；d 值又更大。旧元素既不可能赢"值"也不可能赢"存活时间"，留着只会挡路。

### **三、代码**

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int k = in.nextInt();
        int n = in.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = in.nextInt();

        // 用 long 防止极端情况下累加上溢（|sum| 上界约 1e9，int 也够，long 更稳）
        final long NEG = Long.MIN_VALUE / 2;
        long[] d = new long[n];
        Arrays.fill(d, NEG);
        d[0] = a[0];

        // 队列存下标，保证对应 d 值单调递减
        Deque<Integer> dq = new ArrayDeque<>();
        dq.addLast(0);

        for (int i = 1; i < n; i++) {
            // 1. 踢掉已经跳出窗口 [i-k, i-1] 的队首
            while (!dq.isEmpty() && dq.peekFirst() < i - k) {
                dq.pollFirst();
            }
            // 2. 队首即窗口内最大 d 值
            d[i] = a[i] + d[dq.peekFirst()];
            // 3. 保持单调递减：队尾 d 值 <= d[i] 的都没用了
            while (!dq.isEmpty() && d[dq.peekLast()] <= d[i]) {
                dq.pollLast();
            }
            dq.addLast(i);
        }

        System.out.print(d[n - 1]);
    }
}
```

### **四、一个具体例子走一遍**

**示例1**：`k=2, a=[3,-5,-10,2,-1,5,-6,-5]`

| i | 踢过期后队首 | d[i] 计算 | 维护单调（弹队尾） | 队列 |
|---|-------------|----------|--------------------|------|
| 0 | — | d[0] = 3 | — | [0] |
| 1 | 队首 0 在窗口内 | d[1] = -5 + 3 = **-2** | 3 > -2 不弹 | [0,1] |
| 2 | 队首 0 在窗口内 | d[2] = -10 + 3 = **-7** | 3 > -2 > -7 不弹 | [0,1,2] |
| 3 | 0 < 3-2 → 弹 0 | d[3] = 2 + (-2) = **0** | 弹 2(-7)、1(-2) | [3] |
| 4 | 队首 3 在窗口内 | d[4] = -1 + 0 = **-1** | -1 > 0？不弹 | [3,4] |
| 5 | 队首 3 在窗口内 | d[5] = 5 + 0 = **5** | 弹 4(-1)、3(0) | [5] |
| 6 | 队首 5 在窗口内 | d[6] = -6 + 5 = **-1** | 5 > -1 不弹 | [5,6] |
| 7 | 队首 5 在窗口内 | d[7] = -5 + 5 = **0** | 弹 6(-1)，5 > 0 不弹 | [5,7] |

输出 `d[7] = 0` ✓（对应路径 [3,-5,2,5,-5]）

**示例2**：`k=3, a=[1,-5,-2,4,0,7]`

| i | 踢过期后队首 | d[i] 计算 | 维护单调 | 队列 |
|---|-------------|----------|---------|------|
| 0 | — | d[0] = 1 | — | [0] |
| 1 | 队首 0 | d[1] = -5 + 1 = **-4** | 不弹 | [0,1] |
| 2 | 队首 0 | d[2] = -2 + 1 = **-1** | 弹 1(-4) | [0,2] |
| 3 | 队首 0 | d[3] = 4 + 1 = **5** | 弹 2(-1)、0(1) | [3] |
| 4 | 队首 3 | d[4] = 0 + 5 = **5** | 弹 3(5 ≤ 5) | [4] |
| 5 | 队首 4 | d[5] = 7 + 5 = **12** | 弹 4(5) | [5] |

输出 `d[5] = 12` ✓（对应路径 [1,4,7]）

### **五、复杂度分析**

- **时间复杂度**：$O(n)$。每个下标最多入队一次、出队一次，摊还 $O(1)$。
- **空间复杂度**：$O(n)$。d 数组 $O(n)$，队列 $O(n)$。

---

### **六、为什么不能简单贪心**

不是"每次跳到能跳范围内能量最大的信标"——当前跳到的信标能量高，不代表它后面的可达范围好。例如示例2 中 `1 → 4 → 7` 跳过了能量 0 的信标 4（下标），说明局部最优不保证全局最优，必须 DP。

### **七、面试话术**

1. **为什么朴素 DP 会超时？** — 每个 i 要枚举 k 个前驱，$O(nk)$，$n=k=10^5$ 时 $10^{10}$ 次操作。
2. **单调队列优化了什么？** — 把"窗口内最大值"从 $O(k)$ 降到摊还 $O(1)$。维护的是 d 值的单调递减队列（存下标），队首永远是当前窗口最大。
3. **为什么可以弹队尾？** — 新元素 i 下标更大、d 值更大：它比队尾活得更久（更晚出窗口）、值又更大，队尾在两者上都输，不可能再被用到。
4. **d 数组为什么用 long？** — $|E_i| \le 10^4$，路径最长 $10^5$ 个信标，累加上界约 $10^9$，int 也够；但用 long 更稳，防极端边界。
5. **与 [[239.滑动窗口最大值]] 的关系** — 同样的单调队列模板，只是本题把窗口最大值接进了 DP 转移里，属于"数据结构优化 DP"的经典题型。

### **LeetCode 1186「删除一次得到子数组最大和」动态规划解法**

核心思路是**双状态 DP**：`d[i][0]` 表示以第 i 个元素为右端点、不删除任何元素时的最大子数组和；`d[i][1]` 表示以第 i 个元素为右端点、已删除恰好一个元素时的最大子数组和。时间复杂度 $O(n)$，空间可滚动优化到 $O(1)$。

---

### **一、问题本身**

给定一个整数数组 `arr`，返回**删除恰好一个元素**后（删除后子数组至少有一个元素），子数组的最大和。

> 例如 `arr = [1,-2,0,3]`，删除 `-2` 后子数组 `[1,0,3]` 和为 4，是最优解。

---

### **二、子问题拆分**

枚举子数组的右端点 `i`，原问题拆分为两个子问题：

1. **不删除数字**，右端点为 `i` 的最大子数组和 → `d[i][0]`
2. **必须删除一个数字**，右端点为 `i` 的最大子数组和 → `d[i][1]`

每个子问题再递归到前一位：

- 子问题 1 的左端点 = 子问题 1 或子问题 2 在 `i-1` 的答案
- 子问题 2 的左端点 = 子问题 1 或子问题 2 在 `i-1` 的答案

---

### **三、DP 解法**

```java
class Solution {
    public int maximumSum(int[] arr) {
        int n = arr.length;
        int[][] d = new int[n][2];
        d[0][0] = arr[0];
        d[0][1] = -20000;  // 不能为空数组
        int ans = arr[0];

        for (int i = 1; i < n; i++) {
            // d[i][0]: 以第 i 个元素为右端点，不删元素时的最大值
            d[i][0] = Math.max(d[i - 1][0] + arr[i], arr[i]);

            // d[i][1]: 以第 i 个元素为右端点，删了一个元素时的最大值
            // 分为两种情况：
            //   1. 删当前元素 arr[i] → 继承 d[i-1][0]
            //   2. 不删当前元素 → 继承 d[i-1][1] + arr[i]
            d[i][1] = Math.max(d[i - 1][0], d[i - 1][1] + arr[i]);

            ans = Math.max(ans, Math.max(d[i][0], d[i][1]));
        }
        return ans;
    }
}
```

#### **状态定义**

`d[i][0]`：以第 `i` 个元素为子数组右端点、**不删除**任何元素时的最大子数组和。
`d[i][1]`：以第 `i` 个元素为子数组右端点、**已删除恰好一个**元素时的最大子数组和。

#### **状态转移**

**`d[i][0]`（不删，经典 Kadane）：**

$$
d[i][0] = \max(d[i-1][0] + arr[i],\ arr[i])
$$

要么接上前面的子数组，要么从当前元素重新开始。

**`d[i][1]`（已删一个），分两种情况：**

| 情况 | 含义 | 转移来源 |
|------|------|---------|
| 删当前元素 `arr[i]` | 当前元素被删掉，子数组在 `i-1` 结束 | `d[i-1][0]` |
| 不删当前元素 | 前面已经删了一个，当前元素保留 | `d[i-1][1] + arr[i]` |

$$
d[i][1] = \max(d[i-1][0],\ d[i-1][1] + arr[i])
$$

#### **初始化**

`d[0][0] = arr[0]`（单个元素，不删就是自身）。
`d[0][1] = -∞`（不能删掉唯一元素导致空数组，所以初始化为极小值）。
`ans = arr[0]`。

#### **答案**

`max(ans, max(d[n-1][0], d[n-1][1]))`，即全局最大值。

### **四、一个具体例子走一遍**

以 `arr = [1, -2, 0, 3]`（`n = 4`）为例：

| i | arr[i] | d[i][0] | 来源 | d[i][1] | 来源 | ans |
|---|--------|---------|------|---------|------|-----|
| 0 | 1      | 1       | 自身 | -20000  | 初始 | 1   |
| 1 | -2     | max(1+(-2), -2) = **-1** | 接前 | max(1, -20000+(-2)) = **1** | 删-2 | 1   |
| 2 | 0      | max(-1+0, 0) = **0** | 重新开始 | max(-1, 1+0) = **1** | 不删0 | 1   |
| 3 | 3      | max(0+3, 3) = **3** | 接前 | max(0, 1+3) = **4** | 不删3 | **4** |

返回 `ans = 4`，对应子数组 `[1, 0, 3]`（删除了 `-2`）。

### **五、空间优化**

`d[i]` 只依赖 `d[i-1]`，可压缩为 4 个变量：

```java
class Solution {
    public int maximumSum(int[] arr) {
        int n = arr.length;
        int a0 = arr[0], b0 = -20000;
        int a1, b1;
        int ans = arr[0];

        for (int i = 1; i < n; i++) {
            a1 = Math.max(a0 + arr[i], arr[i]);
            b1 = Math.max(a0, b0 + arr[i]);
            ans = Math.max(ans, Math.max(a1, b1));
            a0 = a1;
            b0 = b1;
        }
        return ans;
    }
}
```

### **六、与 [[53. 最大子数组和]] 的对比**

| 维度 | [[53. 最大子数组和]] | 1186. 删除一次得到子数组最大和 |
|------|-------------------|---------------------------|
| 问题 | 最大子数组和（Kadane） | 删除一个元素后的最大子数组和 |
| 状态维度 | 一维 `f[i]` | **二维 `d[i][2]`** |
| 状态含义 | 以 i 结尾的最大子数组和 | `[0]` 不删 / `[1]` 已删一个 |
| 核心思想 | `f[i] = max(f[i-1]+arr[i], arr[i])` | 在 Kadane 基础上加一层"删/不删"选择 |
| 复杂度 | $O(n)$ | $O(n)$ |

本质是在 [[53. 最大子数组和]] 的 Kadane 算法上叠加一个"删除"维度。`d[i][0]` 就是 Kadane 本身，`d[i][1]` 是 Kadane 的"允许跳过一次"版本。

### **七、面试话术**

1. **为什么 `d[0][1] = -20000`？** — 不能删掉唯一元素导致空数组。用极小值确保"删当前"这条路径不会在 `i=0` 时被选中。
2. **`d[i][1]` 的两种选择** — "删当前"等价于子数组在 `i-1` 结束（不删的情况），`d[i-1][0]`；"不删当前"等价于前面已经删过了，当前元素续上，`d[i-1][1] + arr[i]`。
3. **与 Kadane 的关系** — `d[i][0]` 就是 Kadane 模板；`d[i][1]` 是在 Kadane 的"重新开始"和"接上前缀"之外，多了一个"跳过当前"的选择。
4. **为什么是恰好删除一个？** — `d[i][1]` 保证了恰好删除一个，`d[i][0]` 保证零删除。`ans` 取两者的最大值，覆盖了"删"和"不删"两种策略。

### **LeetCode 198「打家劫舍」动态规划解法**

核心思路是**线性 DP**：`dp[i]` 表示前 `i` 个房屋能偷到的最大金额，状态转移取"不偷当前 / 偷当前"的最大值。时间复杂度 $O(n)$，空间可滚动数组优化到 $O(1)$。

---

### **一、问题本身**

一排房屋，第 `i` 间有金额 `nums[i]`。规则：相邻房屋不能同时偷，求能偷到的最大总金额。

> 例如 `nums = [1,2,3,1]`，最优偷 `1(第1间) + 3(第3间) = 4`。

---

### **二、DP 解法**

```java
class Solution {
    public int rob(int[] nums) {
        int n = nums.length;
        if (n == 1) return nums[0];
        int[] dp = new int[n];
        dp[0] = nums[0];
        dp[1] = Math.max(nums[0], nums[1]);
        for (int i = 2; i < n; i++) {
            dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[i]);
        }
        return dp[n - 1];
    }
}
```

#### **状态定义**

`dp[i]`：前 `i` 间房屋（`nums[0..i]`）能偷到的**最大金额**。

#### **状态转移**

对第 `i` 间房屋，两种选择：

1. **不偷第 i 间**：最大金额 = `dp[i-1]`（继承前一间的最优）
2. **偷第 i 间**：最大金额 = `dp[i-2] + nums[i]`（不能偷相邻的第 i-1 间，加上当前金额）

$$
dp[i] = \max(dp[i-1],\ dp[i-2] + nums[i])
$$

#### **边界条件**

- `dp[0] = nums[0]`：只有 1 间，偷它
- `dp[1] = max(nums[0], nums[1])`：2 间，偷金额更大的那间
- `n == 1` 单独处理（避免 `nums[1]` 越界）

#### **答案**

`dp[n-1]`，即前 n 间房屋的最大偷窃金额。

---

### **三、空间优化（滚动数组）**

`dp[i]` 只依赖 `dp[i-1]` 和 `dp[i-2]`，可压缩为两个变量：

```java
class Solution {
    public int rob(int[] nums) {
        int n = nums.length;
        if (n == 1) return nums[0];
        int prev2 = nums[0];          // dp[i-2]
        int prev1 = Math.max(nums[0], nums[1]);  // dp[i-1]
        for (int i = 2; i < n; i++) {
            int cur = Math.max(prev1, prev2 + nums[i]);
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }
}
```

### **四、一个具体例子走一遍**

以 `nums = [1,2,3,1]`（`n = 4`）为例：

| i | nums[i] | dp[i-1]（不偷） | dp[i-2]+nums[i]（偷） | dp[i] |
|---|---------|----------------|---------------------|-------|
| 0 | 1       | —              | —                   | **1** |
| 1 | 2       | dp[0]=1        | dp[-1]+2=0+2=2      | **2** |
| 2 | 3       | dp[1]=2        | dp[0]+3=1+3=4       | **4** |
| 3 | 1       | dp[2]=4        | dp[1]+1=2+1=3       | **4** |

返回 `dp[3] = 4`（偷第 1 间和第 3 间）。

### **六、面试话术**

1. **为什么是 `dp[i-1]` 和 `dp[i-2]`？** — 偷当前房屋就不能偷前一间，所以看"偷了 i-2 时的最大值 + 当前值"vs"不偷当前，继承 i-1 的值"。
2. **为什么 `dp[1] = max(nums[0], nums[1])`？** — 2 间房只能偷一间，选金额大的；不能两间都偷（相邻限制）。
3. **滚动数组本质** — 只保存"前一天"和"前两天"的最优值，其余历史值无用处，空间从 $O(n)$ 降到 $O(1)$。
4. **与 [[70.爬楼梯]] 的对比** — 模板相似（`dp[i]` 依赖前两个状态），但爬楼梯是加法累加，打家劫舍是 `max` 取最优。

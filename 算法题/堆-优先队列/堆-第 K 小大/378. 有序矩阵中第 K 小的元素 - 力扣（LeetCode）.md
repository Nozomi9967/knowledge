[378\. 有序矩阵中第 K 小的元素](https://leetcode.cn/problems/kth-smallest-element-in-a-sorted-matrix/)


给你一个 `n x n` 矩阵 `matrix` ，其中每行和每列元素均按升序排序，找到矩阵中第 `k` 小的元素。  
请注意，它是 **排序后** 的第 `k` 小元素，而不是第 `k` 个 **不同** 的元素。

你必须找到一个内存复杂度优于 `O(n^2)` 的解决方案。

**示例 1：**

```
输入：matrix = [[1,5,9],[10,11,13],[12,13,15]], k = 8
输出：13
解释：矩阵中的元素为 [1,5,9,10,11,12,13,13,15]，第 8 小元素是 13
```

**示例 2：**

```
输入：matrix = [[-5]], k = 1
输出：-5
```

**提示：**

- `n == matrix.length`
- `n == matrix[i].length`
- `1 <= n <= 300`
- `-10^9 <= matrix[i][j] <= 10^9`
- 题目数据 **保证** `matrix` 中的所有行和列都按 **非递减顺序** 排列
- `1 <= k <= n^2`

**进阶：**

- 你能否用一个恒定的内存(即 `O(1)` 内存复杂度)来解决这个问题?
- 你能在 `O(n)` 的时间复杂度下解决这个问题吗?这个方法对于面试来说可能太超前了，但是你会发现阅读这篇文章（ [this paper](http://www.cse.yorku.ca/~andy/pubs/X+Y.pdf) ）很有趣。

### 原解法

```java
    class Solution {

        public int kthSmallest(int[][] matrix, int k) {

            int n=matrix.length;

            int l=matrix[0][0],r=matrix[n-1][n-1];

            while(l<=r){

                int m=(r-l)/2+l;

                if(check(m,matrix,k)) r=m-1;

                else l=m+1;

            }

            return l;

        }

  

        public boolean check(int m,int[][] matrix,int k){

            int cnt=0;

            int n=matrix.length;

            for(int i=0;i<n;i++){

                if(m>=matrix[i][n-1]){

                    cnt+=n;

                    continue;

                }

                for(int j=0;j<n;j++){

                    if(m>=matrix[i][j]) cnt++;

                }

            }

            return cnt>=k;

        }

    }
```

### 堆解法

```java
class Solution {

  

    class Node{

        public int i;

        public int j;

        Node(){}

  

        Node(int i,int j){

            this.i=i;

            this.j=j;

        }

  

        // 1. 正确的 Object 类型的 equals

        @Override

        public boolean equals(Object o) {

            if (this == o) return true;

            if (o == null || getClass() != o.getClass()) return false;

            Node node = (Node) o;

            return i == node.i && j == node.j;

        }

  

        // 2. 必须重写 hashCode

        @Override

        public int hashCode() {

            return java.util.Objects.hash(i, j);

        }

    }

  

    public int kthSmallest(int[][] matrix, int k) {

        var pq=new PriorityQueue<int[]>(

            (a,b)->Integer.compare(a[0],b[0])

        );

        var hash=new HashSet<Node>();

        int n=matrix.length;

        for(int i=0;i<n;i++){

            pq.offer(new int[]{matrix[i][0],i,0});

            hash.add(new Node(i,0));

        }

  

        Node no=new Node();

        int ans=0;

        while (k-- > 0 && !pq.isEmpty()) {

            int[] arr = pq.poll();

            ans = arr[0];

            int ci = arr[1], cj = arr[2];

  

            // 向右扩展

            if (cj + 1 < n) {

                Node next = new Node(ci, cj + 1);

                if (!hash.contains(next)) {

                    hash.add(next);

                    pq.offer(new int[]{matrix[ci][cj + 1], ci, cj + 1});

                }

            }

            // 向下扩展

            if (ci + 1 < n) {

                Node next = new Node(ci + 1, cj);

                if (!hash.contains(next)) {

                    hash.add(next);

                    pq.offer(new int[]{matrix[ci + 1][cj], ci + 1, cj});

                }

            }

        }

        return ans;

    }

}
```

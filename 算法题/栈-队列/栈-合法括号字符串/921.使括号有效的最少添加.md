## 题目

https://leetcode.cn/problems/minimum-add-to-make-parentheses-valid/

## 我的题解

```java
class Solution {

    public int minAddToMakeValid(String s) {

        var st=new Stack<Character>();

        for(char c:s.toCharArray()){

            if(st.isEmpty()) st.push(c);

            else{

                if(st.peek()=='('&&c==')'){

                    st.pop();

                }else{

                    st.push(c);

                }

            }

        }

        return st.size();

    }

}
```

## 题目

https://leetcode.cn/problems/triangle/description/?envType=study-plan-v2&envId=top-interview-150





## 题解



```java
class Solution {
    public int minimumTotal(List<List<Integer>> triangle) {
        if(triangle.size()==1) return triangle.get(0).get(0);
        List<List<Integer>> ans=new ArrayList<>();
        ans.add(List.of(triangle.get(0).get(0)));
        for(int i=1;i<triangle.size();i++){
            List<Integer> list=new ArrayList<>();
            for(int j=0;j<triangle.get(i).size();j++){
                int cur=triangle.get(i).get(j);
                int left=(j-1>=0)?ans.get(i-1).get(j-1):Integer.MAX_VALUE;
                int right=(j<i)?ans.get(i-1).get(j):Integer.MAX_VALUE;
                list.add(
                    cur+Math.min(left,right)
                );
            }
            ans.add(list);
        }
        int min=Integer.MAX_VALUE;
        for(int i=0;i<ans.size();i++){
            min=Math.min(min,ans.get(ans.size()-1).get(i));
        }
        return min;
    }
}
```

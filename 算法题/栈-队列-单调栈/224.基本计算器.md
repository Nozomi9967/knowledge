前提是整个表达式没有乘除，所以都是累加、累减，默认是加 ，重点就在于什么时候减

意思是，如果一个表达式中有括号，且括号里面外面都是+，那么整个表达式都是相加的操作，因为+并不会使得操作反转

（减号会，因为如果减号在一个括号外面，会使得括号内的运算都变成 `-` ，例如`-(1+1) ->  -1-1`）



```java
class Solution {
    public int calculate(String s) {
        int ans=0;
        Deque<Integer> ops = new LinkedList<>();
        ops.push(1);
        int i=0;
        int sign=1;
        while(i<s.length()){
            char c=s.charAt(i);
            if(c==' '){
                i++;
                continue;
            }else if(c=='+'){
                sign=ops.peek();
                i++;
            }else if(c=='-'){
                sign=-ops.peek();
                i++;
            }else if(c=='('){
                ops.push(sign);
                i++;
            }else if(c==')'){
                ops.pop();
                i++;
            }else{
                int num=0;
                while(c>='0'&&c<='9'){
                    num*=10;
                    num+=(c-'0');
                    i++;
                    if(i>=s.length()) break;
                    c=s.charAt(i);
                }
                ans+=(sign*num);
            }
        }
        return ans;
    }
}
```

# 位运算操作符与 lowbit（x & -x）速查

> **一句话：** Java 七个位运算符 + 刷题必背的技巧写法，重点讲透 `x & -x`（取出最低位的 1），它是 [[机试]] 笔记里树状数组模板的核心。

---

## 一、七个操作符

| 符号 | 名称 | 规则 | 例子 |
|---|---|---|---|
| `&` | 按位与 | 两位**都是 1** 才得 1 | `12 & 10`：`1100 & 1010` = `1000` = 8 |
| `\|` | 按位或 | 有一位是 1 就得 1 | `12 \| 10` = `1110` = 14 |
| `^` | 按位异或 | **不同**得 1，相同得 0 | `12 ^ 10` = `0110` = 6 |
| `~` | 按位取反 | 单目，逐位 0↔1 翻转 | `~12` = -13，恒等式 `~x == -x - 1` |
| `<<` | 左移 | 低位补 0，等价 `× 2^k` | `3 << 2` = 12 |
| `>>` | 算术右移 | **高位补符号位**，等价 `÷ 2^k` 向下取整 | `-8 >> 1` = -4 |
| `>>>` | 无符号右移 | **高位补 0**（Java 特有，C/C++ 没有） | `-8 >>> 1` = 2147483644 |

异或的四条性质（LC 136 那一类题的全部依据）：

- `a ^ a = 0`（自己和自己抵消）
- `a ^ 0 = a`（和 0 异或不变）
- 满足**交换律与结合律**（所以一串数异或的顺序无所谓）
- 自反性 `a ^ b ^ b = a`（异或同一个数两次等于没做）

## 二、四个必踩的坑

1. **`&`、`^`、`\|` 的优先级低于 `==`**（比所有比较运算符都低）。`if (x & 1 == 0)` 会被解析成 `x & (1 == 0)`，**直接编译报错**。判奇偶必须写 `if ((x & 1) == 0)`，那对括号不是可选的。
2. **移位位数会先取模**：`int` 取 `& 31`，`long` 取 `& 63`。所以 `1 << 32` 不是 0 而是 **1**，`1 << 33` 是 2。循环里让 `i` 跑到 32 不会得 0，而是静默绕回去，错得没有痕迹。
3. **`1 << 31` 已经溢出成负数**（正是 `Integer.MIN_VALUE`）。状压 DP 里 `n` 到 40、60 时掩码必须写 `1L << i`；写成 `1 << i` 再赋给 `long` 是**先按 int 移完再提升**，赋值前就已经错了。
4. **负数右移分两种**：`>>` 保留符号，`-1 >> 1` 恒等于 `-1`，永远移不成 0——`while (x != 0) x >>= 1` 遇到负数直接死循环；`>>>` 补 0，负数一次就变成很大的正数。逐位扫 32 位，统一用 `>>>` 或干脆固定循环 32 次。

## 三、常用技巧速查

| 目的 | 写法 |
|---|---|
| 判奇偶 | `(x & 1) == 1` |
| 乘 / 除 2^k | `x << k` / `x >> k` |
| 取第 `i` 位（0 基） | `(x >> i) & 1` |
| 第 `i` 位置 1 | `x \| (1 << i)` |
| 第 `i` 位置 0 | `x & ~(1 << i)` |
| 第 `i` 位翻转 | `x ^ (1 << i)` |
| **清掉**最低位的 1 | `x & (x - 1)` |
| **取出**最低位的 1 | `x & -x` |
| 判断是否 2 的幂 | `x > 0 && (x & (x - 1)) == 0` |
| 数二进制里 1 的个数 | `Integer.bitCount(x)` |

最后两组是一对，别记混：`x & (x - 1)` 把最低位的 1 **去掉**，`x & -x` 只**留下**最低位的 1。

## 四、`x & -x` —— lowbit，取出最低位的 1

**它算的是什么：** 保留 `x` 二进制里**最低位的那个 1**，其余位全部清零。注意结果是那个 1 所代表的**权值（一个 2 的幂）**，不是它的下标。

| x | 二进制 | `x & -x` | 结果二进制 |
|---|---|---|---|
| 12 | `1100` | **4** | `0100` |
| 6 | `0110` | **2** | `0010` |
| 8 | `1000` | **8** | `1000` |
| 7 | `0111` | **1** | `0001` |
| 0 | `0000` | **0** | `0000` |

**为什么成立 —— 全靠补码。** 补码下 `-x == ~x + 1`。以 x = 12 用 8 位演示：

```
x         =  0000 1100
~x        =  1111 0011
-x = ~x+1 =  1111 0100
------------------------ &
x & -x    =  0000 0100   = 4
```

一般化推导：把 x 写成 `A 1 000…0` 的形状（最低位的 1，后面跟 k 个 0，前面 `A` 是任意位串）。

1. `~x` = `~A 0 111…1`（逐位翻转）
2. `+1` 让末尾那 k 个 1 全部进位归 0，进位刚好填到原本那个 0 位上变成 1，得 `-x = ~A 1 000…0`
3. 分三段看：**最低位 1 那一位**，x 与 -x 都是 1 → 与出来是 1；**它右边 k 位**，两者都是 0 → 与出来是 0；**它左边**，是 `A` 与 `~A` 逐位互补 → 与出来全是 0

结果只剩最低位那个 1。

**三个边界要记住：**

- **`x = 0` 时结果是 0。** 所以任何拿 lowbit 当步长的循环都必须先判非零，否则 `i -= 0` 就是死循环——树状数组模板里的 `while (i > 0)` 正是为这个而写。
- **`x = Integer.MIN_VALUE` 时** `-x` 溢出后仍是它自己，`x & -x` 得到 `0x80000000`，恰好就是它唯一的那个 1，**结论依然正确**，只是结果为负。
- **等价写法与现成方法**：`x & (~x + 1)` 与它完全等价；标准库的 `Integer.lowestOneBit(x)` 就是这个函数。如果要的是**位置下标**而不是权值，用 `Integer.numberOfTrailingZeros(x)`。

## 五、树状数组为什么用 lowbit

树状数组的全部设计都压在一句话上：**`tree[i]` 负责的区间是 `(i - lowbit(i), i]`，长度正好等于 `lowbit(i)`。**

| i | `lowbit(i)` | `tree[i]` 管辖区间 | 含几个元素 |
|---|---|---|---|
| 1 | 1 | (0, 1] | 1 |
| 2 | 2 | (0, 2] | 2 |
| 3 | 1 | (2, 3] | 1 |
| 4 | 4 | (0, 4] | 4 |
| 6 | 2 | (4, 6] | 2 |
| 8 | 8 | (0, 8] | 8 |

于是两个方向的跳法各自只需一行：

- **`query` 求前缀和 → `i -= i & -i`**：`tree[i]` 已经覆盖到 `i - lowbit(i)` 为止，减掉后正好落在左边紧邻的那一块，把互不重叠的块一路串起来就是 `[1, i]`。例：`query(6)` = `tree[6]`（管 {5,6}）+ `tree[4]`（管 {1,2,3,4}），`4 - 4 = 0` 停 → 恰好拼成 `[1, 6]`，不重不漏。
- **`add` 单点更新 → `i += i & -i`**：加上 lowbit 就跳到**包含当前位置的下一个更大区间**。例：`add(3)` 依次更新 `tree[3] → tree[4] → tree[8] → tree[16] …`，这些正是所有覆盖了下标 3 的节点。

**为什么是 $O(\log N)$：** `-= lowbit` 每次消掉一个 1，`+= lowbit` 每次向高位进一位，`int` 只有 32 位，所以两个循环都跑不过 log N 步。

## 六、lowbit 的其他用法

**枚举掩码里所有为 1 的位**（状压 DP 高频。比固定扫 32 次快，循环次数只等于「1 的个数」）：

```java
int m = mask;
while (m != 0) {
    int bit = m & -m;                              // 取最低位的 1（权值）
    int idx = Integer.numberOfTrailingZeros(bit);  // 换成下标
    // 处理第 idx 个元素 ...
    m ^= bit;                                      // 消掉这一位；m -= bit / m &= m - 1 等价
}
```

**兄弟操作 `x & (x - 1)`（消掉最低位的 1）也有两个经典用法：**

```java
// 1. 数 1 的个数（Brian Kernighan，循环次数 = 1 的个数，LC 191）
int cnt = 0;
while (x != 0) { x &= x - 1; cnt++; }

// 2. 判断 2 的幂：只有一个 1，消掉后必然为 0（LC 231）
boolean isPow2 = x > 0 && (x & (x - 1)) == 0;
```

## 七、Integer / Long 现成方法（能用就别手写）

| 方法 | 作用 |
|---|---|
| `Integer.bitCount(x)` | 二进制里 1 的个数（popcount） |
| `Integer.lowestOneBit(x)` | 就是 `x & -x` |
| `Integer.highestOneBit(x)` | 最高位那个 1 的权值 |
| `Integer.numberOfTrailingZeros(x)` | 末尾 0 的个数 = 最低位 1 的**下标** |
| `Integer.numberOfLeadingZeros(x)` | 前导 0 的个数 |
| `Integer.reverse(x)` | 32 位整体翻转（LC 190 一行解） |
| `Integer.toBinaryString(x)` | 转二进制字符串，调试神器 |

`long` 全部换成 `Long.` 前缀的同名方法。别拿 `Integer.bitCount` 去数 `long`——参数会被截成低 32 位，静默丢掉高位。

# 行走问题（可达性 + 曼哈顿距离 + 奇偶性）

## 一、题目

**行走**

小美在无限大的二维坐标轴上运动，初始位于 $(x, y)$。她将基于一个由 $n$ 个整数组成的数组 $\{a_1, a_2, \ldots, a_n\}$ 进行移动。对于第 $i$ 次移动，她需要选择两个整数 $l$ 和 $r$，满足 $|l| + |r| = a_i$，随后移动到 $(x + l,\ y + r)$。

**问：$n$ 次移动后，她能否恰好移动到 $(p, q)$？**

- 时间限制：C/C++ 1 秒，其他语言 2 秒
- 空间限制：C/C++ 256M，其他语言 512M
- $1 \le t \le 1000$，$1 \le n \le 10^5$，$0 \le a_i \le 1$，$-10^{18} \le x, y, p, q \le 10^{18}$，单个测试文件 $\sum n \le 10^5$
- 能到达输出 "YES"，否则 "NO"

### 示例

```
输入：                输出：
2
2                    YES
0 0
1 1 1 1
3                    NO
1 1 1
1 1 2 2
```

- 第一组：$a = \{0, 0\}$，$k = 0$，起点即终点 $(1,1)$，YES。
- 第二组：$a = \{1,1,1\}$，$k = 3$，起点 $(1,1)$，终点 $(2,2)$，$d = |2-1|+|2-1| = 2$，$d$ 偶 $k$ 奇，奇偶不符，NO。

---

## 二、核心模型转化

每步选 $l, r$ 使 $|l| + |r| = a_i$，而 $a_i \in \{0, 1\}$，所以只有两种情况：

| $a_i$ | 含义 |
|---|---|
| 0 | $l = r = 0$，原地不动 |
| 1 | 恰好走一个四邻格：上下左右相邻（如 $(1,0), (-1,0), (0,1), (0,-1)$） |

**关键转化**：整个移动过程等价于"真正走了 $k$ 步"，其中

$$k = \sum_{i=1}^{n} a_i$$

即数组中 1 的个数。每步方向自由选择，**允许重复经过格子**。

所以问题变成经典的：**在网格图上走 $k$ 步（每步四邻格），能否恰好停在终点？**

---

## 三、判定条件（充要）

设 $d = |p - x| + |q - y|$（起点到终点的**曼哈顿距离**），则能到达当且仅当：

$$\boxed{d \le k \quad \text{且} \quad d \equiv k \pmod 2}$$

代码：`ok = (d <= k) && ((d ^ k) & 1) == 0;`

### 3.1 曼哈顿距离

$$d = |p - x| + |q - y|$$

即"只能横走 + 竖走"时两点间的最短步数（也叫出租车距离）。从 $(0,0)$ 到 $(3,4)$：直线距离 5，曼哈顿距离 $3 + 4 = 7$。

### 3.2 条件一：$d \le k$（必要性）

每走一步最多使曼哈顿距离缩短 1（不存在斜跳）。要走 $k$ 步到达，最短需求 $d$ 不能超过 $k$。

### 3.3 条件二：奇偶一致（必要性）

**染色视角**：把每个格子按 $x+y$ 的奇偶性染色（类似棋盘黑白格）。相邻格子颜色必然不同，因为没有斜走。

```
y=2  · # · #
y=1  # · # ·
y=0  · # · #
      x=0 1 2 3
```

- 每走一步，$x+y$ 奇偶翻转一次 → 走 $k$ 步后落在哪一色由 $k$ 的奇偶决定（偶数步回原色，奇数步异色）。
- 起终点颜色差由 $d$ 的奇偶决定（$d$ 偶同色，$d$ 奇异色）。
- 恰好停在终点 ⟹ 两者颜色必须一致 ⟹ $d \equiv k \pmod 2$。

**"来回走"为什么救不了奇偶不符的情况**：来回走一步再回来消耗 2 步，颜色翻转两次相互抵消——来回走只能"加 2 步"，永远改变不了最终颜色。反例：起点 $(0,0)$、终点 $(1,0)$（$d=1$）、$k=2$：穷尽所有走法（一步到终点再离开 / 来回走 / 走到别处），都不可能 2 步恰好停在 $(1,0)$。

### 3.4 充分性（为什么满足就一定能到）

先朝终点直走 $d$ 步到达终点；剩余 $k - d$ 步为偶数步，每 2 步用"来回蹭"消耗掉（例如直走一步改走 $(0,1) \to (1,1) \to (1,0)$，或原地一去一回）。因为题目允许重复经过格子，多余偶数步总能消化，且最终仍停在终点。

> [!warning] 注意"允许重复走格子"是充分性成立的前提——这也正是错误 BFS 的死因。

## 四、易错点（血泪教训）

1. **BFS + visited 剪枝是错的**。visited 会把"第一次到过就标记"的格子堵死，但中途到过终点不算数（必须第 $k$ 步恰好停在终点），且合法路径本身允许重复走格子。反例：起点 $(0,0)$、终点 $(1,0)$、$a=\{1,1,1\}$（$k=3$）：正确答案 YES（可走 $(0,0)\to(0,1)\to(1,1)\to(1,0)$），但 $(1,0)$ 在第 1 层就被 visited，BFS 判成 NO。
2. **中途到达不算**，不能"入队时碰到终点就打标记"。
3. **起点即终点不能直接 YES**：$d=0$，需 $k$ 为偶数才 YES（来回消耗步数），奇数则 NO。数学式天然覆盖，无需特判。
4. **$a_i = 0$ 不影响答案**，只需累加 $k$，不用逐步模拟。
5. **溢出**：$x, y, p, q$ 达 $10^{18}$。$|p - x|$ 最大约 $2 \times 10^{18}$，未超 `long` 上限（约 $9.2 \times 10^{18}$）；$d = |dx| + |dy|$ 最大约 $4 \times 10^{18}$，仍安全。直接用 `long` 计算即可，但不要做更大范围的无脑加法。
6. **奇偶判定写法**：`(d ^ k) & 1) == 0` 或 `(d - k) % 2 == 0`，两者等价（$d, k$ 均非负）。
7. **IO 优化**：$\sum n \le 10^5$、$t \le 1000$，Java 用 `StreamTokenizer` / `BufferedReader`，配 `StringBuilder` 一次性输出，避免 `Scanner` 超时。

## 五、AC 代码（Java，$O(n)$ 每组）

```java
import java.util.*;
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StreamTokenizer st = new StreamTokenizer(br);
        st.nextToken();
        int t = (int) st.nval;
        StringBuilder sb = new StringBuilder();
        while (t-- > 0) {
            st.nextToken();
            int n = (int) st.nval;
            long k = 0;
            for (int i = 0; i < n; i++) {
                st.nextToken();
                k += (long) st.nval;   // 只统计 1 的个数
            }
            st.nextToken(); long x = (long) st.nval;
            st.nextToken(); long y = (long) st.nval;
            st.nextToken(); long p = (long) st.nval;
            st.nextToken(); long q = (long) st.nval;
            long d = Math.abs(p - x) + Math.abs(q - y);
            boolean ok = d <= k && ((d ^ k) & 1) == 0;
            sb.append(ok ? "YES" : "NO").append('\n');
        }
        System.out.print(sb);
    }
}
```

## 六、方法总结（可迁移）

这类"网格上走 $k$ 步能否到达"的题，套路是固定的两板斧：

1. **数步数**：$k = \sum a_i$（距离为 0/1 的特殊结构常常让模拟退化为计数）。
2. **两个不变量**：
   - 下界/可达性：曼哈顿距离 $d \le k$；
   - 奇偶守恒：棋盘染色下每步换色 ⟹ $d \equiv k \pmod 2$。

推广记忆：每步走四邻格、可重复走时，**"距离不超过 + 奇偶相同"就是充要条件**；若题目禁止重复走格子或步长不止 1，条件会变化，需重新分析（此时才考虑 BFS/构造）。

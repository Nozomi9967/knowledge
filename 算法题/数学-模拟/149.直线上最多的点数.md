## 题目

https://leetcode.cn/problems/max-points-on-a-line/description/?envType=study-plan-v2&envId=top-interview-150



## 题解



```java
class Solution {

    int gcd(int a,int b){
        return b!=0?gcd(b,a%b):a;
    }

    public int maxPoints(int[][] points) {
        int n=points.length;
        if(n<=2) return n;
        int res=0;
        for(int i=0;i<n;i++){
            if(res>=n-i || res>n/2) break;
            Map<Integer,Integer> map = new HashMap<>();
            for(int j=i+1;j<n;j++){
                int my=points[i][1]-points[j][1];
                int mx=points[i][0]-points[j][0];
                // 斜率为0
                if(my==0) mx=0;
                else if(mx==0) my=1;
                else{
                    if(my<0){
                        my=-my;
                        mx=-mx;
                    }
                    int gcdXY=gcd(Math.abs(mx),Math.abs(my));
                    mx/=gcdXY;
                    my/=gcdXY;
                }
                int key=mx+my*20001;
                map.put(key,map.getOrDefault(key,1)+1);
            }
            int maxn=2;
            for(int key:map.keySet()){
                maxn=Math.max(maxn,map.get(key));
            }
            res=Math.max(maxn,res);
        }
        return res;
    }
}
```



**思路**

​	固定每一个点，与其他点计算斜率，斜率一样则在同一条直线，用一个map存储满足不同斜率的点数，求value最大的那个



既然要求斜率，那么肯定要给分子分母化简



**那么怎么求最大公因子？**

```java
    int gcd(int a,int b){
        return b!=0?gcd(b,a%b):a;
    }

// 如果a能够被b整除，那么b就是最大公因子，也就是进入gcd(最大公因子-b本身,0)，接着b==0，返回答案
// 如果最大公因子是1呢？那么就不断递归，最后进入gcd(1,0)，返回1
// 如果a<b呢？第一次递归正好就会翻转过来
```



**如果斜率是负数，负号到底给分子还是分母？**

​	统一定为给分母，==>如果分子为负数，分子分母同时取负，即可实现



**既然用map的key来区分斜率的唯一，怎么将斜率转换为key？**

​	也就是将化简后的mx和my，通过某种计算，得到一个唯一值

​	由于`-10000 <= xi, yi <= 10000	`

​	*mx* 落在区间 [−20000,20000] 内，*my* 落在区间 [0,20000] 内（因为规定my不为负数）

​	因此规定 key = `my` + 20001 x `mx`

​	因为当mx=0时，key的范围为 [0,20000] 

​	而当mx!=0时，key的范围一定不会与mx=0时的重叠，并且不会因为my值的取值而导致key重复，

​	因为只要有一份mx就必定大于20000
​	再看临界值mx=-1，这时key是最可能重复的，key此时最接近只能到达-1（mx=-1 my=20000）

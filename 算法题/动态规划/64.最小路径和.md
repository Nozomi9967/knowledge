## 题目

https://leetcode.cn/problems/minimum-path-sum/?envType=study-plan-v2&envId=top-interview-150



## 题解



```java
class Solution {
    public int minPathSum(int[][] grid) {
        int m=grid.length;
        int n=grid[0].length;
        int[][] ans = new int[m][n];
        ans[0][0]=grid[0][0];
        // 第一行、列累加
        for(int i=1;i<n;i++) ans[0][i]=ans[0][i-1]+grid[0][i];
        for(int i=1;i<m;i++) ans[i][0]=ans[i-1][0]+grid[i][0];

        for(int i=1;i<m;i++){
            for(int j=1;j<n;j++){
                ans[i][j]= grid[i][j]+Math.min(ans[i][j-1],ans[i-1][j]);
            }
        }

        return ans[m-1][n-1];
    }
}
```

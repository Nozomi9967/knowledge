给你一个小写英文字母组成的字符串 `s` 和一个二维整数数组 `shifts` ，其中 `shifts[i] = [start_i, end_i, direction_i]` 。对于每个 `i` ，将 `s` 中从下标 `start_i` 到下标 `end_i` （两者都包含）所有字符都进行移位运算，如果 `direction_i = 1` 将字符向后移位，如果 `direction_i = 0` 将字符向前移位。

将一个字符 **向后** 移位的意思是将这个字符用字母表中 **下一个** 字母替换（字母表视为环绕的，所以 `'z'` 变成 `'a'` ）。类似的，将一个字符 **向前** 移位的意思是将这个字符用字母表中 **前一个** 字母替换（字母表是环绕的，所以 `'a'` 变成 `'z'` ）。

请你返回对 `s` 进行所有移位操作以后得到的最终字符串。

**示例 1：**

```
输入：s = "abc", shifts = [[0,1,0],[1,2,1],[0,2,1]]
输出："ace"
解释：首先，将下标从 0 到 1 的字母向前移位，得到 s = "zac" 。
然后，将下标从 1 到 2 的字母向后移位，得到 s = "zbd" 。
最后，将下标从 0 到 2 的字符向后移位，得到 s = "ace" 。
```

**示例 2:**

```
输入：s = "dztz", shifts = [[0,0,0],[1,1,1]]
输出："catz"
解释：首先，将下标从 0 到 0 的字母向前移位，得到 s = "cztz" 。
最后，将下标从 1 到 1 的字符向后移位，得到 s = "catz" 。
```

**提示：**

- `1 <= s.length, shifts.length <= 5 * 10^4`
- `shifts[i].length == 3`
- `0 <= start_i <= end_i < s.length`
- `0 <= direction_i <= 1`
- `s` 只包含小写英文字母。

## ==我的题解==

```java
class Solution {

    public String shiftingLetters(String s, int[][] shifts) {

        TreeMap<Integer,Integer> d=new TreeMap<>();

        for(int[] shi:shifts){

            int start=shi[0],end=shi[1],dir=shi[2]==0?-1:shi[2];

            d.merge(start,dir,Integer::sum);

            d.merge(end+1,-dir,Integer::sum);

        }

        int n=s.length();

        int offset=0;

        StringBuilder sb =new StringBuilder();

        for(int i=0;i<n;i++){

            offset+=d.getOrDefault(i,0);

            int num=s.charAt(i)-'a';

            num=((num+offset)%26+26)%26;

            sb.append((char)('a'+num));

        }

        return sb.toString();

    }

}
```

```java
class Solution {
    public String shiftingLetters(String s, int[][] shifts) {
        int n = s.length();
        int[] diff = new int[n + 1];

        // 区间差分：方向为 1 表示后移 +1，方向为 0 表示前移 -1
        for (int[] shift : shifts) {
            int start = shift[0];
            int end = shift[1];
            int delta = shift[2] == 1 ? 1 : -1;

            diff[start] += delta;
            diff[end + 1] -= delta;
        }

        StringBuilder result = new StringBuilder(n);
        int shiftSum = 0;

        for (int i = 0; i < n; i++) {
            shiftSum += diff[i];

            // Java 的负数取模结果可能为负，所以加 26 后再取模
            int letterIndex = (s.charAt(i) - 'a' + shiftSum % 26 + 26) % 26;
            result.append((char) ('a' + letterIndex));
        }

        return result.toString();
    }
}
```

### **LeetCode 583「两个字符串的删除操作」有两种等价解法：直接 DP（`dp[i][j]` = 让两串相同的最少删除次数）或者转成 LCS（答案是 `m + n - 2×LCS`）。后者更好记——留下的公共子序列不用删，其余全删。**

### **一、问题本身**

每次可以删掉任意一个字符串中的一个字符，求让两个字符串相同的最少删除步数。

```
s = "sea", t = "eat"
删 s 的 's' → "ea"；删 t 的 't' → "ea"  →  2 步
```

---

### **二、思路一：转成最长公共子序列（推荐）**

两个串最后变成的"相同的串"，一定是它们的**公共子序列**。要让删除次数最少，这个公共子序列就应该最长（LCS）。

设 `L = LCS(s, t)`，则：

```
答案 = (m - L) + (n - L) = m + n - 2L
```

即"两个串各自删掉不属于公共子序列的部分"。

LCS 的经典 DP：

```java
class Solution {
    public int minDistance(String s, String t) {
        int m = s.length(), n = t.length();
        int[][] dp = new int[m + 1][n + 1];   // LCS 长度

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (s.charAt(i - 1) == t.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }
        return m + n - 2 * dp[m][n];
    }
}
```

### **三、思路二：直接定义删除次数**

**状态**：`dp[i][j]` = 让 `s[0..i-1]` 和 `t[0..j-1]` 相同的最少删除次数。

**转移**：

```java
if (s[i-1] == t[j-1]) {
    dp[i][j] = dp[i-1][j-1];                 // 末尾相同，不用删
} else {
    dp[i][j] = 1 + Math.min(dp[i-1][j],     // 删掉 s 的末尾
                            dp[i][j-1]);     // 删掉 t 的末尾
}
```

**边界**：

```java
dp[i][0] = i;    // t 为空，s 要删掉全部 i 个
dp[0][j] = j;    // s 为空，t 要删掉全部 j 个
```

这种写法和 72（编辑距离）很像，区别是编辑距离还允许"替换"，而本题只能删。

### **四、两种解法怎么选**

| 解法 | 优点 | 缺点 |
|---|---|---|
| LCS | 复用现成模板，答案 = m+n-2L 一句话记住 | 需要多一步转换，面试要解释清楚为什么 |
| 直接 DP | 语义直接，和 72 编辑距离同一套骨架 | 边界（`dp[i][0]=i`）容易写错 |

**面试建议先讲直接 DP，再提"其实这题等价于 LCS"**——既展示了推导能力，又展示了模式识别能力。

---

### **五、复杂度与易错点**

| 项 | 复杂度 |
|---|---|
| 时间 | O(m·n) |
| 空间 | O(m·n)，可压到 O(n) |

**易错点**：

1. **直接 DP 的边界写错**：`dp[i][0]` 必须是 `i`，不是 0
2. **LCS 转换时忘了乘 2**：答案是 `m + n - 2L`，不是 `m + n - L`
3. **和 72 编辑距离混淆**：编辑距离允许替换，所以不等时是 `1 + min(删, 删, 换)`；本题没有替换
4. **以为要保证顺序**：删除后的"相同字符串"必须是原串的子序列（顺序保留），不是任意重排
5. **空串情况**：`s=""`、`t=""` 返回 0；`s="abc"`、`t=""` 返回 3，边界公式能覆盖

### **六、同族题对照**

| 题号 | 允许的操作 | 核心 |
|---|---|---|
| 583（本题） | 只能删 | `m + n - 2×LCS` |
| 72 编辑距离 | 增 / 删 / 改 | `dp[i][j]` 三选一 |
| 1143 最长公共子序列 | 无（求长度） | 标准 LCS |
| 1035 不相交的线 | 无（求最大连线数） | 本质就是 LCS |

**一句话**：这一族题都在"两个序列对齐"的框架里，差别只在允许的操作集合。

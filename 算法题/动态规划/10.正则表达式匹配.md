# LeetCode 10. 正则表达式匹配 — 学习笔记

---

## 一、题目描述

> 给你一个字符串 `s` 和一个字符规律 `p`，请你来实现一个支持 `.` 和 `*` 的正则表达式匹配。
>
> - `.` 匹配任意**单个**字符
> - `*` 匹配**零个或多个前面的那一个元素**
>
> 匹配需要覆盖**整个**字符串 `s`，而不是部分匹配。

**示例：**

| 输入 | 输出 | 解释 |
|------|------|------|
| `s = "aa"`, `p = "a"` | `false` | `"a"` 无法匹配 `"aa"` 整个字符串 |
| `s = "aa"`, `p = "a*"` | `true` | `a*` 表示 `a` 重复 2 次 |
| `s = "ab"`, `p = ".*"` | `true` | `.*` 表示任意字符重复任意次 |
| `s = "aab"`, `p = "c*a*b"` | `true` | `c*` 匹配 0 次，`a*` 匹配 2 次，`b` 匹配 1 次 |

---

## 二、核心概念理解

### 2.1 `.` 的含义（简单）

`.` 就是万能牌，可以匹配任意**一个**字符。

```
"." 能匹配 "a" ✅
"." 能匹配 "z" ✅
"." 能匹配 "3" ✅
".." 能匹配 "ab" ✅（两个任意字符）
```

### 2.2 `*` 的含义（重点！）

#### ⚠️ 核心原则：`*` 永远不单独干活，必须和左边字符绑定成一个"小组"

```
模式串:  a  b  *  c
         ↑  ↑──↑  ↑
         │   小组  │
         │  "b*"  │
         单独的    单独的
```

#### `x*` 的完整含义

> **字符 `x` 可以出现 0 次、1 次、2 次、3 次……无限次。**

| 字符串 | `b*` 能匹配吗？ | 原因 |
|--------|:-:|------|
| `""`（空） | ✅ | b 出现 **0 次** |
| `"b"` | ✅ | b 出现 **1 次** |
| `"bb"` | ✅ | b 出现 **2 次** |
| `"bbb"` | ✅ | b 出现 **3 次** |
| `"a"` | ❌ | `a` ≠ `b`，`b*` 管不了 `a` |

#### 完整模式串示例：`p = "ab*c"`

```
a    → 必须有一个 a
b*   → b 可以出现 0次、1次、2次……
c    → 最后必须有一个 c
```

| 字符串 s | 匹配？ | 拆解 |
|----------|:-:|------|
| `"ac"` | ✅ | `a` + **0 个 b** + `c` |
| `"abc"` | ✅ | `a` + **1 个 b** + `c` |
| `"abbc"` | ✅ | `a` + **2 个 b** + `c` |
| `"abbbbc"` | ✅ | `a` + **4 个 b** + `c` |
| `"adc"` | ❌ | 中间 `d` 不是 `b` |
| `"ab"` | ❌ | 缺少结尾 `c` |

#### 特殊组合 `.*`

> `.` = 任意字符，`*` = 任意次数 → **`.*` = 什么都能匹配**

### 2.3 生活类比 🧃

把 `a*` 想象成一台**无限续杯的果汁机**：

- **匹配 0 次**：没人接果汁，直接把机器搬走
- **匹配 1 次**：一个人接了一杯，机器还在
- **匹配多次**：好几个人排队接，机器一直在，直到没人了再搬走

**关键：每接一杯，顾客少一个（`i-1`），但机器还在原地（`j` 不变）。**

---

## 三、为什么不能用贪心/双指针？

因为 `*` 带来了**不确定性（分支选择）**。

**反例：** `s = "aaa"`, `p = "a*a"`

- 如果贪心让 `a*` 吃掉所有 3 个 `a`，后面的 `a` 就没东西匹配了 → ❌
- 正确做法：`a*` 只吃 2 个 `a`，留 1 个给后面的 `a` → ✅

**结论：** 存在重叠子问题 + 最优子结构 → 使用**动态规划**。

---

## 四、动态规划解法（核心）

### 4.1 状态定义

```
dp[i][j] = s 的前 i 个字符（s[0..i-1]）与 p 的前 j 个字符（p[0..j-1]）是否匹配
```

> 注意：`dp` 数组大小是 `(m+1) × (n+1)`，下标从 0 开始，0 代表空字符串。

### 4.2 辅助函数 `matches(i, j)`

判断 `s` 的第 `i` 个字符和 `p` 的第 `j` 个字符是否匹配：

```java
private boolean matches(String s, String p, int i, int j) {
    if (i == 0) return false;          // ⚠️ 关键：s 为空，无字符可匹配
    if (p.charAt(j - 1) == '.') return true;  // '.' 匹配任意字符
    return s.charAt(i - 1) == p.charAt(j - 1); // 普通字符比较
}
```

#### ❓ 为什么 `i == 0` 返回 `false`？

| 原因 | 说明 |
|------|------|
| **防崩溃** | 不拦截的话 `s.charAt(-1)` 会数组越界 |
| **合逻辑** | 空字符串没有字符，无法和任何字符匹配 |
| **合语义** | `*` 想"吃掉" `s` 的一个字符，但 `s` 是空的，吃不到 |

### 4.3 状态转移方程

遍历 `p` 的当前字符 `p[j-1]`，分两种情况：

---

#### 情况 1：`p[j-1] != '*'`（普通字符或 `.`）

直接比较当前字符，结果取决于前面的子串：

```
如果 matches(i, j) 为真：
    dp[i][j] = dp[i-1][j-1]
否则：
    dp[i][j] = false
```

**图示：**
```
s: ... x     ← s[i-1]
p: ... y     ← p[j-1]（不是 *）

如果 x == y 或 y == '.'：
    看 dp[i-1][j-1]（前面的是否匹配）
```

---

#### 情况 2：`p[j-1] == '*'`（重点！）

`*` 和 `p[j-2]` 绑定为套餐 `x*`，有两种选择：

##### 选择 A：匹配 0 次（扔掉整个 `x*` 套餐）

```
dp[i][j] = dp[i][j-2]
```

```
s: ... (不变)
p: ... x  *   ← 这两个字符直接跳过
         ↑  ↑
         j-2 j    → 回退 2 步！
```

##### 选择 B：匹配 1 次或多次

**前提：** `s[i-1]` 必须能和 `p[j-2]`（`*` 前面的字符）匹配。

```
如果 matches(i, j-1) 为真：
    dp[i][j] = dp[i-1][j]
```

```
s: ... x     ← 被吃掉一个，i-1
p: ... y  *  ← 套餐还在！j 不变！
         ↑
         j-1（检查的是 * 前面的字符）
```

#### ❓ 为什么选择 B 是 `dp[i-1][j]` 而不是 `dp[i-1][j-2]`？

| 写法 | 含义 | 结果 |
|------|------|------|
| `dp[i-1][j]` ✅ | 吃掉 s 一个字符，**套餐留着继续用** | 正确！可以匹配多次 |
| `dp[i-1][j-2]` ❌ | 吃掉 s 一个字符，**套餐也扔了** | 错误！只能匹配 1 次 |

**举例：** `s = "aaa"`, `p = "a*"`

```
如果错误地用 dp[i-1][j-2]：
  dp[3][2] → 吃掉一个 a，扔掉 a* → dp[2][0] → "aa" vs "" → false ❌

正确地用 dp[i-1][j]：
  dp[3][2] → 吃掉一个 a，a* 还在 → dp[2][2]
  dp[2][2] → 吃掉一个 a，a* 还在 → dp[1][2]
  dp[1][2] → 吃掉一个 a，a* 还在 → dp[0][2]
  dp[0][2] → 选择 A，扔掉 a*    → dp[0][0] = true ✅
```

**生活类比：** 果汁机（`a*`）给一个顾客接完一杯后，机器还在原地（`j` 不变），下一个顾客还能继续接。如果接一杯就把机器搬走（`j-2`），后面排队的顾客怎么办？

##### 综合情况 2：

```
dp[i][j] = dp[i][j-2] || (matches(i, j-1) && dp[i-1][j])
            ↑ 选择A              ↑ 选择B的前提    ↑ 选择B
```

---

### 4.4 初始状态（Base Case）

| 状态 | 值 | 原因 |
|------|---|------|
| `dp[0][0]` | `true` | 空串 vs 空模式，匹配 |
| `dp[i][0]`（`i > 0`） | `false` | 非空串 vs 空模式，不可能匹配 |
| `dp[0][j]`（`j > 0`） | 看情况 | 空串 vs 非空模式，只有 `a*b*c*` 这种能匹配 0 次的才行 |

`dp[0][j]` 的初始化：

```java
for (int j = 2; j <= n; j++) {
    if (p.charAt(j - 1) == '*') {
        dp[0][j] = dp[0][j - 2]; // 空串只能靠 "匹配0次" 来匹配
    }
}
```

## 五、完整 DP 表格演示

**示例：** `s = "aab"`, `p = "c*a*b"`

```
      ""    c    *    a    *    b
""  [ T ]  F   [T]   F   [T]   F
a   [ F ]  F    F   [T]  [T]   F
a   [ F ]  F    F    F   [T]   F
b   [ F ]  F    F    F    F   [T] ✅
```

> 方括号 `[ ]` 标记的是关键路径。最终 `dp[3][5] = true`。

## 六、Java 完整代码

```java
class Solution {
    public boolean isMatch(String s, String p) {
        int m = s.length();
        int n = p.length();

        // dp[i][j]: s 的前 i 个字符与 p 的前 j 个字符是否匹配
        boolean[][] dp = new boolean[m + 1][n + 1];

        // 1. 初始化：空字符串和空模式串匹配
        dp[0][0] = true;

        // 2. 初始化第一行：空字符串 s 与非空模式串 p
        //    例如 s = "", p = "a*b*c*" → 全部匹配 0 次即可
        for (int j = 2; j <= n; j++) {
            if (p.charAt(j - 1) == '*') {
                dp[0][j] = dp[0][j - 2];
            }
        }

        // 3. 状态转移
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (p.charAt(j - 1) != '*') {
                    // 情况 1：普通字符或 '.'
                    if (matches(s, p, i, j)) {
                        dp[i][j] = dp[i - 1][j - 1];
                    }
                } else {
                    // 情况 2：当前字符是 '*'
                    // 选择 A：匹配 0 次，扔掉 x* 套餐
                    dp[i][j] = dp[i][j - 2];
                    // 选择 B：匹配 1 次或多次，套餐留着继续用
                    if (matches(s, p, i, j - 1)) {
                        dp[i][j] = dp[i][j] || dp[i - 1][j];
                    }
                }
            }
        }

        return dp[m][n];
    }

    /**
     * 判断 s 的第 i 个字符是否能匹配 p 的第 j 个字符
     */
    private boolean matches(String s, String p, int i, int j) {
        if (i == 0) return false;                      // s 为空，无字符可匹配
        if (p.charAt(j - 1) == '.') return true;       // '.' 匹配任意字符
        return s.charAt(i - 1) == p.charAt(j - 1);     // 普通字符比较
    }
}
```

## 七、复杂度分析

| | 复杂度 | 说明 |
|--|--------|------|
| **时间** | $O(m \times n)$ | 两层嵌套循环，每个状态转移 $O(1)$ |
| **空间** | $O(m \times n)$ | 二维 DP 数组（可优化为 $O(n)$ 滚动数组） |

## 八、易错点总结

| # | 易错点 | 正确做法 |
|---|--------|---------|
| 1 | `*` 单独处理 | `*` 必须和 `p[j-2]` 绑定为整体 |
| 2 | 选择 B 写成 `dp[i-1][j-2]` | 应该是 `dp[i-1][j]`（套餐留着） |
| 3 | 忘记 `i == 0` 的边界保护 | `matches` 中 `i == 0` 返回 `false` |
| 4 | 忘记初始化 `dp[0][j]` | 空串可以匹配 `a*b*c*` 这种模式 |
| 5 | 下标搞混 | `dp[i][j]` 对应 `s.charAt(i-1)` 和 `p.charAt(j-1)` |

## 九、记忆口诀

> **遇到 `*`，看前面；**
> **零次扔俩（`j-2`），多次留原（`j` 不变）；**
> **`i-1` 吃字符，套餐桌上放；**
> **空串没得吃，`false` 保平安。**

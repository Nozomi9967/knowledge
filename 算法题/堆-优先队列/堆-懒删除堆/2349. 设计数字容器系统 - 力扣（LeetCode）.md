设计一个数字容器系统，可以实现以下功能：

- 在系统中给定下标处 **插入** 或者 **替换** 一个数字。
- **返回** 系统中给定数字的最小下标。

请你实现一个 `NumberContainers` 类：

- `NumberContainers()` 初始化数字容器系统。
- `void change(int index, int number)` 在下标 `index` 处填入 `number` 。如果该下标 `index` 处已经有数字了，那么用 `number` 替换该数字。
- `int find(int number)` 返回给定数字 `number` 在系统中的最小下标。如果系统中没有 `number` ，那么返回 `-1` 。

**示例：**

```
输入：
["NumberContainers", "find", "change", "change", "change", "change", "find", "change", "find"]
[[], [10], [2, 10], [1, 10], [3, 10], [5, 10], [10], [1, 20], [10]]
输出：
[null, -1, null, null, null, null, 1, null, 2]

解释：
NumberContainers nc = new NumberContainers();
nc.find(10); // 没有数字 10 ，所以返回 -1 。
nc.change(2, 10); // 容器中下标为 2 处填入数字 10 。
nc.change(1, 10); // 容器中下标为 1 处填入数字 10 。
nc.change(3, 10); // 容器中下标为 3 处填入数字 10 。
nc.change(5, 10); // 容器中下标为 5 处填入数字 10 。
nc.find(10); // 数字 10 所在的下标为 1 ，2 ，3 和 5 。因为最小下标为 1 ，所以返回 1 。
nc.change(1, 20); // 容器中下标为 1 处填入数字 20 。注意，下标 1 处之前为 10 ，现在被替换为 20 。
nc.find(10); // 数字 10 所在下标为 2 ，3 和 5 。最小下标为 2 ，所以返回 2 。
```

**提示：**

- `1 <= index, number <= 10^9`
- 调用 `change` 和 `find` 的 **总次数** 不超过 `10^5` 次。

## 我的题解-超时

```java
class NumberContainers {

  

    private Map<Integer,Integer> con;

    private Map<Integer,PriorityQueue<Integer>> hash;

  

    public NumberContainers() {

        con=new HashMap<>();

        hash=new HashMap<>();

    }

    public void change(int index, int number) {

  

        if(con.containsKey(index)){

            int ori=con.get(index);

            var pq=hash.get(ori);

            pq.remove(index);

        }

  
  

        if(!hash.containsKey(number)){

            PriorityQueue<Integer> pq=new PriorityQueue<>();

            pq.offer(index);

            hash.put(number,pq);

        }else{

            var pq=hash.get(number);

            pq.offer(index);

        }

        con.put(index,number);

    }

    public int find(int number) {

        if(!hash.containsKey(number)||hash.get(number).size()<1) return -1;

        return hash.get(number).peek();

    }

}

  

/**

 * Your NumberContainers object will be instantiated and called as such:

 * NumberContainers obj = new NumberContainers();

 * obj.change(index,number);

 * int param_2 = obj.find(number);

 */
```


## 修改后-懒删除

### 什么是懒删除？

当一个索引的数字被换掉时，我们**不急着**去原有的 `PriorityQueue` 里把这个索引抠出来（假装没看见它）。 只有当别人调用 `find(number)` 想要看堆顶元素时，我们再检查堆顶的索引是否有效。如果堆顶的索引已经换成别的数字了，这时候再把它 `poll()` 扔掉。


```java
class NumberContainers {

  

    private Map<Integer,Integer> con;

    private Map<Integer,PriorityQueue<Integer>> hash;

  

    public NumberContainers() {

        con=new HashMap<>();

        hash=new HashMap<>();

    }

    public void change(int index, int number) {

  
  

        if(!hash.containsKey(number)){

            PriorityQueue<Integer> pq=new PriorityQueue<>();

            pq.offer(index);

            hash.put(number,pq);

        }else{

            var pq=hash.get(number);

            pq.offer(index);

        }

        con.put(index,number);

    }

    public int find(int number) {

        if(!hash.containsKey(number)||hash.get(number).size()<1) return -1;

        var pq=hash.get(number);

        while(!pq.isEmpty()){

            int index=pq.peek();

            if(con.get(index)==number) return index;

            pq.poll();

        }

        return -1;

    }

}

  

/**

 * Your NumberContainers object will be instantiated and called as such:

 * NumberContainers obj = new NumberContainers();

 * obj.change(index,number);

 * int param_2 = obj.find(number);

 */
```

## ==我的题解==

```java

class Solution {

    public int[] answerQueries(int[] nums, int[] queries) {

        Arrays.sort(nums);

        int n=nums.length;

        int m=queries.length;

        int[] s=new int[n+1];

        for(int i=1;i<=n;i++){

            s[i]=s[i-1]+nums[i-1];

        }

        int[] ans=new int[m];

        for(int i=0;i<m;i++){

            ans[i]=func(queries[i],s);

        }

        return ans;

    }

  

    public int func(int x,int[] s){

        int l=0,r=s.length-1;

        // System.out.println("x: "+x);

        while(l<=r){

            int m=(r-l)/2+l;

            // System.out.println("l: "+l+" m: "+m+" r: "+r+" s[m]: "+s[m]);

            if(s[m]<=x) l=m+1;

            else r=m-1;

        }

        return r;

    }

}

  

// 1,2,4,5

// 0,1,3,7,12
```

## 核心思路

贪心：由于元素和有上限，为了能让子序列尽量长，子序列中的 **元素值越小越好** 。

对于本题来说，元素在数组中的位置是无关紧要的。因为我们从小到大算数组中的元素和，无论数组是 还是 还是别的顺序，不影响答案。所以可以排序。

把 从小到大排序后，再从小到大选择尽量多的元素（相当于选择一个前缀），使这些元素的和不超过询问值。

```
class Solution:
    def answerQueries(self, nums: List[int], queries: List[int]) -> List[int]:
        nums.sort()
        for i in range(1, len(nums)):
            nums[i] += nums[i - 1]  # 原地求前缀和
        for i, q in enumerate(queries):
            queries[i] = bisect_right(nums, q)  # 复用 queries 作为答案
        return queries
```

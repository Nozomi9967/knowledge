## 题目

[219. 存在重复元素 II - 力扣（LeetCode）](https://leetcode.cn/problems/contains-duplicate-ii/description/?envType=study-plan-v2&envId=top-interview-150)







## 题解

固定的滑动窗口

```java
class Solution {
    public boolean containsNearbyDuplicate(int[] nums, int k) {
        int left=0,right=0;
        int len=nums.length;
        if(len==1) return false;
        Set<Integer> set=new HashSet<>();
        set.add(nums[left]);
        do{
            if(Math.abs(left-right)==k){
                left++;
                set.remove(nums[left-1]);
            }
            right++;
            if(right==len) break;
            if(set.contains(nums[right])) return true;
            else set.add(nums[right]);
        }while(true);
        return false;
    }
}

// 优化版
class Solution {
    public boolean containsNearbyDuplicate(int[] nums, int k) {
        int left=0,right=0;
        int len=nums.length;
        if(len==1) return false;
        Set<Integer> set=new HashSet<>();
        set.add(nums[0]);
        do{
            if(right>=k){
                set.remove(nums[right-k]);
            }
            right++;
            if(right==len) break;
            if(set.contains(nums[right])) return true;
            else set.add(nums[right]);
        }while(len!=right);
        return false;
    }
}
```

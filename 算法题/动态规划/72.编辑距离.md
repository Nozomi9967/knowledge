# 72.编辑距离（Levenshtein Distance，二维 DP）

> [!abstract] 题目
> 给定两个单词 `word1` 和 `word2`，要求返回将 `word1` 转换成 `word2` 所需的最少操作数。允许对一个单词执行三种操作：
> - 插入一个字符
> - 删除一个字符
> - 替换一个字符

| 参数 | 范围 |
|-----|------|
| word1.length | 0 ~ 500 |
| word2.length | 0 ~ 500 |
| 字符集 | 小写英文字母 |

**示例 1：**
```
输入：word1 = "horse", word2 = "ros"
输出：3
解释：'h'→'r' 得 "rorse"，删第二个 'r' 得 "rose"，删 'e' 得 "ros"
```

**示例 2：**
```
输入：word1 = "intention", word2 = "execution"
输出：5
解释：删 't' → 改 'i'→'e' → 改 'n'→'x' → 改 'n'→'c' → 插 'u'，共 5 步
```

---

## 核心思路：二维 DP（序列对齐）

将 word1 转换成 word2，本质是**两个序列的对齐**：每个字符要么保留（匹配）、要么被替换、要么被删除/插入。

### 状态定义

`dp[i][j]` = 将 word1 的前 i 个字符转换成 word2 的前 j 个字符所需的最少操作数。

### 初始化

- `dp[i][0] = i`：word1 前 i 个字符全部删除，需要 i 次。
- `dp[0][j] = j`：插入 word2 前 j 个字符，需要 j 次。

### 状态转移

对 `dp[i][j]`，看 word1[i-1] 与 word2[j-1] 是否相等：

| 条件 | 转移 | 含义 |
|------|------|------|
| `A[i-1] == B[j-1]` | `dp[i][j] = dp[i-1][j-1]` | 字符相同，无需操作 |
| `A[i-1] ≠ B[j-1]` | `dp[i][j] = 1 + min(dp[i-1][j-1], dp[i-1][j], dp[i][j-1])` | 取三种操作最小：替换 / 删除 / 插入 |

三种操作的 DP 视角：
- **替换** `dp[i-1][j-1] + 1`：把 A[i-1] 改成 B[j-1]，两个指针都回退。
- **删除** `dp[i-1][j] + 1`：删掉 A[i-1]，A 指针回退，B 不动。
- **插入** `dp[i][j-1] + 1`：在 A 中插入 B[j-1]，B 指针回退，A 不动。

答案 = `dp[m][n]`。

## 完整 Java 代码

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length(), n = word2.length();
        int[][] dp = new int[m + 1][n + 1];

        // 初始化边界
        for (int i = 0; i <= m; i++) dp[i][0] = i; // 全部删除
        for (int j = 0; j <= n; j++) dp[0][j] = j; // 全部插入

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1];          // 相同，不动
                } else {
                    dp[i][j] = 1 + Math.min(dp[i - 1][j - 1], // 替换
                                    Math.min(dp[i - 1][j],     // 删除
                                             dp[i][j - 1]));  // 插入
                }
            }
        }
        return dp[m][n];
    }
}
```

### 滚动数组优化版（空间 O(n)）

`dp[i][j]` 只依赖 `dp[i-1][j-1]`、`dp[i-1][j]`（上一行）和 `dp[i][j-1]`（当前行左侧），可压缩为一维：

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length(), n = word2.length();
        int[] dp = new int[n + 1];
        for (int j = 0; j <= n; j++) dp[j] = j; // 第 0 行：全部插入

        for (int i = 1; i <= m; i++) {
            int prev = dp[0];       // 相当于 dp[i-1][0]
            dp[0] = i;              // 第 i 行第 0 列：全部删除
            for (int j = 1; j <= n; j++) {
                int temp = dp[j];   // 先存 dp[i-1][j]，即旧的 dp[j]
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[j] = prev;   // prev = dp[i-1][j-1]
                } else {
                    dp[j] = 1 + Math.min(prev, Math.min(dp[j], dp[j - 1]));
                }
                prev = temp;        // 下一轮的 prev = 本轮的 dp[i-1][j]
            }
        }
        return dp[n];
    }
}
```

> ⚠️ 滚动数组关键：`prev` 变量保存 `dp[i-1][j-1]`（被覆盖前的左上角值），必须在 `dp[j]` 被覆盖前取出，再用 `temp` 接力传递给下一列。

## 面试话术

1. **为什么是二维 DP？** → 两个序列的转换，状态由两个序列各自的"已处理前缀长度"共同决定，天然是二维 (i, j) 网格。
2. **三种操作怎么对应到转移？** → 替换=两指针各回退一格；删除=word1 指针回退、word2 不动；插入=word2 指针回退、word1 不动。`dp[i][j]` 取三者最小值 +1。
3. **边界初始化为什么是 i 和 j？** → 一个字符串为空时，只能靠删（dp[i][0]=i）或插（dp[0][j]=j）补齐，次数就是另一个串的长度。
4. **和最长公共子序列（LCS）什么关系？** → 编辑距离的替换/删除/插入操作在"只允许删除"或"只允许插入"特例下退化为 LCS：`minDistance = m + n - 2*LCS`。583 题就是这个特例。
5. **什么时候能提前剪枝？** → 若两个串长度差 > 某个阈值 D，编辑距离下界就是长度差，可提前跳过（详见 [[基因序列相似度分析]]）。

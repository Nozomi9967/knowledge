# LeetCode 3620. 恢复网络路径 题解笔记

## 1. 核心思想：二分答案 + DAG 动态规划

本题的目标是找到一条从起点到终点的路径，满足总成本 $\le k$，且使路径上的最小边权最大。这种“最大化最小值”的特征是典型的二分答案应用场景。

  

## 2. 关键变量与数据结构

邻接表 `g` (Adjacency List)

  

• 作用：将扁平的边输入转换成图结构，实现 $O(1)$ 级快速检索某节点的所有邻居。

  

• 结构：`List<int[]>[] g`。`g[x]` 存储从节点 `x` 出发能直接到达的下个节点 `[y, wt]`（`y` 为目的地，`wt` 为边权/恢复成本）。

  

状态数组 `f` (DP Array)

  

• 作用：用于动态规划（DP）递推最小成本。

  

• 含义：`f[i]` 表示在满足当前边权及格线的前提下，从起点 `0` 走到节点 `i` 的最小总成本。

  

## 3. 算法核心流程

一、 猜答案（二分及格线 $X$）

  

1. 设定一个虚拟的边权“及格线” $X$。

  

2. 规定：任何权重 $< X$ 的边都不能走（拉黑/封锁）。

  

二、 算成本（DAG DP 验证）

  

1. 初始化 `f[0] = 0`，其余 `f[i] = \infty`。

  

2. 按照拓扑序遍历节点，当从 `x` 走向 `y` 且满足 `wt >= X` 时，尝试更新 `y` 的最小成本： 

  

3. 检查终点的最小总成本 `f[n-1]`：

  

  • 若 $f[n-1] \le k$：说明预算够，及格线 $X$ 可行。为了让最小边权“最大”，应提高及格线，向右二分（`left = mid`）。

  

  • 若 $f[n-1] > k$ 或无法到达：说明及格线定太高导致无路可走或超支，应降低及格线，向左二分（`right = mid`）。


```java
class Solution {

    public int findMaxPathScore(int[][] edges, boolean[] online, long k) {

        int n=online.length;

        int[] cnt=new int[n];

        int l=0,r=-1; // -1注意

        // 创建邻接表

        List<int[]>[] adj=new ArrayList[n];

        Arrays.setAll(adj,_-> new ArrayList<>());

        for(int[] e:edges){

            int x=e[0],y=e[1],w=e[2];

            if(online[x]&&online[y]){

               adj[x].add(new int[]{y,w});

               cnt[y]++;

               r=Math.max(r,w);

            }

        }

        // 简化

        Queue<Integer> q= new ArrayDeque<>();

        for(int i=1;i<n;i++){

            if(cnt[i]==0) q.offer(i);

        }

        while(!q.isEmpty()){

            int x=q.poll();

            for(int[] e:adj[x]){

                int y=e[0];

                cnt[y]--;

                if(cnt[y]==0) q.offer(y);

            }

        }

  
  

        long[] dp=new long[n];

        // 二分

        while(l<=r){

            int m=(r-l)/2+l;

            // clone注意

            if(check(m,adj,cnt.clone(),k,dp)) l=m+1;

            else r=m-1;

        }

        return r;

    }

  

    private boolean check(int m,List<int[]>[] adj,int[] cnt,long k,long[] dp){

        // 以m为最小成本基准线,去找一条有效路径

        // 可以找到则表示基准还可以更大，返回true，l=m+1

        // 否则false,r=m-1;

        // 规则: w>=m && online[y] == true && dp[n-1] <= k

        // w>=m 任何一条路径上的任何一个weight都必须>=m

        // online[y] == true 确保有效路径在线

        // dp[n-1] <= k 最后到达终点时总恢复成本 不超过 k

        int n=cnt.length;

        Arrays.fill(dp,Long.MAX_VALUE/2);

        dp[0]=0;

        Queue<Integer> q=new ArrayDeque<>();

        q.offer(0);

        while(!q.isEmpty()){

            int x=q.poll();

  

            if(x==n-1){

                return dp[n-1]<=k;

            }

  

            for(int[] e:adj[x]){

                int y=e[0],w=e[1];

                if(w>=m){

                    dp[y]=Math.min(dp[y],dp[x]+w);

                }

                if(--cnt[y]==0) q.offer(y);

            }

        }

        return false;  

  

    }

}
```

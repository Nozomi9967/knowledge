给你一个二维整数数组 `points`，其中 `points[i] = [x_i, y_i]` 表示第 i 个点的坐标。`points` 中的所有坐标都 **互不相同**。

如果一个点被 **激活** ，那么所有与该点具有相同 **x** 坐标或 **y** 坐标的点也会被 **激活** 。

激活会一直持续，直到没有额外的点可以被激活为止。

你可以 **额外添加** 一个不在 `points` 数组中的整数坐标点 `(x, y)` 。从这个新添加的点开始 **激活** 。

返回一个整数，表示可以被激活的 **最大** 点数，包括新添加的点。

**示例 1：**

**输入：** points = \[\[1,1\],\[1,2\],\[2,2\]\]

**输出：** 4

**解释：**

添加并激活一个点，例如 `(1, 3)` ，会导致以下激活：

- `(1, 3)` 与 `(1, 1)` 和 `(1, 2)` 具有相同的 `x = 1` ，因此 `(1, 1)` 和 `(1, 2)` 被激活。
- `(1, 2)` 与 `(2, 2)` 具有相同的 `y = 2` ，因此 `(2, 2)` 被激活。

因此，被激活的点为 `(1, 3)`, `(1, 1)`, `(1, 2)`, `(2, 2)` ，总计 4 个点。可以证明这是最大激活点数。

**示例 2：**

**输入：** points = \[\[2,2\],\[1,1\],\[3,3\]\]

**输出：** 3

**解释：**

添加并激活一个点，例如 `(1, 2)` ，会导致以下激活：

- `(1, 2)` 与 `(1, 1)` 具有相同的 `x = 1` ，因此 `(1, 1)` 被激活。
- `(1, 2)` 与 `(2, 2)` 具有相同的 `y = 2` ，因此 `(2, 2)` 被激活。

因此，被激活的点为 `(1, 2)`, `(1, 1)`, `(2, 2)` ，总计 3 个点。可以证明这是最大激活点数。

**示例 3：**

**输入：** points = \[\[2,3\],\[2,2\],\[1,1\],\[4,5\]\]

**输出：** 4

**解释：**

添加并激活一个点，例如 `(2, 1)` ，会导致以下激活：

- `(2, 1)` 与 `(2, 3)` 和 `(2, 2)` 具有相同的 `x = 2` ，因此 `(2, 3)` 和 `(2, 2)` 被激活。
- `(2, 1)` 与 `(1, 1)` 具有相同的 `y = 1` ，因此 `(1, 1)` 被激活。

因此，被激活的点为 `(2, 1)`, `(2, 3)`, `(2, 2)`, `(1, 1)` ，总计 4 个点。

**提示：**

- `1 <= points.length <= 10^5`
- `points[i] = [x_i, y_i]`
- `-10^9 <= x_i, y_i <= 10^9`
- `points` 中的坐标均 **互不相同** 。

这里的 `size` 记录的是**每个并查集根节点所代表的连通块中，包含多少个原始点**。需要特别注意：并查集的节点是坐标（`x` 和偏移后的 `y`），但 `size` 统计的不是坐标节点数，而是原始点数。

处理每个点时，先把它的 `x` 节点和 `y` 节点合并。然后给合并后的连通块加 `1`，表示当前这个原始点被计入该块：

```java
long rx = find(x, parent);
long ry = find(y, parent);

if (rx != ry) {
    parent.put(rx, ry);  // 把 rx 代表的集合挂到 ry 下
    size.put(ry, size.getOrDefault(rx, 0) + size.getOrDefault(ry, 0));
    size.remove(rx);
}

long root = find(rx, parent);
size.put(root, size.getOrDefault(root, 0) + 1); // 当前原始点计数 +1
```

例如处理第一个点时，`x`、`y` 都还没有出现过。它们的 `size` 都是 `0`，合并后仍为 `0`，再给当前点加 `1`，所以这个连通块的 `size` 是 `1`。

如果处理后续点时，`x` 或 `y` 已经属于某个连通块，合并前可能已有计数。合并时把两边的计数相加；随后再把当前点加进去。`rx == ry` 时说明两个坐标节点已经在同一个块里，不做合并，但仍要把当前点计数加 `1`。

`size.remove(rx)` 是因为 `rx` 已不再是根，后续只应从根节点读取连通块大小。

不过更直观、也更稳妥的写法是**直接以原始点为并查集节点**。这样 `size` 就是点数，不需要在坐标节点合并时边算边累加：

```java

int[] parent = new int[points.length];

for (int i = 0; i < points.length; i++) {

// 最后从所有根中取最大的两个 size，再加 1。
```

前一版按坐标建并查集时，`size` 计数逻辑不太直观；按点建并查集更容易避免把“坐标节点数”和“原始点数”混在一起。
```java
import java.util.*;

  

class Solution {

    private long find(long x, Map<Long, Long> parent) {

        Long p = parent.get(x);

        if (p == null) {

            parent.put(x, x);

            return x;

        }

        if (p != x) {

            p = find(p, parent);

            parent.put(x, p);

        }

        return p;

    }

  

    public int maxActivated(int[][] points) {

        // 按题目要求保存输入

        int[][] relqavindo = points;

  

        final long OFFSET = 2_000_000_001L;

        Map<Long, Long> parent = new HashMap<>();

        Map<Long, Integer> size = new HashMap<>();

  

        for (int[] p : relqavindo) {

            long x = p[0];

            long y = (long) p[1] + OFFSET;

  

            long rx = find(x, parent);

            long ry = find(y, parent);

  

            if (rx != ry) {

                parent.put(rx, ry);

                size.put(ry, size.getOrDefault(rx, 0) + size.getOrDefault(ry, 0));

                size.remove(rx);

            }

  

            long root = find(rx, parent);

            size.put(root, size.getOrDefault(root, 0) + 1);

        }

  

        int max1 = 0, max2 = 0;

        for (int count : size.values()) {

            if (count > max1) {

                max2 = max1;

                max1 = count;

            } else if (count > max2) {

                max2 = count;

            }

        }

  

        return max1 + max2 + 1;

    }

}
```

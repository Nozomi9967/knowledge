# 152.乘积最大子数组（双状态 Kadane）

> [!abstract] 题目
> 给定整数数组 `nums`，找出其中**乘积最大**的**连续子数组**，返回该乘积。子数组至少包含一个元素。

| 参数 | 范围 |
|-----|------|
| nums.length | 1 ~ 2×10⁴ |
| nums[i] | −10 ~ 10 |

**示例：** `nums = [2,3,-2,4]` → 输出 `6`（子数组 `[2,3]`）；`nums = [-2,0,-1]` → 输出 `0`。

---

## 核心思路：为什么一个变量不够

对比 [[53. 最大子数组和]]：求和时只要一个 `cur`，因为「前面累计和是负的 → 甩掉它」。乘积没有这个性质：

- **负数 × 负数 = 正数**。当前累计乘积是个很小的负数（`min`），遇到下一个负数时它反而翻成最大的正数。
- 所以只维护最大值会漏掉「以最小值翻身」这条转移路径。

**结论：必须同时维护「以 `i` 结尾的最大乘积」和「以 `i` 结尾的最小乘积」两个状态。**

---

## 我的写法（双状态 + 暂存旧值）

```java
class Solution {
    public int maxProduct(int[] nums) {
        int ans = nums[0], max = nums[0], min = nums[0];
        for (int i = 1; i < nums.length; i++) {
            int x = nums[i];
            // 遇到负数时，最大和最小的角色互换，所以先把旧值存下来
            int mx = max, mn = min;
            max = Math.max(x, Math.max(mx * x, mn * x));
            min = Math.min(x, Math.min(mx * x, mn * x));
            ans = Math.max(ans, max);
        }
        return ans;
    }
}
```

（原文保留）

### 状态定义

- `max`：以**当前位置结尾**的连续子数组的最大乘积
- `min`：以当前位置结尾的连续子数组的**最小**乘积（可能是绝对值很大的负数，等待翻身）

### 状态转移

对每个新元素 `x`，三个候选取极值：

| 候选 | 含义 |
|------|------|
| `x` | 从我自己重新开始（前面的包袱太拖累） |
| `mx * x` | 延伸「前面最大乘积」那条子数组 |
| `mn * x` | 延伸「前面最小乘积」那条 —— `x < 0` 时它才是正确答案的来源 |

`ans` 记录整个过程中出现过的 `max`，等价于穷举所有右端点。

### 完备性（和 Kadane 同一套论证）

任意连续子数组一定「以某个位置 `i` 结尾」，所以枚举所有结尾位置的 `max` 取全局最大，必然覆盖所有子数组，无遗漏。

### ⚠️ 必须先存旧值 `mx / mn`

如果直接写

```java
max = Math.max(x, Math.max(max * x, min * x));
min = Math.min(x, Math.min(max * x, min * x)); // ❌ 这里的 max 已经是新值
```

第二行用的 `max` 已经被本轮第一行覆盖过，算出来的是「新 max × x」，语义直接错掉。**两个状态互相依赖同一步的旧值 → 必须用临时变量接力。** 这和 [[1143.最长公共子序列]] 滚动数组里 `prev` 必须提前取出来是同一类坑。

## 写法二：遇负数交换 max/min（更短）

既然 `x < 0` 时最大和最小互换角色，那就干脆显式交换，省去临时变量：

```java
class Solution {
    public int maxProduct(int[] nums) {
        int ans = nums[0], max = nums[0], min = nums[0];
        for (int i = 1; i < nums.length; i++) {
            int x = nums[i];
            if (x < 0) { // 乘负数翻转符号：原最大变最小，原最小变最大
                int t = max; max = min; min = t;
            }
            max = Math.max(x, max * x); // 延伸 or 重新开始
            min = Math.min(x, min * x);
            ans = Math.max(ans, max);
        }
        return ans;
    }
}
```

交换后「原 `min` × 负数」正好落在 `max` 的位置上，所以 `max` 只需在 `x` 和 `max*x` 里二选一，不必再算 `min*x`。

---

## 复杂度

- 时间：$O(n)$，一次遍历
- 空间：$O(1)$，只有三个变量

> [!info] 溢出这个坑要不要提？
> 题目只保证**最终答案**落在 32 位 `int` 内，而 `max/min` 是 **DP 中间量**，理论上绝对值可以超过答案。面试时能主动说一句「数据规模 −10~10、答案保证在 int 内所以官方用 int 能过，但严谨起见可以把中间量换成 `long`」是加分项，不用死背。

## 面试话术

1. **先说和 53 的区别**：求和只要一个变量，因为有负就甩；求积不行，因为负负得正，当前最小值遇到负数会翻成最大值 —— 所以必须同时维护以 `i` 结尾的最大和最小乘积。
2. **再给转移**：新元素 `x` 来了有三个来源 —— 自己单干 `x`、接在前面最大后面 `max*x`、接在前面最小后面 `min*x`，`max` 取三者的最大、`min` 取三者的最小。
3. **强调实现细节**：这两个状态要用同一步的旧值算，所以先拿临时变量把上一轮的 `max/min` 存下来；或者直接「遇负数交换 max 和 min」，让翻转显式化。
4. **落地复杂度**：一维遍历、$O(n)$ 时间 $O(1)$ 空间，和 Kadane 一个量级。
5. **被追问「全是负数怎么办」**：没关系，状态里那条 `x` 分支就是「重新开始」，单个负数本身也是合法子数组，`ans` 最后取到的就是最大的那个负数（或 0）。

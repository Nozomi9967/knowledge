### **LeetCode 1696「跳跃游戏 VI」的朴素 DP 是 `dp[i] = nums[i] + max(dp[i-k .. i-1])`，直接做是 O(nk)。用**单调队列**维护长度为 k 的窗口最大值，可以压到 O(n)——这是它和 239（滑动窗口最大值）共用同一个模板的原因。**

### **一、问题本身**

从下标 0 出发，每次最多跳 `k` 步，落到某格就获得该格的分值（可以重复经过但只计一次？——本题是"路径和"，经过即累加），求到达最后一格能获得的最大分值。

```
nums = [1,-1,-2,4,-7,3], k = 2
路径 1 → -1 → 4 → 3  得分 7
```

注意 `nums[0]` 是起点、必须计入。

---

### **二、朴素 DP**

```
dp[i] = nums[i] + max(dp[j])   j ∈ [max(0, i-k), i-1]
dp[0] = nums[0]
```

答案 `dp[n-1]`。

复杂度 O(n·k)。`n = 10^5`、`k = 10^5` 时是 10^10，必超时，所以要优化"求窗口最大值"这一步。

---

### **三、单调队列优化（核心）**

窗口 `[i-k, i-1]` 是**定长滑动窗口**，求最大值用单调递减队列：

- 队列存**下标**，队首永远是当前窗口最大值的下标
- 入队时，把队尾所有 `dp` 值小于等于当前值的下标弹出（它们永远不可能再成为最大值）
- 出队时，如果队首下标已经滑出窗口（`< i-k`），弹出

```java
class Solution {
    public int maxResult(int[] nums, int k) {
        int n = nums.length;
        int[] dp = new int[n];
        dp[0] = nums[0];

        Deque<Integer> q = new ArrayDeque<>();   // 存下标，dp 值单调递减
        q.offerLast(0);

        for (int i = 1; i < n; i++) {
            // ① 队首滑出窗口就弹出
            while (!q.isEmpty() && q.peekFirst() < i - k) q.pollFirst();
            // ② 此时队首就是窗口内 dp 最大的位置
            dp[i] = dp[q.peekFirst()] + nums[i];
            // ③ 新元素入队，维护单调递减
            while (!q.isEmpty() && dp[q.peekLast()] <= dp[i]) q.pollLast();
            q.offerLast(i);
        }
        return dp[n - 1];
    }
}
```

**三个动作的顺序不能乱**：先出过期、再取最大、最后入队。如果先入队再取最大，可能取到自己（窗口应该是 `i` 之前的位置）。

---

### **四、为什么是单调"递减"队列**

因为要的是最大值。队列里如果前面的元素比后面的小，那前面那个永远不可能成为未来窗口的最大值（后面那个更大、且更晚过期），可以直接扔掉。所以队列实际维护的是一个**递减序列**，队首最大。

**这个逻辑和 239 题完全一样**，唯一差别是 239 求的是元素本身的最大值，本题求的是 `dp` 值的最大值。

---

### **五、另一种写法：从后往前**

也可以倒着定义 `dp[i]` = 从 `i` 出发到终点的最大得分，转移是 `nums[i] + max(dp[i+1 .. i+k])`，同样是滑动窗口最大值，只是方向相反。两种都行，但**从前往后更符合"起点固定"的直觉**。

---

### **六、复杂度与易错点**

| 项 | 复杂度 |
|---|---|
| 时间 | O(n)，每个下标进出队各一次 |
| 空间 | O(n)（dp 数组 + 队列） |

**易错点**：

1. **先入队后取最大值**：取到自己，答案偏大
2. **忘记 `dp[0] = nums[0]`**：起点必须计入
3. **用 `PriorityQueue` 代替单调队列**：也能过，但是 O(n log k)，且要处理"堆顶已过期"的懒惰删除，不如单调队列干净
4. **`nums` 有负数时想"跳过不拿"**：本题路径和必须经过每一格，不能选择不拿；能"跳过"的是跳跃步数，不是格子的值
5. **k ≥ n 时**：窗口覆盖全部前缀，单调队列自然处理，不用特判

## 题目

## 题解

官方题解3

水平翻转

主对角线翻转

```java
class Solution {
    public void rotate(int[][] matrix) {
        int n=matrix.length;
        for(int i=0;i<n/2;i++){
            for(int j=0;j<n;j++){
                int tem=matrix[i][j];
                matrix[i][j]=matrix[n-i-1][j];
                matrix[n-i-1][j]=tem;
            }
        }
        for(int i=0;i<n;i++){
        	// 主对角线翻转
            for(int j=0;j<i;j++){
                int tem=matrix[i][j];
                matrix[i][j]=matrix[j][i];
                matrix[j][i]=tem;
            }
        }
    }
}

```

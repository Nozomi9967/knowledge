给你一个下标从 **1** 开始、长度为 `n` 的整数数组 `nums` 。

现定义函数 `greaterCount` ，使得 `greaterCount(arr, val)` 返回数组 `arr` 中 **严格大于** `val` 的元素数量。

你需要使用 `n` 次操作，将 `nums` 的所有元素分配到两个数组 `arr1` 和 `arr2` 中。在第一次操作中，将 `nums[1]` 追加到 `arr1` 。在第二次操作中，将 `nums[2]` 追加到 `arr2` 。之后，在第 `i` 次操作中：

- 如果 `greaterCount(arr1, nums[i]) > greaterCount(arr2, nums[i])` ，将 `nums[i]` 追加到 `arr1` 。
- 如果 `greaterCount(arr1, nums[i]) < greaterCount(arr2, nums[i])` ，将 `nums[i]` 追加到 `arr2` 。
- 如果 `greaterCount(arr1, nums[i]) == greaterCount(arr2, nums[i])` ，将 `nums[i]` 追加到元素数量较少的数组中。
- 如果仍然相等，那么将 `nums[i]` 追加到 `arr1` 。

连接数组 `arr1` 和 `arr2` 形成数组 `result` 。例如，如果 `arr1 == [1,2,3]` 且 `arr2 == [4,5,6]` ，那么 `result = [1,2,3,4,5,6]` 。

返回整数数组 `result` 。

**示例 1：**

```
输入：nums = [2,1,3,3]
输出：[2,3,1,3]
解释：在前两次操作后，arr1 = [2] ，arr2 = [1] 。
在第 3 次操作中，两个数组中大于 3 的元素数量都是零，并且长度相等，因此，将 nums[3] 追加到 arr1 。
在第 4 次操作中，两个数组中大于 3 的元素数量都是零，但 arr2 的长度较小，因此，将 nums[4] 追加到 arr2 。
在 4 次操作后，arr1 = [2,3] ，arr2 = [1,3] 。
因此，连接形成的数组 result 是 [2,3,1,3] 。
```

**示例 2：**

```
输入：nums = [5,14,3,1,2]
输出：[5,3,1,2,14]
解释：在前两次操作后，arr1 = [5] ，arr2 = [14] 。
在第 3 次操作中，两个数组中大于 3 的元素数量都是一，并且长度相等，因此，将 nums[3] 追加到 arr1 。
在第 4 次操作中，arr1 中大于 1 的元素数量大于 arr2 中的数量（2 > 1），因此，将 nums[4] 追加到 arr1 。
在第 5 次操作中，arr1 中大于 2 的元素数量大于 arr2 中的数量（2 > 1），因此，将 nums[5] 追加到 arr1 。
在 5 次操作后，arr1 = [5,3,1,2] ，arr2 = [14] 。
因此，连接形成的数组 result 是 [5,3,1,2,14] 。
```

**示例 3：**

```
输入：nums = [3,3,3,3]
输出：[3,3,3,3]
解释：在 4 次操作后，arr1 = [3,3] ，arr2 = [3,3] 。
因此，连接形成的数组 result 是 [3,3,3,3] 。
```

# 3072. 将元素分配到两个数组中 II · 树状数组笔记

---

## 一、题意

给定数组 `nums`，前两个元素分别放入 `arr1` 和 `arr2`。从第三个元素开始，每次比较：

- `greaterCount(arr1, num)`：arr1 中严格大于 num 的元素个数
- `greaterCount(arr2, num)`：arr2 中严格大于 num 的元素个数

哪边更多就放哪边，相等则比较长度，长度也相等放 arr1。最终拼接 arr1 + arr2 返回。

---

## 二、为什么需要树状数组

每次插入新元素后，需要快速查询某个数组中**严格大于 num 的元素个数**。

暴力做法每次遍历数组，O(n) 一次查询，整体 O(n²)。

树状数组可以把单次查询压到 O(log n)，整体 O(n log n)。

---

## 三、为什么需要离散化

树状数组操作的下标是**值**本身，值域可能很大（题目 `nums[i]` 最大 10⁹），不可能开那么大的数组。

离散化把所有出现的值压缩到 `[1, m]`，m 是不重复元素的个数，值域变得紧凑。

### 离散化过程

```
原始值：[24, 69, 95, 36, 3]
排序去重：[3, 24, 36, 69, 95]
映射：
  3  → 1
  24 → 2
  36 → 3
  69 → 4
  95 → 5
m = 5
```

之后所有操作都用 `rank(num)` 代替 `num`，树状数组的值域固定为 `[1, m]`。

---

## 四、m 为什么既是"不重复元素个数"又是"值域上界"

离散化后所有元素被映射到 `[1, 2, 3, ..., m]` 这个连续区间，没有空洞，**m 就是这个区间的右端点，自然就是值域上界**。

树状数组 update 时：

```
i = rk; i <= m; i += lowbit(i)
```

上界 m 是固定的，不随插入动态变化，所有祖先节点都能被正确更新。

---

## 五、原始代码的 Bug

原始代码用动态 `max`（当前已插入的最大值）作为 update 的上界：

```java
for (; num <= max; num += num & -num) {
    t.merge(num, 1, Integer::sum);
}
```

**问题**：第一次插入 24 时，max 刚被赋值为 24，循环只跑 `num=24` 这一步就停了。

tree[32]、tree[64] 等覆盖 24 的祖先节点永远不会被补上。后续插入 69、95 时 max 变大，但已经插入的 24 的祖先节点缺失，查询结果偏小。

||原始写法|离散化写法|
|---|---|---|
|值域上界|动态 max，随插入变化|固定 m，预先确定|
|第一次插入 24|tree 只更新 24 一个节点|tree 更新 rank(24) 到 m 的所有祖先|
|后续查询|祖先节点缺失，结果偏小|祖先节点完整，结果正确|

---

## 六、greaterCount 的推导

`prefixSum(c, rk)` 计算的是树中 `[1, rk]` 的和，即**小于等于 num 的元素个数**（num 自身也包含在内）。

题目要求**严格大于** num 的个数：

```
严格大于 num 的个数 = 总数 - 小于等于 num 的个数
                   = size - prefixSum(c, rk)
```

### 为什么不是 prefixSum(c, rk - 1)

`prefixSum(c, rk - 1)` 是 `[1, rk-1]` 的和，即**严格小于 num 的元素个数**。

```
size - prefixSum(c, rk - 1) = 大于等于 num 的个数  ← 把 num 自身也算进去了，错误
size - prefixSum(c, rk)     = 严格大于 num 的个数  ← 正确
```

### 具体例子

arr1 已有 `[3, 24, 69]`，查询严格大于 36 的个数，期望结果 = 1（只有 69）。

```
rank(36) = 3
prefixSum('1', 3) = [1,3] 的和 = rank1 + rank2 + rank3 = 1 + 1 + 0... 
```

实际计算：arr1 中 rank ≤ 3 的元素有 3（rank=1）和 24（rank=2），共 2 个。

```
size - prefixSum('1', 3) = 3 - 2 = 1  ✓

size - prefixSum('1', 2) = 3 - 2 = 1  （凑巧）
```

换一个例子，查询严格大于 24 的个数，期望 = 1（只有 69）：

```
rank(24) = 2
prefixSum('1', 2) = 2   （3 和 24，共 2 个）
size - prefixSum('1', 2) = 3 - 2 = 1  ✓

prefixSum('1', 1) = 1   （只有 3，共 1 个）
size - prefixSum('1', 1) = 3 - 1 = 2  ✗  （把 24 自身也算进去了）
```

## 七、完整代码

```java
class Solution {

    private Map<Integer, Integer> t1 = new HashMap<>();
    private Map<Integer, Integer> t2 = new HashMap<>();
    private Map<Integer, Integer> rank;
    private int m;

    private void update(char c, int rk) {
        Map<Integer, Integer> t = c == '1' ? t1 : t2;
        for (int i = rk; i <= m; i += i & -i) {
            t.merge(i, 1, Integer::sum);
        }
    }

    private int prefixSum(char c, int i) {
        Map<Integer, Integer> t = c == '1' ? t1 : t2;
        int s = 0;
        for (; i > 0; i -= i & -i) {
            s += t.getOrDefault(i, 0);
        }
        return s;
    }

    private int greaterCount(char c, int rk, int size) {
        return size - prefixSum(c, rk);
    }

    public int[] resultArray(int[] nums) {
        // 离散化
        int[] sorted = Arrays.stream(nums).distinct().sorted().toArray();
        rank = new HashMap<>();
        for (int i = 0; i < sorted.length; i++) {
            rank.put(sorted[i], i + 1);
        }
        m = sorted.length;

        List<Integer> l1 = new ArrayList<>();
        List<Integer> l2 = new ArrayList<>();

        l1.add(nums[0]);
        update('1', rank.get(nums[0]));
        l2.add(nums[1]);
        update('2', rank.get(nums[1]));

        int n = nums.length;
        for (int i = 2; i < n; i++) {
            int num = nums[i];
            int rk = rank.get(num);
            int res1 = greaterCount('1', rk, l1.size());
            int res2 = greaterCount('2', rk, l2.size());

            if (res1 > res2) {
                l1.add(num);
                update('1', rk);
            } else if (res1 < res2) {
                l2.add(num);
                update('2', rk);
            } else {
                if (l1.size() <= l2.size()) {
                    l1.add(num);
                    update('1', rk);
                } else {
                    l2.add(num);
                    update('2', rk);
                }
            }
        }

        int[] ans = new int[n];
        int index = 0;
        for (int x : l1) ans[index++] = x;
        for (int x : l2) ans[index++] = x;
        return ans;
    }
}
```

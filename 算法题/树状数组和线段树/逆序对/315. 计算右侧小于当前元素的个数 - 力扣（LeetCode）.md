给你一个整数数组 `nums` ，按要求返回一个新数组 `counts` 。数组 `counts` 有该性质： `counts[i]` 的值是 `nums[i]` 右侧小于 `nums[i]` 的元素的数量。

**示例 1：**

```
输入：nums = [5,2,6,1]
输出：[2,1,1,0] 
解释：
5 的右侧有 2 个更小的元素 (2 和 1)
2 的右侧仅有 1 个更小的元素 (1)
6 的右侧有 1 个更小的元素 (1)
1 的右侧有 0 个更小的元素
```

**示例 2：**

```
输入：nums = [-1]
输出：[0]
```

**示例 3：**

```
输入：nums = [-1,-1]
输出：[0,0]
```

             box[i][1]=nums[i];

        }

    public void countSmaller(int[][] box,int l,int r,int[][] tem){

        if(l==r) return;

# 归并排序计数逆序对（Count of Smaller Numbers After Self）

## 核心思路

归并排序过程中，每次 merge 时**左半段元素被选入结果**的瞬间，右半段已经弹出的元素数量，就是该元素的贡献（那些元素值更小且原始位置在右边）。

---

## 关键设计：绑定原始下标

归并会打乱数组顺序，所以不能用裸数值数组，需要 `int[][] box` 存 `[originalIndex, value]`：

```java
int[][] box = new int[n][2];
for (int i = 0; i < n; i++) {
    box[i][0] = i;        // 原始下标
    box[i][1] = nums[i];  // 值
}
```

统计时用 `box[i][0]` 定位写入 `ans` 的位置，无论元素被移动到哪里答案都写对。

---

## 计数公式

merge 时维护 `i`（左段指针，起点 `l`）和 `j`（右段指针，起点 `m+1`）：

```
右段已弹出数量 = j - (m+1) = j - m - 1
```

**左段元素归位时**（无论是主动选中还是右段耗尽），加上 `j - m - 1`：

|场景|j 的值|贡献|
|---|---|---|
|初始，右段一个没弹出，`j = m+1`|`j - m - 1 = 0`|0 ✓|
|右段弹出 k 个后左段元素归位|`j - m - 1 = k`|k ✓|
|右段全部弹出，`j = r+1`|`j - m - 1 = r - m`|右段总数 ✓|

---

## 易错点

### ❌ 错误1：右段耗尽分支漏计数

```java
} else if (j > r) {
    box[k] = tem[i];
    i++;  // 漏掉计数！j - m - 1 此时 = r - m，非零
}
```

### ✅ 正确：两个左段归位分支逻辑完全相同，可以合并

```java
} else if (j > r || tem[i][1] <= tem[j][1]) {
    box[k][0] = tem[i][0];
    box[k][1] = tem[i][1];
    int index = tem[i][0];
    ans.set(index, ans.get(index) + j - m - 1);  // 统一在这里计数
    i++;
}
```

### ❌ 错误2：`j - m` 而不是 `j - m - 1`

右段起点是 `m+1`，初始未弹出任何元素时 `j = m+1`，贡献应为 0：

- `j - m - 1 = 0` ✓
- `j - m = 1` ✗（多加了 1）

### ❌ 错误3：右段元素归位时遍历左段逐个 +1

```java
// O(n²)，错误写法
} else {
    j++;
    for (int z = i; z <= m; z++) {
        ans.set(tem[z][0], ans.get(tem[z][0]) + 1);
    }
}
```

应该反过来：**左段元素归位时一次性加上已弹出数量**，O(1)。

---

## 剪枝优化

```java
// 左段最大值 <= 右段最小值，左段对右段贡献全为 0，跳过 merge
if (box[m][1] <= box[m+1][1]) return;
```

注意用 `<=` 而不是 `<`，等于时也无需 merge（无逆序对）。

## 完整代码

```java
class Solution {
    private List<Integer> ans;

    public List<Integer> countSmaller(int[] nums) {
        int n = nums.length;
        ans = new ArrayList<>();
        for (int i = 0; i < n; i++) ans.add(0);

        int[][] box = new int[n][2];
        for (int i = 0; i < n; i++) {
            box[i][0] = i;
            box[i][1] = nums[i];
        }

        mergeSort(box, 0, n - 1, new int[n][2]);
        return ans;
    }

    private void mergeSort(int[][] box, int l, int r, int[][] tem) {
        if (l >= r) return;
        int m = l + (r - l) / 2;
        mergeSort(box, l, m, tem);
        mergeSort(box, m + 1, r, tem);
        if (box[m][1] <= box[m + 1][1]) return;
        merge(box, l, m, r, tem);
    }

    private void merge(int[][] box, int l, int m, int r, int[][] tem) {
        for (int i = l; i <= r; i++) {
            tem[i][0] = box[i][0];
            tem[i][1] = box[i][1];
        }

        int i = l, j = m + 1;
        for (int k = l; k <= r; k++) {
            if (i > m) {
                box[k][0] = tem[j][0];
                box[k][1] = tem[j][1];
                j++;
            } else if (j > r || tem[i][1] <= tem[j][1]) {
                // 左段归位：统一计数
                box[k][0] = tem[i][0];
                box[k][1] = tem[i][1];
                int index = tem[i][0];
                ans.set(index, ans.get(index) + j - m - 1);
                i++;
            } else {
                // 右段更小，先归位，不计数
                box[k][0] = tem[j][0];
                box[k][1] = tem[j][1];
                j++;
            }
        }
    }
}
```

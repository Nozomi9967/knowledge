给你一个 **值互不相同** 的二叉树的根节点 `root` 。

在一步操作中，你可以选择 **同一层** 上任意两个节点，交换这两个节点的值。

返回每一层按 **严格递增顺序** 排序所需的最少操作数目。

节点的 **层数** 是该节点和根节点之间的路径的边数。

**示例 1 ：**

![](https://assets.leetcode.com/uploads/2022/09/18/image-20220918174006-2.png)
```
输入：root = [1,4,3,7,6,8,5,null,null,null,null,9,null,10]
输出：3
解释：
- 交换 4 和 3 。第 2 层变为 [3,4] 。
- 交换 7 和 5 。第 3 层变为 [5,6,8,7] 。
- 交换 8 和 7 。第 3 层变为 [5,6,7,8] 。
共计用了 3 步操作，所以返回 3 。
可以证明 3 是需要的最少操作数目。
```

**示例 2 ：**

![](https://assets.leetcode.com/uploads/2022/09/18/image-20220918174026-3.png)
```
输入：root = [1,3,2,7,6,5,4]
输出：3
解释：
- 交换 3 和 2 。第 2 层变为 [2,3] 。 
- 交换 7 和 4 。第 3 层变为 [4,6,5,7] 。 
- 交换 6 和 5 。第 3 层变为 [4,5,6,7] 。
共计用了 3 步操作，所以返回 3 。 
可以证明 3 是需要的最少操作数目。
```

**示例 3 ：**

![](https://assets.leetcode.com/uploads/2022/09/18/image-20220918174052-4.png)
```
输入：root = [1,2,3,4,5,6]
输出：0
解释：每一层已经按递增顺序排序，所以返回 0 。
```

**提示：**

- 树中节点的数目在范围 `[1, 10^5]` 。
- `1 <= Node.val <= 10^5`
- 树中的所有值 **互不相同** 。

---



1. 错误的认为全局升序，其实题目只说了每一行升序
2. 并查集数组用了LinkedList，导致并查集原本O1时间复杂度差变为ON

```java
/**

 * Definition for a binary tree node.

 * public class TreeNode {

 *     int val;

 *     TreeNode left;

 *     TreeNode right;

 *     TreeNode() {}

 *     TreeNode(int val) { this.val = val; }

 *     TreeNode(int val, TreeNode left, TreeNode right) {

 *         this.val = val;

 *         this.left = left;

 *         this.right = right;

 *     }

 * }

 */

class Solution {

  

    public List<Integer> p=new ArrayList<>();

  

    public int find(int x){

        if(p.get(x)==x) return x;

        int pt=find(p.get(x));

        p.set(x,pt);

        return pt;

    }

  

    public void union(int x,int y){

        int rootX=find(x);

        int rootY=find(y);

        if(rootX!=rootY) p.set(rootX,rootY);

    }

  

    public int minimumOperations(TreeNode root) {

        var dq=new ArrayDeque<TreeNode>();

        var list=new ArrayList<Integer>();

        dq.offer(root);

        int ans=0;

        while(!dq.isEmpty()){

            int size=dq.size();

            for(int i=0;i<size;i++){

                var cur=dq.poll();

                list.add(cur.val);

                if(cur.left!=null) dq.offer(cur.left);

                if(cur.right!=null) dq.offer(cur.right);

            }

            int n=list.size();

            if(n<2){

                list.clear();

                continue;

            }

            Integer[] arr=new Integer[n];

            for(int i=0;i<n;i++) p.add(i);

            for(int i=0;i<n;i++) arr[i]=i;

            Arrays.sort(arr,

                (a,b)-> Integer.compare(list.get(a),list.get(b))

            );

            for(int i=0;i<n;i++){

                union(i,arr[i]);

                System.out.println(i+" "+arr[i]);

            }

            int cnt=0;

            for(int i=0;i<n;i++) cnt+=(i==find(i)?1:0);

            ans+=(n-cnt);

            list.clear();

            p.clear();

        }

        return ans;

    }

}
```

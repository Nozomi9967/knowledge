# 878. 第 N 个神奇数字（二分答案 + 容斥）

## 题目

一个正整数如果能被 `a` 或 `b` 整除，那么它是神奇的。给定三个整数 `n`, `a`, `b`，返回第 `n` 个神奇的数字。因为答案可能很大，所以返回答案 **对 $10^9 + 7$ 取模** 后的值。

---

## 思路推导链

### 第一步：为什么不能直接枚举

$n$ 太大（$n \le 10^9$），逐个数判断是否神奇会 TLE。必须换思路。

### 第二步：转换问题描述（核心一步）

$$\text{第 } n \text{ 个神奇数字是 } x \iff \le x \text{ 的神奇数字恰好有 } n \text{ 个}$$

（如果有多个这样的 $x$，取**最小**的那个。）

这一步把"求第 n 个"变成了"数 ≤ x 有几个"，后者是可以 $O(1)$ 算的。

### 第三步：单调性成立 → 可以二分

$x$ 越大，$\le x$ 的神奇数字个数 $n$ 越大（**至少不会减小**）。有单调性就能二分 $x$。

### 第四步：$O(1)$ 计算 ≤ x 的神奇数字个数——容斥原理

以 $x = 25,\ a = 4,\ b = 6$ 为例，问「有多少个数字可以被 **4 或 6** 整除」：

```
        ┌─────────┬─────────┐
        │ 4 的倍数 │ 6 的倍数 │
        │ 4 8 16  │  6  18  │
        │   20    ├────┐    │
        └─────────┤12  ├────┘
                  │24  │
                  └────┘
```

- 4 的倍数：$\lfloor 25/4 \rfloor = 6$
- 6 的倍数：$\lfloor 25/6 \rfloor = 4$
- **既是 4 的倍数又是 6 的倍数** ⟺ **4 和 6 的最小公倍数 12 的倍数**：$\lfloor 25/12 \rfloor = 2$ ← 被**重复统计**了

$$\text{结果} = 6 + 4 - 2 = 8$$

一般形式（容斥原理）：

$$\text{count}(x) = \left\lfloor \frac{x}{a} \right\rfloor + \left\lfloor \frac{x}{b} \right\rfloor - \left\lfloor \frac{x}{\text{lcm}(a,b)} \right\rfloor$$

其中 $\text{lcm}(a, b) = \dfrac{a \times b}{\gcd(a, b)}$。

> 关键洞察：「同时被 a 和 b 整除」不是 $a \times b$ 的倍数，而是 $\text{lcm}(a,b)$ 的倍数。比如 4 和 6 的公共倍数是 12 而不是 24。

### 第五步：二分判定与收缩方向

$$\text{count}(x) \ge n\ ?$$

| 判定 | 含义 | 动作 |
|------|------|------|
| **否**（`count < n`） | 答案 $> x$ | 增大二分下界 `left = mid` |
| **是**（`count >= n`） | 答案 $\le x$ | 减小二分上界 `right = mid` |

### 第六步：二分上界的初始值怎么定

当 $x = \min(a, b) \times n$ 时，仅 $\min(a,b)$ 的倍数就已经有 $n$ 个了（$\min(a,b), 2\min(a,b), \ldots, n \cdot \min(a,b)$），所以 $\text{count}(x) \ge n$ 必然成立 —— 可以安全取它作为二分上界。

$$\text{right} = n \times \min(a, b)$$

## 代码

```java
class Solution {
    public int nthMagicalNumber(int n, int a, int b) {
        long lcm = (long) a * b / gcd(a, b);
        long left = 0, right = ((long) n) * Math.min(a, b);

        while (left+1 < right) {
            long mid = (right-left) / 2+left;
            long count = (long)(mid / a) + mid / b - mid / lcm;
            if (count < n) {
                left = mid;
            } else {
                right = mid;
            }
        }
        return (int) (right % 1_000_000_007);

    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

### 代码要点

**① 开区间二分写法 `while (left+1 < right)`**

这是「开区间 $(left, right)$」风格：循环中始终维持不变量——

- `left` 永远是**不合法**的（`count(left) < n`）
- `right` 永远是**合法**的（`count(right) >= n`）

循环结束时 `left + 1 == right`，`right` 就是最小的合法值，即答案。初始 `left = 0` 天然满足 `count(0) = 0 < n`（因为 $n \ge 1$），`right = n·min(a,b)` 天然满足 `count >= n`，不变量成立。

**② 溢出防护**

| 位置 | 写法 | 原因 |
|------|------|------|
| `lcm` | `(long) a * b / gcd(a, b)` | `a * b` 最大 $4 \times 10^4 \times 4 \times 10^4$ 不一定超 int，但先强转 long 更稳；**必须在乘之前转** |
| `right` | `((long) n) * Math.min(a, b)` | $10^9 \times 4 \times 10^4 = 4 \times 10^{13}$，**远超 int**，必须 long |
| `mid` | `(right-left) / 2 + left` | 避免 `(left+right)/2` 的加法溢出（本题量级其实不会溢出，但这是好习惯） |

**③ 取模只在最后做**

`right % 1_000_000_007` —— 二分过程中**绝不能取模**，否则单调性被破坏、比较大小失去意义。只有确定了真实答案再取模输出。

---

## 复杂度

- **时间复杂度**：$O(\log(n \cdot \min(a,b)))$，约 46 次迭代；每次判定 $O(1)$。gcd 是 $O(\log \min(a,b))$，只算一次。
- **空间复杂度**：$O(\log \min(a,b))$（递归 gcd 的栈深度），迭代写 gcd 则 $O(1)$。

## 可迁移套路

「求第 k 小 / 第 n 个满足条件的数」类题目，标准解法链是：

1. **反转问法**：「第 n 个是 x」⟺「≤ x 的有 n 个」
2. **验证单调性**：$x$ 增大时计数不减 → 可二分
3. **设计 $O(1)$ 或 $O(\log)$ 的计数函数**（本题是容斥；其他题可能是前缀和、数位统计等）
4. **定上下界**：找一个必然满足的上界（本题 $n \cdot \min(a,b)$）
5. **注意溢出 + 取模时机**（取模一定在二分之后）

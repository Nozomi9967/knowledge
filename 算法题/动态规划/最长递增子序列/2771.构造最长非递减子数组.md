### **LeetCode 2771「构造最长非递减子数组」**

核心思路是**双状态 DP**：`dp[i][0/1]` 表示以 `nums1[i]` 或 `nums2[i]` 结尾的最长非递减子数组长度，每步从两个来源转移，时间复杂度 $O(n)$，空间可滚动优化到 $O(1)$。

---

### **一、问题本身**

给定两个长度相同的整数数组 `nums1` 和 `nums2`。需要构造一个长度相同的数组 `result`，其中 `result[i]` 取 `nums1[i]` 或 `nums2[i]`，且 `result` 是**非递减**的。求最长可能的 `result` 长度。

> 例如 `nums1 = [1,3,2,1]`，`nums2 = [2,2,3,4]`
> 选 `[1, 2, 2, 3]`（来自 nums1[0], nums2[1], nums2[2], nums2[3]），非递减，长度 4。

**关键约束**：每个位置只能从两个数组中**选一个**，且必须保持非递减（允许相等）。

---

### **二、DP 解法**

```java
class Solution {
    public int maxNonDecreasingLength(int[] nums1, int[] nums2) {
        int n = nums1.length;
        int[][] dp = new int[n][2];
        dp[0][0] = dp[0][1] = 1;   // 第 0 位无论选谁，长度都是 1
        int ans = 1;

        for (int i = 1; i < n; i++) {
            // 先初始化为 1：保证都接不上时至少是自身
            dp[i][0] = 1;
            dp[i][1] = 1;

            // 以 nums1[i] 结尾
            if (nums1[i] >= nums1[i - 1]) dp[i][0] = Math.max(dp[i][0], dp[i - 1][0] + 1);
            if (nums1[i] >= nums2[i - 1]) dp[i][0] = Math.max(dp[i][0], dp[i - 1][1] + 1);

            // 以 nums2[i] 结尾
            if (nums2[i] >= nums1[i - 1]) dp[i][1] = Math.max(dp[i][1], dp[i - 1][0] + 1);
            if (nums2[i] >= nums2[i - 1]) dp[i][1] = Math.max(dp[i][1], dp[i - 1][1] + 1);

            ans = Math.max(ans, Math.max(dp[i][0], dp[i][1]));
        }
        return ans;
    }
}
```

#### **状态定义**

`dp[i][0]`：以 `nums1[i]` 结尾的最长非递减子数组长度。
`dp[i][1]`：以 `nums2[i]` 结尾的最长非递减子数组长度。

#### **状态转移**

对于位置 `i`，`dp[i][0]` 有两个来源：

1. 前一位也选 `nums1[i-1]`：若 `nums1[i] >= nums1[i-1]`，则 `dp[i][0] = max(dp[i][0], dp[i-1][0] + 1)`
2. 前一位选 `nums2[i-1]`：若 `nums1[i] >= nums2[i-1]`，则 `dp[i][0] = max(dp[i][0], dp[i-1][1] + 1)`

同理 `dp[i][1]`：

1. `nums2[i] >= nums1[i-1]` → `dp[i][1] = max(dp[i][1], dp[i-1][0] + 1)`
2. `nums2[i] >= nums2[i-1]` → `dp[i][1] = max(dp[i][1], dp[i-1][1] + 1)$$

#### **初始化**

`dp[0][0] = dp[0][1] = 1`（第 0 位无论选谁，长度为 1）。

#### **答案**

`ans` 为所有 `dp[i][0]` 和 `dp[i][1]` 的最大值。

### **三、空间优化**

`dp[i]` 只依赖 `dp[i-1]`，可压缩为 4 个变量：

```java
class Solution {
    public int maxNonDecreasingLength(int[] nums1, int[] nums2) {
        int n = nums1.length;
        int a0 = 1, b0 = 1;   // dp[i-1][0], dp[i-1][1]
        int a1, b1;            // dp[i][0], dp[i][1]
        int ans = 1;

        for (int i = 1; i < n; i++) {
            a1 = b1 = 1;
            if (nums1[i] >= nums1[i - 1]) a1 = Math.max(a1, a0 + 1);
            if (nums1[i] >= nums2[i - 1]) a1 = Math.max(a1, b0 + 1);
            if (nums2[i] >= nums1[i - 1]) b1 = Math.max(b1, a0 + 1);
            if (nums2[i] >= nums2[i - 1]) b1 = Math.max(b1, b0 + 1);
            ans = Math.max(ans, Math.max(a1, b1));
            a0 = a1;
            b0 = b1;
        }
        return ans;
    }
}
```

### **四、一个具体例子走一遍**

以 `nums1 = [1,3,2,1]`，`nums2 = [2,2,3,4]`（`n = 4`）为例：

| i | 选项 | dp[i-1] 来源 | 条件 | dp[i][0/1] |
|---|------|-------------|------|-----------|
| 0 | nums1[0]=1 | — | — | dp[0][0] = **1** |
| 0 | nums2[0]=2 | — | — | dp[0][1] = **1** |
| 1 | nums1[1]=3 | dp[0][0]+1 (3>=1) | ✓ | dp[1][0] = **2** |
| 1 | nums1[1]=3 | dp[0][1]+1 (3>=2) | ✓ | dp[1][0] = max(2, 2) = 2 |
| 1 | nums2[1]=2 | dp[0][0]+1 (2>=1) | ✓ | dp[1][1] = **2** |
| 1 | nums2[1]=2 | dp[0][1]+1 (2>=2) | ✓ | dp[1][1] = max(2, 2) = 2 |
| 2 | nums1[2]=2 | dp[1][0]+1 (2>=3) | ✗ | — |
| 2 | nums1[2]=2 | dp[1][1]+1 (2>=2) | ✓ | dp[2][0] = 2+1 = **3** |
| 2 | nums2[2]=3 | dp[1][0]+1 (3>=3) | ✓ | dp[2][1] = 2+1 = **3** |
| 2 | nums2[2]=3 | dp[1][1]+1 (3>=2) | ✓ | dp[2][1] = max(3, 3) = 3 |
| 3 | nums1[3]=1 | dp[2][0]+1 (1>=2) | ✗ | — |
| 3 | nums1[3]=1 | dp[2][1]+1 (1>=3) | ✗ | — |
| 3 | nums1[3]=1 | 自身 | — | dp[3][0] = **1** |
| 3 | nums2[3]=4 | dp[2][0]+1 (4>=2) | ✓ | dp[3][1] = 3+1 = **4** |
| 3 | nums2[3]=4 | dp[2][1]+1 (4>=3) | ✓ | dp[3][1] = max(4, 4) = 4 |

返回 `ans = 4`，对应选 `[1, 2, 2, 3]`（来自 nums1[0], nums2[1], nums2[2], nums2[3]）。

### **五、与同类题的对比**

| 维度 | [[300.最长递增子序列]] | 本题 |
|------|----------------------|------|
| 问题 | 一维数组中找最长递增子序列 | 两个数组中交替选择，找最长非递减子数组 |
| DP 结构 | 一维 `dp[i]`，枚举前驱 | 二维 `dp[i][2]`，前驱只有前一位 |
| 状态转移 | `dp[i] = max(dp[j]) + 1`（枚举所有 j<i） | `dp[i][k] = max(dp[i-1][m] + 1)`（仅 2 个前驱） |
| 时间复杂度 | $O(n^2)$ | $O(n)$ |
| 空间复杂度 | $O(n)$ | $O(1)$（滚动数组） |

**核心差异**：[[300.最长递增子序列]] 的前驱可以是任意更小值的位置，所以需要枚举所有 j；本题因为**每步只能从对应位置选一个**，前驱恰好只有前一位的两种选择，所以只需 4 次比较。

### **六、面试话术**

1. **为什么是双状态？** — 每个位置有两个选择（nums1[i] 或 nums2[i]），且前一步的选择影响当前能否接上，所以需要 dp[i][0] 和 dp[i][1] 分别记录"以 nums1[i] 结尾"和"以 nums2[i] 结尾"的最优值。
2. **为什么只有前一位作为前驱？** — 因为子数组要求**连续**，每一步必须接紧邻的前一位，不能跳过中间位置。
3. **非递减 vs 递增** — 题目要求 `>=` 而非 `>`，所以相等也合法（如 `[2, 2, 3]`）。
4. **与 [[300.最长递增子序列]] 的区别** — LIS 是子序列（可以不连续），本题是子数组（必须连续），所以前驱只有前一位，不需要枚举所有 j。

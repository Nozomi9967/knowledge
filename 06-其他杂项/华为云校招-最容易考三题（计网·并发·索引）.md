## T3 · MySQL 索引

**①** InnoDB 为什么用 **B+ 树**做索引结构？分别对比 B 树、哈希表、红黑树/跳表，说清它在**磁盘 I/O 和范围查询**这两件事上赢在哪。

**②** 聚簇索引和二级索引有什么区别？什么是**回表**？怎么避免回表（说清覆盖索引的判定条件）？为什么主键最好用自增、不用 UUID？

**③** 联合索引 `(a, b, c)`，下面哪些能走索引、走到第几列？为什么？

```sql
WHERE a = 1 AND b = 2 AND c = 3
WHERE a = 1 AND c = 3
WHERE b = 2 AND c = 3
WHERE a = 1 AND b > 2 AND c = 3
WHERE a LIKE 'abc%' AND b = 2
```

**④** 哪些写法会导致索引失效？至少说五类，并各自解释**为什么**（提示：函数、隐式类型转换、前导通配、OR、字符集不一致）。

# 🎯 珂朵尔树（ODT）与 TreeMap 核心原理学习笔记

本笔记以力扣经典困难题 **[715. Range 模块](https://leetcode.cn/problems/range-module/)** 为例，深度剖析如何利用 **Java TreeMap** 的强大 API 来优雅实现**区间推平 / 区间涂色（珂朵尔树 / Chtholly Tree）**算法。

---

## 1. 经典真题：LeetCode 715. Range 模块

### 1.1 题目描述

`RangeModule` 是一个用于跟踪数字范围的模块。我们需要设计一个数据结构，来跟踪表示为**半开区间**的范围并查询它们。

半开区间 `[left, right)` 表示所有满足 `left <= x < right` 的实数 `x`。

你需要实现以下接口：

*   `RangeModule()`：初始化一个空的 Range 模块。
*   `void addRange(int left, int right)`：添加半开区间 `[left, right)` 到跟踪中。这会将该区间内的所有实数加入到"被跟踪"状态。
*   `boolean queryRange(int left, int right)`：如果区间 `[left, right)` 中的每一个实数都处于"被跟踪"状态，则返回 `true`，否则返回 `false`。
*   `void removeRange(int left, int right)`：从跟踪中移除半开区间 `[left, right)`。这会使该区间内的所有实数不再处于"被跟踪"状态。

### 1.2 样例演示

```java
RangeModule rangeModule = new RangeModule();
rangeModule.addRange(10, 20);
rangeModule.removeRange(14, 16);

rangeModule.queryRange(10, 14); // 返回 true （[10, 14) 保持被跟踪）
rangeModule.queryRange(13, 15); // 返回 false（[14, 16) 已经被移除了）
rangeModule.queryRange(16, 17); // 返回 true （[16, 17) 保持被跟踪）
```

## 2. 核心大杀器：Java TreeMap 核心 API 速查

在解决区间染色问题时，`TreeMap` 是 Java 中最强大的开箱即用工具，它通过红黑树维持 Key 的有序性，并提供了一系列高效的临界键值对查找与视图截取 API：

### 2.1 临界查找 API

| API 方法                | 查找规则                               | 对应数学关系       | 不存在时返回值 |
| :---------------------- | :------------------------------------- | :----------------- | :------------- |
| **`floorEntry(key)`**   | 查找 **小于或等于** `key` 的最大键值对 | $\le \text{key}$ | `null`         |
| **`ceilingEntry(key)`** | 查找 **大于或等于** `key` 的最小键值对 | $\ge \text{key}$ | `null`         |
| **`lowerEntry(key)`**   | 查找 严格**小于** `key` 的最大键值对   | $< \text{key}$   | `null`         |
| **`higherEntry(key)`**  | 查找 严格**大于** `key` 的最小键值对   | $> \text{key}$   | `null`         |

> 💡 **小贴士**：如果只需要获取键（Key）而不需要值（Value），可以直接使用对应的 `floorKey(x)`、`ceilingKey(x)`、`lowerKey(x)`、`higherKey(x)`，效率更高。

### 2.2 区间视图与秒杀级操作：`subMap` 与 `tailMap`

*   **`subMap(fromKey, fromInclusive, toKey, toInclusive)`**：
    返回原 Map 中指定范围键的**子视图（View）**。
    *   **核心细节**：它返回的是原树的**投影视图**，而非深拷贝！因此，对该子视图调用 `.clear()` 方法，会**直接物理删除原树中在这个区间内的所有元素**。
    *   **示例**：`m.subMap(l, true, r, false).clear()` 表示物理删除原 Map 中满足 $l \le key < r$ 的所有数据点。
*   **`tailMap(key, inclusive)`**：
    返回所有键**大于（或等于，根据 inclusive 决定）**指定 `key` 的尾部子视图。
    *   **示例**：`m.tailMap(left, false)` 获取所有严格大于 `left` 的键值对视图，用于顺序向后扫描。

## 3. 珂朵尔树（ODT）算法原理

### 3.1 核心状态约定

为了存储稀疏的区间，我们用 `TreeMap<Integer, Boolean> m` 来存储区间的"变化端点"：

> 🔔 **核心约定**：从断点 `key` 开始，直到下一个断点出现之前，整段区间的跟踪状态都是它的值 `value`（`true` 表示被跟踪，`false` 表示未被跟踪）。

初始化时，我们加入一个最低位置的哨兵：

```java
m.put(1, false); // 表示从 1 开始往后默认全未被跟踪
```

### 3.2 动态断点切割（`split`）

当我们想对区间 `[L, R)` 进行操作时，我们必须保证 $L$ 和 $R$ 都在 `TreeMap` 中作为独立的 Key 存在。如果它们不在，就需要在该位置**切一刀（split）**，分裂成独立端点：

```java
private void split(int x) {
    if (m.containsKey(x)) return; // 已经是端点，无需分裂
    Map.Entry<Integer, Boolean> e = m.floorEntry(x); // 找到覆盖 x 的前驱端点状态
    m.put(x, e == null ? false : e.getValue()); // 复制前驱状态，在 x 处落下新端点
}
```

### 3.3 区间推平涂色（`assign`）

在准备好端点 $L$ 和 $R$ 后，将区间 `[L, R)` 统一涂色为 $c$（`true` 或 `false`）：

1.  首先调用 `split(R)`，再调用 `split(L)`，锁定断点。
2.  利用 `subMap` 将夹在 $L$ 和 $R$ 之间的所有旧冗余断点**全部清除**。
3.  在起点 $L$ 处涂色：`m.put(L, c)`。

```java
private void assign(int l, int r, boolean c) {
    split(r); // 先 split 右边界
    split(l); // 再 split 左边界
    m.subMap(l, true, r, false).clear(); // 清理 [l, r) 内部的陈旧碎片断点
    m.put(l, c); // 将 l 位置涂为新颜色 c
}
```

## 4. 715. Range 模块 通关源码

结合以上设计，我们可以写出极其简练且高效的通关代码：

```java
import java.util.*;

class RangeModule {

    private TreeMap<Integer, Boolean> m;

    public RangeModule() {
        m = new TreeMap<>();
        m.put(1, false); // 哨兵：1 处默认为未跟踪
    }

    // 在 x 处分裂出新端点，沿用前驱颜色
    private void split(int x) {
        if (m.containsKey(x)) return;
        Map.Entry<Integer, Boolean> e = m.floorEntry(x);
        m.put(x, e == null ? false : e.getValue());
    }

    // 将区间 [l, r) 统一赋值为颜色 c
    private void assign(int l, int r, boolean c) {
        split(r); // ⚠️ 注意：右开区间，右端点是 r
        split(l);
        m.subMap(l, true, r, false).clear(); // 物理删除 [l, r) 内部的断点
        m.put(l, c); // 设置起始颜色
    }
    
    // 启用区间：将 [left, right) 涂色为 true
    public void addRange(int left, int right) {
        assign(left, right, true);
    }
    
    // 禁用区间：将 [left, right) 涂色为 false
    public void removeRange(int left, int right) {
        assign(left, right, false);
    }
    
    // 查询区间：判断 [left, right) 是否全被涂成 true
    public boolean queryRange(int left, int right) {
        // 1. 获取包含 left 的前驱节点状态
        Map.Entry<Integer, Boolean> s = m.floorEntry(left);
        if (s == null || !s.getValue()) return false; // 如果起点就没被跟踪，直接 false

        // 2. 扫描从 left 往后到 right 之前的所有端点，必须全部是 true 状态
        for (Map.Entry<Integer, Boolean> e : m.tailMap(left, false).entrySet()) {
            if (e.getKey() >= right) break; // 已经超出待查询的 right 范围，退出
            if (!e.getValue()) return false; // 中间一旦出现未跟踪的断点，返回 false
        }
        return true;
    }
}
```

## 5. 珂朵尔树的复杂度优势

1.  **空间复杂度**：$O(N)$（$N$ 为操作次数），只与区间覆盖的操作频次相关，彻底告别了线段树极大的空间开销。
2.  **时间复杂度**：区间操作通过 `TreeMap` 可以在 $O(\log M + K)$ 内完成（$M$ 为端点数，$K$ 为被清除的内部端点数）。由于每个端点最多被加入两次、清除一次，摊还复杂度为极低且稳定的 **$O(\log N)$**。

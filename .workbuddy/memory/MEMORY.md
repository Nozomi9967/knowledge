# 八股 LLM Wiki — 工作记忆（长期）

> 跨会话的轻量备忘。完整规范在 AGENTS.md；实操记录在日期日志。

## 用户偏好（输出与整理）

- **「知识点整理」输出风格**（2026-10-14 定稿，全文存档 [[知识点整理提示词]]）：
  两段式——「知识点」（一句话定义加粗 + 4~6 条要点：是什么 / 怎么工作 / 为什么需要 / 为什么安全）→「知识点场景」（3 个：使用场景 / 验证方法（命令或现象）/ 面试对照）。
  粒度：300~400 字，只讲主线，不展开历史演进与边缘细节；无 emoji、不加总结段、不写鼓励追问的结尾。
- 该库默认引号风格为 **ASCII 直引号**（写新内容时保持一致）。
- **回答风格（2026-10-14 教训）**：用户提具体问题时**先直接给答案**（是/否 + 结论），再补辨析与展开；不要用"纠正提问者概念"式开场。用户理解正确时要**明确肯定**（"你说得对"），不要绕圈子。反例：软链接/目录项连环追问中，先纠正概念再回答导致用户强烈不满（"你到底能不能听懂人话"）；正例：同批 TLS 题答疑先肯定用户逻辑再分析，用户就接受了。

## 编辑与操作教训（该库通用）

- 部分文件含 **NBSP（U+00A0，网页粘贴带入）**：Edit 精确匹配会报 not found——先 `python repr()` 输出目标行定位字符（2026-10-14 两处实证）。
- Edit 报 `EBUSY: resource busy or locked` 是文件被瞬时锁住（Obsidian/同步进程），**重试即可**。
- Markdown 表格单元格里的 `|` 即使在内联代码中也要转义成 `\|`；表格必须顶格独立成块。
- 定位标题前先确认层级（`## 9.x` 还是 `### 9.x`），不要凭记忆写锚点。
- 新页面落库五件套：建页面 → 补相关页面回链 → 更新 index.md → 追加 log.md → 写当日 memory。

提示

你准备参加一场远足活动。给你一个二维 `rows x columns` 的地图 `heights` ，其中 `heights[row][col]` 表示格子 `(row, col)` 的高度。一开始你在最左上角的格子 `(0, 0)` ，且你希望去最右下角的格子 `(rows-1, columns-1)` （注意下标从 **0** 开始编号）。你每次可以往 **上** ， **下** ， **左** ， **右** 四个方向之一移动，你想要找到耗费 **体力** 最小的一条路径。

一条路径耗费的 **体力值** 是路径上相邻格子之间 **高度差绝对值** 的 **最大值** 决定的。

请你返回从左上角走到右下角的最小 **体力消耗值** 。

**示例 1：**

![](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2020/10/25/ex1.png)

```
输入：heights = [[1,2,2],[3,8,2],[5,3,5]]
输出：2
解释：路径 [1,3,5,3,5] 连续格子的差值绝对值最大为 2 。
这条路径比路径 [1,2,2,2,5] 更优，因为另一条路径差值最大值为 3 。
```

**示例 2：**

![](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2020/10/25/ex2.png)

```
输入：heights = [[1,2,3],[3,8,4],[5,3,5]]
输出：1
解释：路径 [1,2,3,4,5] 的相邻格子差值绝对值最大为 1 ，比路径 [1,3,5,3,5] 更优。
```

**示例 3：**

![](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2020/10/25/ex3.png)
```
输入：heights = [[1,2,1,1,1],[1,2,1,2,1],[1,2,1,2,1],[1,2,1,2,1],[1,1,1,2,1]]
输出：0
解释：上图所示路径不需要消耗任何体力。
```

**提示：**

- `rows == heights.length`
- `columns == heights[i].length`
- `1 <= rows, columns <= 100`
- `1 <= heights[i][j] <= 10^6`

```java
class Solution {

    public int minimumEffortPath(int[][] heights) {

        int n=heights.length;

        int m=heights[0].length;

        var dist=new int[n][m];

        var dir=new int[][]{{1,0},{-1,0},{0,1},{0,-1}};

        for(int i=0;i<n;i++) Arrays.fill(dist[i],Integer.MAX_VALUE);

  

        var pq=new PriorityQueue<int[]>(

            (a,b)->a[0]-b[0]

        );

        // arr[0]: 到达arr[1],arr[2]位置需要的体力值

        pq.offer(new int[]{0,0,0});

        while(!pq.isEmpty()){

            int[] cur=pq.poll();

            int dx=cur[0];

            int x=cur[1];

            int y=cur[2];

            if(dist[x][y]<dx) continue;

            for(int i=0;i<4;i++){

                int nx=x+dir[i][0];

                int ny=y+dir[i][1];

                if(nx<0||ny<0||nx>=n||ny>=m) continue;

                int dy=Math.abs(heights[nx][ny]-heights[x][y]);

                int newDis=Math.max(dy,dx);

                if(dist[nx][ny]>newDis){

                    dist[nx][ny]=newDis;

                    pq.offer(new int[]{newDis,nx,ny});

                }

            }

        }

        return dist[n-1][m-1]==Integer.MAX_VALUE?0:dist[n-1][m-1];

    }

}
```

```java
class Solution {

    public int minimumEffortPath(int[][] heights) {

        int n = heights.length, m = heights[0].length;

        int[][] dis = new int[n][m];

        for (int[] row : dis) Arrays.fill(row, Integer.MAX_VALUE);

        dis[0][0] = 0;

        int[] dx = {0, 0, 1, -1}, dy = {1, -1, 0, 0};

        // {代价, x, y}，按代价从小到大

        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);

        pq.offer(new int[]{0, 0, 0});

  

        while (!pq.isEmpty()) {

            int[] cur = pq.poll();

            int d = cur[0], x = cur[1], y = cur[2];

            if (x == n - 1 && y == m - 1) return d;   // 出堆时才确定答案

            if (d > dis[x][y]) continue;              // 过期条目，跳过

            for (int i = 0; i < 4; i++) {

                int nx = x + dx[i], ny = y + dy[i];

                if (nx < 0 || ny < 0 || nx >= n || ny >= m) continue;

                int nd = Math.max(d, Math.abs(heights[x][y] - heights[nx][ny]));

                if (nd < dis[nx][ny]) {

                    dis[nx][ny] = nd;

                    pq.offer(new int[]{nd, nx, ny});

                }

            }

        }

        return 0; // 不会走到这里

    }

}
```

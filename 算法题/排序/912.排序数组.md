# 912. 排序数组（手写归并 + 随机化三路快排）

## 题目

https://leetcode.cn/problems/sort-an-array/description/

给一个整数数组，升序排列它。要求**不能用库排序**，自己实现 `O(n log n)`。

数据范围：`1 ≤ n ≤ 5×10⁴`，`-5×10⁴ ≤ nums[i] ≤ 5×10⁴`。

## 题解一：归并排序（稳定，保证 O(n log n)）

```java
class Solution {
    public int[] sortArray(int[] nums) {
        mergeSort(nums);
        return nums;
    }

    void mergeSort(int[] nums){
        int n=nums.length;
        if(n<=1) return;
        int[] tem=new int[n];            // 辅助数组只开一次，全程复用
        mSort(nums,0,n-1,tem);
    }

    void mSort(int[] nums,int l,int r,int[] tem){
        if(l<r){
            int m=(r-l)/2+l;             // 防 l+r 溢出的中点写法
            mSort(nums,l,m,tem);
            mSort(nums,m+1,r,tem);
            merge(nums,l,m,r,tem);
        }
    }

    void merge(int[] nums,int l,int m,int r,int[] tem){
        int i=l,j=m+1,t=l;
        while(i<=m&&j<=r){
            if(nums[i]<=nums[j]){         // ⭐ <= 才稳定：相等时先取左半
                tem[t]=nums[i];
                i++;
            }else{
                tem[t]=nums[j];
                j++;
            }
            t++;
        }
        while(i<=m) tem[t++]=nums[i++];   // 左半剩余
        while(j<=r) tem[t++]=nums[j++];   // 右半剩余
        t=l;
        while(t<=r) nums[t]=tem[t++];     // 回填
    }
}
```

### 逐点拆解

- **辅助数组 `tem` 只 `new` 一次**：放在 `mergeSort` 里开、传下去复用。如果每次 `merge` 都 new 一个，`O(n log n)` 次分配会把常数拉爆（甚至被卡 TLE）。
- **中点 `(r-l)/2+l`**：等价 `(l+r)/2`，但 `l+r` 可能溢出。
- **`nums[i] <= nums[j]` 的 `<=` 是稳定性的关键**：相等时优先取左半，相等元素相对顺序不变 → 归并排序**稳定**。写成 `<` 就破坏稳定性（对纯数值题无感，但"排序稳定性"是个面试考点）。
- **回填必须逐位拷回 `nums`**：`merge` 结束后 `nums[l..r]` 才是有序段，供上层继续合并。
- 树高 `O(log n)`，`mSort` 递归深度安全（n=5×10⁴ 不担心爆栈）。

## 题解二：随机化三路快速排序（原地，平均 O(n log n)）

> 下面 `rand` 是类里的静态字段 `private static final Random rand = new Random();`，`swap` 是交换辅助方法，原题解里省略了，默写时要补上。

```java
private static final Random rand = new Random();

private static void swap(int[] arr, int i, int j) {
    int t = arr[i];
    arr[i] = arr[j];
    arr[j] = t;
}

// ==================== 快速排序 START（随机化三路快排） ====================
private static void quickSort(int[] arr, int low, int high) {
    if (low >= high) return;

    // 优化 1：随机基准值（防止有序数组退化为 O(N^2)）
    int randomIndex = low + rand.nextInt(high - low + 1);
    swap(arr, low, randomIndex);

    int pivot = arr[low];

    // 优化 2：三路切分（处理大量重复元素）
    // [low, lt-1]   < pivot
    // [lt, i-1]     == pivot
    // [gt+1, high]  > pivot
    int lt = low;      // 小于区的右边界
    int gt = high;     // 大于区的左边界
    int i = low + 1;   // 当前扫描的指针

    while (i <= gt) {
        if (arr[i] < pivot) {
            swap(arr, lt, i);
            lt++;
            i++;
        } else if (arr[i] > pivot) {
            swap(arr, i, gt);
            gt--; // 注意：从 gt 换过来的元素未经过检查，i 不自增
        } else {
            i++;  // 等于 pivot，直接跳过
        }
    }

    // 递归左半部分（小于区）和右半部分（大于区），等于区自动归位无需处理
    quickSort(arr, low, lt - 1);
    quickSort(arr, gt + 1, high);
}
// ==================== 快速排序 END ====================
```

### 三路切分不变量（本代码核心）

进入循环时维持三段（外加一段未知区）：

```
[ low .. lt-1 ]  <  pivot
[ lt  .. i-1  ]  == pivot
[ i   .. gt   ]  未知（待扫描）
[ gt+1.. high ]  >  pivot
```

初始 `lt=low, i=low+1, gt=high`：`==` 区恰好是 `[low, low]` 里的 pivot 本身，`<` / `>` 区为空，全部未知区是 `[low+1, high]`。

三个分支各自做了什么：

| 分支 | 动作 | 为什么 |
|------|------|--------|
| `arr[i] < pivot` | `swap(lt, i)`，`lt++`，`i++` | 换到 `lt` 处并入 `<` 区；从 `lt` 换回来的元素必为 `==pivot`（`==` 区左端），随 `i++` 自然并入 `==` 区，所以 `i` 要前进 |
| `arr[i] > pivot` | `swap(i, gt)`，`gt--`，**`i` 不动** | 换到 `gt` 处并入 `>` 区；从 `gt` 换进来的元素**还没检查过**，必须留在 `i` 位置下轮再判，所以 `i` 不自增（最容易写错的一行） |
| `arr[i] == pivot` | `i++` | 直接并入 `==` 区 |

循环结束 `i > gt`，此时 `[lt, gt]` 全是 `==pivot`，**等于区天然全部归位**，只需递归 `[low, lt-1]` 和 `[gt+1, high]` 两段——这正是三路快排在**大量重复元素**下不退化的原因。

### 两个优化各自解决什么

- **随机基准**：固定取首元素做 pivot 时，已排序 / 逆序数组会让切分极度不平衡，递归深度退化成 `O(n)` → `O(n²)` + 栈溢出。随机化把最坏情形的概率降到可忽略，期望 `O(n log n)`。
- **三路切分**：二路切分（`<=` / `>`）在全相等数组上每次只切掉一个元素，同样退化 `O(n²)`。三路把所有 `==pivot` 一次归位，全相等数组一次就整体排完。

## 两种排序对比

| 维度 | 归并排序（题解一） | 随机化三路快排（题解二） |
|------|------|------|
| 平均时间 | `O(n log n)` | `O(n log n)` |
| 最坏时间 | `O(n log n)`（有保证） | `O(n²)`（随机化后概率极低） |
| 额外空间 | `O(n)`（辅助数组） | `O(log n)`（递归栈） |
| 稳定性 | **稳定** | 不稳定 |
| 适用 | 要求稳定 / 链表排序 / 外部排序 | 原地、常数小、实测更快 |
| 重复元素 | 无影响 | 三路切分天生抗重复 |

选型口诀：**要稳定或要最坏保证 → 归并；要原地最快 → 三路快排。** LC 912 两者都能过。

## 912 的坑

1. **不能用库排序**：题目明确要求自己实现，`Arrays.sort` 直接不给分。
2. **固定 pivot 的快排会被卡**：LC 912 有针对性用例，普通"取首元素/取中间"二路快排容易 TLE 或栈溢出，必须随机化（或三路）。
3. **递归栈**：`n=5×10⁴` 时归并（`log n ≈ 16` 层）和随机化快排（期望 `log n` 层）都安全。
4. **稳定性别答错**：归并稳定、快排不稳定、堆排不稳定、插入/冒泡稳定——排序稳定性是高频面试小问。

## 复杂度

- 归并：时间 `O(n log n)`（任何输入），空间 `O(n)`（辅助数组）+ `O(log n)` 栈
- 快排：平均时间 `O(n log n)`、期望栈 `O(log n)`；最坏 `O(n²)`、栈 `O(n)`（随机化后实际不出现）

## 默写建议

机试/面试手撕排序，**优先写归并排序**——模板固定、无随机性、不用担心被卡，且稳定性是加分点。快排只在"要求原地"或"面试官点名"时写，务必带上**随机 pivot + 三路（或至少二路随机）**。另见 [[机试#排序（真实雷区）]] 里 `Arrays.sort(int[])` 双轴快排最坏 O(n²) 的坑。

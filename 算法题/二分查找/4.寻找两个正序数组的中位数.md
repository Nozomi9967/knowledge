# 4. 寻找两个正序数组的中位数（第 K 小消去法）

## 题目

https://leetcode.cn/problems/median-of-two-sorted-arrays/description/

给两个**已排序**数组 `nums1`、`nums2`，返回合并后的中位数。要求时间复杂度 `O(log(m+n))`。

## 题解：findKth 第 K 小 · 每次砍掉 k/2 个

**转化视角**：中位数 = 合并后第 `(n+1)/2` 小（奇数）或第 `n/2` 与 `n/2+1` 小的平均（偶数）。所以问题归结为**在两个有序数组里找第 k 小**，用一个 `findKth` 就同时覆盖奇偶两种情况。

```java
class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        int total = nums1.length + nums2.length;

        if (total % 2 == 1) {
            // 奇数：找第 (total/2 + 1) 小
            return findKth(nums1, 0, nums2, 0, total / 2 + 1);
        } else {
            // 偶数：找第 total/2 和 total/2+1 小的平均值
            double left = findKth(nums1, 0, nums2, 0, total / 2);
            double right = findKth(nums1, 0, nums2, 0, total / 2 + 1);
            return (left + right) / 2.0;
        }
    }

    /**
     * 找从 nums1[start1]、nums2[start2] 开始的第 k 小的元素
     */
    private int findKth(int[] nums1, int start1, int[] nums2, int start2, int k) {
        // 递归终止条件1：nums1 已用完
        if (start1 >= nums1.length) {
            return nums2[start2 + k - 1];
        }
        // 递归终止条件2：nums2 已用完
        if (start2 >= nums2.length) {
            return nums1[start1 + k - 1];
        }
        // 递归终止条件3：k=1，返回两数组当前最小值
        if (k == 1) {
            return Math.min(nums1[start1], nums2[start2]);
        }

        int half = k / 2;
        // 防止数组越界，取实际能取到的位置
        int idx1 = Math.min(start1 + half, nums1.length) - 1;
        int idx2 = Math.min(start2 + half, nums2.length) - 1;

        int val1 = nums1[idx1];
        int val2 = nums2[idx2];

        if (val1 <= val2) {
            // 排除 nums1 的前 (idx1 - start1 + 1) 个元素
            return findKth(nums1, idx1 + 1, nums2, start2, k - (idx1 - start1 + 1));
        } else {
            // 排除 nums2 的前 (idx2 - start2 + 1) 个元素
            return findKth(nums1, start1, nums2, idx2 + 1, k - (idx2 - start2 + 1));
        }
    }
}
```

## 逐点拆解

### 1. 砍半为什么合法（核心正确性论证）

比较 `val1 = nums1[start1 + k/2 - 1]` 和 `val2 = nums2[start2 + k/2 - 1]`。设 `val1 <= val2`：

- `nums1[start1 .. idx1]` 这 `k/2` 个数**全部 ≤ val2**，而 val2 前面（含自己在内）两个数组加起来最多凑出 `k/2 + k/2 = k` 个数——即 `nums1` 这段里的任何一个数，**在合并序里最多排第 k 位之前**，绝不可能就是第 k 小本身或更靠后。
- 所以这 `k/2` 个可以**整体安全排除**，问题变成"在剩下的里找第 `k - 实际排除数` 小"。

`val1 > val2` 时对称砍 nums2。这就是"每次消去 k/2 个"的第 K 小经典算法。

### 2. 三个递归终止条件（顺序不能换）

| 条件 | 代码 | 含义 |
|------|------|------|
| nums1 用完 | `start1 >= n1 → nums2[start2+k-1]` | 只剩 nums2，第 k 小直接按下标取 |
| nums2 用完 | 对称 | 同上 |
| k == 1 | `min(两当前头)` | 第 1 小就是两个未消费段的最小值 |

⚠ **先判越界再判 k==1**：k==1 分支里直接访问 `nums1[start1]`，如果该数组已耗尽会越界——终止条件顺序写反就挂。

### 3. `Math.min(start + half, len) - 1` 的防越界取法

某边剩余不足 `k/2` 个时，`start + half` 会越过数组末尾。写法上先 `min` 到 `len` 再 `-1`，拿到**实际能取到的最后一个下标**。于是排除数量是 `idx - start + 1`（**可能小于 k/2**），k 的扣减必须用这个实际值、不能写死 `k - half`——你代码里 `k - (idx1 - start1 + 1)` 正是此意，这也是本模板**最容易抄错的一处**。

### 4. 奇偶两次调用

偶数时调 `findKth(k=n/2)` 和 `findKth(k=n/2+1)` 取平均。两次独立递归，各 `O(log n)`，总复杂度不变。比"一次递归带出两个数"的写法多花一倍常数，但代码机械好背——机试选简单。

### 5. `val1 <= val2` 取等归哪边？

归 nums1（砍 nums1）。**两边取哪边都对**：相等时两个候选值同值，砍任意一边都不破坏第 1 节的论证。保持 `<=` 统一即可，面试被问就答"相等时任意一边先排除，正确性不受影响"。

## 复杂度

- 时间：每层 k 减半（至少减 `k/2` 的进度），递归 `O(log k)` 层；主调两次也才 `O(log(m+n))` ✅ 满足题目要求
- 空间：递归栈 `O(log(m+n))`

## 与另一主流解法「划分二分」的关系

官方题解的 `O(log(min(m,n)))` 解法是另一思路：**在短数组上二分切割点**，找 `i+j = (m+n+1)/2` 的划分，使左半全部 ≤ 右半（检查 `nums1[i-1] <= nums2[j] && nums2[j-1] <= nums1[i]`）。

| | 第 K 小消去（本文） | 划分二分 |
|---|---|---|
| 复杂度 | O(log(m+n)) | O(log(min(m,n))) |
| 思维模型 | "每次砍 k/2 个"，可推广到任意第 K 小 | "左半右半各占一半"，只解中位数 |
| 边界处理 | 三个终止条件，较直白 | 切割点 ±1 交叉判断，极易写错 |
| 面试建议 | **先写这个**，讲清砍半论证即是满分 | 被追问"能否更快/另一思路"再补 |

**推广性是本解法的隐藏优势**：把"找中位数"换成"两个有序数组第 K 小"（如面试变体、[[算法题/二分查找/378.有序矩阵中第K小的元素-二分.md]] 的一维版思维）模板直接复用。

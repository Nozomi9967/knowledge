# 小红的虚拟机任务拼装（完全背包 + 字典序最小重建）

## 题目描述

小红有若干台虚拟机，每台虚拟机有一个 RAM 容量。有 4 种任务，每种任务占用一种固定 RAM，任务数量无限。

对于每台虚拟机，小红希望选择若干任务，使任务占用的 RAM 总和恰好等于该机器容量。在满足占满容量的前提下，**任务数量越少越好**。如果存在多种任务数量最少的方案，先将方案中的任务占用值**升序排列**，再按**序列字典序**选择最小的方案输出。

题目保证 4 种任务中存在占用为 1 的任务，因此任意机器容量都可以被填满。

### 输入描述

- 第一行：一个整数 $n$ 表示虚拟机数量，以及 4 个整数表示 4 种任务的 RAM 占用值。
- 接下来 $n$ 行：每行一个整数表示一台虚拟机的 RAM 容量。

### 输出描述

对于每台虚拟机，输出一行，包含若干个整数，表示选中的任务 RAM 占用值（升序排列后字典序最小的方案），整数之间用空格分隔。

---

## 核心思路

**本质是硬币找零（完全背包）问题**：有 4 种面值的硬币，数量无限，凑出目标金额，要求硬币数最少，平票时按升序序列字典序最小。

### 算法步骤

#### Step 1：排序任务值

将 4 种任务 RAM 值升序排列。这样在重建时按升序尝试，自然地得到升序序列中的字典序最小方案。

#### Step 2：完全背包求最少任务数

$dp[i] =$ 凑出容量 $i$ 所需的最少任务数。

$$dp[0] = 0$$
$$dp[i] = \min_{v \in \text{values}} (dp[i - v] + 1)$$

因为面值含 1，所有 $dp[i]$ 都有限。

#### Step 3：字典序最小重建

对于每个容量 $C$，从**最小面值**开始贪心：尽可能多地取当前面值 $v$，即取最大的 $x$ 使得 $dp[C' - x \cdot v] + x = dp[C']$（其中 $C'$ 是剩余容量），然后 $C' \leftarrow C' - x \cdot v$，继续尝试下一个面值。

**为什么贪心正确**：升序序列中字典序比较，第一个元素越小越优。贪心取尽可能多的最小面值，相当于让序列开头尽可能堆满小值，自然得到字典序最小的升序序列。

### 复杂度

- $dp$ 数组：$O(\text{maxCap} \cdot 4)$
- 重建：$O(\text{maxCap} \cdot 4)$
- 总时间完全足够

## 完整代码

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] v = new int[4];
        for (int i = 0; i < 4; i++) v[i] = in.nextInt();
        Arrays.sort(v); // 升序，保证重建时字典序最小

        int maxC = 0;
        int[] caps = new int[n];
        for (int i = 0; i < n; i++) {
            caps[i] = in.nextInt();
            maxC = Math.max(maxC, caps[i]);
        }

        // dp[i] = 凑出容量 i 的最少任务数
        int[] dp = new int[maxC + 1];
        Arrays.fill(dp, Integer.MAX_VALUE / 2);
        dp[0] = 0;

        for (int i = 0; i <= maxC; i++) {
            if (dp[i] == Integer.MAX_VALUE / 2) continue;
            for (int j = 0; j < 4; j++) {
                int nxt = i + v[j];
                if (nxt <= maxC) {
                    dp[nxt] = Math.min(dp[nxt], dp[i] + 1);
                }
            }
        }

        // 重建：对每个容量，贪心取尽可能多的最小面值
        for (int c : caps) {
            int rem = c;
            List<Integer> ans = new ArrayList<>();
            for (int j = 0; j < 4; j++) {
                while (rem >= v[j] && dp[rem - v[j]] + 1 == dp[rem]) {
                    ans.add(v[j]);
                    rem -= v[j];
                }
            }
            // 输出
            for (int i = 0; i < ans.size(); i++) {
                if (i > 0) System.out.print(" ");
                System.out.print(ans.get(i));
            }
            System.out.println();
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：$O(\text{maxCap} \cdot 4)$，maxCap 为最大机器容量
- **空间复杂度**：$O(\text{maxCap})$，dp 数组

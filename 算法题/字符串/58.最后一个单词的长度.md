## 题目

https://leetcode.cn/problems/length-of-last-word/

```java
// 我的
class Solution {
    public int lengthOfLastWord(String s) {
        int count=0;
        boolean flag=false;
        int len=s.length();
        for(int i=len-1;i>=0;i--){
            if(flag&&s.charAt(i)==' ') break;
            if(s.charAt(i)==' ') continue;
            count++;
            flag=true;
        }
        return count;
    }
}
// 不推荐使用split()
```

# 山峰间的极限跳跃（树形DP最长交替路径）

> [!abstract] 题目
> 您是一位极限运动家，正挑战一片由计算机生成的、结构奇特的数字山脉。这片山脉由 N 个山峰组成，每个山峰都有其独特的海拔高度。您的目标是规划出一条最长的、符合"极限跳跃"规则的下山路径。
>
> 这片数字山脉的结构可以用一棵二叉树来精确描述。您规划的路径必须遵循一系列严格的规则，我们称之为一条"极限交替路径"：
>
> **路径方向**：路线必须严格自上而下，即只能从一个山峰移动到与之直接相连的子山峰。
> **严格交替**：路径上海拔的变化必须是严格的交替上升和下降。例如，一条合法的路径可以是海拔 p1→p2→p3→p4，其海拔序列满足 p1 < p2 > p3 < p4。无论是"先升后降"还是"先降后升"的交替模式都是允许的。
> **极限跳跃**：每次移动（从一个山峰到下一个）的海拔绝对差值必须大于或等于一个给定的阈值 k。形式化地，对于路径上任意相邻的两个山峰 A 和 B，必须满足 |altitude(B) - altitude(A)| ≥ k。
>
> 您的任务是找出在这片山脉中，能够规划出的最长"极限交替路径"的长度。路径的长度以其所包含的山峰数量计算。

| 参数 | 范围 |
|-----|------|
| N | 1 ~ 10000 |
| k | 1 ~ 100 |
| 海拔 | [1, 100000]，互不相同 |

**输入描述：** 第一行包含两个整数 N 和 K。接下来的 N 行描述了山脉的结构。每行包含三个整数 X, Y, Z：X 是当前山峰的海拔，Y 是其左侧子山峰的海拔，Z 是其右侧子山峰的海拔。如果某个子山峰不存在，则用 -1 表示。所有山峰的海拔高度都在 [1, 100000] 范围内，且保证互不相同。这 N 行的输入顺序遵循该山脉地图的先序遍历顺序。

**输出描述：** 一个整数，代表最长"极限交替路径"的长度。

---

## 思路

### 树形 DP，O(N) 时间，对每个节点维护"先升"和"先降"两种最长交替路径长度

这道题的核心是一个经典的树形 DP。由于路径必须严格自上而下（父→子），所以最长路径一定是某条从祖先到后代的自上而下的链。对每个节点维护两个状态：`up[u]`（从 u 出发、第一步海拔**上升**的最长交替路径长度）和 `down[u]`（从 u 出发、第一步海拔**下降**的最长交替路径长度），交替性自然由两个状态互相引用来保证。

---

### 状态定义

对于每个节点 u（以海拔值标识）：

- **`up[u]`**：从 u 出发往下走的最长交替路径长度，且第一步是**上升**（u 的海拔 < 子节点海拔）。由于第一步上升，下一步必须下降，所以递推时需要接上子节点的 `down` 值。
- **`down[u]`**：从 u 出发往下走的最长交替路径长度，且第一步是**下降**（u 的海拔 > 子节点海拔）。下一步必须上升，所以接上子节点的 `up` 值。

### 递推关系

对于节点 u 的每个子节点 v（满足 |alt[v] - alt[u]| ≥ k）：

- 若 alt[v] > alt[u]（上升）：`up[u] = max(up[u], 1 + down[v])`
- 若 alt[v] < alt[u]（下降）：`down[u] = max(down[u], 1 + up[v])`

若无合法子节点，则 `up[u] = down[u] = 1`（仅含自身）。

最终答案为所有节点 `max(up[u], down[u])` 的最大值。

### 遍历顺序

- 输入为先序遍历，第一行就是根节点。
- 用**双栈迭代**实现后序遍历（避免递归栈溢出，N=10000 可能退化链）。
- 子节点先于父节点被计算 → 后序 DP。

### 关键细节

- 海拔互不相同且在 [1, 100000]，可用数组直接索引（海拔值做下标），省去 HashMap。
- 叶子节点：`up = down = 1`。
- 答案为所有节点 `max(up[u], down[u])` 的最大值。

---

## 复杂度分析

- **时间复杂度**：O(N)。建树 O(N)，后序遍历每个节点处理一次 O(N)，总时间 O(N)。
- **空间复杂度**：O(maxAlt) = O(100001)，即约 400KB 的数组空间，远在限制之内。

## 完整 Java 代码

```java
import java.util.*;
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        PrintWriter out = new PrintWriter(new BufferedOutputStream(System.out));

        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        int k = Integer.parseInt(st.nextToken());

        // 海拔值范围 [1, 100000]，用数组直接索引
        int[] leftChild = new int[100001];
        int[] rightChild = new int[100001];
        Arrays.fill(leftChild, -1);
        Arrays.fill(rightChild, -1);

        int rootAlt = -1;
        for (int i = 0; i < n; i++) {
            st = new StringTokenizer(br.readLine());
            int x = Integer.parseInt(st.nextToken()); // 当前海拔
            int y = Integer.parseInt(st.nextToken()); // 左子海拔
            int z = Integer.parseInt(st.nextToken()); // 右子海拔
            leftChild[x] = y;
            rightChild[x] = z;
            if (i == 0) rootAlt = x; // 先序第一个就是根
        }

        // 双栈迭代后序遍历：stack1 做 DFS，stack2 收集后序
        Deque<Integer> stack1 = new ArrayDeque<>();
        Deque<Integer> stack2 = new ArrayDeque<>();
        stack1.push(rootAlt);
        while (!stack1.isEmpty()) {
            int alt = stack1.pop();
            stack2.push(alt);
            if (leftChild[alt] != -1) stack1.push(leftChild[alt]);
            if (rightChild[alt] != -1) stack1.push(rightChild[alt]);
        }

        // up[i]: 从 i 出发、第一步上升的最长交替路径长度
        // down[i]: 从 i 出发、第一步下降的最长交替路径长度
        int[] up = new int[100001];
        int[] down = new int[100001];
        int ans = 0;

        // 按后序处理：子节点先于父节点被计算
        while (!stack2.isEmpty()) {
            int alt = stack2.pop();
            int upVal = 1;   // 至少包含自身
            int downVal = 1;

            int lc = leftChild[alt];
            int rc = rightChild[alt];

            // 处理左子
            if (lc != -1) {
                int diff = Math.abs(lc - alt);
                if (diff >= k) {
                    if (lc > alt) {
                        // 上升：下一步需要下降，接 down[lc]
                        upVal = Math.max(upVal, 1 + down[lc]);
                    } else {
                        // 下降：下一步需要上升，接 up[lc]
                        downVal = Math.max(downVal, 1 + up[lc]);
                    }
                }
            }
            // 处理右子
            if (rc != -1) {
                int diff = Math.abs(rc - alt);
                if (diff >= k) {
                    if (rc > alt) {
                        upVal = Math.max(upVal, 1 + down[rc]);
                    } else {
                        downVal = Math.max(downVal, 1 + up[rc]);
                    }
                }
            }

            up[alt] = upVal;
            down[alt] = downVal;
            ans = Math.max(ans, Math.max(upVal, downVal));
        }

        out.println(ans);
        out.flush();
    }
}
```

## 示例验证

以给出的样例为例，树结构是一条链 20→10→21→11→22→12，k=10：

| 后序处理 | 节点 | up | down | 说明 |
|---------|------|----|------|------|
| 1 | 12（叶子） | 1 | 1 | — |
| 2 | 22 | 1 | 2 | ↓12，接 up[12]=1 |
| 3 | 11 | 3 | 1 | ↑22，接 down[22]=2 |
| 4 | 21 | 1 | 4 | ↓11，接 up[11]=3 |
| 5 | 10 | 5 | 1 | ↑21，接 down[21]=4 |
| 6 | 20 | 1 | 6 | ↓10，接 up[10]=5 |

整条链的海拔序列 20, 10, 21, 11, 22, 12 恰好是"降升降升降"的严格交替模式，每步差值都 ≥ 10，所以答案为 6。

## 面试话术

1. 为什么需要两个状态？→ 交替性要求下一步方向与当前相反，用 up/down 区分起始方向。
2. 为什么后序遍历？→ 子节点状态必须先于父节点计算。
3. 为什么用数组不用 HashMap？→ 海拔范围已知且互不相同，直接索引 O(1)。
4. 为什么不考虑"拐弯"（从一棵子树到另一棵）？→ 路径严格自上而下，不能从父到左子再到右子。

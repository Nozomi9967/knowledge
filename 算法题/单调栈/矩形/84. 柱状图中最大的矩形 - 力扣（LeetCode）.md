[84\. 柱状图中最大的矩形](https://leetcode.cn/problems/largest-rectangle-in-histogram/)


给定 *n* 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 1 。

求在该柱状图中，能够勾勒出来的矩形的最大面积。

**示例 1:**

![](https://assets.leetcode.com/uploads/2021/01/04/histogram.jpg)

```
输入：heights = [2,1,5,6,2,3]
输出：10
解释：最大的矩形为图中红色区域，面积为 10
```

**示例 2：**

![](https://assets.leetcode.com/uploads/2021/01/04/histogram-1.jpg)

```
输入： heights = [2,4]
输出： 4
```

```java
class Solution {

    public int largestRectangleArea(int[] heights) {

        int max=0;

        int n=heights.length;

        // st单调栈里面一定是递增的

        var st=new ArrayDeque<Integer>();

        // 左边第一个比i小的

        int[] left=new int[n];

        // 右边第一个比i小的

        int[] right=new int[n];

        // 想象极端情况：heights整体单调递增,right没有任何一个元素会被赋值

        // 因为遍历的时候没有小的，都比以前的大

        // 如果单调递增的话，所有元素的right值都应该是n

        // 所以干脆一开始都设置为n

        Arrays.fill(right, n);

        for(int i=0;i<n;i++){

            int x=heights[i];

            while(!st.isEmpty()&&x<=heights[st.peek()]){

                // 由于单调栈递增，所以对于每一个被弹出的元素来说，i都是第一个比他们小的，且i在他们右边

                // 因为只有第一个才能把他们弹出

                right[st.pop()]=i;

            }

            // 对于每一个i来说，i会不断跟单调栈栈顶元素比较，直到i比栈顶元素大

            // 换句话说，直到遇到第一个栈顶元素比i小的，而且该元素在i左边

            left[i]=st.isEmpty()?-1:st.peek();

            st.push(i);

        }

  

        for(int i=0;i<n;i++) max=Math.max(max,heights[i]*(right[i]-left[i]-1));

        return max;

    }

}
```

```java
        int n=heights.length;

        int[] l=new int[n];

        Arrays.fill(l,-1);
```

## left 与 right 数组：为什么是矩形宽度的关键

### 1. 核心思路：以当前柱子为「基准高度」

求最大矩形面积，依据**木桶效应（短板效应）**：一个矩形的高度，取决于这个范围内**最矮**的那根柱子。

因此转换思维：

> 遍历每一根柱子 $i$，假设以 $heights[i]$ 作为这个矩形的高度（即 $i$ 是这个矩形里最矮的柱子），那么这个矩形最大能有多宽？

要让高度维持在 $heights[i]$，矩形向左向右延伸时，遇到的柱子高度必须 **$\ge heights[i]$**：
- **向左延伸**：一直延伸，直到遇到**第一个比它矮**的柱子停下（位置记为 `left[i]`）
- **向右延伸**：一直延伸，直到遇到**第一个比它矮**的柱子停下（位置记为 `right[i]`）

### 2. `left[i]` 与 `right[i]` 的含义

- **`left[i]`**：$i$ 左边**第一个比 $heights[i]$ 矮**的柱子的下标
- **`right[i]`**：$i$ 右边**第一个比 $heights[i]$ 矮**的柱子的下标

这意味着：在**开区间 $(left[i],\ right[i])$** 内部的所有柱子，高度全部 **$\ge heights[i]$**——它们都可以被纳入以 $heights[i]$ 为高的矩形中。

> [!note] 与代码对应：为什么代码里用 `<=` 而不是 `<`
> 代码 `while(!st.isEmpty() && x <= heights[st.peek()])` 遇到**高度相等**的柱子也会弹出并赋 `right`，所以 `right[i]` 实际是「右边第一个 **≤** heights[i]」的下标。相等柱子被提前截断**不影响最大面积**：那根等高柱会作为新的基准，向左侧借到同样的 `left`，再向右延伸更远的跨度，联合区间被它完整覆盖——同时避免了重复计算相同高度的矩形。

### 3. 为什么宽度 = `right[i] - left[i] - 1`

既然开区间 $(left[i],\ right[i])$ 里的柱子都可以被纳入这个矩形：
- 左边界是 $left[i] + 1$
- 右边界是 $right[i] - 1$

那么有效柱子的总个数（即宽度）为：

$$\text{width} = (right[i]-1) - (left[i]+1) + 1 = right[i] - left[i] - 1$$

### 4. 具体例子

`heights = [2, 1, 5, 6, 2, 3]`，看下标 $i = 2$（高度为 $5$ 的柱子）：

- **向左看**：左边第一个比 $5$ 矮的是下标 $1$（高 $1$）→ `left[2] = 1`
- **向右看**：右边第一个比 $5$ 矮的是下标 $4$（高 $2$）→ `right[2] = 4`
- **宽度**：$\text{width} = 4 - 1 - 1 = 2$（覆盖下标 $2$、$3$，高度 $5$、$6$，都 $\ge 5$）
- **面积**：$\text{area} = 5 \times 2 = 10$

### 5. 总结

`left` 和 `right` 数组本质是在**划定边界**：

1. **`left[i]` 划定左边界**——防止矩形向左越界（碰到比它矮的柱子）
2. **`right[i]` 划定右边界**——防止矩形向右越界（碰到比它矮的柱子）
3. 有了这两个边界，就能在 **O(1) 时间**内精准算出以 $heights[i]$ 为高度的矩形的最大宽度

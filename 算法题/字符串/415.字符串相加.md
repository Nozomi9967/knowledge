# 415. 字符串相加

## 题目

https://leetcode.cn/problems/add-strings/description/

给定两个字符串形式的非负整数 `num1`、`num2`，计算它们的和并返回字符串形式。不能用任何内建 BigInteger 库，不能直接转整数。

## 题解：双指针从低位往高位 + 进位

**核心**：两个指针分别从两串末尾（个位）开始往前对齐，逐位相加并维护进位 `inc`。循环条件写成「任一指针没走完 **或者** 还有进位」，一次性覆盖「长短不一」和「最高位进位」两种边界。

```java
class Solution {
    public String addStrings(String num1, String num2) {
        StringBuilder sb = new StringBuilder();
        int i = num1.length() - 1;
        int j = num2.length() - 1;
        int inc = 0;                                  // 进位
        while (i >= 0 || j >= 0 || inc > 0) {
            int x = i >= 0 ? num1.charAt(i) - '0' : 0; // 短串取完了就当 0 补位
            int y = j >= 0 ? num2.charAt(j) - '0' : 0;
            int sum = x + y + inc;
            sb.append((char) (sum % 10 + '0'));       // ⭐ 低位先 append，+'0' 不能漏
            inc = sum / 10;
            i--;
            j--;
        }
        return sb.reverse().toString();               // 反转成高位在前
    }
}
```

## 逐点拆解

### 1. `i >= 0 ? ... : 0` —— 长短不一的对齐技巧

两个数位数不同时，短的那个指针会先走到 -1。这里不单独写「剩余部分直接拷贝」的收尾循环，而是**把越界位当 0**——`0 + 那位 + 进位` 自然继续算，代码只有一个循环，边界更少。

### 2. 循环条件 `|| inc > 0` —— 最高位进位的兜底

只写 `i >= 0 || j >= 0` 会漏掉一种情况：`"9" + "1" = "10"`。两个指针都走完时若 `inc` 还剩 1，这一位必须补上。把 `inc > 0` 并进循环条件，进位就自动落成结果最高位。

> 这是本题最常见的失分点——样例 `"11" + "123"` 不会暴露，但 `"9" + "9"` 会。

### 3. `+'0'` 是字符运算的必修课

`sum % 10` 得到 0~9 的 **int**，直接 `(char)` 强转是控制字符（乱码），必须 `+'0'` 才是 `'0'`~`'9'`。反向 `charAt(i) - '0'` 才是数字。**一进一出两次转换，一次都不能漏**——与 [[43.字符串相乘]] 的 bug 3 同源。

### 4. 先 `append` 低位、最后 `reverse()`

从个位开始算，天然得到「低位在前」的串，`reverse()` 一次就正序。**别写 `sb.insert(0, ...)`**——头部插入每次要搬移整个数组，复杂度从 `O(n)` 退化到 `O(n²)`（同 [[43.字符串相乘]] 的次要问题 1）。

## 与 43.字符串相乘的关系

415 是 [[43.字符串相乘]] 里那个 `add` 方法的**独立简化版**：相乘需要「乘一位 → 错位 → 多次相加」，而加法只有「逐位相加」一步。

| | 415 字符串相加 | 43 字符串相乘 |
|---|---|---|
| 核心动作 | 双指针逐位加 + 进位 | 乘一位 + 错位补零 + 多次相加 |
| 循环层数 | 单层 | 外层枚举 `num2` 每位 × 内层乘一位 |
| 复杂度 | `O(max(m,n))` | `O(m·n)` |
| 边界 | 最高位进位（`|| inc>0`） | 前导零、负零、进位收尾 |

**建议练习顺序**：先默写 415 把「双指针 + 进位 + `+'0'`」这套肌肉记忆打牢，再写 43——43 的两个辅助方法（`f1` 乘一位、`add` 累加）本质就是 415 的加法逻辑套一层乘法外循环。

## 复杂度

- 时间 `O(max(m, n))`：单层循环，最长走 `max(m,n) + 1` 次（进位那一位）
- 空间 `O(max(m, n))`：结果串

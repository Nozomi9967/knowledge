### **剑指 Offer 47「礼物的最大价值」和「62 不同路径」是同一个网格 DP，只把"方案数"换成了"最大和"：`dp[i][j] = max(dp[i-1][j], dp[i][j-1]) + grid[i][j]`，空间可以原地优化到 O(1)。**

### **一、问题本身**

`m × n` 的棋盘，每格有价值，从左上角走到右下角，每步只能向右或向下，求路径上价值之和的最大值。

```
grid = [[1,3,1],
        [1,5,1],
        [4,2,1]]
路径 1→3→1→1→1 的和是 7（走 1,3,1,1,1）
```

---

### **二、状态与转移**

**状态**：`dp[i][j]` = 从 `(0,0)` 走到 `(i,j)` 能拿到的最大价值。

**转移**：到达 `(i,j)` 只能从上方或左方来，取两者较大的再加当前格价值：

```
dp[i][j] = max(dp[i-1][j], dp[i][j-1]) + grid[i][j]
```

**边界**：

```
dp[0][0] = grid[0][0]
dp[0][j] = dp[0][j-1] + grid[0][j]     // 第一行只能从左来
dp[i][0] = dp[i-1][0] + grid[i][0]     // 第一列只能从上来
```

和 62 的区别：62 的边界是**全 1**（只有一条路），这里是**前缀和**（累加价值）。

---

### **三、代码（标准写法）**

```java
class Solution {
    public int maxValue(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] dp = new int[m][n];
        dp[0][0] = grid[0][0];

        for (int j = 1; j < n; j++) dp[0][j] = dp[0][j - 1] + grid[0][j];
        for (int i = 1; i < m; i++) dp[i][0] = dp[i - 1][0] + grid[i][0];

        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]) + grid[i][j];
            }
        }
        return dp[m - 1][n - 1];
    }
}
```

---

### **四、空间优化：直接改原数组（这道题常被要求）**

因为 `dp[i][j]` 只依赖"上方"和"左方"，而这两个位置在计算当前格时已经算完了，所以**可以直接用 `grid` 数组当 dp 数组**，把空间降到 O(1)（不计输入）：

```java
class Solution {
    public int maxValue(int[][] grid) {
        int m = grid.length, n = grid[0].length;

        // 第一列：累加
        for (int i = 1; i < m; i++) grid[i][0] += grid[i - 1][0];
        // 第一行：累加
        for (int j = 1; j < n; j++) grid[0][j] += grid[0][j - 1];
        // 其余格：上/左取大
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                grid[i][j] += Math.max(grid[i - 1][j], grid[i][j - 1]);
            }
        }
        return grid[m - 1][n - 1];
    }
}
```

**面试时主动提这个优化是加分项**——同样的逻辑，「62 不同路径」也能原地做（把 grid 当 dp，边界置 1），但要注意"修改输入"在工程上是有副作用的，面试时补一句"如果输入不允许修改，还是要开额外数组"更稳。

### **五、复杂度**

| 项 | 复杂度 |
|---|---|
| 时间 | O(m·n) |
| 空间 | O(m·n) → 原地优化后 O(1) |

---

### **六、易错点**

1. **边界写成 1**（套用 62 的写法）：这里是累加，不是计数
2. **第一行/第一列忘记处理**：直接从 `(1,1)` 开始循环，前两行边界会漏
3. **`grid` 为空**：剑指里一般保证 `m,n ≥ 1`，但工程代码要判空
4. **原地优化时先改了 `grid`，后面又用原始值**：原地修改是单向的，不能回头再用原值
5. **和 62 混淆**：62 问方案数（加法），这题问最大和（取 max 再加法），转移只差一个 `max`

### **七、同族题**

| 题号 | 目标 | 转移 |
|---|---|---|
| 62 不同路径 | 方案数 | `dp[i][j] = dp[i-1][j] + dp[i][j-1]` |
| 63 不同路径 II | 方案数（有障碍） | 同上，障碍格置 0 |
| 64 最小路径和 | 最小和 | `min(...) + grid[i][j]` |
| 剑指 47（本题） | 最大和 | `max(...) + grid[i][j]` |

**这四题是一个模板的四个变体**，面试时能主动串起来说，比单答一道题更显体系感。

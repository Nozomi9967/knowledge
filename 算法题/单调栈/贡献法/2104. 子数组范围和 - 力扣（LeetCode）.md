给你一个整数数组 `nums` 。 `nums` 中，子数组的 **范围** 是子数组中最大元素和最小元素的差值。

返回 `nums` 中 **所有** 子数组范围的 **和** *。*

子数组是数组中一个连续 **非空** 的元素序列。

**示例 1：**

```
输入：nums = [1,2,3]
输出：4
解释：nums 的 6 个子数组如下所示：
[1]，范围 = 最大 - 最小 = 1 - 1 = 0 
[2]，范围 = 2 - 2 = 0
[3]，范围 = 3 - 3 = 0
[1,2]，范围 = 2 - 1 = 1
[2,3]，范围 = 3 - 2 = 1
[1,2,3]，范围 = 3 - 1 = 2
所有范围的和是 0 + 0 + 0 + 1 + 1 + 2 = 4
```

**示例 2：**

```
输入：nums = [1,3,3]
输出：4
解释：nums 的 6 个子数组如下所示：
[1]，范围 = 最大 - 最小 = 1 - 1 = 0
[3]，范围 = 3 - 3 = 0
[3]，范围 = 3 - 3 = 0
[1,3]，范围 = 3 - 1 = 2
[3,3]，范围 = 3 - 3 = 0
[1,3,3]，范围 = 3 - 1 = 2
所有范围的和是 0 + 0 + 0 + 2 + 0 + 2 = 4
```

**示例 3：**

```
输入：nums = [4,-2,-3,4,1]
输出：59
解释：nums 中所有子数组范围的和是 59
```

**提示：**

- `1 <= nums.length <= 1000`
- `-10^9 <= nums[i] <= 10^9`

**进阶：** 你可以设计一种时间复杂度为 `O(n)` 的解决方案吗？

---


其实就是把数组每个元素当做子数组中的最大值时，计算贡献度，求最大值时贡献度总和

再当做最小值计算一波贡献度总和，最后相减

**注意溢出问题**

```java
class Solution {

    public long subArrayRanges(int[] nums) {

        int n=nums.length;

        var st=new ArrayDeque<Integer>();

        int[] left=new int[n];

        int[] right=new int[n];

        Arrays.fill(right,n);

        for(int i=0;i<n;i++){

            int x=nums[i];

            while(!st.isEmpty()&&x>nums[st.peek()]){

                right[st.pop()]=i;

            }

  

            left[i]= st.isEmpty()?-1:st.peek();

            st.push(i);

        }

        long max=0;

        for(int i=0;i<n;i++){

            long tem=(right[i]-i)*(i-left[i]);

             max+=nums[i]*tem;

        }

  

        Arrays.fill(left,-1);

        Arrays.fill(right,n);

        st.clear();

        for(int i=0;i<n;i++){

            int x=nums[i];

            while(!st.isEmpty()&&x<nums[st.peek()]){

                right[st.pop()]=i;

            }

  

            left[i]= st.isEmpty()?-1:st.peek();

            st.push(i);

        }

        long min=0;

        for(int i=0;i<n;i++){

            long tem=(right[i]-i)*(i-left[i]);

             min+=nums[i]*tem;

        }      

        return max-min;

    }

}
```

```java
class Solution {

    public long subArrayRanges(int[] nums) {

        int n=nums.length;

        int[] minL=new int[n];

        int[] minR=new int[n];

        int[] maxL=new int[n];

        int[] maxR=new int[n];

        var st=new ArrayDeque<Integer>();

        for(int i=0;i<n;i++){

            int x=nums[i];

            while(!st.isEmpty()&&x<nums[st.peek()]){

                minR[st.pop()]=i;

            }

            minL[i]= st.isEmpty()?-1:st.peek();

            st.push(i);

        }

        while(!st.isEmpty()) minR[st.pop()]=n;

        for(int i=n-1;i>=0;i--){

            int x=nums[i];

            while(!st.isEmpty()&&x>nums[st.peek()]){

                maxL[st.pop()]=i;

            }

            maxR[i]= st.isEmpty()?n:st.peek();

            st.push(i);

        }

        while(!st.isEmpty()) maxL[st.pop()]=-1;

        long ans=0;

        for(int i=0;i<n;i++){

            ans+= (long)(i-maxL[i])*(maxR[i]-i)*nums[i];

            ans-= (long)(i-minL[i])*(minR[i]-i)*nums[i];

            System.out.println(ans);

        }

        return ans;

    }

}
```

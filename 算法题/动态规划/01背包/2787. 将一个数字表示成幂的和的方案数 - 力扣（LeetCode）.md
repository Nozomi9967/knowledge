[2787\. 将一个数字表示成幂的和的方案数](https://leetcode.cn/problems/ways-to-express-an-integer-as-sum-of-powers/)


给你两个 **正** 整数 `n` 和 `x` 。

请你返回将 `n` 表示成一些 **互不相同** 正整数的 `x` 次幂之和的方案数。换句话说，你需要返回互不相同整数 `[n_1, n_2, ..., n_k]` 的集合数目，满足 $n = n_1^x + n_2^x + \cdots + n_k^x$ 。

由于答案可能非常大，请你将它对 `10^9 + 7` 取余后返回。

比方说， `n = 160` 且 `x = 3` ，一个表示 `n` 的方法是 `n = 2^3 + 3^3 + 5^3` 。

**示例 1：**

```
输入：n = 10, x = 2
输出：1
解释：我们可以将 n 表示为：n = 3^2 + 1^2 = 10 。
这是唯一将 10 表达成不同整数 2 次方之和的方案。
```

**示例 2：**

```
输入：n = 4, x = 1
输出：2
解释：我们可以将 n 按以下方案表示：
- n = 4^1 = 4 。
- n = 3^1 + 1^1 = 4 。
```

**提示：**

---



```java
class Solution {

    public int numberOfWays(int n, int x) {

        // dp[i][j]: 前i个元素(1-n),x次幂组合和=j的方案数

        final long INF=1000000000+7;

        int[][] dp=new int[n+1][n+1];

        Arrays.fill(dp[0],0);

        dp[0][0]=1;

        for(int i=0;i<n;i++){

            int y=i+1;

            for(int j=0;j<=n;j++){

                dp[i+1][j]=dp[i][j];

                int p=(int)Math.pow(y,x);

                if(p<=j&&dp[i][j-p]!=0) dp[i+1][j]+=dp[i][j-p];

                dp[i+1][j]%=INF;

            }

        }

        return dp[n][n];

    }

}
```

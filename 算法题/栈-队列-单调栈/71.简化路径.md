## 题解

```java
class Solution {
    public String simplifyPath(String path) {
        Stack<String> stack=new Stack<>();
        String[] arr=Arrays.stream(path.split("/")).filter(s->!s.isEmpty()).toArray(String[]::new);
        for(int i=0;i<arr.length;i++){
            String s=arr[i];
            if(s.equals(".")) continue;
            else if(s.equals("..")){
                if(!stack.empty())  stack.pop();
            }
            else stack.push(s);
            System.out.println(s);
        }
        String res="";
        while(!stack.empty()){
            res=("/"+stack.pop()+res);
        }
        return res==""?"/":res;
    }
}
```

1. 用split分隔，并去除空字符串
2. 取每一个字符串进行判断
   1. 如果是 .  不管它
   2. 如果是 .. 且栈不为空，弹出栈顶
   3. 其他的都push

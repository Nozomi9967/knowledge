## DNAT 和 SNAT 是什么？

这是 **iptables** 中的两个核心网络地址转换技术，用来修改数据包的**目标地址**或**源地址**。

---

## 一、概念对比

|          | **DNAT** (Destination NAT)              | **SNAT** (Source NAT)              |
| -------- | --------------------------------------- | ---------------------------------- |
| 全称     | Destination Network Address Translation | Source Network Address Translation |
| 作用     | 修改数据包的**目标地址**                | 修改数据包的**源地址**             |
| 方向     | 处理**流入**的数据包                    | 处理**流出**的数据包               |
| 典型场景 | 端口映射、负载均衡                      | 内网上网、隐藏内部IP               |
| 链位置   | PREROUTING、OUTPUT                      | POSTROUTING                        |

---

## 二、DNAT 详解

### 作用
把数据包的目标 IP/端口 改成别的地址。

### 典型场景：阿里云 ECS 的公网访问

**你的 ECS 配置**：
- 公网 IP：`101.37.182.129`（不在网卡上）
- 内网 IP：`172.17.153.70`（在网卡上）

**外部客户端访问 `101.37.182.129:9092` 的路径**：

```
客户端 → 阿里云网关 → ECS (172.17.153.70:9092)
```

阿里云网关在进入 ECS 之前做了 **DNAT**：
```
原始数据包目标地址：101.37.182.129:9092
网关修改后目标地址：172.17.153.70:9092
```

这样流量才能到达你的 ECS 网卡。

### 你的 iptables 规则也是 DNAT

```bash
iptables -t nat -A OUTPUT -d 101.37.182.129 -j DNAT --to-destination 172.17.153.70
```

**作用**：当 ECS 本机进程发数据包到 `101.37.182.129` 时，把目标地址改成 `172.17.153.70`，让流量留在内网，不用出去绕网关。

---

## 三、SNAT 详解

### 作用
把数据包的源地址改成别的地址。

### 典型场景：内网机器上外网

```
内网机器 (192.168.1.2) → 路由器 → 互联网
```

路由器做 SNAT（通常叫 MASQUERADE）：
```
原始数据包源地址：192.168.1.2
路由器修改后源地址：路由器公网 IP
```

因为互联网不认识 `192.168.1.x` 内网地址，必须改成公网 IP 才能路由回去。

### 另一场景：让响应包原路返回

阿里云网关也会做 SNAT：
```
ECS (172.17.153.70) 响应包 → 网关 → 客户端
网关修改源地址：172.17.153.70 → 101.37.182.129
```

客户端看到的响应来自 `101.37.182.129`，逻辑上一致。

## 四、一个完整的请求生命周期（以你的 Kafka 为例）

**外部客户端访问 Kafka**：

| 方向               | 地址变化                                     | NAT 类型   |
| ------------------ | -------------------------------------------- | ---------- |
| 请求：客户端 → ECS | `客户端IP:port → 101.37.182.129:9092`        | 客户端发出 |
| 阿里云网关         | `目标地址改：101.37.182.129 → 172.17.153.70` | **DNAT**   |
| ECS 收到请求       | 源=客户端IP，目标=172.17.153.70              | -          |
| ECS 处理           | -                                            | -          |
| 响应：ECS → 客户端 | `172.17.153.70 → 客户端IP`                   | ECS 发出   |
| 阿里云网关         | `源地址改：172.17.153.70 → 101.37.182.129`   | **SNAT**   |
| 客户端收到响应     | 源=101.37.182.129                            | 符合预期   |

## 五、iptables 中的链位置

```
         ┌─────────────────────────────────────────────┐
         │                数据包进入                    │
         └─────────────────┬───────────────────────────┘
                           ↓
                    ┌─────────────┐
                    │ PREROUTING  │ ← DNAT 在这里做（改目标地址）
                    └──────┬──────┘
                           ↓
                    ┌─────────────┐
                    │   路由决策   │ （判断走 INPUT 还是 FORWARD）
                    └──────┬──────┘
                           ↓
              ┌────────────┴────────────┐
              ↓                          ↓
       ┌─────────────┐            ┌─────────────┐
       │   INPUT     │            │  FORWARD    │
       │ (本机进程)   │            │ (转发)       │
       └──────┬──────┘            └──────┬──────┘
              ↓                          ↓
       ┌─────────────┐            ┌─────────────┐
       │   OUTPUT    │ ← 你的 DNAT 在这里做      │
       └──────┬──────┘            └──────┬──────┘
              ↓                          ↓
       ┌─────────────┐            ┌─────────────┐
       │  POSTROUTING│ ← SNAT 在这里做（改源地址）│
       └─────────────┘            └─────────────┘
```

## 六、你文档中的 iptables 规则解读

```bash
iptables -t nat -A OUTPUT -d 101.37.182.129 -j DNAT --to-destination 172.17.153.70
```

| 部分                                     | 含义                                 |
| ---------------------------------------- | ------------------------------------ |
| `-t nat`                                 | 使用 NAT 表                          |
| `-A OUTPUT`                              | 追加规则到 OUTPUT 链（本机发出的包） |
| `-d 101.37.182.129`                      | 匹配目标地址为公网 IP 的包           |
| `-j DNAT --to-destination 172.17.153.70` | 把目标地址改成内网 IP                |

**效果**：ECS 上任何进程（Druid、kcat、容器内应用）试图访问 `101.37.182.129:9092` 时，目标地址被改成本机内网 IP `172.17.153.70`，流量走内网直达，绕过阿里云网关的 NAT 回环问题。

## 题目

https://leetcode.cn/problems/check-if-all-the-integers-in-a-range-are-covered/

```java
class Solution {

    public boolean isCovered(int[][] ranges, int left, int right) {

        int[] d=new int[52];

        for(int[] r:ranges){

            int l=r[0],ri=r[1];

            d[l]++;

            d[ri+1]--;

        }

        int s=0;

        for(int i=1;i<=right;i++){

            s+=d[i];

            if(i>=left&&i<=right&&s<1) return false;

        }

        return true;

    }

}
```

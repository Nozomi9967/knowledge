### **LeetCode 714「买卖股票含手续费」和 122（无限次交易）只差一个地方：卖出时多减一笔手续费。两状态（持有 / 不持有）就够，不需要额外维度。**

### **一、问题本身**

可以无限次交易，但每次卖出要付 `fee` 的手续费，求最大利润。

```
prices = [1,3,2,8,4,9], fee = 2
买1卖8（利润 7-2=5）→ 买4卖9（利润 5-2=3）  →  8
```

---

### **二、状态定义与转移**

```
hold[i]：第 i 天结束时持有股票的最大利润
free[i]：第 i 天结束时不持有的最大利润

hold[i] = max(hold[i-1], free[i-1] - prices[i])      // 继续持有 / 今天买入
free[i] = max(free[i-1], hold[i-1] + prices[i] - fee) // 继续空仓 / 今天卖出（扣手续费）
```

和 122 的唯一区别就是 `free` 的转移里多了 `- fee`。

**关键点：手续费在卖出时扣，所以只影响 `free` 的转移，不影响 `hold`。** 有人会想在买入时扣，那样也可以（等价于把成本提前算），但要注意**不能重复扣**——两边都减 fee 就错了。

---

### **三、代码**

```java
class Solution {
    public int maxProfit(int[] prices, int fee) {
        int hold = -prices[0];   // 第 0 天买入
        int free = 0;            // 第 0 天不买

        for (int i = 1; i < prices.length; i++) {
            int newHold = Math.max(hold, free - prices[i]);
            int newFree = Math.max(free, hold + prices[i] - fee);
            hold = newHold;
            free = newFree;
        }
        return free;   // 最后一定是不持有状态利润最大
    }
}
```

**为什么最后返回 `free` 而不是 `max(hold, free)`**：`hold` 的语义是"还拿着股票"，没卖掉的浮盈不能算收益。题目问的是已实现利润，所以只看 `free`。

> 注意：这一点和 309（冷冻期）不同——309 里 `cool`（刚卖）和 `free`（早就卖）都属于"已实现"，所以要取 max；这里 `hold` 是"没卖"，不该算。

---

### **四、另一条思路：把手续费摊到买入价**

也可以这样理解：每次买入相当于成本增加了 `fee`，即 `hold[i] = max(hold[i-1], free[i-1] - prices[i] - fee)`，卖出时不再扣。

两种写法结果相同，因为一次完整的"买-卖"总成本都是 `fee`。**选一种写清楚就行，别两边都扣。**

### **六、易错点**

1. **两边都扣 fee**：买的时候扣一次、卖的时候又扣一次，结果偏小
2. **返回 `max(hold, free)`**：把浮盈当成实际收益（这题必须返回 free）
3. **想成"必须找到最优交易次数"**：本题不限次数，只要利润为正就交易，DP 会自动决定做不做
4. **fee 很大时的极端情况**：如果 `fee > 最大价差`，最优策略是一次都不交易（利润 0），DP 也能正确返回 0

### **七、股票系列对照表（面试常被连问）**

| 题号 | 限制 | 状态数 | 关键差别 |
|---|---|---|---|
| 121 | 只能交易 1 次 | 2 | `hold` 的买入项是 `-prices[i]`，不累加历史利润 |
| 122 | 无限次 | 2 | 标准状态机 |
| 123 | 最多 2 次 | 2×3 | 加一维交易次数 |
| 188 | 最多 k 次 | 2×(k+1) | 同 123，k 可变；k ≥ n/2 时退化成 122 |
| 309 | 无限次 + 冷冻期 | 3 | 多一个 cool 状态 |
| 714 | 无限次 + 手续费 | 2 | 卖出减 fee |

**一句话记**：所有股票题都是"持有 / 不持有"两态的状态机，差异只在买入成本怎么算、卖出有没有附加条件、交易次数有没有上限。

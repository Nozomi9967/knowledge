### **LeetCode 392「判断子序列」——单次查询用双指针 O(n+m) 就够；但如果题目改成"大量 s 反复查询同一个 t"（进阶版），就要用 DP 预处理 `next[i][c]` 表，把每次查询降到 O(|s|)。**

### **一、问题本身**

判断 `s` 是否是 `t` 的子序列（`s` 的字符在 `t` 中按顺序出现，可以不连续）。

```
s = "abc", t = "ahbgdc"  →  true
s = "axc", t = "ahbgdc"  →  false
```

---

### **二、基础解法：双指针**

`i` 扫 `s`、`j` 扫 `t`，字符相同就都前进，不同就只让 `j` 前进。最后看 `i` 是否走到了 `s` 的末尾。

```java
class Solution {
    public boolean isSubsequence(String s, String t) {
        int i = 0, j = 0;
        while (i < s.length() && j < t.length()) {
            if (s.charAt(i) == t.charAt(j)) i++;
            j++;
        }
        return i == s.length();
    }
}
```

- 时间 O(|s| + |t|)，最多扫一遍 t
- 空间 O(1)

**这是本题的默认答案**，面试答到这里已经及格。注意判空：`s` 为空时直接返回 true（空串是任何串的子序列）。

---

### **三、进阶：大量查询用 DP 预处理**

如果题目变成"给 10 亿个 `s`，都判断是否为同一个 `t` 的子序列"，每次 O(|t|) 就太慢了。

**预处理一张"下一个字符位置表"**：

```
next[i][c] = 从 t 的下标 i 开始（含 i），字符 c 第一次出现的位置；不存在则为 -1
```

有了这张表，查询时从 `pos = 0` 开始，对 `s` 的每个字符 `c`：`pos = next[pos][c] + 1`，一旦得到 -1 就返回 false。查询复杂度 **O(|s|)**，与 `t` 的长度无关。

**表的构造**（从后往前填）：

```java
int[][] next = new int[n + 1][26];
Arrays.fill(next[n], -1);             // 越界哨兵
for (int i = n - 1; i >= 0; i--) {
    System.arraycopy(next[i + 1], 0, next[i], 0, 26);   // 先继承后一个位置的表
    next[i][t.charAt(i) - 'a'] = i;                      // 再覆盖自己这个字符
}
```

```java
// 查询
int pos = 0;
for (char c : s.toCharArray()) {
    if (pos >= n) return false;
    int p = next[pos][c - 'a'];
    if (p == -1) return false;
    pos = p + 1;
}
return true;
```

- 预处理 O(26·n)，查询 O(|s|)
- 空间 O(26·n)

**为什么这个表能"跳着找"**：`next[i][c]` 直接告诉你"从 i 开始往右，字符 c 最早在哪"，不用一个个扫。这是"用空间换时间"的典型——预处理一次，查询无数次。

---

### **四、两种解法的选择**

| 场景 | 选哪个 |
|---|---|
| 单次或少数几次查询 | 双指针，O(m+n)，实现最简单 |
| 大量 s，同一个 t | DP 预处理，均摊 O(|s|) |
| t 很长（10^5），s 很多 | 必须 DP，否则超时 |

**面试话术**：先给双指针（本题默认要求），然后主动说"如果场景变成大量查询，可以用 `next` 表预处理，把每次查询降到 O(|s|)"——这个补充能直接体现对进阶版（LeetCode 792）的理解。

---

### **五、易错点**

1. **`s` 为空**：返回 true（空串是任何串的子序列），双指针自然能满足（`i=0 == s.length()=0`）
2. **`t` 为空但 `s` 非空**：返回 false
3. **双指针里 `i++` 后忘记 `j++`**：`j` 必须每轮都前进
4. **DP 表的 `next[n]` 忘记初始化为 -1**：默认是 0，会误判为"字符在下标 0 处"
5. **`Array.copyOf` 与 `System.arraycopy` 混用**：二维数组的行复制要用 `System.arraycopy` 或 `Arrays.copyOf(next[i+1], 26)`
6. **只答双指针，不提进阶**：本题是 LeetCode 392，进阶版 792 才是"考察是否想到预处理"的地方

---

### **六、类似的"预处理加速多次查询"套路**

这类题的通用模式是**离线预处理 + O(1) 或 O(|s|) 查询**：

- 392/792：next 表查子序列
- 前缀和：多次区间求和
- 稀疏表（ST 表）：多次区间最值
- 并查集：多次连通性查询

**共同点**：把"重复计算的公共部分"提前算好。看到"多次查询同一个静态数据"就该想到这个方向。

在股票交易中，如果前一天的股价高于后一天的股价，则可以认为存在一个「交易逆序对」。请设计一个程序，输入一段时间内的股票交易记录 `record` ，返回其中存在的「交易逆序对」总数。

**示例 1：**

```
输入：record = [9, 7, 5, 4, 6]
输出：8
解释：交易中的逆序对为 (9, 7), (9, 5), (9, 4), (9, 6), (7, 5), (7, 4), (7, 6), (5, 4)。
```

**提示：**

`0 <= record.length <= 50000`

---


```java
class Solution {

    public int reversePairs(int[] record) {

        int n=record.length;

  

        if(n==0) return 0;

        int[] tem=new int[n];

        return reversePairs(record,0,n-1,tem);

    }

  

    public int reversePairs(int[] record,int l,int r,int[] tem){

        if(l==r) return 0;

  

        int m=(r-l)/2+l;

  

        int leftSum=reversePairs(record,l,m,tem);

        int rightSum=reversePairs(record,m+1,r,tem);

  

        // 剪枝

        if(record[m]<record[m+1]){

            return leftSum+rightSum;

        }

  

        int mergeSum=mergeAndCount(record,l,m,r,tem);

  

        return leftSum+mergeSum+rightSum;

    }

  

    public int mergeAndCount(int[] record,int l,int m,int r,int[] tem){

        for(int i=l;i<=r;i++) tem[i]=record[i];

  

        int i=l,j=m+1;

        int cnt=0;

        for(int k=l;k<=r;k++){

            if(i>m){

                record[k]=tem[j];

                j++;                

            }else if(j>r){

                record[k]=tem[i];

                i++;

            }else if(tem[i]<=tem[j]){

                record[k]=tem[i];

                i++;

            }else{

                record[k]=tem[j];

                cnt+= m-i+1;

                j++;

            }

        }

        return cnt;

    }

}
```


# 数组中的逆序对 —— 归并排序解法笔记

## 题意

给定数组 `record`，统计所有满足 `i < j` 且 `record[i] > record[j]` 的pair数量。

---

## 核心思路

利用归并排序，在 merge 的过程中顺便统计跨越左右两半的逆序对数量。

分治结构：

```
总逆序对 = 左半内部逆序对 + 右半内部逆序对 + 跨越左右的逆序对
```

左半/右半内部的逆序对由递归解决，跨越的由 `mergeAndCount` 解决。

---

## 为什么归并能统计跨越逆序对

merge 之前，左右两个子数组**各自已经是升序的**。

当 `temp[i] > temp[j]`（左半当前元素 > 右半当前元素）时，由于左半升序：

```
temp[i] <= temp[i+1] <= ... <= temp[mid]
```

所以 `temp[j]` 与左半从 `i` 到 `mid` 的**每一个元素**都构成逆序对，一次性累加：

```java
count += (mid - i + 1);
```

不需要两层循环暴力枚举，这就是归并方案能做到 O(n log n) 的原因。

### 举例

```
左半: [2, 4, 6]   mid=2
右半: [1, 3, 5]
```

|i|j|temp[i]|temp[j]|动作|count|
|---|---|---|---|---|---|
|0|0|2|1|2>1，count += 3 (mid-0+1)|3|
|0|1|2|3|2<=3，i++|3|
|1|1|4|3|4>3，count += 2 (mid-1+1)|5|
|1|2|4|5|4<=5，i++|5|
|2|2|6|5|6>5，count += 1 (mid-2+1)|6|

---

## 剪枝优化

```java
if (record[mid] <= record[mid + 1]) {
    return leftPairs + rightPairs;
}
```

`record[mid]` 是左半**最大值**，`record[mid+1]` 是右半**最小值**。

若满足条件，则：

```
左半所有元素 <= record[mid] <= record[mid+1] <= 右半所有元素
```

任取左半元素 `a`、右半元素 `b`，均有 `a <= b`，不满足逆序对定义 `a > b`，跨越逆序对数为 0，直接跳过 merge。

对**近乎有序**的数组效果显著，不影响正确性，只是性能优化。

---

## copy 数组

```java
int[] copy = new int[len];
for (int i = 0; i < len; i++) {
    copy[i] = record[i];
}
```

归并排序会原地修改数组，copy 是为了不破坏原始入参。这道题本身没有保留原数组的要求，**去掉 copy 直接操作 record 也完全正确**，属于官方题解的防御性习惯写法。

---

## temp 数组的作用

```java
int[] temp = new int[len];
```

merge 时需要一个临时空间暂存数据，temp 在最外层分配一次并传递给所有递归调用，避免每次 merge 都 new 数组，减少内存分配开销。

---

## 完整流程

```
reversePairs(0, n-1)
├── reversePairs(0, mid)        # 左半递归
├── reversePairs(mid+1, n-1)    # 右半递归
├── [剪枝] record[mid] <= record[mid+1] → 直接返回
└── mergeAndCount(left, mid, right)
    ├── 复制到 temp
    ├── 双指针归并
    │   ├── temp[i] <= temp[j] → 取左，i++
    │   └── temp[i] >  temp[j] → 取右，j++，count += (mid-i+1)
    └── 返回 count
```

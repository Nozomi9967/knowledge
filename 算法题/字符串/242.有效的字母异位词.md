## 题解

```java
class Solution {
    public boolean isAnagram(String s, String t) {
        if(s.length()!=t.length()) return false;
        int len=s.length();
        // 由于小写英文字符只有26个
        int[] arr=new int[26];
        for(int i=0;i<len;i++){
            arr[s.charAt(i)-'a']++;
        }
        for(int i=0;i<len;i++){
            arr[t.charAt(i)-'a']--;
        }
        for(int i=0;i<26;i++){
            if(arr[i]!=0) return false;
        }
        return true;
    }
}
```

# 小红的花圃抬高方案（二分答案）

> [!abstract] 题目
> 小红要用土把所有花圃的最低高度尽量抬高。每单位土的填埋成本为 U；每车最多运 C 单位土，每启用一车另付运输费 F，一车土可分给多个花圃。预算为 B。求预算内所有花圃最终最低高度的最大值。

| 参数 | 范围 |
|-----|------|
| B（预算） | 1 ~ 10¹¹ |
| C（每车容量） | 1 ~ 100 |
| F（每车运输费） | 1 ~ 100 |
| U（单位填埋费） | 1 ~ 100 |
| n（花圃数） | 1 ~ 10⁵ |
| 初始高度 | [0, 10⁶] |

**输入描述：** 依次输入预算 B、每车容量 C、运输费 F、单位填埋费 U、花圃数 n，最后输入 n 个初始高度。

**输出描述：** 输出可达到的最大最低高度。

**示例 1：**
```
输入：
100
10
5
2
5
1 2 5 3 4
输出：
11
说明：抬高到 11 需要 40 单位土，填埋费 80、运输费 20。
```

**示例 2：**
```
输入：
50
10
10
1
10
1 2 5 3 4 5 4 1 1 1
输出：
4
说明：抬高到 4 总成本 35，抬高到 5 总成本 53。
```

## 核心思路：二分答案

要求"预算内最大最低高度"，是典型的**最大化最小值**问题，对目标高度 t 二分，用 check(t) 验证 t 秒内能否把成本控制在预算内。

### check(t)：抬高到 t 的成本

把花圃整体抬高到高度 t，每个花圃需要补 `max(0, t - h[i])` 单位土：

```
th = Σ max(0, t - h[i])          // 总土量
```

成本由两部分组成：

```
填埋费 = u × th
运输费 = ⌈th / c⌉ × f            // 每车最多 c 单位，向上取整车数
总成本 = u·th + ⌈th/c⌉·f
```

check 返回 `总成本 ≤ b`。

### 二分上界 r

- 初始 `l = min(hs)`（最低高度至少是当前最小值）、`r = max(hs)`。
- 上界估算：`r += b·c / (f + c·u)`——假设预算全部买土（每 c 单位土的成本 = f + c·u，即一车运输费加一车土的填埋费），最多还能补多少单位高度。这是一个松上界，保证答案落在 [l, r] 内。

### 二分框架

```
while (l <= r) {
    m = (r - l) / 2 + l;
    if (check(m)) l = m + 1;   // 成本够，还能更高
    else r = m - 1;            // 成本不够，降低目标
}
输出 r
```

注意：`check(m)` 成立时 `l = m+1`，最后输出的是 `r`（最后一个满足 check 的高度）。

## 完整 Java 代码

```java
import java.util.Scanner;

// 注意类名必须为 Main, 不要有任何 package xxx 信息
public class Main {

    public static long b;
    public static int c, f, u, n;
    public static int[] hs;

    public static boolean check(long t) {
        long th = 0;
        for (int h : hs) {
            th += Math.max(0, t - h);
        }
        long idelB = (th + c - 1) / c * (long) f + u * th;
        // System.out.println(t + " " + idelB);
        return idelB <= b;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        b = in.nextLong();
        c = in.nextInt();
        f = in.nextInt();
        u = in.nextInt();
        n = in.nextInt();
        hs = new int[n];
        long l = Long.MAX_VALUE, r = Long.MIN_VALUE;
        for (int i = 0; i < n; i++) {
            hs[i] = in.nextInt();
            l = Math.min(l, hs[i]);
            r = Math.max(r, hs[i]);
        }
        r += (b * c / (f + c * u));
        while (l <= r) {
            long m = (r - l) / 2 + l;
            // System.out.println(l + " " + m + " " + r);
            if (check(m)) l = m + 1;
            else r = m - 1;
        }
        System.out.print(r);
    }
}
```

## 复杂度

- 时间：O(n log H)，check 每次 O(n)，二分迭代约 log(H) 次，H 为上界（高度 + 预算折算）
- 空间：O(n)，hs 数组

## 面试话术

1. **为什么能二分？** → 单调性：目标高度越高，所需土量越多、成本越高，check 单调。最大化最小值 → 二分答案标准结构。
2. **成本为什么是两段式？** → 填埋费按土量线性 u·th；运输费按车数非线性 ⌈th/c⌉·f，向上取整是每车固定容量带来的离散成本，必须精确计算不能漏。
3. **上界为什么加 b·c/(f+c·u)？** → 用"预算全部按最便宜的整车边际成本买土"估算还能抬多高，保证答案不越界；b 是 long 防溢出。
4. **为什么最后输出 r 而不是 l？** → check(m) 成立时 l=m+1，循环退出时 r 是最后一个 check 成立的高度，恰好是最大可行解。
5. **要不要把每车分给多个花圃的特例？** → 不用，车土可分给多个花圃只影响总土量的车数统计，⌈th/c⌉ 已经正确建模。

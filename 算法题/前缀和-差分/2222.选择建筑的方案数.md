### **LeetCode 2222「选择建筑的方案数」前缀计数解法**

核心思路是**左右前缀计数**：对每个字符，统计其左侧和右侧的异类字符数量，乘积即为以该字符为中心的合法三元组数。时间复杂度 $O(n)$，空间 $O(n)$。

---

### **一、问题本身**

给定一个仅含 `'0'` 和 `'1'` 的字符串 `s`，需要选出 **3 个下标** `i < j < k`，要求选出的 3 个字符**两两不同**（即不能是三个相同字符）。求总共有多少种选法。

> 例如 `s = "001101"`，合法三元组：
> - `010` 型：`0(0) 1(3) 0(4)`、`0(0) 1(3) 0(5)`、`0(2) 1(3) 0(4)`、`0(2) 1(3) 0(5)` → 4 种
> - `101` 型：`1(3) 0(4) 1(5)` → 1 种
> 共 5 种。

**关键约束**：三个字符两两不同，等价于它们只能是两种排列：
- `010`：中间是 `1`，两边是 `0`
- `101`：中间是 `0`，两边是 `1`

没有其他可能（三个字符只有两种取值，两两不同必然是交替排列）。

---

### **二、解法**

```java
class Solution {
    public long numberOfWays(String s) {
        int n = s.length();
        long[] l = new long[n];  // l[i]: s[i] 左侧异类字符数
        long[] r = new long[n];  // r[i]: s[i] 右侧异类字符数
        char[] arr = s.toCharArray();
        long zero_l = 0, one_l = 0, zero_r = 0, one_r = 0;
        // 从左往右扫，填 l[]
        for (int i = 0; i < n; i++) {
            char cl = arr[i];
            if (cl == '0') {
                l[i] = one_l;    // 左边 1 的个数
                zero_l++;
            } else {
                l[i] = zero_l;   // 左边 0 的个数
                one_l++;
            }
        }
        // 从右往左扫，填 r[]
        for (int i = n - 1; i >= 0; i--) {
            char cr = arr[i];
            if (cr == '0') {
                r[i] = one_r;    // 右边 1 的个数
                zero_r++;
            } else {
                r[i] = zero_r;   // 右边 0 的个数
                one_r++;
            }
        }
        long ans = 0;
        for (int i = 0; i < n; i++) {
            ans += l[i] * r[i];
        }
        return ans;
    }
}
```

#### **核心思想**

对每个位置 `i`，`l[i]` 是 `s[i]` 左侧异类字符的个数，`r[i]` 是右侧异类字符的个数。以 `i` 作为三元组中间字符时：

- 若 `s[i] == '1'`，三元组为 `0 1 0`，方案数 = `l[i]（左边0的个数）× r[i]（右边0的个数）`
- 若 `s[i] == '0'`，三元组为 `1 0 1`，方案数 = `l[i]（左边1的个数）× r[i]（右边1的个数）`

无论哪种情况，乘积 `l[i] × r[i]` 都正确。对所有 `i` 累加即得总方案数。

#### **前缀计数原理**

`l[i]` 的维护：从左往右扫，遇到 `'0'` 时 `l[i]` 赋值为当前已累计的 `one_l`（左边 `'1'` 的数量），遇到 `'1'` 时赋值为 `zero_l`。这样 `l[i]` 始终等于 `s[i]` 左侧异类字符的个数。

`r[i]` 同理，只是从右往左扫。

---

### **三、复杂度分析**

- **时间复杂度**：三次线性扫描（左→右、右→左、求和），总计 $O(n)$。
- **空间复杂度**：`l / r` 两数组各 $O(n)$，可滚动优化到 $O(1)$（见下方优化）。

---

### **四、空间优化**

`ans` 只需要 `l[i] × r[i]` 的累加和，不需要同时存储整个 `l / r` 数组。可以先从左往右扫一遍把 `l` 算出，再从右往左扫，当场累加 `ans += l[i] * r_cur`，`r` 只保留一个当前值：

```java
class Solution {
    public long numberOfWays(String s) {
        int n = s.length();
        char[] a = s.toCharArray();
        long[] l = new long[n];
        long z = 0, o = 0;
        for (int i = 0; i < n; i++) {
            l[i] = a[i] == '0' ? o : z;
            if (a[i] == '0') z++; else o++;
        }
        long ans = 0;
        z = 0; o = 0;
        for (int i = n - 1; i >= 0; i--) {
            long r = a[i] == '0' ? o : z;
            ans += l[i] * r;
            if (a[i] == '0') z++; else o++;
        }
        return ans;
    }
}
```

空间从 $O(n)$ 降到 $O(n)$（`l` 数组保留，`r` 变常量），若再进一步把 `l` 也省略，需要两次往返扫描，写法稍繁琐但可行。

### **五、一个具体例子走一遍**

以 `s = "001101"`（`n = 6`）为例：

**第一遍（左→右，填 `l[]`）：**

| i | s[i] | one_l | zero_l | l[i]（左边异类数） |
|---|------|-------|--------|-------------------|
| 0 | '0'  | 0     | 1      | 0（左边无 `'1'`）  |
| 1 | '0'  | 0     | 2      | 0                |
| 2 | '1'  | 1     | 2      | 2（左边 2 个 `'0'`）|
| 3 | '1'  | 2     | 2      | 2（左边 2 个 `'0'`）|
| 4 | '0'  | 2     | 3      | 2（左边 2 个 `'1'`）|
| 5 | '1'  | 3     | 3      | 3（左边 3 个 `'0'`）|

**第二遍（右→左，填 `r[]`）：**

| i | s[i] | one_r | zero_r | r[i]（右边异类数） |
|---|------|-------|--------|-------------------|
| 5 | '1'  | 1     | 0      | 0（右边无 `'0'`）  |
| 4 | '0'  | 1     | 1      | 1（右边 1 个 `'1'`）|
| 3 | '1'  | 2     | 1      | 1（右边 1 个 `'0'`）|
| 2 | '1'  | 3     | 1      | 1（右边 1 个 `'0'`）|
| 1 | '0'  | 3     | 2      | 3（右边 3 个 `'1'`）|
| 0 | '0'  | 3     | 3      | 3（右边 3 个 `'1'`）|

**累加 `ans = Σ l[i] × r[i]`：**

| i | l[i] | r[i] | 乘积 | 对应三元组 |
|---|------|------|------|-----------|
| 0 | 0    | 3    | 0    | —         |
| 1 | 0    | 3    | 0    | —         |
| 2 | 2    | 1    | **2** | `0(0)1(2)0(4)`、`0(1)1(2)0(4)` |
| 3 | 2    | 1    | **2** | `0(0)1(3)0(4)`、`0(1)1(3)0(4)` |
| 4 | 2    | 1    | **2** | `1(2)0(4)1(5)`、`1(3)0(4)1(5)` |
| 5 | 3    | 0    | 0    | —         |

`ans = 2 + 2 + 2 = 6`，即 `"001101"` 共有 6 种选法，符合预期。

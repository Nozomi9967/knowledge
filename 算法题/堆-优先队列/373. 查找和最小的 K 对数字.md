## 题目

https://leetcode.cn/problems/find-k-pairs-with-smallest-sums/description/?envType=study-plan-v2&envId=top-interview-150

## 题解



```java
class Solution {
    public List<List<Integer>> kSmallestPairs(int[] nums1, int[] nums2, int k) {
        List<List<Integer>> ans=new ArrayList<>(k);
        PriorityQueue<int[]> pq=new PriorityQueue<>((a,b)->a[0]-b[0]);
        for(int i=0;i<nums1.length;i++) pq.offer(new int[]{nums1[i]+nums2[0],i,0});

        while(k-->0){
            int[] arr=pq.poll();
            int i=arr[1];
            int j=arr[2];
            ans.add(List.of(nums1[i],nums2[j]));
            if(j+1<nums2.length) pq.offer(new int[]{nums1[i]+nums2[j+1],i,j+1});
        }
        return ans;
    }
}
```

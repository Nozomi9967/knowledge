## 📋 版本一：标准版（约90秒，适合大多数面试）

> 面试官好，我叫**彭仁希**，来自**杭州电子科技大学计算机科学与技术专业**，目前大四，GPA 4.054/5。

> 技术方面，我熟悉 Java 并发、JVM 内存模型，熟悉 Spring Boot 和 Spring Cloud Alibaba 微服务体系，包括 Nacos、Gateway、Sentinel、Seata；在数据层掌握 MySQL 索引调优、Redis 分布式锁、RocketMQ 事务消息，以及 Elasticsearch 搜索方案。

> **实习方面**，我在北京远舢智能先后做过运维部署和后端开发实习，参与了数据中台告警模块的接口开发和 Bug 排查工作。

> 此外，我有一个比较特别的经历——**用3个月、借助 AI Agent 独立交付了一套面向自己生活上使用的全栈系统**，涵盖 Vue 前端、Spring Boot 微服务和 Android App，完整走过开发到 ECS 生产部署的全流程。

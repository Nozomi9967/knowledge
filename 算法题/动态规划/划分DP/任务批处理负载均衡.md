### **任务批处理负载均衡 — 划分 DP + 切点回溯**

核心思路是**划分 DP + path 数组回溯**：把 n 个连续任务按顺序分成 m 批，最小化每批成本和的平方和（等价于最小化标准差），状态转移枚举最后一批的起点 k，用 path 数组记录最优切点以还原每批任务数。时间复杂度 $O(n^2 m)$，空间 $O(nm)$。

---

### **一、题目描述**

#### **任务批处理负载均衡**

一个云计算中心接收到了一系列需要连续处理的微任务。现在有 $n$ 个任务排成一队，每个任务都有一个已知的计算成本。为了高效利用服务器资源，系统需要将这 $n$ 个连续的任务划分成 $m$ 个"批次"进行处理。

划分的规则是：必须按照任务队列的顺序进行划分，不能打乱任务原有的先后次序。例如，第一个批次处理前 $k_1$ 个任务，第二个批次处理接下来的 $k_2$ 个任务，以此类推。

为了使服务器负载尽可能平稳，调控目标是：找到一种划分方案，使得这 $m$ 个批次各自的"总计算成本"（即批次内所有任务的成本之和）的标准差达到最小。

你的任务就是找出这个最优的划分方案。

#### **限制条件**

- **时间限制**：C/C++ 1秒，其他语言 2秒
- **空间限制**：C/C++ 256M，其他语言 512M
- **数据范围**：
  - 任务总数 $n$（$2 < n \le 20$）
  - 划分的批次数目 $m$（$2 < m < n$）
  - 每个任务的计算成本 $c_i$（$0 < c_i < 100$）

#### **输入描述**

- 第一行输入两个整数，第一个是任务总数 $n$，第二个是需要划分的批次数目 $m$。
- 第二行输入一个包含 $n$ 个正整数的序列 $C = \{c_0, c_1, \dots, c_{n-1}\}$，其中第 $i$ 个元素 $c_i$ 代表第 $i$ 个任务的计算成本。

#### **输出描述**

- 输出一行，包含 $m$ 个整数，代表最优划分方案中，每个批次依次包含的任务数量。
- 例如，输出 `3 3 2 2` 表示：第 1 批包含前 3 个任务，第 2 批包含接下来的 3 个任务，第 3 批包含再接下来的 2 个任务，第 4 批包含最后 2 个任务。

#### **示例 1**

- **输入**：

  ```text
  8 4
  30 42 85 19 65 13 94 57
  ```

- **输出**：

  ```text
  2 1 3 2
  ```

### **二、核心数学背景补充**

> **为什么代码中最小化的是"每批成本之和的平方和"？**
>
> 题目要求使 $m$ 个批次的"总计算成本"的**标准差**达到最小。
> 标准差的计算公式为：
> $$\sigma = \sqrt{\frac{1}{m} \sum_{i=1}^{m} (X_i - \bar{X})^2}$$
> 其中 $X_i$ 是第 $i$ 批的成本和，$\bar{X}$ 是所有批次成本的平均值。
>
> 观察公式可以发现：
> 1. 所有任务的总计算成本 $\sum c_i$ 是固定的，因此平均值 $\bar{X} = \frac{\sum c_i}{m}$ 也是一个**常数**。
> 2. 批次数 $m$ 也是固定的常数。
>
> 将方差公式展开：
> $$\sum (X_i - \bar{X})^2 = \sum (X_i^2 - 2X_i\bar{X} + \bar{X}^2) = \sum X_i^2 - 2\bar{X}\sum X_i + m\bar{X}^2$$
> 因为 $\sum X_i$（所有批次的和之和）等于总成本，是一个常数。所以，公式中的 $- 2\bar{X}\sum X_i + m\bar{X}^2$ 部分在任何划分方案下都是一个**固定常数**。
>
> **结论**：要让标准差最小，等价于让每个批次和的平方和 $\sum X_i^2$ 达到最小。这就是为什么我们可以直接用动态规划来求最小平方和。

### **三、动态规划填表详解**

这部分填表的核心逻辑非常直观，以下是详细拆解：

这段代码的填表部分其实就在反复回答一个问题：**前 i 个任务，分成 j 批，怎么分能让"每批和的平方"加起来最小？** 关键在于抓住一个事实——不管怎么分，第 j 批（最后一批）一定是以第 i 个任务结尾的连续一段，唯一不确定的是它从哪儿开始，而这个起点由 $k$ 决定。

#### **核心思想：最后一批是"以 i 结尾的后缀"**

一旦确定了切点 $k$，整个划分就被拆成两块独立的部分：

- **前 k 个任务**：已经分成 $j-1$ 批，它的最优解就是 `dp[k][j-1]`（之前算好的）
- **第 j 批**：任务 $k+1$ 到 $i$，这批的和 = `prefixSum[i] - prefixSum[k]`，贡献的平方就是 $(S_i - S_k)^2$

所以枚举所有合法的切点 $k$，取其中最小的那个，状态转移就是：

$$
dp[i][j] = \min_{k} \left\{\, dp[k][j-1] + (S_i - S_k)^2 \,\right\}
$$

对应到代码里就是这句：

```java
dp[i][j] = dp[k][j - 1] + currentSq;   // currentSq = (prefixSum[i]-prefixSum[k])²
```

用图来理解这个切点最直观：

```text
任务(1-indexed):  1   2   3  ...  k  ‖  k+1  k+2  ...  i
                 ←—— 前 k 个分 j−1 批 ——→  ←— 第 j 批 —→
                  最优值 = dp[k][j-1]        和 = S_i − S_k
```

竖线 `‖` 就是切点 $k$。内层循环干的事，就是把这条竖线从左往右挪，每挪一个位置就算一次总代价，最后留下最小的。

#### **三重循环各自在干什么**

外层 `i`（1→n）表示"现在考虑前几个任务"，是逐步把任务一个一个加进来。

中层 `j`（1→`min(i,m)`）表示"分成几批"。为什么是 `min(i,m)`？因为批数不能超过两个上限：一是任务数 `i`（每个批至少 1 个任务，i 个任务最多 i 批），二是题目给的 `m`（最多 m 批）。取两者较小值，避免去算那些根本不可能的状态。

内层 `k` 就是上面说的切点，把竖线挨个试一遍。

#### **k 的范围为什么是 `[j-1, i-1]`**

下界 `k ≥ j−1`：切点 k 意味着前 k 个任务要分成 j−1 批。每批至少 1 个任务，j−1 批至少需要 j−1 个任务，所以 k 最小只能是 j−1。

上界 `k < i`（循环写的是 `k < i`，即 `k ≤ i−1`）：第 j 批必须包含第 i 个任务（它是以 i 结尾的后缀），不能是空的，所以切点最多到 i−1，把第 i 个任务留给最后一批。

这两个边界合起来保证：前面 j−1 批"够分"，后面第 j 批"非空"。

#### **那两个 if 在防什么**

```java
if (dp[k][j - 1] != INF) {                          // ① 状态可达吗
    if (dp[k][j - 1] + currentSq < dp[i][j]) {       // ② 更优吗
        dp[i][j] = dp[k][j - 1] + currentSq;
        path[i][j] = k;
    }
}
```

① `dp[k][j-1] != INF`：前 k 个任务分 j−1 批这个状态可能根本不合法（比如 k 太小、分不满 j−1 批时它一直停留在初始的 `INF`）。遇到 `INF` 直接跳过，否则会把 `INF + currentSq` 当成有效解，算出错误的最小值。

② `dp[k][j-1] + currentSq < dp[i][j]`：标准的"取最小"判断。`dp[i][j]` 初始是 `INF`，第一个合法的 k 会把它拉下来，之后只有更小的才能继续更新。

#### **拿一个具体例子算一遍**

设 `n=4`，`costs=[1,2,3,4]`，`m=2`，则 `prefixSum=[0,1,3,6,10]`。来算 `dp[4][2]`（4 个任务分 2 批的最小平方和），k 取 1 到 3：

| k | 前半 `dp[k][1]` | 第 2 批和 $S_4-S_k$ | 平方 | 合计 | 对应划分 |
|---|----------------|-------------------|------|------|---------|
| 1 | 1 ($=1^2$)     | 10−1=9            | 81   | **82** | [1] \| [2,3,4] |
| 2 | 9 ($=3^2$)     | 10−3=7            | 49   | **58** | [1,2] \| [3,4] |
| 3 | 36 ($=6^2$)    | 10−6=4            | 16   | **52** | [1,2,3] \| [4] |

最小是 52，发生在 `k=3`，于是 `path[4][2]=3`。这就是 `path` 数组的作用——**记下"最优的那一刀切在哪"**，这样最后回溯时就能知道每批到底有几个任务：从 `dp[4][2]` 查到 `path[4][2]=3`，说明第 2 批是 `4−3=1` 个任务；再跳到 `dp[3][1]` 继续往前推，就把整个划分还原出来了。

一句话总结这段填表：**固定"最后一批以 i 结尾"，枚举它的起点 k，把问题拆成"前 k 个分 j−1 批的最优解 + 最后一批的平方"，取所有 k 里的最小值。**

### **四、完整代码**

```java
import java.util.*;

public class Main {
    static final long INF = Long.MAX_VALUE / 2;

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int m = in.nextInt();

        long[] prefix = new long[n + 1];
        for (int i = 1; i <= n; i++) {
            prefix[i] = prefix[i - 1] + in.nextInt();
        }

        // dp[i][j]：前 i 个任务分成 j 批的最小平方和
        long[][] dp = new long[n + 1][m + 1];
        int[][] path = new int[n + 1][m + 1];   // path[i][j]：最优切点
        for (long[] row : dp) Arrays.fill(row, INF);
        dp[0][0] = 0;   // 0 个任务分 0 批，代价 0

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= Math.min(i, m); j++) {
                for (int k = j - 1; k < i; k++) {
                    if (dp[k][j - 1] == INF) continue;        // ① 状态不可达
                    long cur = prefix[i] - prefix[k];         // 第 j 批的和
                    long cost = dp[k][j - 1] + cur * cur;     // ② 更优则更新
                    if (cost < dp[i][j]) {
                        dp[i][j] = cost;
                        path[i][j] = k;
                    }
                }
            }
        }

        // 回溯每批任务数
        int[] cnt = new int[m];
        int cur = n;
        for (int j = m; j >= 1; j--) {
            int k = path[cur][j];
            cnt[j - 1] = cur - k;
            cur = k;
        }x
        for (int i = 0; i < m; i++) {
            if (i > 0) System.out.print(" ");
            System.out.print(cnt[i]);
        }
        System.out.println();
    }
}
```

### **五、复杂度分析**

- **时间复杂度**：$O(n^2 m)$。三重循环：外层 $n$、中层 $m$、内层切点 $k$ 最多 $n$ 个。$n \le 20$，实际计算量极小。
- **空间复杂度**：$O(nm)$。dp 表和 path 表各 $O(nm)$，prefix 表 $O(n)$。

### **六、面试话术**

1. **为什么最小化平方和而不是直接算标准差？** — 标准差公式展开后，含 $\bar{X}$ 的项都是常数（总成本固定、m 固定），唯一随划分变化的只有 $\sum X_i^2$。最小化标准差等价于最小化平方和，避免小数运算和开根号。
2. **为什么用划分 DP？** — 连续顺序划分、批数上限 m、每个批次至少一个任务——三个约束正好对应划分 DP 的三重循环：`i`（前缀长度）、`j`（批数）、`k`（最后一批起点）。
3. **k 的边界怎么定？** — 下界 `j-1`：前 k 个要分 j-1 批，每批至少 1 个任务；上界 `i-1`：最后一批必须以 i 结尾且非空。
4. **为什么需要 path 数组？** — 题目要求输出划分方案（每批任务数），只存 dp 值无法还原切点。`path[i][j]` 记录 dp[i][j] 最优时的 k，从 `(n, m)` 倒推即可输出方案。
5. **与 [[813.最大平均值和的分组]] 的关系** — 同一模板：枚举最后一段起点 + 前缀和算段和。813 多了分组数 ≤ k 的维度，本题多了 path 回溯输出方案。

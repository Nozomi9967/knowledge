给定一个不重复的整数数组 `nums` 。 **最大二叉树** 可以用下面的算法从 `nums` 递归地构建:

1. 创建一个根节点，其值为 `nums` 中的最大值。
2. 递归地在最大值 **左边** 的 **子数组前缀上** 构建左子树。
3. 递归地在最大值 **右边** 的 **子数组后缀上** 构建右子树。

返回 *`nums` 构建的* ***最大二叉树*** 。

**示例 1：**

![](https://assets.leetcode.com/uploads/2020/12/24/tree1.jpg)
```
输入：nums = [3,2,1,6,0,5]
输出：[6,3,5,null,2,0,null,null,1]
解释：递归调用如下所示：
- [3,2,1,6,0,5] 中的最大值是 6 ，左边部分是 [3,2,1] ，右边部分是 [0,5] 。
    - [3,2,1] 中的最大值是 3 ，左边部分是 [] ，右边部分是 [2,1] 。
        - 空数组，无子节点。
        - [2,1] 中的最大值是 2 ，左边部分是 [] ，右边部分是 [1] 。
            - 空数组，无子节点。
            - 只有一个元素，所以子节点是一个值为 1 的节点。
    - [0,5] 中的最大值是 5 ，左边部分是 [0] ，右边部分是 [] 。
        - 只有一个元素，所以子节点是一个值为 0 的节点。
        - 空数组，无子节点。
```

**示例 2：**

![](https://assets.leetcode.com/uploads/2020/12/24/tree2.jpg)
```
输入：nums = [3,2,1]
输出：[3,null,2,null,1]
```

**提示：**

- `1 <= nums.length <= 1000`
- `0 <= nums[i] <= 1000`
- `nums` 中的所有整数 **互不相同**

递归
```java
/**

 * Definition for a binary tree node.

 * public class TreeNode {

 *     int val;

 *     TreeNode left;

 *     TreeNode right;

 *     TreeNode() {}

 *     TreeNode(int val) { this.val = val; }

 *     TreeNode(int val, TreeNode left, TreeNode right) {

 *         this.val = val;

 *         this.left = left;

 *         this.right = right;

 *     }

 * }

 */

class Solution {

  

    public TreeNode fun(int[] nums,int l,int r){

        if(l>r) return null;

        int max=l;

        for(int i=l;i<=r;i++) max=nums[max]<nums[i]?i:max;

  

        var root=new TreeNode(nums[max]);

        root.left=fun(nums,l,max-1);

        root.right=fun(nums,max+1,r);

  

        return root;

    }

  

    public TreeNode constructMaximumBinaryTree(int[] nums) {

        return fun(nums,0,nums.length-1);

    }

}
```


单调栈
```java
class Solution {
    public TreeNode constructMaximumBinaryTree(int[] nums) {
        int n = nums.length;
        Deque<Integer> stack = new ArrayDeque<Integer>();
        int[] left = new int[n];
        int[] right = new int[n];
        Arrays.fill(left, -1);
        Arrays.fill(right, -1);
        TreeNode[] tree = new TreeNode[n];
        for (int i = 0; i < n; ++i) {
            tree[i] = new TreeNode(nums[i]);
            while (!stack.isEmpty() && nums[i] > nums[stack.peek()]) {
                right[stack.pop()] = i;
            }
            if (!stack.isEmpty()) {
                left[i] = stack.peek();
            }
            stack.push(i);
        }

        TreeNode root = null;
        for (int i = 0; i < n; ++i) {
            if (left[i] == -1 && right[i] == -1) {
                root = tree[i];
            } else if (right[i] == -1 || (left[i] != -1 && nums[left[i]] < nums[right[i]])) {
                tree[left[i]].right = tree[i];
            } else {
                tree[right[i]].left = tree[i];
            }
        }
        return root;
    }
}
```

这段代码实现了 **“构造最大二叉树” (Maximum Binary Tree)** 的算法，且使用了一种时间复杂度为 **$O(n)$** 的单调栈（Monotonic Stack）优化方法。

为了让你更容易理解，我们分两部分来看：

### 1. 什么是“最大二叉树”？

题目定义如下：

- 二叉树的根是数组中的最大值。
    
- 左子树是最大值左边数组部分构造出的最大二叉树。
    
- 右子树是最大值右边数组部分构造出的最大二叉树。
    

### 2. 代码逻辑解析

普通的递归解法时间复杂度是 $O(n^2)$，因为每次都要遍历数组找最大值。这份代码用了单调栈，把复杂度优化到了 $O(n)$。

#### 第一阶段：确定父子关系（单调栈部分）

Java

```
for (int i = 0; i < n; ++i) {
    // 维护一个单调递减栈
    while (!stack.isEmpty() && nums[i] > nums[stack.peek()]) {
        right[stack.pop()] = i; // 当前元素 nums[i] 是栈顶元素的右边界
    }
    if (!stack.isEmpty()) {
        left[i] = stack.peek(); // 栈顶元素是当前元素 nums[i] 的左边界
    }
    stack.push(i);
}
```

- **核心逻辑**：对于任何一个元素 `nums[i]`，它的“父节点”一定是它左边第一个比它大的数和右边第一个比它大的数中，**值较小的那一个**。
    
- `left[i]` 存的是左边第一个比 `nums[i]` 大的下标。
    
- `right[i]` 存的是右边第一个比 `nums[i]` 大的下标。
    

#### 第二阶段：构建树

Java

```
for (int i = 0; i < n; ++i) {
    if (left[i] == -1 && right[i] == -1) {
        root = tree[i]; // 没左也没右，说明它是全局最大，即根节点
    } else if (right[i] == -1 || (left[i] != -1 && nums[left[i]] < nums[right[i]])) {
        tree[left[i]].right = tree[i]; // 连接到左父节点的右侧
    } else {
        tree[right[i]].left = tree[i]; // 连接到右父节点的左侧
    }
}
```

- 这一步把逻辑简化为：把当前的节点 `tree[i]` 挂载到它的左右父节点中较小的那一个下面。
    

### 总结：为什么要这样做？

- **直观理解**：数组中每个数 `nums[i]` 都有其左边和右边最近的“老大”（比它大的数）。为了满足最大二叉树的定义，`nums[i]` 必须成为这两个“老大”中**较小的那一个**的子节点。
    
- **性能**：
    
    - **普通递归**：每层都要遍历找最大值，最坏情况是 $O(n^2)$。
        
    - **单调栈**：每个元素进栈出栈各一次，时间复杂度为 $O(n)$，是最高效的解法。
        

**简单来说：这段代码通过“单调栈”快速找到了数组中每个元素在树结构中的直接父节点，然后直接连线建树。**

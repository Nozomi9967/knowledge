# P1048 [NOIP 2005 普及组] 采药（01 背包）

## 题目描述

辰辰是个天资聪颖的孩子，他的梦想是成为世界上最伟大的医师。为此，他想拜附近最有威望的医师为师。医师为了判断他的资质，给他出了一个难题。医师把他带到一个到处都是草药的山洞里对他说："孩子，这个山洞里有一些不同的草药，采每一株都需要一些时间，每一株也有它自身的价值。我会给你一段时间，在这段时间里，你可以采到一些草药。如果你是一个聪明的孩子，你应该可以让采到的草药的总价值最大。"

如果你是辰辰，你能完成这个任务吗？

## 输入格式

第一行有 2 个整数 T（1 ≤ T ≤ 1000）和 M（1 ≤ M ≤ 100），用一个空格隔开，T 代表总共能够用来采药的时间，M 代表山洞里的草药的数目。

接下来的 M 行每行包括两个在 1 到 100 之间（包括 1 和 100）的整数，分别表示采摘某株草药的时间和这株草药的价值。

## 输出格式

输出在规定的时间内可以采到的草药的最大总价值。

## 输入输出样例 #1

### 输入 #1

```
70 3
71 100
69 1
1 2
```

### 输出 #1

```
3
```

## 说明/提示

**【数据范围】**

- 对于 30% 的数据，M ≤ 10；
- 对于全部的数据，M ≤ 100。

**【题目来源】**

NOIP 2005 普及组第三题

## 解法：01 背包

每株草药只有「采」或「不采」两种选择，时间就是背包容量，价值就是物品价值。经典 01 背包。

### 状态定义

`d[j]` = 在总时间恰好为 j 的情况下，能采到的草药最大总价值。初始 `d[0] = 0`，其余为 -1（表示不可达）。

### 递推关系

对每株草药（时间 T，价值 V），从后往前更新：

```java
for (int j = t; j >= T; j--) {
    if (d[j - T] != -1) {
        d[j] = Math.max(d[j - T] + V, d[j]);
    }
}
```

从后往前是为了避免同一株草药被重复选择（0-1 背包核心套路）。

### 完整 Java 代码

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String args[]) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StreamTokenizer st = new StreamTokenizer(br);

        st.nextToken(); int t = (int)st.nval;
        st.nextToken(); int m = (int)st.nval;

        int[] d = new int[t + 1];
        Arrays.fill(d, -1);
        d[0] = 0;
        int ans = 0;

        for (int i = 0; i < m; i++) {
            st.nextToken(); int T = (int)st.nval;
            st.nextToken(); int V = (int)st.nval;
            if (T > t) continue;
            for (int j = t; j >= T; j--) {
                if (d[j - T] != -1) {
                    d[j] = Math.max(d[j - T] + V, d[j]);
                    ans = Math.max(ans, d[j]);
                }
            }
        }
        System.out.println(ans);
    }
}
```

### 复杂度

- 时间：O(M × T)，M ≤ 100，T ≤ 1000，完全可过
- 空间：O(T)

## 面试话术

1. **为什么是 01 背包而不是完全背包？** → 每株草药只能采一次，不是无限量供应的物品，所以是 0-1 背包。
2. **为什么用 -1 初始化而不是 0？** → -1 表示该时间量不可达；如果全用 0 初始化，无法区分"时间恰好 j 能拿到价值 0"和"时间 j 根本凑不出来"。
3. **为什么内层循环从后往前？** → 0-1 背包每件物品只能用一次，正序会导致同一物品被反复选取（选了又选），倒序保证每件物品在每个容量下只被考虑一次。
4. **ans 为什么在循环内实时更新？** → 因为 `d[j]` 只保证"恰好 j 时间"的最大值，而答案可能在任意 j ≤ t 处取得，所以每次更新后取全局最大。

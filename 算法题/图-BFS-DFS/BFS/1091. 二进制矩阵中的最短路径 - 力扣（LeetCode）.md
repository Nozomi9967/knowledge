提示

给你一个 `n x n` 的二进制矩阵 `grid` 中，返回矩阵中最短 **畅通路径** 的长度。如果不存在这样的路径，返回 `-1` 。

二进制矩阵中的 畅通路径 是一条从 **左上角** 单元格（即， `(0, 0)` ）到 右下角 单元格（即， `(n - 1, n - 1)` ）的路径，该路径同时满足下述要求：

- 路径途经的所有单元格的值都是 `0` 。
- 路径中所有相邻的单元格应当在 **8 个方向之一** 上连通（即，相邻两单元之间彼此不同且共享一条边或者一个角）。

**畅通路径的长度** 是该路径途经的单元格总数。

**示例 1：**

![](https://assets.leetcode.com/uploads/2021/02/18/example1_1.png)
```
输入：grid = [[0,1],[1,0]]
输出：2
```

**示例 2：**

![](https://assets.leetcode.com/uploads/2021/02/18/example2_1.png)
```
输入：grid = [[0,0,0],[1,1,0],[1,1,0]]
输出：4
```

**示例 3：**

```
输入：grid = [[1,0,0],[1,1,0],[1,1,0]]
输出：-1
```

class Solution {

    public int shortestPathBinaryMatrix(int[][] grid) {

        if(grid[0][0]==1) return -1;

        int m=grid.length;

        int n=grid[0].length;

        var v=new boolean[m][n];

        var pq=new ArrayDeque<int[]>();

        pq.offer(new int[]{0,0});

        v[0][0]=true;

        int cnt=0;

        int[] dx=new int[]{0,0,-1,1,-1,1,-1,1};

        int[] dy=new int[]{-1,1,1,-1,0,0,-1,1};

        while(!pq.isEmpty()){

            int size=pq.size();

            cnt++;

            while(size-->0){

                int[] pos=pq.poll();

                int x=pos[0],y=pos[1];

                for(int i=0;i<8;i++){

                    int nx=x+dx[i];

                    int ny=y+dy[i];

                    if(nx<0||ny<0||nx>=m||ny>=n||v[nx][ny]||grid[nx][ny]==1) continue;

                    if(nx==m-1&&ny==n-1) return cnt+1;

                    pq.offer(new int[]{nx,ny});

                    v[nx][ny]=true;

                }

            }

        }

  

        return v[m-1][n-1]?cnt:-1;

    }

}

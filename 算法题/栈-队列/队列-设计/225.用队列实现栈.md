### **LeetCode 225「用队列实现栈」只需要一个队列：每次 push 之后，把队头前面已有的元素依次搬到队尾，让新元素始终在队头。这样 push 是 O(n)、pop/peek 是 O(1)——用"写时搬运"换"读时开销"。**

### **一、问题本身**

只允许用队列（先进先出）实现栈的四个方法：`push`、`pop`、`top`、`empty`。

```
push(1), push(2), top() → 2, pop() → 2, empty() → false
```

---

### **二、核心思路：一个队列就够了**

队列是"尾进头出"，栈是"后进先出"。要让最后进去的元素从队头出来，**在 push 的时候把它搬到队头**：

```
初始：[] 
push(1)：入队 [1]，新元素本来就在队头，不搬
push(2)：入队 [1,2]，把 2 前面的 1 个元素搬到队尾 → [2,1]
push(3)：入队 [2,1,3]，把 3 前面的 2 个元素搬走 → [3,2,1]
```

此时队列的队头就是栈顶，`pop` 直接 `poll()` 即可。

**关键操作**：新元素入队后，把"当前队列长度 - 1"个元素从队头取出再放回队尾。因为队列长度在入队后是 `size`，所以要搬 `size - 1` 次。

---

### **三、代码**

```java
class MyStack {
    private Deque<Integer> q;

    public MyStack() {
        q = new ArrayDeque<>();
    }

    public void push(int x) {
        q.offerLast(x);
        // 把新元素之前的 size-1 个元素全部转到队尾
        int size = q.size();
        for (int i = 0; i < size - 1; i++) {
            q.offerLast(q.pollFirst());
        }
    }

    public int pop() {
        return q.pollFirst();    // 队头就是栈顶
    }

    public int top() {
        return q.peekFirst();
    }

    public boolean empty() {
        return q.isEmpty();
    }
}
```

---

### **四、为什么不用两个队列**

经典教科书答案是"两个队列，一个存数据一个辅助"，push 时把数据全搬到辅助队列再换回来——效果和单队列一样，只是多一个容器。**单队列更简洁，面试时能主动说"其实一个队列就够"是加分项。**

两个队列的写法反而容易出错：搬运后忘记交换引用、辅助队列没清空等。

---

### **五、复杂度**

| 操作 | 时间复杂度 |
|---|---|
| push | O(n) —— 搬 n-1 个元素 |
| pop / top / empty | O(1) |

**和 232 对比**：232 是"push 便宜、pop 均摊 O(1)"，这题是"push 贵、pop 便宜"。**两题刚好相反的原因在于：栈和队列的"新元素位置"不同。** 队列的新元素在队尾，要让它变队头必须搬；栈的新元素天然在栈顶，不用搬。

如果想让 push 变 O(1)，就只能在 pop 时搬——但队列在 pop 时没法"从尾部取"，所以用队列实现栈**必然有一边是 O(n)**，这是数据结构性质决定的，不是实现问题。

---

### **六、易错点**

1. **搬运次数写成 `size`**：入队后长度是 `size`，只需搬 `size - 1` 个（新元素本身不搬）
2. **先取 size 再入队**：必须先入队、再取 size，或者用 `size = q.size()` 入队后取
3. **搬运时用 `pollLast`**：队列只能从队头取（`pollFirst`），从尾部取就不是队列了
4. **pop 时判空**：本题保证 pop 时非空，工程代码要判
5. **以为需要两个队列**：单队列即可，这是本题最容易被低估的点

---

### **七、面试延伸**

**"如果用链表实现呢"**：队列用 `LinkedList`，逻辑完全一样，只是 `pollFirst` 变成 `removeFirst`。

**"能不能两边都 O(1)"**：不能。用队列模拟栈，必然有一边 O(n)，因为队列不支持从尾部取元素。这是**数据结构的表达能力**问题——队列的表达能力弱于栈（栈可以模拟队列，但队列模拟栈必须付代价）。

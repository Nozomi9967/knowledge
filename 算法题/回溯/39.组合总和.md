## 题解



```java
class Solution {
    List<List<Integer>> res=new ArrayList<>();

    void dfs(int index,int len,int[] candidates,int target,List<Integer> list){
        if(target==0){
            res.add(List.copyOf(list));
            return;
        }
        if(index==len||target<0) return;
        // 不选
        dfs(index+1,len,candidates,target,list);
        // 选
        list.add(candidates[index]);
        dfs(index,len,candidates,target-candidates[index],list);
        list.remove(list.size()-1);
    }

    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        int len=candidates.length;
        dfs(0,len,candidates,target,new ArrayList<Integer>());
        return res;
    }
}
```

## 「选或不选」模板 · cur 累加写法（2026-09 补充）

与 [[算法题/回溯/78.子集.md]] / [[算法题/回溯/90.子集II.md]] / [[算法题/回溯/40.组合总和II.md]] 同一套模板的完全对齐版——把「剩余 target 递减」换成「当前和 cur 递增」，分支顺序换成先选后不选：

```java
class Solution {

    void dfs(int i,int[] candidates,int cur,int target,List<Integer> tem,List<List<Integer>> ans){
        if(cur==target){
            ans.add(new ArrayList<Integer>(tem));
            return;
        }
        if(cur>target || i==candidates.length) return;

        // 重复加自己
        tem.add(candidates[i]);
        dfs(i,candidates,cur+candidates[i],target,tem,ans);
        tem.removeLast();

        // 加别人
        dfs(i+1,candidates,cur,target,tem,ans);
    }

    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        List<List<Integer>> ans=new ArrayList<>();
        dfs(0,candidates,0,target,new ArrayList<Integer>(),ans);
        return ans;
    }
}
```

### 与上面两版的关系

- **cur 累加 vs target 递减**：等价的两种记账方式。`cur==target` ⇔ `target剩余==0`；`cur>target` 越界剪枝 ⇔ `target<0`。cur 版的好处是收集条件、剪枝条件都是「当前状态和目标的直观比较」，和 78 题模板只差一个 cur 参数。
- **「选」分支 `dfs(i)` 不 +1**：本题的灵魂——同一个数字可以无限重复用，选完还停在 i。对照 [[算法题/回溯/40.组合总和II.md]]（每个数字限用一次，「选」分支 `dfs(i+1)`）。
- **分支顺序先选后不选**：与收集正确性无关，两支都会穷举；先写「选」时 path 增长更直观，撤销（removeLast）紧跟在选分支后面也更好检查配对。
- **注释「重复加自己 / 加别人」** 就是这个模板两分支的一句话记忆法。

### 本题无需排序

candidates 元素可重复使用、且不存在「相等的两个元素」的层间去重问题（题目保证 candidates 无重复元素），所以排序不是必须；只有为了 `cur>target` 之外的更强剪枝（选分支加 `if(candidates[i]<=target)` 判断提前跳过整支）时，排序才有收益。

整数数组的一个 **排列** 就是将其所有成员以序列或线性顺序排列。

- 例如， `arr = [1,2,3]` ，以下这些都可以视作 `arr` 的排列： `[1,2,3]` 、 `[1,3,2]` 、 `[3,1,2]` 、 `[2,3,1]` 。

整数数组的 **下一个排列** 是指其整数的下一个字典序更大的排列。更正式地，如果数组的所有排列根据其字典顺序从小到大排列在一个容器中，那么数组的 **下一个排列** 就是在这个有序容器中排在它后面的那个排列。如果不存在下一个更大的排列，那么这个数组必须重排为字典序最小的排列（即，其元素按升序排列）。

- 例如， `arr = [1,2,3]` 的下一个排列是 `[1,3,2]` 。
- 类似地， `arr = [2,3,1]` 的下一个排列是 `[3,1,2]` 。
- 而 `arr = [3,2,1]` 的下一个排列是 `[1,2,3]` ，因为 `[3,2,1]` 不存在一个字典序更大的排列。

给你一个整数数组 `nums` ，找出 `nums` 的下一个排列。

必须 **[原地](https://baike.baidu.com/item/%E5%8E%9F%E5%9C%B0%E7%AE%97%E6%B3%95)** 修改，只允许使用额外常数空间。

**示例 1：**

```
输入：nums = [1,2,3]
输出：[1,3,2]
```

**示例 2：**

```
输入：nums = [3,2,1]
输出：[1,2,3]
```

**示例 3：**

```
输入：nums = [1,1,5]
输出：[1,5,1]
```

**提示：**

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 100`

---

因为要求的是**下一个排列**，所以目标不是随便构造一个更大的排列，而是构造“刚好比当前排列大一点”的、字典序最小的排列。

可以把数组看成两部分：前面尽量保持不变，只在尽可能靠右的位置让数值变大；变大之后，再让后面的部分尽可能小。

从右向左寻找第一个满足：

```text
nums[i] < nums[i + 1]
```

的位置，记为 `i`。

之所以要找最右侧的这个位置，是因为越靠右的位置对整体字典序的影响越小。我们希望尽可能不改变前面的高位，只调整最靠右的、仍有机会变大的位置。

同时，由于 `i` 是从右往左找到的第一个递增对，所以在它右侧不存在递增对，即：

```text
nums[i + 1] >= nums[i + 2] >= ... >= nums[n - 1]
```

因此，后缀区间 `[i + 1, n)` 一定是非递增序列。

接下来，需要在后缀中找一个数与 `nums[i]` 交换，使 `nums[i]` 变大，但增幅尽可能小。由于后缀本身是非递增的，因此从右向左找到的第一个满足：

```text
nums[j] > nums[i]
```

的元素，就是后缀中**大于 `nums[i]` 的最小元素**。

记住这里“从右向左找”的原因：后缀是降序的，越靠右元素越小；因此第一个大于 `nums[i]` 的元素，正好就是最适合交换的、最小的更大元素。

交换 `nums[i]` 与 `nums[j]` 后，后缀 `[i + 1, n)` 依旧是非递增的。

原因是交换前有：

```text
nums[j - 1] >= nums[j] > nums[i] >= nums[j + 1]
```

其中左右边界不存在时可忽略。交换后，原来的 `nums[i]` 被放到 `j` 位置，于是：

```text
nums[j - 1] >= 原 nums[j] > 原 nums[i]
原 nums[i] >= nums[j + 1]
```

所以 `j` 附近仍符合非递增关系，其他位置本来就没有变化，因此整个后缀仍然非递增。

最后，为了让交换后的排列尽可能小，需要把后缀调整为最小字典序，也就是升序。又因为它此时恰好是非递增序列，所以直接反转后缀即可，不需要额外排序。

```text
1 2 7 4 3 1
  ↑ i       ↑ j（3 是后缀中最小的、比 2 大的数）

交换：
1 3 7 4 2 1

反转后缀：
1 3 1 2 4 7
```

你原文里这句：

> 因为 `nums[b]` 是第一个大于 `nums[a]` 的数字，意味着 `nums[b-1]` 是第二个大于的，`nums[b+1]` 小于 `nums[a]`

可以改成更准确的说法：

> 因为后缀是非递增的，且 `b` 是从右向左第一个满足 `nums[b] > nums[a]` 的位置，所以 `nums[b-1] >= nums[b] > nums[a]`，而 `nums[b+1] <= nums[a]`。交换后，`nums[a]` 被放到位置 `b`，仍然夹在一个不小于它的左侧元素与一个不大于它的右侧元素之间，因此后缀依然非递增。

```java
class Solution {

    public void nextPermutation(int[] nums) {

        int n=nums.length;

        int a=-1;

        for(int i=n-2;i>=0;i--){

            if(nums[i]<nums[i+1]){

                a=i;

                break;

            }

        }

        if(a==-1){

            Arrays.sort(nums);

            return;

        }

        int b=-1;

        for(int i=n-1;i>=a+1;i--){

            if(nums[i]>nums[a]){

                b=i;

                break;

            }

        }

        int tem=nums[a];

        nums[a]=nums[b];

        nums[b]=tem;

        reverse(nums,a+1,n-1);

        return;

    }

  

    public void reverse(int[] nums,int a,int b){

        while(a<=b){

            int tem=nums[a];

            nums[a]=nums[b];

            nums[b]=tem;

            a++;

            b--;

        }

    }

}
```

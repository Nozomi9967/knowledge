# 能量传递（后缀和 / 模分组倒序累加）

> [!abstract] 题目
> 给定一个长度为 n 的数组 energy，下标从 0 到 n-1。每个元素可以将其能量传递给下标 i+k 的元素（如果 i+k < n）。一条「能量传递路径」是：
> - 从任意位置 i 开始
> - 依次向右跳 k 步：i → i+k → i+2k → ...
> - 直到无法再跳（i + mk < n 但 i + (m+1)k ≥ n），最后一个元素吸收所有传递来的能量
>
> 求路径终点元素能获得的最大能量值。

| 参数 | 范围 |
|-----|------|
| n | energy 数组长度 |
| k | 跳跃步长 |
| energy[i] | 能量值 |

---

## 从特殊到一般

### k = 1

此时只能一步一步向右走。无论起点在哪，终点都是 n-1。

如果选择 i 为起点，计算的是子数组 [i, n-1] 的元素和，即**后缀和**。

倒着遍历 energy，同时累加元素和，即为后缀和。答案等于所有后缀和的最大值。

### k = 2

此时有两个「终点族」：余数 1（n-2, n-4, ...）和余数 0（n-1, n-3, ...）。

对于终点 n-1：
- 起点 n-3 → 累加 n-3 + n-1
- 起点 n-5 → 累加 n-5 + n-3 + n-1
- ...

对于终点 n-2：
- 起点 n-4 → 累加 n-4 + n-2
- 起点 n-6 → 累加 n-6 + n-4 + n-2
- ...

**不能从 n-3 开始倒着遍历**——因为 n-3 还可以向右跳到 n-1，所以 n-3 不是终点。

### 一般 k

终点是所有满足 i+k ≥ n 的位置（即 i ≥ n-k）。这些位置按 i%k 分成 k 个族。

对于每个余数 r ∈ [1, k]（从 n-1 往前推），从终点 n-r 开始倒着遍历，步长为 -k，累加元素和，取最大值。

---

## 解法

对每个 r = 1..k（r 代表从倒数第 r 个位置开始）：
- sum = 0
- 从 j = n-r 开始，j -= k，累加 energy[j] 到 sum
- 每步更新 ans = max(ans, sum)

**核心：按 i%k 分 k 组，每组内倒序累加后缀和，取全局最大。**

### Java 代码

```java
class Solution {
    public int maximumEnergy(int[] energy, int k) {
        int n = energy.length;
        int ans = Integer.MIN_VALUE;
        for (int i = 1; i <= k; i++) {
            int sum = 0;
            for (int j = n - i; j >= 0; j -= k) {
                sum += energy[j];
                ans = Math.max(ans, sum);
            }
        }
        return ans;
    }
}
```

---

## 复杂度

- 时间：O(n)。每个元素恰好被访问一次（按余数分组后每组遍历一次）。
- 空间：O(1)。只用了 sum 和 ans 两个变量。

## 面试话术

1. **为什么可以倒着遍历？** → 能量只向右传递，倒着遍历就是逆推"如果从此处开始，最终能量是多少"。
2. **为什么按 i%k 分组？** → 跳跃步长为 k，同余位置的元素永远在一条路径上，互不干扰。
3. **为什么内层循环不需要额外数组？** → 倒序累加本身就是后缀和，sum 实时维护即可。
4. **ans 初始值为什么用 MIN_VALUE？** → energy[i] 可能为负，必须用最小整数初始化。

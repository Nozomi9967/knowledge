## 题目

https://leetcode.cn/problems/maximum-subarray/?envType=study-plan-v2&envId=top-interview-150

## 题解



```java
class Solution {
    public int maxSubArray(int[] nums) {
        int n=nums.length;
        // dp[i]表示以i为右边界的子数组的最大和
        // dp[i]只有两种情况
        // 1. 只算自己，因为dp[i-1]<0，和前面相加只会越来越少
        // 2. 和dp[i]对接，因为dp[i]>0，加一起会更多
        // 由于只看dp[i-1]，所以不用dp数组，只需维护一个变量: cur
        // 也就是，如果跟前面相加还不如我自身大，那么就从我自己这里开始
        // 否则，跟着前面一起
        // 而max就记录这整个过程中产生的cur最大值
        int cur=nums[0]; // 表示dp[i]
        int max=nums[0];
        for(int i=1;i<n;i++){
            cur=Math.max(nums[i],nums[i]+cur);
            max=Math.max(max,cur);
        }
        return max;
    }
}
```





Kadane算法的核心思想其实很简单，但值得从头想清楚。

## 问题建模

给定数组 `[-2, 1, -3, 4, -1, 2, 1, -5, 4]`，找连续子数组的最大和。

## 关键洞察

考虑以位置 `i` 结尾的所有子数组，它们的最大和记为 `dp[i]`。

**关键问题**：`dp[i]` 怎么从 `dp[i-1]` 推导？

以 `i` 结尾的子数组，只有两种可能：

1. 只包含 `nums[i]` 自己
2. 在以 `i-1` 结尾的最优子数组后面，拼上 `nums[i]`

所以：

```
dp[i] = max(nums[i], dp[i-1] + nums[i])
      = max(nums[i], dp[i-1] + nums[i])
```

等价于：

```
dp[i] = nums[i] + max(0, dp[i-1])
```

**白话翻译**：如果前面积累的和是负数，带上它只会拖累我，不如从我自己重新开始。

## 为什么这个递推是完备的？

因为任意子数组 `[l..r]` 一定"以某个位置 `r` 结尾"，所以遍历所有 `dp[i]` 取最大值，一定覆盖了所有可能的子数组。没有遗漏。

## 空间压缩

`dp[i]` 只依赖 `dp[i-1]`，所以不需要数组，一个变量滚动即可：

```python
def maxSubArray(nums):
    cur  = nums[0]   # dp[i]：以当前位置结尾的最大子数组和
    best = nums[0]   # 全局最优

    for x in nums[1:]:
        cur  = max(x, cur + x)   # 要么重新开始，要么继续延伸
        best = max(best, cur)

    return best
```

## 走一遍例子

```
nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]

 i   x    cur = max(x, cur+x)   best
 0  -2    -2                    -2
 1   1    max(1, -1) = 1         1
 2  -3    max(-3, -2) = -2       1
 3   4    max(4,  2) = 4         4
 4  -1    max(-1, 3) = 3         4
 5   2    max(2,  5) = 5         5
 6   1    max(1,  6) = 6         6   ← 最优子数组 [4,-1,2,1]
 7  -5    max(-5, 1) = 1         6
 8   4    max(4,  5) = 5         6
```

答案 **6**，对应子数组 `[4, -1, 2, 1]`。

## 本质是什么

Kadane 本质是一维 DP，状态定义为"**以当前位置结尾**的最优解"，这个定义让转移方程极其简单（只需看要不要"甩掉"前面的包袱），同时遍历一遍就穷举了所有子数组，时间 O(n)，空间 O(1)。

# 3296.移山所需的最少秒数（二分答案 + 数学）

https://leetcode.cn/problems/minimum-number-of-seconds-to-make-mountain-height-zero/

> [!abstract] 题目
> 给定山的高度 `mountainHeight` 和工人工作时间数组 `workerTimes`。工人同时降低山高：
> - 工人 i 降低 1 单位需 `workerTimes[i]` 秒；
> - 降低 x 单位的总时间为 `workerTimes[i] × (1 + 2 + ... + x)`；
> - 所需总时间是所有工人用时的最大值。
>
> 请返回将山降低至 0 所需的最少秒数。

| 参数 | 范围 |
|-----|------|
| mountainHeight | 1 ~ 10⁵ |
| workerTimes.length | 1 ~ 10⁴ |
| workerTimes[i] | 1 ~ 10⁶ |
| 难度/标签 | 中等 · 贪心、二分查找、数学 |

**示例 1：**
```
输入：mountainHeight = 4, workerTimes = [2,1,1]
输出：3
解释：三名工人分别降低 1、2、1 个单位，用时分别为 2、3、1 秒。
     同步工作时，总耗时为最大值 3 秒。
```

**示例 2：**
```
输入：mountainHeight = 10, workerTimes = [3,2,2,4]
输出：12
解释：四名工人分别降低 2、3、3、2 个单位，用时分别为 9、12、12、12 秒，
     因此总耗时为 12 秒。
```

## 核心思路：二分时间

这是一个**最小化最大值**问题，对"时间 t"做二分，用 check(t) 验证 t 秒内能否把山挖完。

---

## 两个关键公式

### 1. check 函数：已知时间 t，求工人能挖多少单位 k（要开方）

工人 i 挖 k 单位的累计耗时：

```
w · k(k+1)/2 ≤ t
```

整理成标准二次方程 k² + k − 2t/w = 0，k 是未知数，套求根公式：

```
k = (−1 + √(1 + 8t/w)) / 2
```

**为什么这里要开方**：k 是未知数，方程有 k² 项，必须用求根公式，k² 藏在判别式 √(b²−4ac) 里。

### 2. 上界 r：已知单位数 H，求时间（不用开方）

最慢工人（maxW）单独挖完整座山 H 个单位，时间是：

```
r = maxW · H(H+1)/2
```

**为什么这里不用开方**：H 是题目给的已知数，这不是在解方程，只是代入求和，没有未知数的平方要解。

## 踩过的两个坑

### 坑 1：整数溢出

```java
// ❌ int * int = int，100000 * 100001 = 10^10 超过 int 上限
long r = mountainHeight * (mountainHeight + 1) * max / 2 - 1;

// ✅ 加 1L 让运算提升到 long
long r = mountainHeight * (mountainHeight + 1L) * max / 2 - 1;
```

mountainHeight 是 int，两个 int 相乘在赋给 long 之前就已经溢出截断了。(mountainHeight + 1L) 中的 1L 是 long，触发类型提升，整条表达式都在 long 域计算。

### 坑 2：浮点精度

```java
// ❌ 大数时 double 只有 15~16 位有效数字，Math.floor 后 k 偏小
long k = (long) ((Math.sqrt(1.0 + 8.0 * s / w) - 1) / 2);

// ✅ 浮点算近似值，整数运算回验修正
long k = (long) ((Math.sqrt(1.0 + 8.0 * s / w) - 1) / 2);
while ((long) w * k * (k + 1) / 2 <= s) k++;   // 算小了，往上找
while ((long) w * k * (k + 1) / 2 > s) k--;     // 算大了，往下找
```

w · k · (k+1) 最大约 10⁶ × 10⁵ × 10⁵ = 10¹⁶，在 long 范围内（上限 ≈ 9.2 × 10¹⁸），不会溢出。

## 完整 AC 代码

```java
class Solution {
    public long minNumberOfSeconds(int mountainHeight, int[] workerTimes) {
        int max = Arrays.stream(workerTimes).max().getAsInt();
        // 上界 = 最慢工人单独挖完整座山的时间
        long r = mountainHeight * (mountainHeight + 1L) * max / 2 - 1;
        long l = 1;
        while (l <= r) {
            long m = (r - l) / 2 + l;
            if (check(m, workerTimes, mountainHeight)) r = m - 1;
            else l = m + 1;
        }
        return l;
    }

    public boolean check(long s, int[] workerTimes, int mountainHeight) {
        long sum = 0;
        for (int w : workerTimes) {
            long k = (long) ((Math.sqrt(1.0 + 8.0 * s / w) - 1) / 2);
            // 整数回验修正浮点误差
            while ((long) w * k * (k + 1) / 2 <= s) k++;
            while ((long) w * k * (k + 1) / 2 > s) k--;
            sum += k;
            if (sum >= mountainHeight) return true;
        }
        return sum >= mountainHeight;
    }
}
```

**复杂度**：时间 O(n log U)，n 为工人数，U ≈ 5×10¹⁵（约 52 次二分迭代）；空间 O(1)。

## 面试话术

1. **为什么能二分？** → 单调性：时间越长，能挖的土越多（check 单调不减），是最小化最大值问题的标准二分答案结构。
2. **check 里的求和公式为什么是 w·k(k+1)/2？** → 挖第 1 单位耗时 w、第 2 单位 2w、…、第 k 单位 kw，累加 w(1+2+…+k) = w·k(k+1)/2。
3. **求根公式 vs 代入求和，什么时候开方？** → 解方程（k 未知）才开方；已知 H 代公式求时间，只是求和，不开方。
4. **浮点开方怎么保证不出错？** → 开方只用来算近似起点，随后用整数乘除回验，往小了加、往大了减，修正 double 精度损失。
5. **为什么用 long？** → mountainHeight 达 10⁵，两个 int 相乘在提升前就溢出；w·k(k+1) 达 10¹⁶ 也超出 int。

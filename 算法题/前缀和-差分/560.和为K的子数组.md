## 题目

https://leetcode.cn/problems/subarray-sum-equals-k/

```java
class Solution {

    public int subarraySum(int[] nums, int k) {

        int n=nums.length;

        int[] s=new int[n+1];

        for(int i=1;i<=n;i++){

            s[i]=(s[i-1]+nums[i-1]);

        }

        // 和为k的子数组

        // -> 寻找 i,j(i<j) 使得 s[j]-s[i]=k

        Map<Integer,Integer> cnt=new HashMap<>();

        int ans=0;

        for(int sj:s){

            ans+=cnt.getOrDefault(sj-k,0);

            cnt.merge(sj,1,Integer::sum);

        }

        return ans;

    }

}
```

```java
class Solution {
    public int maxSubarraySumCircular(int[] nums) {
        int n=nums.length;
        int cur=nums[0];
        int max=nums[0];
        int sum=nums[0];
        for(int i=1;i<n;i++){
            cur=Math.max(nums[i],cur+nums[i]);
            max=Math.max(max,cur);
            sum+=nums[i];
        }
        int min=nums[0];
        cur=nums[0];
        for(int i=1;i<n;i++){
            cur=Math.min(nums[i],nums[i]+cur);
            min=Math.min(cur,min);
        }
        return sum==min?max:Math.max(max,sum-min);
    }
}
```

### **这段代码用两次 Kadane 算法，分别求最大子数组和与最小子数组和，再用总和减去最小子数组和得到环形的最大值**

整体思路是：环形数组的答案只有两种可能。一是最大子数组落在数组中间，不跨越首尾，这由第一次 Kadane 求出。二是最大子数组跨越首尾，它的补集是数组中间的一段连续子数组，所以跨越首尾的和等于 `sum - min`，其中 `min` 是最小子数组和。

**第一段循环：求非环形的最大子数组和，同时累加总和**

```java
int n=nums.length;
int cur=nums[0];
int max=nums[0];
int sum=nums[0];
for(int i=1;i<n;i++){
    cur=Math.max(nums[i],cur+nums[i]);
    max=Math.max(max,cur);
    sum+=nums[i];
}
```

`cur` 表示以当前元素结尾的最大子数组和。`cur+nums[i]` 是把当前元素接在前面的子数组后面，`nums[i]` 则是从当前位置重新开始，取两者较大值即可。`max` 记录所有位置上 `cur` 的最大值，也就是普通数组的最大子数组和。

这里把初始值设为 `nums[0]`，而不是 0，是为了正确处理全为负数的情况。如果初始值是 0，数组全为负时会错误地返回 0，但子数组必须非空，正确答案应该是最大的那个负数。`sum` 在同一个循环中顺便累加，不需要额外遍历一次。

**第二段循环：求最小子数组和**

```java
int min=nums[0];
cur=nums[0];
for(int i=1;i<n;i++){
    cur=Math.min(nums[i],nums[i]+cur);
    min=Math.min(cur,min);
}
```

这一段与第一段完全对称，只是把最大换成最小。`cur` 复用了前面的变量，并重新赋值为 `nums[0]`，所以不会受第一段结果的影响。`min` 得到的是非空的最小子数组和。

**返回值：处理跨越首尾的情况**

```java
return sum==min?max:Math.max(max,sum-min);
```

如果 `sum == min`，说明整个数组本身就是那个最小子数组。此时它的补集为空，`sum - min` 等于 0，对应的是空子数组，不合法，因此直接返回 `max`。这种情况通常出现在全为负数的数组中。

否则，跨越首尾的候选值是 `sum - min`，与不跨越首尾的 `max` 取较大者即可。

**以 `[5,-3,5]` 为例走一遍**

总和 `sum = 7`。第一段中，`max` 最终为 7，对应整个数组。第二段中，`min` 为 -3，对应中间的 `-3`。`sum == min` 不成立，于是返回 `max(7, 7-(-3)) = 10`，即首尾两个 5 组成的子数组，这正是跨越首尾的情况。

**复杂度**

时间复杂度为 O(n)，只遍历数组两次。空间复杂度为 O(1)，只使用了几个变量。

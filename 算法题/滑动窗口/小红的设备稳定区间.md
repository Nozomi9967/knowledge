# 小红的设备稳定区间（滑动窗口 + TreeMap）

## 题目描述

小红正在监控一排设备的运行状态。每台设备都有一个状态值，她希望找到一段连续设备，使得这段设备中**任意两台设备的状态值差的绝对值都不超过 `d`**。

请找出满足条件的最长连续区间。如果有多个长度相同的区间，输出**起始编号最小**的那个。设备编号从 1 开始。若最长区间长度为 1，也按要求输出对应的单点区间。

### 输入描述

- 第一行输入两个整数 $n, d$。
- 第二行输入 $n$ 个整数状态值。

### 输出描述

输出两个整数 `L R`，表示最长稳定区间的起始编号和结束编号（1-based）。若有多个等长区间，输出起始编号最小的。

---

## 核心思路

**问题转化**：区间内任意两元素差的绝对值 ≤ d ⟺ **`max - min ≤ d`**（只需检查区间最大值与最小值，其他元素差必被夹在其中）。

**滑动窗口 + TreeMap 维护窗口极值**：

1. 右指针 `r` 扩张，把 `a[r]` 加入 `TreeMap`（值 → 出现次数，支持重复元素）。
2. 当 `map.lastKey() - map.firstKey() > d`（窗口不合法）时，左指针 `l` 右移收缩：把 `a[l]` 的计数减一，减到 0 就移除，直到窗口重新合法。
3. 每次窗口合法时更新最优解：`r - l + 1 > maxLen` 才更新（**严格大于**保证等长时保留最早出现的区间）。
4. 输出转为 1-based：`bestL = l + 1`、`bestR = r + 1`。

### 为什么用 TreeMap 而不用双端单调队列

| 方案 | 维护内容 | 复杂度 |
|------|---------|--------|
| TreeMap | 值→次数，`firstKey()`/`lastKey()` 取 min/max | 每个元素进出 $O(\log n)$，总 $O(n \log n)$ |
| 双端单调队列（max deque + min deque） | 单调队列存下标 | 每个元素进出 $O(1)$，总 $O(n)$ |

两种都能过，TreeMap 写法更短、更不容易错（尤其要处理重复值时计数天然方便）；追求最优常数可用双端队列。本题数据量若在 $10^5$ 量级，TreeMap 的 $O(n \log n)$ 完全够。

## 完整代码

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        if (!in.hasNextInt()) return;
        int n = in.nextInt(), d = in.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = in.nextInt();

        TreeMap<Integer, Integer> map = new TreeMap<>();
        int l = 0, maxLen = 0, bestL = 1, bestR = 1;

        for (int r = 0; r < n; r++) {
            map.put(a[r], map.getOrDefault(a[r], 0) + 1);

            // 当最大值与最小值之差大于 d 时，缩小左边界
            while (map.lastKey() - map.firstKey() > d) {
                map.put(a[l], map.get(a[l]) - 1);
                if (map.get(a[l]) == 0) {
                    map.remove(a[l]);
                }
                l++;
            }

            // 更新最优解（严格大于保证了长度相同时取最早出现的区间）
            if (r - l + 1 > maxLen) {
                maxLen = r - l + 1;
                bestL = l + 1; // 转为 1-based 索引
                bestR = r + 1;
            }
        }

        System.out.println(bestL + " " + bestR);
    }
}
```

## 复杂度分析

- **时间复杂度**：$O(n \log n)$，每个元素入 TreeMap 一次、出一次
- **空间复杂度**：$O(n)$（TreeMap 存储窗口内不同值）

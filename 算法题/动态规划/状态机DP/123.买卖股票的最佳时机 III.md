### **LeetCode 123「买卖股票的最佳时机 III」动态规划解法**

核心思路是**带交易次数维度的 DP**，本题最多完成 2 笔交易。朴素写法的状态转移方程会因内层循环退化成 $O(n^2)$，通过把内层 `max` 拆解为一个"随 `i` 累进维护的前缀最大值"，可消去内层循环降到 $O(n)$；进一步压缩为 4 个状态机变量后空间也降到 $O(1)$。

---

### **一、问题本身**

给定第 `i` 天的股票价格 `prices[i]`，最多完成 **2 笔交易**（买入必须在卖出之后，同一时间最多持有一股），求最大收益。

> 例如 `prices = [3,3,5,0,0,3,1,4]`，最优操作：第 4 天买入、第 6 天卖出（+3），第 7 天买入、第 8 天卖出（+3），总收益 6。

---

### **二、朴素 DP（$O(n^2)$，会超时）**

```java
class Solution {
    public int maxProfit(int[] prices) {
        int n = prices.length;
        // d[i][j]: 前i天，最多j笔交易的最大收益
        int[][] d = new int[n + 1][3];
        for (int i = 0; i < n; i++) {
            d[i + 1][2] = d[i][2];
            d[i + 1][1] = d[i][1];
            for (int j = i; j >= 0; j--) {
                int delta = prices[i] - prices[j];
                // delta: 在第 j+1 天买入、第 i+1 天卖出的利润
                // 如果利润小于等于 0，直接跳过
                if (delta <= 0) continue;
                d[i + 1][2] = Math.max(d[j + 1][1] + delta, d[i + 1][2]);
                d[i + 1][1] = Math.max(d[j + 1][0] + delta, d[i + 1][1]);
            }
        }
        return Math.max(d[n][2], d[n][1]);
    }
}
```

#### **状态定义**

`d[i][j]`：前 `i` 天，最多完成 `j` 笔交易的**最大收益**。

#### **状态转移**

第 `i+1` 天卖出，枚举买入日 `j+1`（即在第 `j` 天结束之后买入），收益 `delta = prices[i] - prices[j]`：

$$d[i+1][k] = \max\Big(d[i][k],\ \ \max_{0 \le j \le i}\big(d[j+1][k-1] + \text{prices}[i] - \text{prices}[j]\big)\Big)$$

`d[j+1][k-1]` 是"完成买入前的累积收益"，加上这笔交易的 `delta`。两笔交易分开更新 `d[i+1][1]` 和 `d[i+1][2]`。

#### **问题：内层循环 $O(n^2)$ 超时**

第 206 个测试用例 `n = 10^4`，双重循环 $10^8$ 次运算超时。核心瓶颈是内层 `max_j` 每次都从头扫。

---

### **三、消去内层循环：拆出前缀最大值**

把内层 `max` 拆开：

$$\max_{0 \le j \le i}\big(d[j+1][k-1] + \text{prices}[i] - \text{prices}[j]\big) = \text{prices}[i] + \max_{0 \le j \le i}\big(d[j+1][k-1] - \text{prices}[j]\big)$$

关键发现：右边的 $\max\big(d[j+1][k-1] - \text{prices}[j]\big)$ 只依赖 $j \le i$ 的历史值，**可以随 `i` 的推进累进维护一个前缀最大值**，免去每次从头扫。

- 对 $k=1$：`d[j+1][0] = 0`，维护 `max1 = max(max1, -prices[j])`
- 对 $k=2$：维护 `max2 = max(max2, d[j+1][1] - prices[j])`

### **方案一：保留 DP 结构（$O(n)$ 时间，$O(n)$ 空间）**

最小改动——去掉内层循环，用两个累进变量：

```java
class Solution {
    public int maxProfit(int[] prices) {
        int n = prices.length;
        int[][] d = new int[n + 1][3];
        int max1 = Integer.MIN_VALUE; // max of (d[j+1][0] - prices[j]) = -prices[j]
        int max2 = Integer.MIN_VALUE; // max of (d[j+1][1] - prices[j])
        for (int i = 0; i < n; i++) {
            d[i + 1][1] = d[i][1];
            d[i + 1][2] = d[i][2];
            // 第一笔交易
            max1 = Math.max(max1, -prices[i]);
            d[i + 1][1] = Math.max(d[i + 1][1], prices[i] + max1);
            // 第二笔交易（用刚更新过的 d[i+1][1]）
            max2 = Math.max(max2, d[i + 1][1] - prices[i]);
            d[i + 1][2] = Math.max(d[i + 1][2], prices[i] + max2);
        }
        return Math.max(d[n][2], d[n][1]);
    }
}
```

**更新顺序很重要**：先算 `d[i+1][1]`，再用它更新 `max2`，保证"今天完成第一笔交易、同时开始第二笔买入"这种合法状态用的是当天最新值，与原内层循环语义一致。

### **四、状态机 DP（$O(n)$ 时间，$O(1)$ 空间）— 推荐**

`d` 数组只用到前一天值，压缩为 4 个变量：

```java
class Solution {
    public int maxProfit(int[] prices) {
        // buy1: 第一次买入后的最大利润（负数，因为花了钱）
        // sell1: 第一次卖出后的最大利润
        // buy2: 第二次买入后的最大利润
        // sell2: 第二次卖出后的最大利润
        int buy1 = Integer.MIN_VALUE, sell1 = 0;
        int buy2 = Integer.MIN_VALUE, sell2 = 0;
        for (int price : prices) {
            buy1  = Math.max(buy1,  -price);          // 对应 max1
            sell1 = Math.max(sell1, buy1 + price);    // 对应 d[i+1][1]
            buy2  = Math.max(buy2,  sell1 - price);   // 对应 max2
            sell2 = Math.max(sell2, buy2 + price);    // 对应 d[i+1][2]
        }
        return sell2;
    }
}
```

#### **四变量与 DP 的对应关系**

| 状态机变量 | DP 含义 | 维护内容 |
|------------|---------|----------|
| `buy1` | `max1` | $\max_j(-\text{prices}[j])$ |
| `sell1` | `d[i+1][1]` | 至多 1 笔交易的最大收益 |
| `buy2` | `max2` | $\max_j(d[j+1][1] - \text{prices}[j])$ |
| `sell2` | `d[i+1][2]` | 至多 2 笔交易的最大收益 |

**更新顺序同样关键**：`buy1 → sell1 → buy2 → sell2`，确保 `buy2` 能用上当天刚更新的 `sell1`。

#### **初始值的语义**

- `buy1 = buy2 = Integer.MIN_VALUE`：未买入前的"持有状态"设为负无穷，保证首次 `Math.max` 时不会选到非法状态。
- `sell1 = sell2 = 0`：未卖出前的收益为 0（什么都不做也是一种合法方案）。

> [!abstract] 为什么是「至多」而非「恰好」？
> 状态机允许"跳过"买入或卖出（`buy1` 一直取 `-price` 但不强制卖出），所以 `sell2` 表示**至多** 2 笔交易的最大收益。元素全为正、交易越多收益越高时，"至多 2"自然等于"恰好 2"；当价格单调递减时，0 笔交易（收益 0）最优，"至多"语义正好覆盖。

### **五、状态机视角**

把每天的持有状态画成有限状态机，每条边是一个决策（买/卖/不动），就是经典的**股票买卖状态机 DP**模板：

```
        buy                  sell                  buy                  sell
┌────┐ ──────► ┌────┐ ──────► ┌────┐ ──────► ┌────┐ ──────► ┌────┐
│空闲│         │持1 │         │空1 │         │持2 │         │空2 │
└────┘ ◄────── └────┘ ◄────── └────┘ ◄────── └────┘ ◄────── └────┘
            不动             不动             不动             不动
```

四个变量 `buy1 / sell1 / buy2 / sell2` 分别对应「持1 / 空1 / 持2 / 空2」四个状态上累计的最大利润。这种状态机模型可推广到 [[188.买卖股票的最佳时机 IV]]（k 笔交易）和带冷冻期、手续费的变体。

### **六、一个具体例子走一遍**

以 `prices = [3,3,5,0,0,3,1,4]` 为例，状态机 DP 各变量逐天变化：

| 天 | price | buy1 | sell1 | buy2 | sell2 |
|----|-------|------|-------|------|-------|
| 0  | 3     | -3   | 0     | -3   | 0     |
| 1  | 3     | -3   | 0     | -3   | 0     |
| 2  | 5     | -3   | 2     | -3   | 2     |
| 3  | 0     | 0    | 2     | 2    | 2     |
| 4  | 0     | 0    | 2     | 2    | 2     |
| 5  | 3     | 0    | 3     | 2    | 5     |
| 6  | 1     | 0    | 3     | 2    | 5     |
| 7  | 4     | 0    | 4     | 2    | **6** |

返回 `sell2 = 6`：第 4 天（price=0）买入、第 6 天（price=3）卖出（+3），第 7 天（price=1）买入、第 8 天（price=4）卖出（+3），总收益 6。

关键观察第 5 天 `sell1` 从 2 跳到 3：`buy1` 在第 4 天更新为 0（最低价买入），第 5 天 `sell1 = buy1 + 3 = 3`。`buy2` 也在第 4 天更新为 `sell1 - price = 2 - 0 = 2`，为第二笔交易埋下伏笔。

### **七、面试话术**

1. **为什么用状态机 DP 而不是普通划分 DP？** — 股票问题有"持有/不持有"的离散状态，每一步决策转移依赖前一个状态，天然是有限状态机；而交易次数限制只是给状态加了第二维（最多 k 笔）。
2. **`buy` 初始值为什么是 `MIN_VALUE`？** — 表示"还没买入过"的非法状态，首次比较时 `-price` 一定更大，自然覆盖非法值。
3. **更新顺序为什么是 `buy1 → sell1 → buy2 → sell2`？** — 同一天可以"卖出第 1 笔 + 买入第 2 笔"，顺序保证第 2 笔的 `buy2` 能用上当天最新的 `sell1`。
4. **与朴素 DP 的关系** — 朴素 DP 内层循环 $\max_j(d[j+1][k-1] - \text{prices}[j])$ 正是状态机里 `buyk` 变量维护的内容；消去内层循环 = 状态机压缩。

## 题目

https://leetcode.cn/problems/h-index/

```java
// 我的题解
// 定义一个hash数组，index表示引用次数，值为具有该引用次数的论文个数
// 更新数组，值的意思更新为大于等于该引用次数的论文个数
class Solution {
    public int hIndex(int[] citations) {
        int n=1000;
        int[] hash=new int[n+1];
        int len=citations.length;
        for(int i=0;i<len;i++){
            hash[citations[i]]++;
        }
        if(hash[n]>=1000) return 1000;
        while(n-->=0){
            hash[n]+=hash[n+1];
            if(hash[n]>=n) break;
        }
        return n;
    }
}
```

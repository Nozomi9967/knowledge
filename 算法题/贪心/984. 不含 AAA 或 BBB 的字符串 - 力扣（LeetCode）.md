给定两个整数 `a` 和 `b` ，返回 **任意** 字符串 `s` ，要求满足：

- `s` 的长度为 `a + b` ，且正好包含 `a` 个 `'a'` 字母与 `b` 个 `'b'` 字母；
- 子串 `'aaa'` 没有出现在 `s` 中；
- 子串 `'bbb'` 没有出现在 `s` 中。

**示例 1：**

```
输入：a = 1, b = 2
输出："abb"
解释："abb", "bab" 和 "bba" 都是正确答案。
```

**示例 2：**

```
输入：a = 4, b = 1
输出："aabaa"
```

**提示：**

- `0 <= a, b <= 100`
- 对于给定的 `a` 和 `b` ，保证存在满足要求的 `s`

---



### 题解

贪心，剩下的 a 多就 aab，剩下的 b 多就 bba，一样多就 ab

```java
class Solution {
    public String strWithout3a3b(int a, int b) {
        StringBuilder sb = new StringBuilder();

        while (a > b && b > 0) { sb.append("aab"); --a; --a; --b; }
        while (b > a && a > 0) { sb.append("bba"); --b; --b; --a; }
        while (a > 0 && b > 0) { sb.append("ab"); --a; --b; }
        while (a > 0) { sb.append('a'); --a; }
        while (b > 0) { sb.append('b'); --b; }
        return sb.toString();
    } // strWithout3a3b(int, int)
} // Solution Class
```

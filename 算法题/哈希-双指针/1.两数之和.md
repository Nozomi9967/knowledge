## 题目

[1. 两数之和 - 力扣（LeetCode）](https://leetcode.cn/problems/two-sum/?envType=study-plan-v2&envId=top-interview-150)





## 题解一：哈希表（最优解，O(n)）

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> hashtable = new HashMap<Integer, Integer>();
        for (int i = 0; i < nums.length; ++i) {
            if (hashtable.containsKey(target - nums[i])) {
                return new int[]{hashtable.get(target - nums[i]), i};
            }
            hashtable.put(nums[i], i);
        }
        return new int[0];
    }
}
```

## 题解二：排序 + 对撞双指针（O(n log n)）

### 前提与坑

双指针（对撞指针）**只在有序数组上成立**，而本题数组无序、且要求返回**原始下标**。所以不能直接对 `nums` 排序——排完下标就丢了。必须把「值 + 原下标」打包在一起排序。

### 单调性（为什么左右夹逼不会漏解）

排序后 `nums[left] <= nums[right]`：

- `sum < target`：说明当前 `left` 配上**最大的** `right` 都不够大，那 `left` 配任何更小的数都不可能成立 → `left` 这个数可以整个排除，`left++`
- `sum > target`：同理 `right` 配上最小的 `left` 都超了 → `right--`
- `sum == target`：命中，返回

每步都只排除掉一个**确定不可能**的元素，所以不漏解，总共 O(n) 次移动。

### 代码

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        int n = nums.length;
        // pairs[i] = {值, 原下标}
        int[][] pairs = new int[n][2];
        for (int i = 0; i < n; i++) {
            pairs[i][0] = nums[i];
            pairs[i][1] = i;
        }
        Arrays.sort(pairs, (a, b) -&gt; a[0] - b[0]);  // 按值升序

        int left = 0, right = n - 1;
        while (left &lt; right) {
            int sum = pairs[left][0] + pairs[right][0];
            if (sum == target) {
                return new int[]{pairs[left][1], pairs[right][1]};  // 返回原下标
            } else if (sum &lt; target) {
                left++;
            } else {
                right--;
            }
        }
        return new int[0];
    }
}
```

注意 `a[0] - b[0]` 在值域接近 `int` 边界时会溢出，稳妥写法用 `Integer.compare(a[0], b[0])`。

### 两种解法对比

| 维度 | 哈希表 | 排序 + 双指针 |
|------|--------|--------------|
| 时间 | O(n) | O(n log n)（瓶颈在排序） |
| 空间 | O(n)（哈希表） | O(n)（存原下标；若允许破坏原数组且不要下标可 O(1)） |
| 遍历次数 | 一趟边查边存 | 排序一趟 + 夹逼一趟 |
| 是否需要有序 | 不需要 | **必须有序** |
| 本题适用性 | ✅ 最优 | ⚠️ 可行但更差 |

### 面试话术

> 这题我会用哈希表，一趟遍历边查 `target - nums[i]` 边存，时间 O(n)。双指针在这题上其实是**降级解**——因为对撞指针的正确性依赖数组有序，而本题无序，我得先排序，时间就退化到 O(n log n)；而且题目要返回原始下标，排序会打乱下标，我还得把值和下标打包成二元组一起排，空间也省不下来。所以双指针在这题没有优势。
>
> 双指针真正的用武之地是 **167. 两数之和 II——输入有序数组**：数组本来就有序，省掉排序，时间 O(n)、空间 O(1)，比哈希表还省空间。判断标准就是一句话：**数组有序就用双指针，无序就用哈希**。

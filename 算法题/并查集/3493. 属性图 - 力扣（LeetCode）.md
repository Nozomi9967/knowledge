给你一个二维整数数组 `properties` ，其维度为 `n x m` ，以及一个整数 `k` 。

定义一个函数 `intersect(a, b)` ，它返回数组 `a` 和 `b` 中 **共有的不同整数的数量** 。

构造一个 **无向图** ，其中每个索引 `i` 对应 `properties[i]` 。如果且仅当 `intersect(properties[i], properties[j]) >= k` （其中 `i` 和 `j` 的范围为 `[0, n - 1]` 且 `i != j` ），节点 `i` 和节点 `j` 之间有一条边。

返回结果图中 **连通分量** 的数量。

**示例 1：**

**输入：** properties = \[\[1,2\],\[1,1\],\[3,4\],\[4,5\],\[5,6\],\[7,7\]\], k = 1

**输出：** 3

**解释：**

生成的图有 3 个连通分量：

![](https://pic.leetcode.cn/1742665594-CDVPWz-image.png)

**示例 2：**

**输入：** properties = \[\[1,2,3\],\[2,3,4\],\[4,3,5\]\], k = 2

**输出：** 1

**解释：**

生成的图有 1 个连通分量：

![](https://pic.leetcode.cn/1742665565-NzYlYH-screenshot-from-2025-02-27-23-58-34.png)

**示例 3：**

**输入：** properties = \[\[1,1\],\[1,1\]\], k = 2

**输出：** 2

**解释：**

`intersect(properties[0], properties[1]) = 1` ，小于 `k` 。因此在图中 `properties[0]` 和 `properties[1]` 之间没有边。

**提示：**

- `1 <= n == properties.length <= 100`
- `1 <= m == properties[i].length <= 100`
- `1 <= properties[i][j] <= 100`
- `1 <= k <= m`

## 优化前

```java
class Solution {

  

    public int intersect(int[][] properties,int a,int b){

        set.clear();

        int m=properties[0].length;

        for(int i=0;i<m;i++){

            for(int j=0;j<m;j++){

                if(properties[a][i]==properties[b][j]) set.add(properties[a][i]);

            }

        }

        return set.size();

    }

    public int[] p;

    public HashSet<Integer> set=new HashSet<>();

  

    public int find(int x){

        if(p[x]==x) return x;

        return p[x]=find(p[x]);

    }

  

    public void union(int x,int y){

        int rootX=find(x);

        int rootY=find(y);

        if(rootX!=rootY) p[rootX]=rootY;

    }

  

    public int numberOfComponents(int[][] properties, int k) {

        int n=properties.length;

        p=new int[n];

        for(int i=0;i<n;i++) p[i]=i;

        for(int i=0;i<n;i++){

            for(int j=i+1;j<n;j++){

                int num=intersect(properties,i,j);

                if(num>=k) union(i,j);

            }

        }

  

        var s=new HashSet<Integer>();

        for(int i=0;i<n;i++){

            int root=find(i);

            // System.out.println("i: "+i+" root:"+root);

            if(!s.contains(root)) s.add(root);

        }

        return s.size();

    }

}
```

## 优化后

```java
class Solution {

    int[] p;

  

    public int numberOfComponents(int[][] properties, int k) {

        int n = properties.length;

        int m = properties[0].length;

  

        // 找最大属性值，确定bitset所需的long数组长度

        int maxVal = 0;

        for (int[] row : properties)

            for (int v : row)

                maxVal = Math.max(maxVal, v);

        int words = maxVal / 64 + 1;

  

        // 预处理：每行转成bitset

        long[][] bits = new long[n][words];

        for (int i = 0; i < n; i++) {

            for (int v : properties[i]) {

                bits[i][v / 64] |= (1L << (v % 64));

            }

        }

  

        p = new int[n];

        for (int i = 0; i < n; i++) p[i] = i;

  

        for (int i = 0; i < n; i++) {

            for (int j = i + 1; j < n; j++) {

                if (find(i) == find(j)) continue; // 已连通，跳过

                int cnt = 0;

                for (int w = 0; w < words; w++) {

                    cnt += Long.bitCount(bits[i][w] & bits[j][w]);

                }

                if (cnt >= k) union(i, j);

            }

        }

  

        int components = 0;

        for (int i = 0; i < n; i++) {

            if (find(i) == i) components++;

        }

        return components;

    }

  

    int find(int x) {

        if (p[x] == x) return x;

        return p[x] = find(p[x]);

    }

  

    void union(int x, int y) {

        int rootX = find(x), rootY = find(y);

        if (rootX != rootY) p[rootX] = rootY;

    }

}
```



# 并查集优化：bitset 求交集 笔记

## 问题背景

原始解法用嵌套循环 + HashSet 求两个属性数组的交集，复杂度 O(m²)，是性能瓶颈。优化思路：用**位运算**代替逐元素比较。

---

## 核心思想：用二进制位表示集合

把"一个值是否出现过"，编码成一个二进制数里**某一位是 0 还是 1**。

例如：

```
properties[0] = [1, 3, 5, 3]
properties[1] = [2, 3, 5]
```

把出现过的值对应位置 1（其余为0）：

```
位号:        7 6 5 4 3 2 1 0
bits[0]:     0 0 1 0 1 0 1 0   ← 值1,3,5出现
bits[1]:     0 0 1 1 0 1 0 0   ← 值2,3,5出现
```

这样一行数组就被压缩成了一个 `long` 整数。

---

## 为什么交集变成了按位与（&）

两排"位"同时为1的位置，就是两个集合的公共元素：

```
bits[0]:  0 0 1 0 1 0 1 0
bits[1]:  0 0 1 1 0 1 0 0
按位与:   0 0 1 0 0 0 0 0   ← 只有位2和位5同时为1
```

`Long.bitCount(x)` 数二进制里 1 的个数，结果就是交集大小。这是 CPU 原生支持的位运算，速度接近常数时间，比逐元素比较快得多。

---

## 为什么要用数组 `bits[i][w]`（多个 long）

一个 `long` 只有 **64 位**，只能表示值 0~63。如果属性值能超过 63（比如到 99），就需要**多个 long 拼接**，相当于多挂几节"车厢"：

```java
int words = maxVal / 64 + 1;
```

- `maxVal / 64`：算出最大值落在第几节车厢（从0开始编号）
- `+1`：把"车厢编号"换算成"一共需要几节车厢"（数组长度）

**示例验证：**

|maxVal|maxVal/64|words|说明|
|---|---|---|---|
|63|0|1|刚好一节车厢够用（下标0）|
|64|1|2|溢出到下一节（下标0,1）|
|99|1|2|落在第1节车厢（下标0,1）|

---

## 代码对照

**构建 bitset（把数组转成位图）：**

```java
int words = maxVal / 64 + 1;
long[][] bits = new long[n][words];

for (int v : properties[i]) {
    bits[i][v / 64] |= (1L << (v % 64));
    //        ↑               ↑
    //   第几节车厢      这节车厢里的第几位
}
```

- `1L << v`：生成一个只有第 v 位是 1 的数（"点亮"编号为 v 的灯泡）
- `|=`：把新点亮的位叠加到已有结果上，不影响其他已亮的位

**求交集大小：**

```java
int cnt = 0;
for (int w = 0; w < words; w++) {
    cnt += Long.bitCount(bits[i][w] & bits[j][w]);
}
```

每节车厢分别按位与，再把各节的 1 的个数累加，就是完整的交集大小。

---

## 复杂度对比

|方法|求交集方式|复杂度|
|---|---|---|
|HashSet|双重循环 + 哈希查找|O(m²)|
|bitset|按位与 + popcount|O(m/64)|

---

## 一句话总结

`bits[i]` 把"一个值是否出现"编码成二进制的某一位，使"求交集大小"从"逐个比较元素"变成"整数按位与 + 数1的个数"，利用 CPU 对位运算的原生支持大幅提速。这是处理**小范围整数集合**交并补问题的经典套路（状态压缩的常见用法）。

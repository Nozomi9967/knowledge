### **LeetCode 91「解码方法」动态规划解法**

核心思路是**一维序列 DP**：`f[i]` 表示前缀 `s[1..i]` 的解码方法数，通过考虑"最后一次解码用了 1 个字符还是 2 个字符"完成状态转移，时间复杂度 $O(n)$。

---

### **一、问题本身**

给定一个只包含数字的字符串 `s`，按照如下规则将其解码为字母：

- `'A'` ↔ `1`，`'B'` ↔ `2`，⋯，`'Z'` ↔ `26`

求总共有多少种不同的解码方法。

> 例如 `s = "226"`，可以解码为：
> - `"BBF"`（2, 2, 6）
> - `"BZ"`（2, 26）
> - `"VF"`（22, 6）
> 共 3 种方法。

**关键约束**：`'0'` 不能单独解码（没有对应字母），只能与前一个数字组合成 `10` 或 `20` 使用。

---

### **二、DP 解法**

```java
public int numDecodings(String s) {
    int n = s.length();
    int[] f = new int[n + 1];
    f[0] = 1;  // 空串有 1 种解码方式

    for (int i = 1; i <= n; i++) {
        // 情况一：单独解码 s[i]
        if (s.charAt(i - 1) != '0') {
            f[i] += f[i - 1];
        }
        // 情况二：与前一个字符组合解码 s[i-1]s[i]
        if (i > 1 && s.charAt(i - 2) != '0'
            && (s.charAt(i - 2) - '0') * 10 + (s.charAt(i - 1) - '0') <= 26) {
            f[i] += f[i - 2];
        }
    }
    return f[n];
}
```

#### **状态定义**

`f[i]`：字符串前缀 `s[1..i]` 的**解码方法数**。

#### **状态转移**

最后一次解码有两种可能：

**情况一：用了 1 个字符 `s[i]`**

只要 `s[i] ≠ '0'`，它可以解码为 A–I（1–9），贡献 `f[i-1]` 种方法：

$$
f[i] = f[i-1], \quad s[i] \neq 0
$$

**情况二：用了 2 个字符 `s[i-1]s[i]`**

要求 `s[i-1] ≠ '0'` 且 `10·s[i-1] + s[i] ≤ 26`，即组成 J–Z（10–26），贡献 `f[i-2]` 种方法：

$$
f[i] = f[i-2], \quad s[i-1] \neq 0 \text{ 且 } 10 \cdot s[i-1] + s[i] \le 26
$$

**两种情况累加**：

$$
f[i] = \begin{cases}
f[i-1] + f[i-2], & \text{两种情况都满足} \\
f[i-1], & \text{仅情况一满足} \\
f[i-2], & \text{仅情况二满足} \\
0, & \text{都不满足}
\end{cases}
$$

#### **边界条件**

`f[0] = 1`（空串有 1 种解码方式——解码出一个空字符串）。

这个边界至关重要：当 `s = "12"` 时，`f[2]` 需要 `f[0]` 来计算"12"作为一个整体的解码方式（`'AB'` 和 `'L'` 两种），`f[0] = 1` 让这个计数成立。

---

### **三、为什么 `f[0] = 1` 是核心技巧**

很多人在写这道题时卡在 `f[0]` 设多少。设 `f[0] = 1` 的好处：

1. **统一了状态转移**：`f[i]` 只依赖 `f[i-1]` 和 `f[i-2]`，不需要为"前两个字符组成一个合法编码"写特殊逻辑。
2. **自然处理了开头为双字符的情况**：`s = "12"` → `f[2] = f[1] + f[0] = 1 + 1 = 2`（`"AB"` 和 `"L"`），`f[0]` 贡献了"把整个前缀当作一个双字符编码"的那 1 种方法。
3. **如果 `f[0] = 0`**：`s = "12"` 会算出 `f[2] = f[1] + 0 = 1`，漏掉 `"L"` 这种情况，结果错误。

---

### **四、边界情况与陷阱**

| 输入 | 结果 | 原因 |
|------|------|------|
| `"0"` | 0 | `'0'` 不能单独解码，也无法与前字符组合 |
| `"10"` | 1 | `"10"` → `'J'`，仅 1 种 |
| `"101"` | 1 | `"10"` → `'J'`，`"1"` → `'A'` |
| `"27"` | 1 | `"2"` → `'B'`，`"7"` → `'G'`；`"27" > 26` 不能组合 |
| `"226"` | 3 | `"BBF"`, `"BZ"`, `"VF"` |
| `"06"` | 0 | 开头为 `'0'`，不能解码 |

**面试高频追问**：为什么 `"101"` 结果是 1 而不是 0？
- `f[2] = 1`（`"10"` → `'J'`），`f[3]` 时 `s[3] = '1' ≠ 0` 所以 `f[3] += f[2] = 1`，但 `"01"` 不是合法组合（前导 0），所以不触发 `f[1]` 分支。结果 1，正确。

### **五、一个具体例子走一遍**

以 `s = "226"`（`n = 3`）为例：

| i | 前缀 | s[i-1] | 情况一 (单字符) | 情况二 (双字符) | f[i] |
|---|------|--------|----------------|----------------|------|
| 0 | ""   | —      | —              | —              | **1** |
| 1 | "2"  | '2'≠0  | f[0]=1         | i=1 跳过       | **1** |
| 2 | "22" | '2'≠0  | f[1]=1         | "22"≤26, f[0]=1 | **2** |
| 3 | "226"| '6'≠0  | f[2]=2         | "26"≤26, f[1]=1 | **3** |

返回 `f[3] = 3`，即 `"226"` 有 3 种解码方法，符合预期。

### **六、空间优化**

`f[i]` 只依赖 `f[i-1]` 和 `f[i-2]`，可以只用两个变量滚动：

```java
public int numDecodings(String s) {
    int n = s.length();
    int a = 0, b = 1, c = 0;  // a=f[i-2], b=f[i-1], c=f[i]
    for (int i = 1; i <= n; i++) {
        c = 0;
        if (s.charAt(i - 1) != '0') {
            c += b;
        }
        if (i > 1 && s.charAt(i - 2) != '0'
            && (s.charAt(i - 2) - '0') * 10 + (s.charAt(i - 1) - '0') <= 26) {
            c += a;
        }
        a = b;
        b = c;
    }
    return c;
}
```

空间从 $O(n)$ 降到 $O(1)$，面试时主动提出来会加分。

### **七、面试话术**

1. **为什么用 DP？** — 每个位置的状态只依赖前两个位置，最优子结构明显，且存在重叠子问题（同一个前缀被多次复用）。
2. **`f[0] = 1` 的含义** — 空串有 1 种解码方式，这是让双字符组合的计数成立的关键技巧。
3. **`'0'` 的处理** — `'0'` 不能单独解码，只能作为 `10` 或 `20` 的个位；如果 `'0'` 前面不是 `'1'` 或 `'2'`，直接返回 0。
4. **与爬楼梯的类比** — 本质和 [[70.爬楼梯]] 是同一类 DP（`f[i] = f[i-1] + f[i-2]`），区别在于爬楼梯的转移无条件成立，而本题需要判断字符是否合法。

class Solution {

    public int numDecodings(String s) {

        int n=s.length();

        int[] d=new int[n+1];

        d[0]=1;

        boolean flag=true;

        for(int i=1;i<=n;i++){

            char c=s.charAt(i-1);

  

            // 有无法解码的字符 或 整个字符串有前导0

            if((c<'0'||c>'9')||(flag&&c=='0')){

                return 0;

            }

  

            flag=false;

  

            // 当前字符数字不是0时，才能继承前面d[i-1]的方法数

            if(c!='0') d[i]=d[i-1];

            if(i-2>=0){

                int x=Integer.valueOf(s.substring(i-2,i));    

                // 只有s[i-2,i-1]是合法编码时，才能继承d[i-2]的方法数        

                if(s.charAt(i-2)!='0'&&x>=1&&x<=26) d[i]+=d[i-2];

            }

        }

  

        return d[n];

    }

}

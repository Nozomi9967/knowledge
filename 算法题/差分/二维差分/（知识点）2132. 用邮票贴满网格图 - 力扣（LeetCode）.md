## 思路

1. 由于邮票可以互相重叠，贪心地想，能放邮票就放邮票。
2. 遍历所有能放邮票的位置去放邮票。注意邮票不能覆盖被占据的格子，也不能出界。
3. 放邮票的同时，记录每个空格子被多少张邮票覆盖。如果存在一个空格子没被邮票覆盖，则返回 false，否则返回 true。

## 细节

1. 怎么快速判断一个矩形区域可以放邮票？求出 grid 的 **二维前缀和** s，从而 O(1) 地求出任意矩形区域的元素和。如果一个矩形区域的元素和等于 0，就表示该矩形区域的所有格子都是 0。
2. 假设用一个二维计数矩阵 d 记录每个空格子被多少张邮票覆盖，那么放邮票时，就需要把 d 的一个矩形区域都加一。怎么快速实现？可以用 **二维差分矩阵** 来代替 d。矩形区域都加一的操作，转变成 O(1) 地对差分矩阵中四个位置的更新操作。
3. 最后从二维差分矩阵 d 还原出二维计数矩阵。类似对一维差分数组求前缀和得到原数组，我们需要 **对二维差分矩阵求二维前缀和** 。遍历 d，如果存在一个空格子的计数值为 0，就表明该空格子没有被邮票覆盖，返回 false，否则返回 true。代码实现时，可以直接在 d 数组上 **原地** 计算出结果。

```java
class Solution {
    public boolean possibleToStamp(int[][] grid, int stampHeight, int stampWidth) {
        int m = grid.length;
        int n = grid[0].length;

        // 1. 计算 grid 的二维前缀和
        int[][] s = new int[m + 1][n + 1];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                s[i + 1][j + 1] = s[i + 1][j] + s[i][j + 1] - s[i][j] + grid[i][j];
            }
        }

        // 2. 计算二维差分
        // 为方便第 3 步的计算，在 d 数组的最上面和最左边各加了一行（列），所以下标要 +1
        int[][] d = new int[m + 2][n + 2];
        for (int i2 = stampHeight; i2 <= m; i2++) {
            for (int j2 = stampWidth; j2 <= n; j2++) {
                int i1 = i2 - stampHeight + 1;
                int j1 = j2 - stampWidth + 1;
                if (s[i2][j2] - s[i2][j1 - 1] - s[i1 - 1][j2] + s[i1 - 1][j1 - 1] == 0) {
                    d[i1][j1]++;
                    d[i1][j2 + 1]--;
                    d[i2 + 1][j1]--;
                    d[i2 + 1][j2 + 1]++;
                }
            }
        }

        // 3. 还原二维差分矩阵对应的计数矩阵（原地计算）
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                d[i + 1][j + 1] += d[i + 1][j] + d[i][j + 1] - d[i][j];
                if (grid[i][j] == 0 && d[i + 1][j + 1] == 0) {
                    return false;
                }
            }
        }
        return true;
    }
}
```

#### 复杂度分析

- 时间复杂度：$O(m \times n)$，其中 $m$ 和 $n$ 分别为 grid 的行数和列数。
- 空间复杂度：$O(m \times n)$。

## Gemini

### 1. 核心算法源码 (Java)

本节归档了关于力扣（LeetCode）第 2132 题的高效解法分析。该解法由著名算法题解博主 **灵茶山艾府** 提出，核心通过结合 **二维前缀和** 与 **二维差分** 两个高级技巧，在 $O(m \times n)$ 的时间与空间复杂度内完美解决区域覆盖与状态校验问题。

```java
class Solution {
    public boolean possibleToStamp(int[][] grid, int stampHeight, int stampWidth) {
        int m = grid.length;
        int n = grid[0].length;

        // 1. 计算 grid 的二维前缀和
        int[][] s = new int[m + 1][n + 1];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                s[i + 1][j + 1] = s[i + 1][j] + s[i][j + 1] - s[i][j] + grid[i][j];
            }
        }

        // 2. 计算二维差分
        // 为方便第 3 步的计算，在 d 数组的最上面和最左边各加了一行（列），所以下标要 +1
        int[][] d = new int[m + 2][n + 2];
        for (int i2 = stampHeight; i2 <= m; i2++) {
            for (int j2 = stampWidth; j2 <= n; j2++) {
                int i1 = i2 - stampHeight + 1;
                int j1 = j2 - stampWidth + 1;
                if (s[i2][j2] - s[i2][j1 - 1] - s[i1 - 1][j2] + s[i1 - 1][j1 - 1] == 0) {
                    d[i1][j1]++;
                    d[i1][j2 + 1]--;
                    d[i2 + 1][j1]--;
                    d[i2 + 1][j2 + 1]++;
                }
            }
        }

        // 3. 还原二维差分矩阵对应的计数矩阵（原地计算）
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                d[i + 1][j + 1] += d[i + 1][j] + d[i][j + 1] - d[i][j];
                if (grid[i][j] == 0 && d[i + 1][j + 1] == 0) {
                    return false;
                }
            }
        }
        return true;
    }
}
```

### 2. 核心解题思路

这道题的核心要求是用大小为 `stampHeight × stampWidth` 的邮票覆盖所有的空白格子（`0`），且不能覆盖障碍物（`1`）。

直接模拟贴邮票会导致极其高昂的时间复杂度。该解法将问题巧妙地拆分为两个视角：

1. **能不能贴？**（利用 **二维前缀和** 快速判断：以某点为右下角的区域内是否有障碍物。如果没有，就可以在这里下一枚邮票）。
2. **有没有被贴到？**（利用 **二维差分** 批量记录哪些格子被邮票覆盖了，最后检查是否有空白格子被遗漏）。

### 3. 代码逐段拆解与数学原理

#### 步骤一：计算 grid 的二维前缀和

- **目的**：在 $O(1)$ 的时间内计算出网格中任意一个子矩阵内障碍物（`1`）的总数。
- **状态定义**：`s[i][j]` 表示从网格左上角 `(0,0)` 到 `(i-1, j-1)` 这个矩形区域内的数字之和。由于加入了 `0` 作为辅助边界，整体坐标向右下平移了一位。

#### 步骤二：枚举位置与二维差分标记

- **寻找合法的邮票放置点**：外层两个循环枚举的是邮票的**右下角坐标** `(i2, j2)`。通过邮票的长宽，可以反推出邮票的**左上角坐标** `(i1, j1)`。
- **校验是否能贴**：

$$\text{sum} = s[i_2][j_2] - s[i_2][j_1 - 1] - s[i_1 - 1][j_2] + s[i_1 - 1][j_1 - 1]$$

如果求和结果为 `0`，说明这一整块区域里全都是空白格子，可以安全放置邮票。

- **二维差分批量修改**：为了将该矩形区域内的值整体 `+1`，在矩形的四个关键顶点进行差分标记，避免了暴力循环遍历。

#### 步骤三：还原差分矩阵并校验结果

- **还原覆盖次数**：对差分数组 `d` 再次求一遍二维前缀和，让之前在四个顶点做的标记"扩散"开来。此时 `d[i+1][j+1]` 存储的就是原网格 `grid[i][j]` 最终**被几张邮票覆盖过**。
- **终极判定**：如果存在一个格子，在原网格里是空白（`grid[i][j] == 0`），但是它被邮票覆盖的次数也是 0（`d[i+1][j+1] == 0`），说明该死角无法被任何邮票覆盖，直接返回 `false`。

### 4. 关键疑问解答：为什么差分数组 `d` 的大小是 `(m + 2) \times (n + 2)`？

在二维差分算法中，将数组 `d` 的大小定义为 `(m + 2) \times (n + 2)` 是一个经典的**边界防御（防止越界）**和**下标对齐**的设计。它实际上是由两次"坐标右移"叠加而成的：

#### 4.1 第一层右移（+1）：前缀和的下标对齐

为了防止左上角计算 `i-1` 或 `j-1` 时越界，前缀和数组 `s` 整体向右下移动了一位，因此最大有效位置达到了 `m` 和 `n`。此时，原网格的坐标 `(i, j)` 映射到了前缀和里的 `(i+1, j+1)`。

#### 4.2 第二层右移（+1）：二维差分的超界标记需求

在二维差分中，对一个左上角为 `(i1, j1)`、右下角为 `(i2, j2)` 的矩形区域整体加上 `1` 时，标准的差分更新公式为：

- `d[i1][j1]++`
- `d[i1][j2 + 1]--`
- `d[i2 + 1][j1]--`
- `d[i2 + 1][j2 + 1]++`

注意公式中的 **`i2 + 1`** 和 **`j2 + 1`**。

当邮票正好贴在网格的最右下角时，此时在前缀和坐标系下 `i2 = m`, `j2 = n`。

那么差分标记就需要打在 `i2 + 1` 的位置，也就是 **`m + 1`**，以及 `j2 + 1` 的位置，也就是 **`n + 1`**。

#### 4.3 下标与长度对照表

| **维度** | **有效网格坐标 (0基)** | **前缀和/差分核心区 (1基)** | **差分标记可能达到的最大下标** | **最终数组需要的长度** |
| --- | --- | --- | --- | --- |
| **行 (Height)** | `0` 到 `m - 1` | `1` 到 `m` | `m + 1` (当 $i2 = m$ 时) | **`m + 2`** |
| **列 (Width)** | `0` 到 `n - 1` | `1` 到 `n` | `n + 1` (当 $j2 = n$ 时) | **`n + 2`** |

**结论**：

前缀和为了防止**左上角**越界（规避 `i-1`）向右下移了一位；二维差分为了防止**右下角**标记溢出（规避 `i2+1`）又向右下扩展了一位。两层扩容叠加，使得数组大小最终必须为 `(m + 2) \times (n + 2)`。有了这个边界防御，代码在运行时就完全不需要写任何繁琐的边界判断 `if` 语句，执行效率极高。

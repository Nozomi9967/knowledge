## 题目

https://leetcode.cn/problems/min-stack/description/?envType=study-plan-v2&envId=top-interview-150



## 题解

```java
class MinStack {

    private int[] min=new int[16];
    private int[] arr=new int[16];
    private int size=-1;

    public MinStack() {
        
    }

    private void resize(){
        int newCapa=(size+1)*2;
        int[] newArr=new int[newCapa];
        int[] newMin=new int[newCapa];
        for(int i=0;i<=size;i++){
            newArr[i]=arr[i];
            newMin[i]=min[i];
        }
        arr=newArr;
        min=newMin;
    }
    
    public void push(int val) {
        if(size+1==arr.length) resize();
        arr[++size]=val;
        if(size==0) min[size]=val;
        else{
            min[size]=Math.min(min[size-1],val);
        }
    }
    
    public void pop() {
        size--;
    }
    
    public int top() {
        return arr[size];
    }
    
    public int getMin() {
        return min[size];
    }
}

/**
 * Your MinStack object will be instantiated and called as such:
 * MinStack obj = new MinStack();
 * obj.push(val);
 * obj.pop();
 * int param_3 = obj.top();
 * int param_4 = obj.getMin();
 */
```

提示

给你一个 `m x n` 的迷宫矩阵 `maze` （ **下标从 0 开始** ），矩阵中有空格子（用 `'.'` 表示）和墙（用 `'+'` 表示）。同时给你迷宫的入口 `entrance` ，用 `entrance = [entrance_row, entrance_col]` 表示你一开始所在格子的行和列。

每一步操作，你可以往 **上** ， **下** ， **左** 或者 **右** 移动一个格子。你不能进入墙所在的格子，你也不能离开迷宫。你的目标是找到离 `entrance` **最近** 的出口。 **出口** 的含义是 `maze` **边界** 上的 **空格子** 。 `entrance` 格子 **不算** 出口。

请你返回从 `entrance` 到最近出口的最短路径的 **步数** ，如果不存在这样的路径，请你返回 `-1` 。

**示例 1：**

![](https://assets.leetcode.com/uploads/2021/06/04/nearest1-grid.jpg)
```
输入：maze = [["+","+",".","+"],[".",".",".","+"],["+","+","+","."]], entrance = [1,2]
输出：1
解释：总共有 3 个出口，分别位于 (1,0)，(0,2) 和 (2,3) 。
一开始，你在入口格子 (1,2) 处。
- 你可以往左移动 2 步到达 (1,0) 。
- 你可以往上移动 1 步到达 (0,2) 。
从入口处没法到达 (2,3) 。
所以，最近的出口是 (0,2) ，距离为 1 步。
```

**示例 2：**

![](https://assets.leetcode.com/uploads/2021/06/04/nearesr2-grid.jpg)
```
输入：maze = [["+","+","+"],[".",".","."],["+","+","+"]], entrance = [1,0]
输出：2
解释：迷宫中只有 1 个出口，在 (1,2) 处。
(1,0) 不算出口，因为它是入口格子。
初始时，你在入口与格子 (1,0) 处。
- 你可以往右移动 2 步到达 (1,2) 处。
所以，最近的出口为 (1,2) ，距离为 2 步。
```

**示例 3：**

![](https://assets.leetcode.com/uploads/2021/06/04/nearest3-grid.jpg)
```
输入：maze = [[".","+"]], entrance = [0,0]
输出：-1
解释：这个迷宫中没有出口。
```

**提示：**

- `maze.length == m`
- `maze[i].length == n`
- `1 <= m, n <= 100`
- `maze[i][j]` 要么是 `'.'` ，要么是 `'+'` 。
- `entrance.length == 2`
- `0 <= entrance_row < m`
- `0 <= entrance_col < n`
- `entrance` 一定是空格子。

```java
class Solution {

    public int nearestExit(char[][] maze, int[] entrance) {

        int m=maze.length;

        int n=maze[0].length;

        var v=new boolean[m][n];

        var pq=new ArrayDeque<int[]>();

        pq.offer(entrance);

        int[] dx=new int[]{0,0,1,-1};

        int[] dy=new int[]{1,-1,0,0};

        int cnt=0;

        while(!pq.isEmpty()){

            int size=pq.size();

            while(size-->0){

                int[] posi=pq.poll();

                int x=posi[0],y=posi[1];

  

                if((x==0||y==0||x==m-1||y==n-1)&&(x!=entrance[0]||y!=entrance[1])){

                    return cnt;

                }

  

                v[x][y]=true;

                for(int i=0;i<4;i++){

                    int nx=x+dx[i];

                    int ny=y+dy[i];

                    if(nx>=0&&ny>=0&&nx<m&&ny<n&&!v[nx][ny]&&maze[nx][ny]!='+'){

                        pq.offer(new int[]{nx,ny});

                        System.out.println(nx+" "+ny);

                    }

                }

            }

            cnt++;

        }

        return -1;

    }

}
```

剪枝后
```java
class Solution {

    public int nearestExit(char[][] maze, int[] entrance) {

        int m = maze.length;

        int n = maze[0].length;

        boolean[][] visited = new boolean[m][n];

        Deque<int[]> queue = new ArrayDeque<>();

        queue.offer(entrance);

        visited[entrance[0]][entrance[1]] = true; // 入口提前标记

  

        int[] dx = {0, 0, 1, -1};

        int[] dy = {1, -1, 0, 0};

        int cnt = 0;

  

        while (!queue.isEmpty()) {

            int size = queue.size();

            cnt++; // 提前自增,代表"如果这一轮扩展出的邻居是出口,走的步数就是 cnt"

  

            while (size-- > 0) {

                int[] posi = queue.poll();

                int x = posi[0], y = posi[1];

  

                for (int i = 0; i < 4; i++) {

                    int nx = x + dx[i];

                    int ny = y + dy[i];

  

                    if (nx < 0 || ny < 0 || nx >= m || ny >= n

                            || visited[nx][ny] || maze[nx][ny] == '+') {

                        continue; // 越界、已访问、墙,直接跳过

                    }

  

                    // 关键剪枝:在发现邻居的这一刻就判断是否为出口,而不是等它出队

                    if (nx == 0 || ny == 0 || nx == m - 1 || ny == n - 1) {

                        return cnt;

                    }

  

                    visited[nx][ny] = true; // 关键剪枝:入队即标记,避免重复入队

                    queue.offer(new int[]{nx, ny});

                }

            }

        }

        return -1;

    }

}
```

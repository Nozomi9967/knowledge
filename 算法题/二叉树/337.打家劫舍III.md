# 337.打家劫舍 III（树形DP，后序）

> [!abstract] 题目
> 小偷又发现了一个新的可行窃的地区。这个地区只有一个入口，我们称之为 root。
>
> 除了 root 之外，每栋房子有且只有一个"父"房子与之相连。一番侦察之后，聪明的小偷意识到"这个地方的所有房屋的排列类似于一棵二叉树"。如果两个直接相连的房子在同一天晚上被打劫，房屋将自动报警。
>
> 给定二叉树的 root，返回在不触动警报的情况下，小偷能够盗取的最高金额。

| 参数 | 范围 |
|-----|------|
| 节点数 | [1, 10⁴] |
| 节点值 | [0, 1000] |

**示例 1：**
```
输入：root = [3,2,3,null,3,null,1]
输出：7
解释：小偷一晚能够盗取的最高金额 3 + 3 + 1 = 7
```

**示例 2：**
```
输入：root = [3,4,5,1,3,null,1]
输出：9
解释：小偷一晚能够盗取的最高金额 4 + 5 = 9
```

## 核心思路：树形 DP（后序遍历）

每个节点只有两种选择：**偷** 或 **不偷**，且父子直接相连不能同时偷。

### 状态定义

`fun(root)` 返回 `int[2]`：

| 下标 | 含义 |
|-----|------|
| `[0]` | **偷** 当前节点时，子树能获得的最大金额 |
| `[1]` | **不偷** 当前节点时，子树能获得的最大金额 |

### 递推关系

对每个节点，先递归求出左右子树的 `{偷, 不偷}`，再合并：

```
偷 root   = 不偷 left + 不偷 right + root.val
不偷 root = max(左偷, 左不偷) + max(右偷, 右不偷)
```

- **偷 root**：左右子节点都不能偷，只能取它们各自的"不偷"值。
- **不偷 root**：左右子节点可以自由选择（偷或不偷），各取最大。

答案 = `max(偷根, 不偷根)`。

> 注意数组语义：代码里 `fun(root)[0]` 是"偷"，`[1]` 是"不偷"。递归时 `a[1]+b[1]+root.val`（偷当前 → 子都不偷）、`max(a[0],a[1])+max(b[0],b[1])`（不偷当前 → 子任选）。

## 完整 Java 代码

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {

    int[] fun(TreeNode root) {
        if (root == null) return null;

        int[] a = fun(root.left);
        int[] b = fun(root.right);
        if (a == null) a = new int[]{0, 0};
        if (b == null) b = new int[]{0, 0};

        // [0] = 偷当前节点，[1] = 不偷当前节点
        return new int[]{
            a[1] + b[1] + root.val,                 // 偷：左右子都不能偷
            Math.max(a[0], a[1]) + Math.max(b[0], b[1])  // 不偷：左右子任选最大
        };
    }

    public int rob(TreeNode root) {
        int[] a = fun(root);
        return Math.max(a[0], a[1]);
    }
}
```

## 复杂度

- 时间：O(n)，后序遍历每个节点一次
- 空间：O(h)，h 为树高（递归栈）

## 面试话术

1. **为什么父子不能同时偷？** → 题目规定"两个直接相连的房子同一天晚上被打劫会报警"，即相邻节点互斥。
2. **状态为什么要拆成偷/不偷两个？** → 树形 DP 的标准手法：一个节点是否被偷，直接决定它孩子的状态能否自由，两个状态互相约束（偷则子不能偷，不偷则子任选）。
3. **为什么后序遍历？** → 父节点的决策依赖子节点的最优值，必须先算出子树，再自底向上合并。
4. **叶子/空节点的边界怎么处理？** → 空子树返回 null，统一补 `{0,0}`（空树偷不偷都是 0）。
5. **和 198 打家劫舍的区别？** → 198 是线性数组，一维 DP `dp[i]=max(dp[i-1], dp[i-2]+nums[i])`；本题是树形结构，数组下标换成树节点，状态从"到 i 为止"变成"当前节点偷/不偷"，本质同构。

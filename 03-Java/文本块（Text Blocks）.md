# 文本块（Text Blocks）

> **文本块**是 Java 15 正式引入、Java 17 LTS 中可直接使用的**多行字符串字面量**，用三个双引号 `"""` 包围。在它之前，写多行字符串（SQL、JSON、HTML）只能靠 `"\n"` 拼接或 `+` 连接每行，既难读又容易错。文本块让**代码里的字符串外观与最终输出基本一致**。

---

## 一、版本沿革（别记错）

| 版本 | 状态 |
|------|------|
| Java 13、14 | 以**预览特性**出现（`--enable-preview`） |
| **Java 15** | 正式转正（JEP 378） |
| Java 17（LTS） | **直接可用，无需开启预览选项** |

## 二、基本语法

文本块以 `"""` 开始，**开始的 `"""` 之后必须紧跟换行符**，内容可跨多行，最后以 `"""` 结束：

```java
String json = """
    {
        "name": "Tabbit",
        "version": 17
    }
    """;
```

得到的字符串就是花括号那段 JSON，**换行和引号都不需要转义**，比传统写法清晰得多。

> 注意：`"""` 开头的那个换行符**不属于内容**——它是语法要求的分隔符，不会进字符串。

## 三、缩进处理：什么叫「自动去除公共前导空白」

这是文本块最关键、也最容易被问到的机制。**编译器会找出所有「参与计算的行」的前导空白，取其中的最小值，然后把每一行开头的这一数量空白统一删掉。**

### 3.1 一个例子

```java
String text = """
        第一行
          第二行
        第三行
        """;
```

三行内容的开头空白分别是 **8、10、8** 个空格。编译器统计后，最小值是 **8**。于是每一行开头去掉 **8** 个空格，结果是：

```text
第一行
  第二行
第三行
```

**关键在于**：第二行比其他行多缩进的 **2 个空格被保留**了——因为那是"内容本身的结构"；而三行**共有**的那 **8 个空格**被当成"排版用的缩进"删掉了。

> 这就是"**公共**前导空白"的含义：**所有行共同拥有的那部分开头空白**。它被视为代码缩进（为了让文本块在源码里对齐好看），不进最终字符串。

### 3.2 「参与计算的行」有哪些

- **所有非空内容行**：参与
- **结束分隔符 `"""` 所在行**：**也参与**（这点很关键）
- **完全空白（blank）的行**：**不参与**——它们缩进多长都不影响结果

### 3.3 用结束分隔符 `"""` 精确控制输出

正因为结束 `"""` 也参与计算，把它放在哪，直接决定结果：

| 结束 `"""` 的位置 | 效果 |
|------------------|------|
| 与内容**同缩进**（如上例） | 它本身贡献最小值，结果**不含多余前导空格** |
| 比内容**更靠右** | 最小值变大，结果中**保留**一部分前导空格 |
| **顶格**（0 缩进） | 最小值 = 0，**所有内容保留全部原有缩进** |

所以想保留原始缩进，就把结束 `"""` 顶格写。

### 3.4 行尾空格会被自动去掉

每行**末尾**的多余空格会被自动剥除。确实需要保留行尾空格时，用转义序列 `\s`（见下）。

## 四、转义字符

文本块里依然支持常见转义：`\t`、`\n`、`\"` 等。

- **单个双引号**无需转义：可以直接写 `"`。
- **连续三个双引号 `"""`** 出现在内容里时，必须转义其中**至少一个**（否则会被当成结束分隔符）。
- **行尾反斜杠 `\`**：**阻止换行**，让长文本在源码里折行书写，但结果字符串里仍是**一行**：

```java
String sql = """
    SELECT id, name \
    FROM users \
    WHERE age > 18
    """;
```

结果等价于 `SELECT id, name FROM users WHERE age > 18`（末尾仍带一个换行），**不包含反斜杠**。

## 五、和字符串方法配合

文本块本身就是普通的 `String` 对象，可以调用所有字符串方法。配合 Java 15 引入的 `formatted()`，可以直接做占位替换：

```java
String msg = """
    Hello, %s!
    今天是 %s。
    """.formatted("Tabbit", "周五");
```

相比 `String.format(...)` 的调用形式更直观，在拼 SQL / HTML 模板时很方便。

## 六、面试话术（口述版）

**问：Java 17 的文本块是什么？**

> 文本块是 Java 15 正式转正、Java 17 LTS 可直接用的多行字符串字面量，用三个双引号 `"""` 括起来，用来解决 Java 长期以来的痛点——写多行 SQL、JSON、HTML 只能靠 `\n` 拼接或者 `+` 连行，可读性差又容易错。它有两个关键机制。第一是**缩进处理**：编译器会统计所有内容行加结束分隔符 `"""` 行的前导空白，取**最小值**，然后把每行开头的这一份空白统一删掉——保留下来的只有各行之间的相对缩进。所以它在源码里怎么缩进排版都不影响结果，除非你把结束的 `"""` 顶格写，那就会保留全部缩进。第二是**转义**：单个双引号不用转义，`\s` 能保留行尾空格，行尾一个反斜杠 `\` 可以阻止换行、让长文本折行书写。它本身还是普通 `String`，能配合 `formatted()` 做占位替换。

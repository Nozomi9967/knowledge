# Dijkstra 模板与变体谱系

> 单源最短路，**前提是边权非负**。堆优化版 $O(m \log m)$（m = 边数），机试第三题图论主力。核心认知：**变体再怎么包装，改动几乎只发生在「松弛」那一行**，模板骨架一字不动。

## 一、堆优化模板（必须能默写）

```java
// ① 建图：adj[x] = 若干个 {邻居 y, 边权 w}
List<int[]>[] adj = new ArrayList[n];
Arrays.setAll(adj, i -> new ArrayList<>());
for (int[] e : edges) {
    int x = e[0], y = e[1], w = e[2];
    adj[x].add(new int[]{y, w});
    adj[y].add(new int[]{x, w});   // 无向图才要这一行
}

// ② dis 数组 + 起点
int[] dis = new int[n];
Arrays.fill(dis, Integer.MAX_VALUE);
dis[start] = 0;

// ③ 小根堆，元素 {当前距离, 节点}，按距离排序
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> Integer.compare(a[0], b[0]));
pq.offer(new int[]{0, start});

while (!pq.isEmpty()) {
    int[] cur = pq.poll();
    int d = cur[0], x = cur[1];
    if (d > dis[x]) continue;          // ④ 过期记录，跳过（懒删除）
    for (int[] e : adj[x]) {
        int y = e[0], w = e[1];
        if (d + w < dis[y]) {          // ⑤ 松弛成功才更新、才入堆
            dis[y] = d + w;
            pq.offer(new int[]{dis[y], y});
        }
    }
}
```

**为什么正确**：边权非负 ⇒ 距离沿路径单调不减 ⇒ 堆顶弹出的点，其 `dis` 不可能再被更短的路径改进，**出堆即最优**。所以只求单点最短路时，出堆时判 `if (x == target) return d;` 可以提前退出。

### 三个必写的点

| 位置 | 写法 | 漏了会怎样 |
|------|------|-----------|
| 过期判断 | `if (d &gt; dis[x]) continue;` | Java 的堆不支持删除堆内元素，同一个点会被多次展开，退化成指数级重复松弛 |
| 松弛成功才入堆 | `if (d + w &lt; dis[y]) { … pq.offer(…); }` | 无脑入堆会让堆膨胀，大图直接 TLE |
| 比较器 | `Integer.compare(a[0], b[0])` | 写 `a[0] - b[0]` 在大边权下整数溢出，排序错乱（见 [[机试]] 第十五节） |

## 二、变体谱系：改的只有松弛那一行

| 变体 | 松弛式的改动 | 代表题 |
|------|-------------|--------|
| 标准最短路（求和） | `dis[y] = dis[x] + w` | 743 网络延迟时间 |
| 瓶颈路：最小化路径上的最大边 | `dis[y] = max(dis[x], w)` | 1631 最小体力消耗路径 |
| 到达时刻有下限（要等） | `dis[y] = max(dis[x], t[y]) + 1` | 3341 到达最后一个房间的最少时间 I |
| 边有通行时间窗 `[begin, end]` | `dis[y] = max(begin, dis[x]) + 1`；且出发时刻 &gt; `end` 时这条边直接不能走 | 3604 有向图中到达终点的最少时间 |
| 节点有失效时刻 | 松弛式不变，多一道 `dis[y] &lt; disappear[y]` 才允许入堆 | 3112 访问消失节点的最少时间 |
| 最短路计数 | 更短时 `cnt[y] = cnt[x]`；相等时 `cnt[y] += cnt[x]` 并取模 | 1976 到达目的地的方案数 |
| 图不是现成的 | 把「一次激活 / 一组打包」抽象成**虚拟节点**连边，再跑标准 Dijkstra | 虫洞网络（华为风格） |

## 三、什么时候别用 Dijkstra

| 场景 | 该用什么 | 理由 |
|------|---------|------|
| 边权全为 1 | BFS 层序 | 队列天然按层递增，$O(n+m)$，不用堆也不用 `dis` 比较 |
| 边权只有 0 和 1 | 01-BFS（`ArrayDeque`，权 0 走 `addFirst`、权 1 走 `addLast`） | 同样 $O(n+m)$ |
| 存在负权边 | Bellman-Ford / SPFA | 「出堆即最优」的贪心前提被负边破坏，Dijkstra 直接错 |
| 要所有点对最短路且 n ≤ 300~500 | Floyd | 三重循环 $O(n^3)$，代码 5 行，见下方关联 |
| 带额外状态（恰好 k 次某操作、剩余油量…） | 分层图 Dijkstra：状态并进节点编号 `x * K + state` | 骨架不变，只是点数翻 K 倍 |

## 四、易错点

1. **累加溢出**：`w` 到 $10^9$ 级、n 到 $10^5$ 时最长路能到 $10^{14}$ → `dis` 用 `long`。
2. **INF 相加溢出**：用 `Integer.MAX_VALUE` 当 INF 时 `dis[x] + w` 会溢出成负数。用 `0x3f3f3f3f`（≈$1.06 \times 10^9$，两个相加还在 int 内）更稳。
3. **无向图漏加反向边**——建图时两条都要 `add`。
4. **网格图**：`dis` 开二维，堆里存 `{d, x, y}`，起点 `dis[0][0] = 0`；判越界写在取邻居之后。
5. **1-indexed 的题**（743 就是）数组要开 `n + 1`，别开 `n`。
6. **不可达的返回值**：题目要 -1 就返回 -1，别把 `Integer.MAX_VALUE` 直接吐出去。743 的判法是「有任一点 `dis` 仍是 INF ⇒ 返回 -1」。

## 五、机试速判流程

1. 读到「最少时间 / 最小花费 / 最短路径 / 最少几步」→ 先看**边权**。
2. 边权全 1 → BFS；边权非负且不等 → Dijkstra；有负权 → Bellman-Ford。
3. 再看问法：单源到所有点（跑一遍取 max）/ 所有点对（Floyd）/ 路径条数（Dijkstra + `cnt`）。
4. 最后看附加约束（等待、时间窗、节点失效、额外状态）→ 只改松弛那一行，或把状态并进节点编号。

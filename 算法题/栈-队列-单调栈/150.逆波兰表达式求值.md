## 题目

https://leetcode.cn/problems/evaluate-reverse-polish-notation/description/?envType=study-plan-v2&envId=top-interview-150



## 题解

```java
class Solution {

    private String operation(String a,String b,String sign){
        Integer aInt=Integer.parseInt(a);
        Integer bInt=Integer.parseInt(b);
        switch(sign){
            case "+": return String.valueOf(aInt+bInt);
            case "-": return String.valueOf(aInt-bInt);
            case "*": return String.valueOf(aInt*bInt);
            case "/": return String.valueOf(aInt/bInt);
        }
        return null;
    }

    private boolean isSign(String s){
        return s.equals("+")||s.equals("-")||s.equals("*")||s.equals("/");
    }

    public int evalRPN(String[] tokens) {

        Stack<String> stack=new Stack<>();

        for(int i=0;i<tokens.length;i++){
            if(stack.empty()||!isSign(tokens[i])) stack.push(tokens[i]);
            else{
                String b=stack.pop();
                String a=stack.pop();
                String res=operation(a,b,tokens[i]);
                stack.push(res);
            }
        }

        return Integer.parseInt(stack.pop());
    }
}
```

> **注** ：题目要求 递增，增大 无意义，所以 不需要在差分数组 中。

题目让我们把 变成递增的，这等价于把每个 都变成 **非负数** 。

根据前置知识，把 的某个子数组中的元素都增加 ，等价于：

- 把差分数组中的一个数增加 。
- 如果子数组不是 的后缀，那么还要把差分数组的另一个数减少 。

由于我们只需把 中的负数变成非负数，减少 无意义，所以每次 **只需操作 的后缀** ，等价于把某个 增加 。

[本题视频讲解](https://leetcode.cn/link/?target=https%3A%2F%2Fwww.bilibili.com%2Fvideo%2FBV1xzZcBZEpe%2F%3Ft%3D9m44s) ，欢迎点赞关注~

```java
class Solution {
    public long minOperations(int[] nums) {
        long ans = 0;
        for (int i = 1; i < nums.length; i++) {
            ans += Math.max(nums[i - 1] - nums[i], 0);
        }
        return ans;
    }
}
```

class Solution:
    def minOperations(self, nums: list[int]) -> int:
        st = []
        n = len(nums)
        ans = 0
        nums.append(inf)
        for i,x in enumerate(nums):
            while st and nums[st[-1]] <= x:
                j = st.pop()
                if not st:
                    continue
                mx = min(x,nums[st[-1]])
                ans += mx - nums[j]
            st.append(i)
        return ans

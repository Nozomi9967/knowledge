## 题目

https://leetcode.cn/problems/single-number/description/?envType=study-plan-v2&envId=top-interview-150





## 题解



```java
class Solution {
    public int singleNumber(int[] nums) {
        int num=0;
        for(int NUM: nums){
            num^=NUM;
        }
        return num;
    }
}
```

class Solution {
    public String shortestCommonSupersequence(String str1, String str2) {
        // f[i+1][j+1] 表示 s 的前缀 [0,i] 和 t 的前缀 [0,j] 的最短公共超序列的长度
        char[] s = str1.toCharArray(), t = str2.toCharArray();
        int n = s.length, m = t.length;
        var f = new int[n + 1][m + 1];
        for (int j = 1; j <= m; ++j) f[0][j] = j; // 递归边界
        for (int i = 1; i <= n; ++i) f[i][0] = i; // 递归边界
        for (int i = 0; i < n; ++i)
            for (int j = 0; j < m; ++j)
                if (s[i] == t[j]) // 最短公共超序列一定包含 s[i]
                    f[i + 1][j + 1] = f[i][j] + 1;
                else // 取更短的组成答案
                    f[i + 1][j + 1] = Math.min(f[i][j + 1], f[i + 1][j]) + 1;

        int na = f[n][m];
        var ans = new char[na];
        for (int i = n - 1, j = m - 1, k = na - 1; ; ) {
            if (i < 0) { // s 是空串，剩余的 t 就是最短公共超序列
                System.arraycopy(t, 0, ans, 0, j + 1);
                break; // 相当于递归边界
            }
            if (j < 0) { // t 是空串，剩余的 s 就是最短公共超序列
                System.arraycopy(s, 0, ans, 0, i + 1);
                break; // 相当于递归边界
            }
            if (s[i] == t[j]) { // 公共超序列一定包含 s[i]
                ans[k--] = s[i--]; // 倒着填 ans
                --j; // 相当于继续递归 makeAns(i - 1, j - 1)
            } else if (f[i + 1][j + 1] == f[i][j + 1] + 1)
                ans[k--] = s[i--]; // 相当于继续递归 makeAns(i - 1, j)
            else
                ans[k--] = t[j--]; // 相当于继续递归 makeAns(i, j - 1)
        }
        return new String(ans);
    }
}

### **这段代码是在根据 DP 表回溯，还原出最短公共超序列的具体字符串**

前面的 DP 部分只算出了长度 `f[n][m]`。这段代码从 `f[n][m]` 出发，沿着"当初是从哪个状态转移来的"倒着走，同时把字符从后往前写进 `ans`，最后得到真正的字符串。`ans` 的长度恰好是 `na = f[n][m]`，所以 `k` 从末尾开始递减，正好填满。

回溯的指针 `i`、`j` 分别指向 `str1` 和 `str2` 中尚未处理的最后一个字符。每一轮有三种情况。

第一种是 `s[i] == t[j]`。这两个字符在超序列中可以共用一个位置，所以只写入一次 `s[i]`，然后 `i` 和 `j` 同时左移。这对应 DP 中的 `f[i][j] + 1` 转移。

第二种是字符不相等，并且 `f[i+1][j+1] == f[i][j+1] + 1`。这说明最优解是通过保留 `s[i]` 得到的，于是写入 `s[i]` 并只左移 `i`。

第三种是前两种都不满足，那么最优解必然是保留 `t[j]` 得到的，写入 `t[j]` 并只左移 `j`。

循环中的两个 `if (i < 0)` 和 `if (j < 0)` 是边界处理。当其中一个字符串已经用完，剩下的另一个字符串的前缀就直接整段拷贝到 `ans` 的前部。此时剩余的空位数量正好等于那段前缀的长度，所以 `System.arraycopy` 能恰好填满。

作者原本是用递归函数 `makeAns(i, j)` 来描述这个过程的，代码注释里提到的"相当于继续递归"指的就是这一点。这里改写成了迭代循环，省去了递归栈。整个回溯过程最多走 `n + m` 步，时间复杂度仍然是 $O(nm)$，主要开销在前面建表的部分。

另外需要注意，你贴的内容里 `int na = f[n][m];` 那一段出现了两次，其中一份是重复粘贴。真正的代码只需要保留一份。

# 40. 组合总和 II（Combination Sum II）

## 题目

https://leetcode.cn/problems/combination-sum-ii/

给定一个**可能包含重复数字**的数组 `candidates` 和目标数 `target`，找出 `candidates` 中所有和为 `target` 的**不重复组合**。每个数字**只能使用一次**。

## 题解：「选或不选」模板 + 去重剪枝

两道题的零件各取一半：

- 来自 [[算法题/回溯/39.组合总和.md]]：收集时机是 `target == 0`
- 来自 [[算法题/回溯/90.子集II.md]]：排序 + 「不选则跳过所有相等值」剪枝
- 与 39 题的关键差异：**「选」分支也要 `i+1`**——每个数字只能用一次

```java
class Solution {
    public List<List<Integer>> combinationSum2(int[] candidates, int target) {
        Arrays.sort(candidates); // 去重的前提：相等元素排在一起
        List<List<Integer>> ans = new ArrayList<>();
        List<Integer> path = new ArrayList<>();
        dfs(0, candidates, target, path, ans);
        return ans;
    }

    private void dfs(int i, int[] nums, int target, List<Integer> path, List<List<Integer>> ans) {
        if (target == 0) { // 组合构造完毕（剪枝后 target 不会 < 0 才到这里）
            ans.add(new ArrayList<>(path));
            return;
        }
        if (i == nums.length) return;

        // 选 nums[i]（每个数字只能用一次 → 下一层是 i+1，不是 39 题的 i）
        if (nums[i] <= target) { // 排序后可选剪枝：当前数已超 target，选它必死
            path.add(nums[i]);
            dfs(i + 1, nums, target - nums[i], path, ans);
            path.removeLast();
        }

        // 不选 nums[i]：后面与它相等的元素也一并跳过（都不能选）
        while (i + 1 < nums.length && nums[i + 1] == nums[i]) i++;
        dfs(i + 1, nums, target, path, ans);
    }
}
```

## 剪枝为什么是对的（和 90 题同一条论证）

以 `candidates = [1,1,2,5]`、`target = 3` 为例。两个 1 是一段相等元素，组合里「取值为 1 的元素取几个」只能 0 或 1（取 2 个 1 和为 2、配不成 3，这里只为说明去重逻辑）。

- **不取 1**：第一个 1 走不选 → while 跳过第二个 1 ✓
- **取一个 1**：第一个 1 走选、第二个 1 随意 ✓
- **想跳过第一个 1、只取第二个？** 被 while 堵死 ✓

所以每段相等元素只能**从左到右连续取前缀**，组合数不重不漏。不排序则相等元素不相邻、while 跳不掉——**排序是这道题去重的前置条件，不是可选项**。

## 与三个同族题的差异速查（背这张表）

| | 收集时机 | 「选」分支递归 | 「不选」分支 | 排序 |
|---|---|---|---|---|
| [[算法题/回溯/78.子集.md]] | `i == n`（叶子） | `dfs(i+1)`（每个最多用一次） | 直接 `dfs(i+1)` | 不需要 |
| [[算法题/回溯/90.子集II.md]] | `i == n`（叶子） | `dfs(i+1)` | while 跳相等后 `dfs(i+1)` | **必须** |
| [[算法题/回溯/39.组合总和.md]] | `target == 0` | `dfs(i)` **不 +1**（可重复用） | 直接 `dfs(i+1)` | 可选（为剪枝加速） |
| **本题** | `target == 0` | `dfs(i+1)`（每个最多用一次） | while 跳相等后 `dfs(i+1)` | **必须** |

两对维度正交：**能不能重复用数字**看「选」分支 +不+1；**要不要去重**看排不排序 + 不选分支跳不跳相等值。四个组合正好对应这四道题。

## 复杂度

- 时间 `O(n · 2ⁿ)`：决策树最多 `2ⁿ` 个节点，收集时拷贝 `O(n)`；排序 `O(n log n)` 被吸收
- 空间 `O(n)`：递归栈 + path（不算输出）

## 常见坑

1. **「选」分支写成 `dfs(i)`** → 同一数字被无限重复使用，答案里出现 `[1,1]`（输入只有一个 1 时）——本题和 39 题唯一的机制分界，审题要盯「每个数字只能使用一次」。
2. **忘了排序** → while 剪枝失效，输出含重复组合。
3. **把去重写成 `path.contains(nums[i])` 判断** → 错。去重针对的是**同一层兄弟分支**间的重复决策，不是路径内判重；路径内判重会误杀合法组合（不同位置的相同值本该各算各的层）。

## 题目

https://leetcode.cn/problems/sum-of-absolute-differences-in-a-sorted-array/

```java
class Solution {

    public int[] getSumAbsoluteDifferences(int[] nums) {

        int n=nums.length;

        int[] pre=new int[n];

        // 计算前缀和

        int sum=0;

        for(int i=0;i<n;i++){

            sum+=nums[i];

            pre[i]=sum;

        }

        // 根据前缀和计算result[i]

        for(int i=0;i<n;i++){

            // 由于是非递减数组,所以 nums[i]比左边都大，比右边都小

            // 可以得出：

            // left=(i+1)*nums[i]-pre[i]

            // -> 这里连同nums[i]本身一起减 可以避免pre[i-1]数组越界

            // right=pre[n-1]-pre[i]-(n-i-1)*nums[i]

            // result[i]= left+right

            int left=(i+1)*nums[i]-pre[i];

            int right=pre[n-1]-pre[i]-(n-i-1)*nums[i];

            nums[i]= left+right;

        }

        return nums;

    }

}
```

## 1. 原始题目描述

### 题目：时间序列
在一次高纬度时空实验中，科学家捕获了两段来自不同宇宙的时间序列信号，分别记为序列 $A$ 和序列 $B$。
为了分析这两段信号的潜在关联，需要找到它们之间"共鸣度"最高的子序列对。

1. **子序列 (Subsequence)**：从一个序列中删除任意数量（可以为零）的元素，保持剩下元素的相对顺序不变，所得到的新序列。例如，`[2, 5]` 是 `[1, 2, 3, 4, 5]` 的一个子序列，但 `[5, 2]` 不是。
2. **共鸣度 (Resonance Score)**：对于两个等长的序列，其共鸣度定义为对应位置元素之差的绝对值之和。例如，对于序列 $X = [x_1, x_2]$ 和 $Y = [y_1, y_2]$，它们的共鸣度为：
   $$S = |x_1 - y_1| + |x_2 - y_2|$$

### 任务
分别从原始时间序列 $A$ 和 $B$ 中，找出一对**长度相同的非空子序列**，使得它们的共鸣度最大，并返回这个最大值。

* **时间限制**：C/C++ 3秒，其他语言6秒
* **空间限制**：C/C++ 256M，其他语言512M

### 输入描述
1. **第一行**：两个整数 $N$ 和 $M$，分别代表序列 $A$ 和序列 $B$ 的长度。($1 \le N, M \le 500$)
2. **第二行**：$N$ 个整数，代表序列 $A$ 的元素，每个元素的取值范围为 $[-1000, 100]$。
3. **第三行**：$M$ 个整数，代表序列 $B$ 的元素，每个元素的取值范围为 $[-1000, 100]$。

### 输出描述
输出一个整数，表示可找到的最大共鸣度。

### 示例
* **示例 1**
  * **输入**：
    ```text
    3 3
    1 3 5
    2 4 6
    ```
  * **输出**：`6`（配对方案为 $A[1]$ 配 $B[2]$， $A[2]$ 配 $B[3]$，即 $|1-4| + |3-6| = 3+3=6$）
* **示例 2**
  * **输入**：
    ```text
    2 2
    1 2
    3 4
    ```
  * **输出**：`4`

## 2. 核心痛点：为什么"知道要用 DP，却总是想不出细节"？

面对这道题，直觉敏锐的人很容易想到动态规划（DP），但常会卡在以下两个认知迷局中：

### 迷局 A：两边长度不一致，怎么控制子序列刚好"等长"？
* **直觉误区**：你可能会认为需要在状态里加一维来记录"当前子序列的长度"，比如设计一个三维 DP $dp[i][j][k]$ 表示前 $i$ 个和前 $j$ 个元素里长度为 $k$ 的最大共鸣度。但这会导致空间和时间复杂度爆炸（$500^3 = 1.25 \times 10^8$，对于 Java 极其危险）。
* **破局核心**：**"配对"动作天生是捆绑的**。只要我们将状态定义为"对齐状态"，不配对时只移动指针而不增加任何元素，两边选出的子序列就永远等长。

### 迷局 B：需不需要考虑"不选"带来的空子序列问题？
* **直觉误区**：题目要求"非空子序列"，如果最后的 DP 结果什么都没选（长度为 0，共鸣度为 0），是不是就不合法了？
* **破局核心**：因为每个对应项的共鸣度贡献是绝对值 $|A[i] - B[j]| \ge 0$，这是一个**非负数**。只要序列中存在任何能让绝对值大于 0 的配对，DP 决策就一定会选择至少配对一次，因为正数大于 0。若所有元素的差值都是 0，那么任选一对的共鸣度也是 0，此时"空"与"非空"对结果没有实质影响。

## 3. 数学与几何证明：凭什么能保证最终等长？

我们将状态转移的过程，映射为在 $N \times M$ **网格图上的路径寻找问题**。

### 3.1 转移方程设计
定义 $dp[i][j]$ 表示使用 $A$ 的前 $i$ 个元素和 $B$ 的前 $j$ 个元素所能获得的最大共鸣度。

在任意节点 $(i, j)$，我们只能做三种移动（决策）：
1. **对角移动（配对）**：从 $(i-1, j-1)$ 走到 $(i, j)$，增加收益 $|A[i-1] - B[j-1]|$。
2. **向下移动（舍弃 A）**：从 $(i-1, j)$ 走到 $(i, j)$，收益不增加。
3. **向右移动（舍弃 B）**：从 $(i, j-1)$ 走到 $(i, j)$，收益不增加。

$$dp[i][j] = \max \begin{cases} 
dp[i-1][j-1] + |A[i-1] - B[j-1]| & (\text{决策 1}) \\ 
dp[i-1][j] & (\text{决策 2}) \\ 
dp[i][j-1] & (\text{决策 3}) 
\end{cases}$$

### 3.2 严格的路径计数证明
从 $(0,0)$ 走到 $(N,M)$ 的任何一条路径，都由以下三种步长组成：
* 对角线步数（配对次数）：$P$ 
* 垂直向下步数（舍弃 A 次数）：$S_A$
* 水平向右步数（舍弃 B 次数）：$S_B$

由于起点是 $(0,0)$，终点是 $(N, M)$，两轴移动的总跨度是固定的：
$$P + S_A = N \quad (\text{横向总跨度})$$
$$P + S_B = M \quad (\text{纵向总跨度})$$

在整条路径中：
* **选入 $A$ 子序列的元素**：只有当发生对角线移动时，对应的 $A[i-1]$ 才会作为配对元素加入子序列。因此，子序列 $A_{sub}$ 的长度为 $P$。
* **选入 $B$ 子序列的元素**：同样，只有对角线移动时 $B[j-1]$ 才会加入。子序列 $B_{sub}$ 的长度也为 $P$。

$$\text{Length}(A_{sub}) = \text{Length}(B_{sub}) = P$$

由于每一条决策路径都严格遵守该规律，**最终得到的两个子序列长度必然完全相等**。

## 4. 示例 1 手跑网格图演示

输入：$A = [1, 3, 5]$, $B = [2, 4, 6]$

填表过程如下（第 0 行和第 0 列作为边界，全部初始化为 0）：

| | $j=0$ | $j=1$ ($B_1=2$) | $j=2$ ($B_2=4$) | $j=3$ ($B_3=6$) |
| :--- | :--- | :--- | :--- | :--- |
| **$i=0$** | **0** | 0 | 0 | 0 |
| **$i=1$ ($A_1=1$)** | 0 | $\max(0+|1-2|, 0, 0) = $ **1** | $\max(0+|1-4|, 0, 1) = $ **3** | $\max(0+|1-6|, 0, 3) = $ **5** |
| **$i=2$ ($A_2=3$)** | 0 | $\max(0+|3-2|, 1, 0) = $ **1** | $\max(1+|3-4|, 3, 1) = $ **3** | $\max(3+|3-6|, 5, 3) = $ **6** |
| **$i=3$ ($A_3=5$)** | 0 | $\max(0+|5-2|, 1, 0) = $ **3** | $\max(1+|5-4|, 3, 3) = $ **3** | $\max(3+|5-6|, 6, 3) = $ **6** |

* 最终结果：$dp[3][3] = 6$。
* 路径回溯：从 $dp[3][3]$ 出发，其值继承自上方 $dp[2][3] = 6$（舍弃 $A_3$）；$dp[2][3]$ 来源于对角线 $dp[1][2] + |3-6| = 3+3 = 6$（配对 $A_2$ 与 $B_3$）；$dp[1][2]$ 来源于对角线 $dp[0][1] + |1-4| = 0+3=3$（配对 $A_1$ 与 $B_2$）。
* 最终选中的子序列为：$A_{sub} = [1, 3]$， $B_{sub} = [4, 6]$。长度均为 2，共鸣度为 6。

## 5. Java 规范代码实现

针对 Java 语言，我们在实现时采用 `BufferedReader` 和 `StringTokenizer` 组合实现超快速 I/O，规避 `Scanner` 的性能开销。

### 5.1 标准二维 DP 版本 (空间复杂度 $O(N \times M)$)
最直观、易于调试和回溯路径的版本。

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String line = br.readLine();
        if (line == null) return;
        
        StringTokenizer st = new StringTokenizer(line);
        int N = Integer.parseInt(st.nextToken());
        int M = Integer.parseInt(st.nextToken());
        
        int[] A = new int[N];
        int[] B = new int[M];
        
        // 快速读取 A 数组
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < N; i++) {
            A[i] = Integer.parseInt(st.nextToken());
        }
        
        // 快速读取 B 数组
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < M; i++) {
            B[i] = Integer.parseInt(st.nextToken());
        }
        
        // dp[i][j] 代表 A[0..i-1] 和 B[0..j-1] 的最大共鸣度
        int[][] dp = new int[N + 1][M + 1];
        
        // 动态规划状态转移
        for (int i = 1; i <= N; i++) {
            for (int j = 1; j <= M; j++) {
                // 决策 1：配对 A[i-1] 和 B[j-1]
                int pair = dp[i - 1][j - 1] + Math.abs(A[i - 1] - B[j - 1]);
                // 决策 2：丢弃 A[i-1]
                int skipA = dp[i - 1][j];
                // 决策 3：丢弃 B[j-1]
                int skipB = dp[i][j - 1];
                
                dp[i][j] = Math.max(pair, Math.max(skipA, skipB));
            }
        }
        
        System.out.println(dp[N][M]);
    }
}
```

### 5.2 滚动数组优化版 (空间复杂度 $O(M)$)
由于 $dp[i][j]$ 的值仅取决于上一行（$i-1$）和当前行左侧（$j-1$）的数据，可以使用两个一维数组交替滚动，使空间开销降至最低。

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class MainOptimized {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String line = br.readLine();
        if (line == null) return;
        
        StringTokenizer st = new StringTokenizer(line);
        int N = Integer.parseInt(st.nextToken());
        int M = Integer.parseInt(st.nextToken());
        
        int[] A = new int[N];
        int[] B = new int[M];
        
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < N; i++) A[i] = Integer.parseInt(st.nextToken());
        
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < M; i++) B[i] = Integer.parseInt(st.nextToken());
        
        // 滚动数组
        int[] prev = new int[M + 1];
        int[] curr = new int[M + 1];
        
        for (int i = 1; i <= N; i++) {
            for (int j = 1; j <= M; j++) {
                int pair = prev[j - 1] + Math.abs(A[i - 1] - B[j - 1]);
                int skipA = prev[j];
                int skipB = curr[j - 1];
                curr[j] = Math.max(pair, Math.max(skipA, skipB));
            }
            // 将当前行的数据拷贝给 prev，供下一行计算使用
            System.arraycopy(curr, 0, prev, 0, M + 1);
        }
        
        System.out.println(curr[M]);
    }
}
```

## 6. 复杂度深度剖析

1. **时间复杂度**：$O(N \times M)$。
   * 双重循环分别执行 $N$ 次和 $M$ 次。
   * 当 $N, M \le 500$ 时，计算次数最多为 $500 \times 500 = 2.5 \times 10^5$ 次。在 Java 中执行通常仅需 **1 ~ 3 毫秒**，远低于 6 秒的限制。
2. **空间复杂度**：
   * **标准版**：$O(N \times M)$。需要开辟 $501 \times 501$ 的二维数组，内存开销大约只有 **1 MB**。
   * **优化版**：$O(M)$。只需维护 2 个长度为 $M+1$ 的一维数组，内存占用几乎可以忽略不计。

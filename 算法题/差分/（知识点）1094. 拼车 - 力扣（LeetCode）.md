## 实现方法

有两种写法：

1. 第一种写法是，创建一个长为 的差分数组，这可以保证 数组不会下标越界。
2. 第二种写法是，用平衡树（C++ 中的 `map` ，Java 中的 `TreeMap` ）代替差分数组，因为我们只需要考虑在 和 这些位置上的乘客数，其余位置的乘客是保持不变的，无需考虑。平衡树可以保证我们是从小到大遍历这些位置的。当然，如果你不想用平衡树的话，也可以用哈希表，把哈希表的 key 取出来排序，就可以从小到大遍历这些位置了。

代码实现时，其实无需创建数组 ，只需要用一个变量 累加差分值，如果在累加过程中发现 就返回 `false` 。如果没有出现这种情况，就返回 `true` 。

#### 第一种写法

```java
class Solution {
    public boolean carPooling(int[][] trips, int capacity) {
        int[] d = new int[1001];
        for (int[] t : trips) {
            int num = t[0], from = t[1], to = t[2];
            d[from] += num;
            d[to] -= num;
        }

        int s = 0;
        for (int v : d) {
            s += v;
            if (s > capacity) {
                return false;
            }
        }
        return true;
    }
}
```

```
class Solution:
    def carPooling(self, trips: List[List[int]], capacity: int) -> bool:
        d = defaultdict(int)
        for num, from_, to in trips:
            d[from_] += num
            d[to] -= num

        s = 0
        for k in sorted(d):
            s += d[k]
            if s > capacity:
                return False
        return True
```

```cpp
class Solution {
public:
    bool carPooling(vector<vector<int>>& trips, int c) {
        int n = trips.size();
        int ci = c;
        vector<array<int, 2>> vc;
        for (auto& t : trips) {
            vc.push_back({t[1], -t[0]});
            vc.push_back({t[2], t[0]});
        }
        // 先下后上
        ranges::sort(vc, {},  { return abs(v[0]) - copysign(1.0, v[1]) * 0.1; });
        for (auto& [posi, ni] : vc) {
            ci += ni;
            if (ci < 0)
                return false;
        }
        return true;
    }
};
```

## 差分数组：

将一个数组转变成查分数组，将数组中每个元素都变成右减左元素之差，开头一个元素不参与操作，与原数组相同。

### 它有如下特性:

1. 从左到右累加可以得到原数组.
2. 原数组将索引为i到j的元素加上x的操作，等价于，将差分数组第i个位置上得元素加上x，第 j+1位置上得元素减去x

(很好理解，因为差分数组中记录的是右边元素与左边元素的差值，所以原数组在一段范围中加上x，查分数组只需要在该范围的起始位置加上x，在最后+1的位置位置处减去x即可)

(若要还原成原数组 从左到右累加时，该范围内的元素都会多加上个x)

```rust
impl Solution {
    pub fn car_pooling(trips: Vec<Vec<i32>>, capacity: i32) -> bool {
        let mut rout=vec![0;1001];
        for t in trips{
            if let [x,s,e] = *t{
                rout[s as usize]+=x;
                rout[e as usize]-=x;
            }
        }
        rout.iter().try_fold(0,|mut acc,&x|{
            acc+=x;
            if acc<=capacity{
                Some(acc)
            }else{
                None
            }
        }).is_some()
    }
}
```

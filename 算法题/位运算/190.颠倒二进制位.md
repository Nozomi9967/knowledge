## 题目

https://leetcode.cn/problems/reverse-bits/?envType=study-plan-v2&envId=top-interview-150



## 题解



```java
class Solution {

    Map<Integer,Integer> map=new HashMap<>();

    public int reverseBits(int n) {
        for(int i=0;i<32;i++) map.put(i,(int)Math.pow(2,i));
        int sum=0;
        for(int i=0;i<32;i++){
            int num=n%2;
            n/=2;
            if(num==0) continue;
            sum+=map.get(31-i);
        }
        return sum;
    }
}
```

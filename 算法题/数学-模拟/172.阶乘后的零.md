## 题目

https://leetcode.cn/problems/factorial-trailing-zeroes/description/?envType=study-plan-v2&envId=top-interview-150



## 题解

```java
class Solution {
    public int trailingZeroes(int n) {
        int count=0;
        while(n>0){
            n/=5;
            count+=n;
        }
        return count;
    }
}
```

这是一个很经典的数论问题，我来帮你梳理清楚思路。

## 核心问题：n! 末尾有几个零？

**例子**：10! = 3628800，末尾有 **2 个零**。

------

## 为什么看 2 和 5 的个数？

末尾的零，每一个都对应一个 **10** 的因子。而 10 = 2 × 5，所以每凑出一对 (2, 5)，就能产生一个尾零。

n! = 1 × 2 × 3 × 4 × … × n，把所有数分解质因子后，会有很多个 2 和 5。**能凑出多少对 (2, 5)，就有多少个尾零**，也就是 min(2的个数, 5的个数)。

------

## 关键简化：2 的个数远多于 5

在 1 到 n 中：

- **偶数**贡献 2，每隔 1 个就有一个偶数
- **5 的倍数**贡献 5，每隔 4 个才有一个

所以 2 的个数**永远多于** 5 的个数，瓶颈在 5 这边。

> 因此，**尾零个数 = n! 中质因子 5 的总个数**

------

## 怎么数 5 的个数？

以 n = 100 为例：

| 贡献来源   | 哪些数                      | 贡献几个 5                        |
| ---------- | --------------------------- | --------------------------------- |
| 5 的倍数   | 5, 10, 15, …, 100，共 20 个 | 每个至少贡献 1 个 5               |
| 25 的倍数  | 25, 50, 75, 100，共 4 个    | 额外再贡献 1 个 5（因为 25 = 5²） |
| 125 的倍数 | 无（125 > 100）             | 0                                 |

总计：20 + 4 = **24 个 5**，所以 100! 末尾有 **24 个零**。

------

## 公式

$$
\text{尾零数} = \left\lfloor\frac{n}{5}\right\rfloor + \left\lfloor\frac{n}{25}\right\rfloor + \left\lfloor\frac{n}{125}\right\rfloor + \cdots
$$

一直加到 
$$
5^k > n
$$
 为止。

**等价的循环写法**（更常见）：

```python
def trailingZeroes(n):
    count = 0
    while n >= 5:
        n //= 5
        count += n
    return count
```

每次把 n 除以 5，相当于依次统计 5 的倍数、25 的倍数、125 的倍数……的贡献，累加即可。

------

## 直觉总结

> 每个 5 的倍数贡献 **至少 1 个** 5；每个 25 的倍数**额外多贡献 1 个**；每个 125 的倍数**再多贡献 1 个**……以此类推。

这也是为什么要累加多轮——高次幂的倍数，它的每一层都要单独算进去。

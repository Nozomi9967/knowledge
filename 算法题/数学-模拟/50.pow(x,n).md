## 题目

https://leetcode.cn/problems/powx-n/





## 题解

```java
class Solution {
    public double myPow(double x, int n) {
        if(x==1.0||x==-1.0) return x;
        double sum=1.0;
        while(n>0){
            sum*=x;
            n--;
        }
        while(n<0){
            sum/=x;
            n++;
        }
        return sum;
    }
}

// 会超时
```

```java
class Solution {
    public double myPow(double x, int n) {
        double ans=1;
        long N=n;
        if(N<0){
            N=-N;
            // 不能写成 N=-n
            // int的-2147483648取负后还是-2147483648
            // 例如-128~1000 0000 取负 也就是按位取反+1  还是 1000 0000
            // 为啥-128=1000 0000 ：是从-127推来的
            // -127 ：+127=0111 1111 按位取反+1 得到 -127=1000 0001
            // -128比-127小1，1000 0001-1=1000 0000
            x=1/x;
        }
        while(N!=0){
            if((N&1)==1){
                ans*=x;
            }
            x*=x;
            N>>=1;
        }
        return ans;
    }
}
```

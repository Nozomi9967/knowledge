# 78. 子集（Subsets）

## 题目

https://leetcode.cn/problems/subsets/description/

给一个不含重复元素的数组 `nums`，返回它所有可能的子集（幂集）。解集不能包含重复子集。

## 题解：选或不选模板

**核心视角**：子集 = 对每个元素做一次「选 or 不选」的二选一决策。`n` 个元素就是 `n` 层决策、每层 2 个分支，递归树是一棵满二叉树，共 `2^n` 个叶子，每个叶子就是一个子集。

```java
class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> ans = new ArrayList<>();
        List<Integer> path = new ArrayList<>();
        dfs(0, nums, path, ans);
        return ans;
    }

    // 选或不选：讨论 nums[i] 是否加入 path
    private void dfs(int i, int[] nums, List<Integer> path, List<List<Integer>> ans) {
        if (i == nums.length) { // 子集构造完毕
            ans.add(new ArrayList<>(path)); // 复制 path
            return;
        }

        // 不选 nums[i]
        dfs(i + 1, nums, path, ans); // 考虑下一个数 nums[i+1] 选或不选

        // 选 nums[i]
        path.add(nums[i]);
        dfs(i + 1, nums, path, ans); // 考虑下一个数 nums[i+1] 选或不选
        path.removeLast(); // path.remove(path.size() - 1);
    }
}
```

## 逐点拆解

### 1. 递归树长什么样（nums = [1,2,3]）

```
                 i=0        path=[]
              不选/  \选
            i=1      i=1     path=[1]
        不选/ \选   不选/ \选
      i=2    i=2    i=2    i=2
     /  \   /  \   /  \   /  \
    []  [3] [2] [2,3] [1] [1,3] [1,2] [1,2,3]   ← 8 个叶子 = 2³ 个子集
```

到 `i == n` 时 path 就是一个完整子集，**叶子全部收集，内部节点不收集**——因为内部节点还没对后面的元素做完决策。

### 2. 为什么「不选」分支直接递归、不用恢复现场

回溯的不变式是：**进入 dfs(i) 时 path 是前 i 个元素的决策结果，离开时必须原样恢复**。

- 不选分支：什么都没往 path 里加，递归回来 path 天然没变，无需恢复
- 选分支：`path.add` 之后递归，回来必须 `removeLast()` 把刚加的撤销

两个分支加起来，恰好穷举了 `2^n` 种决策组合。

### 3. 为什么收集答案要 `new ArrayList<>(path)`

ans 里存的必须是 path 的**快照拷贝**。如果直接 `ans.add(path)`，所有叶子存的都是同一个可变对象引用，回溯一 `removeLast` 全被改掉，最后答案只剩空列表。这是所有回溯题的通用坑。

### 4. `removeLast()`

Java 21 起 `List` 接口有了 `SequencedCollection`，`ArrayList` 直接支持 `removeLast()`；旧版本写 `path.remove(path.size() - 1)`，注意**不能写 `path.remove(数字值)` 那个重载**——`remove(Object)` vs `remove(int index)` 是按参数类型区分的，传 `Integer` 对象才是按下标删。

## 复杂度

- 时间 `O(n · 2^n)`：`2^n` 个叶子，每个叶子拷贝 path 花 `O(n)`
- 空间 `O(n)`：递归栈 + path（不算输出）

## 两种回溯模板的选用

| 模板 | 分支方式 | 适用 |
|------|---------|------|
| **选或不选**（本题） | 每层固定 2 叉：`dfs(i+1)` 和 `add + dfs(i+1)` | 子集、组合、0-1 背包型问题——对每个物品做二元决策 |
| **for 循环枚举**（[[算法题/回溯/77.组合.md]]） | 每层 for 枚举「下一个选谁」 | 组合、排列——按「已选了几个、下一个从哪些里挑」推进 |

本题用 for 循环模板同样能写（每个位置从 `start` 开始枚举加入 path，**每到一个节点就收集**），但「选或不选」模板叶子处统一收集、逻辑更机械，背一个就能通吃子集/组合总和这类题。

## 题目

https://leetcode.cn/problems/permutations/?envType=study-plan-v2&envId=top-interview-150



## 题解

```java
class Solution {
    Set<Integer> visited=new HashSet<>();
    List<List<Integer>> res=new ArrayList<>();

    void dfs(int index,int len,int[] nums,List<Integer> list){
        if(index==len){
             res.add(List.copyOf(list));
             return;
        }
        for(int i=0;i<len;i++){
            int num=nums[i];
            if(!visited.contains(num)){
                list.add(num);
                visited.add(num);
                dfs(index+1,len,nums,list);
                list.remove(list.size()-1);
                visited.remove(num);
            }
        }
        return;
    }

    public List<List<Integer>> permute(int[] nums) {
        int len=nums.length;
        dfs(0,len,nums,new ArrayList<Integer>());
        return res;
    }
}
```

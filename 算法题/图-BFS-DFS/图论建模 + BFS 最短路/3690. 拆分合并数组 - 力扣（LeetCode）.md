给你两个长度为 `n` 的整数数组 `nums1` 和 `nums2` 。你可以对 `nums1` 执行任意次下述的 **拆分合并操作** ：

1. 选择一个子数组 `nums1[L..R]` 。
2. 移除该子数组，留下前缀 `nums1[0..L-1]` （如果 `L = 0` 则为空）和后缀 `nums1[R+1..n-1]` （如果 `R = n - 1` 则为空）。
3. 将移除的子数组（按原顺序）重新插入到剩余数组的 **任意** 位置（即，在任意两个元素之间、最开始或最后面）。

返回将 `nums1` 转换为 `nums2` 所需的 **最少** **拆分合并操作** 次数。

**示例 1:**

**输入:** nums1 = \[3,1,2\], nums2 = \[1,2,3\]

**输出:** 1

**解释:**

- 拆分出子数组 `[3]` (`L = 0`, `R = 0`)；剩余数组为 `[1,2]` 。
- 将 `[3]` 插入到末尾；数组变为 `[1,2,3]` 。

**示例 2:**

**输入:** nums1 = \[1,1,2,3,4,5\], nums2 = \[5,4,3,2,1,1\]

**输出:** 3

**解释:**

- 移除下标 `0 - 2` 处的 `[1,1,2]` ；剩余 `[3,4,5]` ；将 `[1,1,2]` 插入到位置 `2` ，得到 `[3,4,1,1,2,5]` 。
- 移除下标 `1 - 3` 处的 `[4,1,1]` ；剩余 `[3,2,5]` ；将 `[4,1,1]` 插入到位置 `3` ，得到 `[3,2,5,4,1,1]` 。
- 移除下标 `0 - 1` 处的 `[3,2]` ；剩余 `[5,4,1,1]` ；将 `[3,2]` 插入到位置 `2` ，得到 `[5,4,3,2,1,1]` 。

**提示:**

- `2 <= n == nums1.length == nums2.length <= 6`
- `-10^5 <= nums1[i], nums2[i] <= 10^5`
- `nums2` 是 `nums1` 的一个 **排列** 。

```java
class Solution {
    public int minSplitMerge(int[] nums1, int[] nums2) {
        int n = nums1.length;
        List<Integer> nums2List = toList(nums2);
        Set<List<Integer>> vis = new HashSet<>();
        vis.add(toList(nums1));
        List<List<Integer>> q = List.of(toList(nums1));
        for (int ans = 0; ; ans++) {
            List<List<Integer>> tmp = q;
            q = new ArrayList<>();
            for (List<Integer> a : tmp) {
                if (a.equals(nums2List)) {
                    return ans;
                }
                for (int l = 0; l < n; l++) {
                    for (int r = l + 1; r <= n; r++) {
                        List<Integer> sub = a.subList(l, r);
                        List<Integer> b = new ArrayList<>(a);
                        b.subList(l, r).clear(); // 从 b 中移除 sub
                        for (int i = 0; i <= b.size(); i++) {
                            List<Integer> c = new ArrayList<>(b);
                            c.addAll(i, sub);
                            if (vis.add(c)) { // c 不在 vis 中
                                q.add(c);
                            }
                        }
                    }
                }
            }
        }
    }

    private List<Integer> toList(int[] nums) {
        return Arrays.stream(nums).boxed().collect(Collectors.toList());
    }
}
```

### **这段代码用BFS暴力枚举所有"split+merge"操作，核心难点在于`subList`是视图（view）而非拷贝，`clear()`会直接修改底层列表**

这道题（LeetCode 2565「最少得到多少次编辑」类型，实际是"Split and Merge Array Transformation"）允许的操作是：从数组中任取一段连续子数组，把它整体移动到任意位置。代码用BFS暴力尝试所有"取出一段+插入某处"的组合，找到从`nums1`变成`nums2`的最少操作次数。下面把每一步拆开讲清楚。

#### 整体框架：BFS按层扩展

`vis`记录所有出现过的状态（避免重复访问），`q`是当前这一层（用了`ans`次操作后能到达的所有状态）。外层`for (int ans = 0; ; ans++)`每次处理完当前层，就把该层所有状态能扩展出的下一层状态放进新的`q`。一旦某个状态等于`nums2List`，就返回当前的`ans`，这就是最少操作数。

#### 关键的三行：如何"取出一段子数组再插入别处"

这是最容易看晕的部分，逐行拆解：

```java
List<Integer> sub = a.subList(l, r);
```

这一行不是复制，而是创建了`a`从下标`l`到`r-1`这一段的**视图**。也就是说，`sub`和`a`底层共享同一块数据，对`sub`的任何修改都会反映到`a`上（反之亦然，只要不改变结构）。这一点是理解后面代码的关键。

```java
List<Integer> b = new ArrayList<>(a);
b.subList(l, r).clear();
```

这里先用`new ArrayList<>(a)`把`a`**真正复制**一份，得到独立的`b`（避免影响原始状态`a`）。然后对`b`的`[l, r)`区间取子视图并调用`clear()`——由于`subList`返回的是视图，清空这个视图，效果就是把`b`中`[l, r)`这一段元素删除。这样`b`就变成了"`a`去掉被取出的那一段`sub`之后剩下的数组"。

需要注意，第一行的`sub`视图绑定的是原始的`a`，不是`b`，所以`b`被清空并不会影响`sub`里保存的内容（此时`sub`仍然完整地反映着`a`中原来那段数据，只是`a`本身还没被修改，一直没变过）。

```java
for (int i = 0; i <= b.size(); i++) {
    List<Integer> c = new ArrayList<>(b);
    c.addAll(i, sub);
    if (vis.add(c)) {
        q.add(c);
    }
}
```

这个循环尝试把`sub`这段子数组重新插入到`b`的每一个可能位置（从最前面`i=0`到最后面`i=b.size()`）。每次都新建一个`b`的拷贝`c`，再用`addAll(i, sub)`把`sub`整体插入到下标`i`处，得到一个新状态`c`。

`vis.add(c)`利用了`Set.add`的返回值：如果`c`是全新状态（之前没出现过），`add`返回`true`并把`c`加入`vis`，同时把`c`放进下一层的队列`q`；如果`c`已经出现过，则跳过，避免重复搜索造成死循环或浪费。

#### 双重循环`l, r`的含义

外层的`for (l...) for (r...)`枚举了原数组`a`中所有可能的连续子区间`[l, r)`作为"要取出的一段"，长度从1到`n`都有可能，起始位置也遍历所有可能。结合内层插入位置`i`的枚举，整体就穷举了"任选一段连续子数组，剪切后插入到任意新位置"这一次操作的**所有**可能结果，这正好对应题目允许的一次基本操作。

#### 为什么要区分`vis`和`q`

`vis`是全局去重集合，保证BFS不会在同一状态上重复扩展；`q`则是"当前操作次数下所有可达的新状态"，每层结束后整体替换成下一层。这种写法保证了BFS按操作次数严格分层，因此第一次找到`nums2List`时的`ans`一定是最小操作次数。

如果把这套逻辑串起来看：每一层里，程序把当前所有可能的数组状态都拿出来，逐个尝试"任取一段、任插一处"的所有变形，把没见过的新状态收集到下一层，直到某个新状态恰好等于目标数组`nums2`为止，返回的`ans`就是层数，也就是最少的操作次数。这是一种典型的"状态空间BFS"解法，暴力穷举但保证求最短路径（最少次数）是正确的。

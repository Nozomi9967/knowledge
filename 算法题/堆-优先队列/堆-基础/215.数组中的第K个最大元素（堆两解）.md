# 215. 数组中的第 K 个最大元素（堆两解）

## 题目

https://leetcode.cn/problems/kth-largest-element-in-an-array/

给定整数数组 `nums` 和整数 `k`，返回数组中第 `k` 个**最大**元素（排序后位置，不是去重）。要求 `O(n)` 级别思路（快速选择），但堆解 `O(n + k log n)` / 大小 k 堆 `O(n log k)` 面试最常写。

## 解法一：PriorityQueue 全量大根堆 + 弹 k 次

```java
class Solution {
    public int findKthLargest(int[] nums, int k) {
        PriorityQueue<Integer> pq = new PriorityQueue<>(
            (a, b) -> Integer.compare(b, a)   // 大根堆：堆顶是最大值
        );
        for (int num : nums) pq.offer(num);
        int ans = pq.peek();
        for (int i = 1; i <= k; i++) {
            ans = pq.poll();                  // 连弹 k 次，第 k 个弹出值即答案
        }
        return ans;
    }
}
```

### 逐点拆解

- **大根堆构造**：`Integer.compare(b, a)` 交换参数顺序即降序比较器 → 堆顶最大。三种等价写法见 [[机试#大根堆（三种写法，全部防溢出）]]，⚠ 别写 `(a,b) -> b - a`（溢出）。
- **弹 k 次语义**：大根堆 poll 依次弹出第 1 大、第 2 大……第 k 次弹出的就是第 k 大。循环变量从 1 到 k 共 k 次，`ans` 最后一次赋值为所求。
- **`ans = pq.peek()` 是冗余保险**：k 合法（≤ n）时循环至少跑一次、必然覆盖 ans。留着无害，删掉也对。
- 复杂度：建堆 `O(n)`（逐个 offer 是 O(n log n)，但 PQ 全量 addAll 后 heapify 线性；面试说 `O(n + k log n)`），弹 k 次 `O(k log n)`，空间 `O(n)`。

## 解法二：手写堆排序 · 原地弹出 k 次

```java
class Solution {

    void swap(int[] a, int i, int j) {
        int tem = a[i];
        a[i] = a[j];
        a[j] = tem;
    }

    // 下沉：把 a[i] 在长度 n 的堆里往下调整到合法位置
    void heapify(int[] a, int n, int i) {
        int lar = i;
        int l = 2 * i + 1, r = 2 * i + 2;
        if (l < n && a[l] > a[lar]) {
            lar = l;
        }
        if (r < n && a[r] > a[lar]) {
            lar = r;
        }
        if (lar != i) {
            swap(a, lar, i);
            heapify(a, n, lar);   // 只可能在被交换的子树里继续下沉
        }
    }

    public int findKthLargest(int[] nums, int k) {
        int n = nums.length;
        // 建堆：从最后一个非叶子节点 n/2-1 开始倒序下沉，O(n)
        for (int i = n / 2 - 1; i >= 0; i--) {
            heapify(nums, n, i);
        }
        // 弹出 k 次：堆顶与尾部交换（最大值进尾部已排区），堆规模缩 1，堆顶下沉
        for (int i = n - 1; i >= 0; i--) {
            if (--k <= 0) break;
            swap(nums, 0, i);
            heapify(nums, i, 0);
        }
        return nums[0];
    }
}
```

### 堆排序骨架（背这个）

| 步骤 | 代码 | 说明 |
|------|------|------|
| 数组建堆 | `for (i = n/2-1; i >= 0; i--) heapify(a, n, i)` | 最后一个非叶子 = `n/2-1`（0 基下标，节点 i 的子孩子是 `2i+1/2i+2`）；倒序保证下沉时子树已合法；总复杂度 `O(n)` 不是 O(n log n) |
| 弹堆顶 × k | `swap(a, 0, i); heapify(a, i, 0)` | 堆顶（最大值）换到位置 i 即「第 i+1 大就坐」，堆有效长度从 i+1 缩成 i |
| 答案位置 | 弹完 k 次看 `a[0]` | 见下 |

### `--k` 与 `return nums[0]` 的对应关系（本题最绕的一行）

循环里 `if (--k <= 0) break;` **先减再判**：每轮开头 k 减 1，减到 0 时在**做完 k-1 次交换之后、第 k 次交换之前**退出。此时：

- 已排区：尾部 k-1 个位置坐好了第 1~k-1 大
- 堆区（`nums[0..i]`）里剩下的最大值，恰好就是**第 k 大** → 堆顶 `nums[0]`

代入 `k=1` 验证：`--k` 立刻 0、break，一次交换没做，堆刚建完，`nums[0]` 就是最大值 ✓。所以**答案读 `nums[0]`（第 k 大还没弹出，正躺在堆顶）**，不是 `nums[n-k]`。

### 与既有版本（[[215. 数组中的第K个最大元素]]）的对照

那篇的收尾是「先交换后判断 `n-i==k`，返回 `nums[n-k]`」——弹了 k 次、第 k 大已落到尾部位置 `n-k`。两版都对，差异只在**退出时机差一拍**：

| | 本代码（弹 k-1 次） | 既有笔记（弹 k 次） |
|---|---|---|
| break 位置 | 交换**前** `if(--k<=0) break` | 交换**后** `if(n-i==k) break` |
| 答案 | `nums[0]`（堆顶） | `nums[n-k]`（刚换出的堆顶） |
| 记忆点 | 第 k 大还在堆里，读堆顶 | 第 k 大已弹到尾部，读尾部 |

考试时**只背一套**，推荐本代码这版：弹 k-1 次 + 读堆顶，循环体和经典堆排序模板差异最小。

## 两种堆的选型（第 K 大 / 第 K 小通用）

| 需求 | 堆型 | 复杂度 |
|------|------|--------|
| 第 k 大，k 很小 | **大小 k 的小根堆**：堆里放当前最大的 k 个，堆顶 = 第 k 大，来了更大的就替换堆顶 | `O(n log k)` + `O(k)` 空间 |
| 第 k 大，k ≈ n/2 | 本题两解：全量大根堆弹 k 次 | `O(n + k log n)` |
| 数据流动态求第 k 大 | k 大小根堆 + 对顶堆（见 [[算法题/堆-优先队列/堆-对顶堆]]） | 每次插入 `O(log k)` |
| 手写要求 / 不允许 PQ | 本题解法二堆排序骨架 | 同上，另有 `O(1)` 额外空间版 |
| 真 `O(n)` | 快速选择（平均），最坏 `O(n²)` 需随机化 | 见 [[机试]] 无堆排序外的另一路 |

**面试加分话术**：「求第 k 大本质是**部分排序**——只需要把前 k 大的相对顺序搞对。堆解是 `O(n + k log n)` 的确定性方案；如果面试官要求 O(n)，答快速选择，并主动说清楚它最坏 O(n²)、要随机化 pivot。」

## 复杂度

- 解法一：`O(n + k log n)` 时间（若按逐个 offer 建堆则 `O(n log n)`，口述时说线性建堆更专业）、`O(n)` 空间
- 解法二：建堆 `O(n)` + 弹 k 次 `O(k log n)`；**原地**、额外 `O(log n)` 递归栈（heapify 递归版；改 while 则 `O(1)`）

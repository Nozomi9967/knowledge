[768\. 最多能完成排序的块 II](https://leetcode.cn/problems/max-chunks-to-make-sorted-ii/)

给你一个整数数组 `arr` 。

将 `arr` 分割成若干 **块** ，并将这些块分别进行排序。之后再连接起来，使得连接的结果和按升序排序后的原数组相同。

返回能将数组分成的最多块数？

**示例 1：**

```
输入：arr = [5,4,3,2,1]
输出：1
解释：
将数组分成2块或者更多块，都无法得到所需的结果。 
例如，分成 [5, 4], [3, 2, 1] 的结果是 [4, 5, 1, 2, 3]，这不是有序的数组。
```

**示例 2：**

```
输入：arr = [2,1,3,4,4]
输出：4
解释：
可以把它分成两块，例如 [2, 1], [3, 4, 4]。 
然而，分成 [2, 1], [3], [4], [4] 可以得到最多的块数。
```

```java
class Solution {
    public int maxChunksToSorted(int[] arr) {
        int n = arr.length;
        var st = new ArrayDeque<Integer>();
        
        for (int i = 0; i < n; i++) {
            int x = arr[i];
            
            // 如果新来的数比当前最后一个块的最大值（栈顶）要小，说明发生了融合
            if (!st.isEmpty() && x < st.peek()) {
                // 1. 先把当前最后一块的最大值记下来，它就是融合后新块的“老大”
                int head = st.peek(); 
                
                // 2. 开始往左砸碎所有比 x 大的块（把它们和新数融合成一个大块）
                while (!st.isEmpty() && x < st.peek()) {
                    st.pop();
                }
                
                // 3. 融合完毕后，把刚才记下来的“老大”重新压入栈顶
                st.push(head);
            } else {
                // 如果新来的数大于或等于栈顶，说明它很安全，可以自己独立成一个新块
                st.push(x);
            }
        }    
        return st.size();
    }
}
```

这个单调栈在维护一段从左到右插入的递增序列，如果你当前遍历到的元素比左边元素小，那就要和它合并，体现为弹出它，但又不能让递增序列的特性丢了，所以就记一下栈顶（因为根据递增序列的特性，栈顶为当前遍历到的元素中的最大值），刚刚讲到要弹出当前元素左边的元素，这是个循环，那么停止条件是什么？举个例子，2、5、3，明显5和3是一块，不必跟2凑，所以可以看出只要左边元素比自己大，就一直弹出，所以最终栈中序列的各个元素就是各自块中最大值，栈size也就是最多块数

## 题目

https://leetcode.cn/problems/binary-tree-right-side-view/description/?envType=study-plan-v2&envId=top-interview-150


## 思路

就是层序遍历，每一层取最右边的元素

## 题解

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {

    private void BFS(TreeNode root){

    }

    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> res=new ArrayList<>();
        if(root==null) return res;
        List<TreeNode> floor=List.of(root);
        while(!floor.isEmpty()){
            res.add(floor.get(floor.size()-1).val);
            List<TreeNode> ceil=floor;
            floor=new ArrayList<>();
            for(int i=0;i<ceil.size();i++){
                TreeNode n=ceil.get(i);
                if(n.left!=null) floor.add(n.left);
                if(n.right!=null) floor.add(n.right);
            }
        }
        return res;
    }
}
```

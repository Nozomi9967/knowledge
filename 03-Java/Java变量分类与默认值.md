# Java 变量分类与默认值

> 笔试常考的一道辨析：**实例变量、局部变量、类变量、final 变量**。最容易错的一点是**默认值**——**成员变量（实例变量 / 类变量）有默认值，局部变量没有默认值、必须显式初始化**。附带一个被经常搞混的术语：`final` 其实不是和前三者并列的"一种变量"，而是一个**修饰符**。

---

## 一、四类变量对照

| 变量 | 定义位置 | 归属 | 一份还是多份 | 未初始化时 |
|------|---------|------|:---:|-----------|
| **实例变量**（成员变量） | 类中、**非 `static`** | 对象 | 每个对象**一份** | ✅ **有默认值** |
| **类变量**（静态变量） | 类中、用 **`static`** 修饰 | 类 | 全类**只有一份**（随类加载初始化） | ✅ **有默认值** |
| **局部变量** | 方法 / 代码块 / 形参 | 所属方法栈帧 | 每次调用各一份 | ❌ **无默认值**，用前必须显式赋值 |
| **final 变量** | （是一个**修饰符**，可修饰上面任一种） | 同被修饰者 | 同被修饰者 | 视被修饰者而定，但**只能赋值一次** |

> ⚠️ **注意最后一行**：`final` 不是"第四种变量"，而是一个**修饰符**。它既可以修饰实例变量（`private final int x`），也可以修饰局部变量和类变量。题目把 `final 变量`和前三者并列，本身就有点混——理解它只是"赋值一次后不可改"即可。

---

## 二、默认值表（重点）

**成员变量（实例变量 + 类变量）会被 JVM 自动赋默认值：**

| 类型 | 默认值 |
|------|:---:|
| `byte` / `short` / `int` / `long` | `0` |
| `float` / `double` | `0.0` |
| `char` | `'\u0000'`（空字符） |
| `boolean` | `false` |
| 引用类型（对象、数组、`String`…） | `null` |

**局部变量没有默认值：**

```java
public void method() {
    int x;
    System.out.println(x);   // ❌ 编译错误：变量 x 可能尚未初始化
}
```

编译器会直接拒绝——**局部变量必须在使用前显式赋值**，否则编译不通过。

**为什么两者待遇不同？** 成员变量的初始化由 JVM 在分配对象 / 加载类时统一兜底，保证对象一创建就有确定状态；而局部变量随方法调用产生在**栈帧**里，JVM 不做兜底，编译期就强制你赋值，避免"用了未定义的值"。

## 三、把"成员变量"这个术语说清楚

题目里 A 选项："实例变量指的是类中定义的变量，即成员变量，如果没有初始化，会有默认值。"

- **质疑点**（用户提的）：`static` 变量（类变量）**也**定义在类中，所以"类中定义的变量"这个描述不能把实例变量和类变量区分开。
- **结论**：这个质疑**有道理**——严格说，"实例变量"的准确定义是**"类中未用 `static` 修饰的变量"**。
- 但 A 的核心信息（**有默认值**）是对的，且"成员变量"在**部分教材里等于实例变量**（另一些教材里则包含静态变量，术语有歧义），所以考试里把它当**正确**处理。
- **真正错的是一个别的选项**：

| 选项 | 判断 | 原因 |
|------|:---:|------|
| A 实例变量是类中定义、即成员变量，未初始化有默认值 | ✅（表述不严谨但核心对） | 默认值这点没错；只是"类中定义的变量"不能区分静态变量 |
| B 局部变量是方法中定义的变量，未初始化**有默认值** | ❌ **错误（答案）** | 局部变量**没有**默认值，用前必须显式初始化 |
| C 类变量是用 `static` 修饰的属性 | ✅ | 类变量 != 实例变量的分界线就是 `static` |
| D final 变量是用 `final` 修饰的变量 | ✅ | 基本正确，赋值一次后不可改 |

> 📌 所以这道题选 **B**。A 的说法虽不够精确，但考试视角下不构成"错误"；能一眼看出 B 的"局部变量有默认值"才是硬伤。

## 四、面试话术（口述版）

**问：Java 里实例变量、局部变量、类变量有什么区别？**

> 核心分两条线。第一条是**归属**：类变量用 `static` 修饰，属于类、全类只有一份、随类加载初始化；实例变量不带 `static`，属于对象、每个对象一份、随 `new` 分配；局部变量定义在方法或代码块里，每次方法调用各有一份、存在栈帧上。第二条也是笔试最爱考的——**默认值**：成员变量，也就是实例变量和类变量，JVM 会自动赋默认值，数值类型是 0、布尔是 false、引用类型是 null；但**局部变量没有默认值**，用之前必须显式赋值，否则编译器直接报错。至于 `final`，严格说它不是"第四种变量"，而是一个**修饰符**，可以修饰实例变量、局部变量或类变量，作用都是"只能赋值一次"。

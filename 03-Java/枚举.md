# Java 枚举（Enum）全解

## 一、枚举是什么

本质上，`enum` 是一个**特殊的类**，编译器会把它翻译成继承 `java.lang.Enum` 的 final 类，每个枚举常量都是该类的一个 `public static final` 实例。

```java
enum Season { SPRING, SUMMER, AUTUMN, WINTER }

// 编译器实际生成的等价代码（简化版）：
final class Season extends Enum<Season> {
    public static final Season SPRING = new Season("SPRING", 0);
    public static final Season SUMMER = new Season("SUMMER", 1);
    public static final Season AUTUMN = new Season("AUTUMN", 2);
    public static final Season WINTER = new Season("WINTER", 3);
    // ...
}
```

## 二、基础用法

```java
enum Direction { UP, DOWN, LEFT, RIGHT }

Direction d = Direction.UP;
System.out.println(d);          // UP
System.out.println(d.name());   // UP（常量名字符串）
System.out.println(d.ordinal()); // 0（从0开始的序号）

// 字符串转枚举
Direction d2 = Direction.valueOf("DOWN"); // Direction.DOWN

// 遍历所有常量
for (Direction dir : Direction.values()) {
    System.out.println(dir.ordinal() + " -> " + dir);
}
```

## 三、枚举 + 属性和方法（最常用）

枚举可以有**字段、构造器、方法**，构造器必须是 private。

```java
enum Planet {
    MERCURY(3.303e+23, 2.4397e6),
    VENUS  (4.869e+24, 6.0518e6),
    EARTH  (5.976e+24, 6.37814e6);

    private final double mass;   // 质量
    private final double radius; // 半径

    // 构造器必须 private
    Planet(double mass, double radius) {
        this.mass = mass;
        this.radius = radius;
    }

    // 普通方法
    public double surfaceGravity() {
        final double G = 6.67300E-11;
        return G * mass / (radius * radius);
    }
}

System.out.println(Planet.EARTH.surfaceGravity()); // 9.80...
```

## 四、枚举 + 抽象方法（每个常量有不同行为）

```java
enum Operation {
    PLUS("+") {
        @Override
        public double apply(double x, double y) { return x + y; }
    },
    MINUS("-") {
        @Override
        public double apply(double x, double y) { return x - y; }
    },
    TIMES("*") {
        @Override
        public double apply(double x, double y) { return x * y; }
    };

    private final String symbol;

    Operation(String symbol) { this.symbol = symbol; }

    // 抽象方法，每个常量必须实现
    public abstract double apply(double x, double y);

    @Override
    public String toString() { return symbol; }
}

// 使用
for (Operation op : Operation.values()) {
    System.out.printf("3 %s 2 = %.1f%n", op, op.apply(3, 2));
}
// 3 + 2 = 5.0
// 3 - 2 = 1.0
// 3 * 2 = 6.0
```

## 五、switch 中使用枚举

```java
enum Status { PENDING, RUNNING, SUCCESS, FAILED }

Status s = Status.RUNNING;

// 传统 switch
switch (s) {
    case PENDING:  System.out.println("等待中"); break;
    case RUNNING:  System.out.println("运行中"); break;
    case SUCCESS:  System.out.println("成功");   break;
    case FAILED:   System.out.println("失败");   break;
}

// Java 14+ switch 表达式（更简洁）
String msg = switch (s) {
    case PENDING  -> "等待中";
    case RUNNING  -> "运行中";
    case SUCCESS  -> "成功";
    case FAILED   -> "失败";
};
```

## 六、EnumSet 和 EnumMap

专为枚举设计，**性能远优于** HashSet/HashMap（底层用位向量实现）。

```java
enum Day { MON, TUE, WED, THU, FRI, SAT, SUN }

// EnumSet
EnumSet<Day> weekdays  = EnumSet.range(Day.MON, Day.FRI);
EnumSet<Day> weekends  = EnumSet.of(Day.SAT, Day.SUN);
EnumSet<Day> all       = EnumSet.allOf(Day.class);

System.out.println(weekdays.contains(Day.MON)); // true

// EnumMap
EnumMap<Day, String> schedule = new EnumMap<>(Day.class);
schedule.put(Day.MON, "周会");
schedule.put(Day.FRI, "代码审查");
System.out.println(schedule.get(Day.MON)); // 周会
```

## 七、枚举实现接口

```java
interface Printable {
    void print();
}

enum Color implements Printable {
    RED, GREEN, BLUE;

    @Override
    public void print() {
        System.out.println("Color: " + this.name());
    }
}

Color.RED.print(); // Color: RED
```

## 八、枚举与单例模式

枚举是实现单例的**最佳方式**（Effective Java 推荐），天然线程安全、防反射、防反序列化。

```java
enum Singleton {
    INSTANCE;

    private int count = 0;

    public void increment() { count++; }
    public int getCount()   { return count; }
}

// 使用
Singleton.INSTANCE.increment();
Singleton.INSTANCE.increment();
System.out.println(Singleton.INSTANCE.getCount()); // 2
```

## 九、常用 API 汇总

| 方法              | 说明                       |
| ----------------- | -------------------------- |
| `name()`          | 返回常量名字符串           |
| `ordinal()`       | 返回序号（从 0 开始）      |
| `valueOf(String)` | 字符串转枚举，找不到抛异常 |
| `values()`        | 返回所有常量数组           |
| `compareTo(E)`    | 按 ordinal 比较大小        |
| `toString()`      | 默认返回 name()，可重写    |

## 十、注意事项

**不要依赖 `ordinal()`** 存储业务含义，因为增减常量会导致序号变化，应该用显式字段：

```java
// ❌ 错误做法
enum Type { A, B, C }
int code = type.ordinal(); // 脆弱！

// ✅ 正确做法
enum Type {
    A(1), B(2), C(3);
    private final int code;
    Type(int code) { this.code = code; }
    public int getCode() { return code; }
}
```

**`valueOf` 找不到会抛 `IllegalArgumentException`**，需要容错时自己封装：

```java
public static Type fromCode(int code) {
    for (Type t : values()) {
        if (t.code == code) return t;
    }
    throw new IllegalArgumentException("未知 code: " + code);
}
```

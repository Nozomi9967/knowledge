# 算法笔记：命令行解析与出现次数统计

## 1. 题目描述

### 题目背景
在一种复杂的命令行系统中，命令的格式由一个模板字符串定义。模板由关键字、抉择结构 `{...}` 和可选结构 `[...]` 组成，元素间由空格分隔。你的任务是解析这个模板，找出所有在顶层定义的固定关键字，并计算出每一个固定关键字在任意合法的命令中保证会出现的最小次数。

### 核心定义
1. **关键字**：仅由小写字母组成的字符串。
2. **固定关键字**：在模板的顶层，不被任何括号包裹的关键字。它们是命令的根基。
3. **抉择结构 `{ A | B | ... }`**：表示该位置必须从选项 `A`, `B`, ... 中选择一个。选项本身可以是复杂的子模板。
4. **可选结构 `[ C ]`**：表示 `C` 部分是可选的，可以出现 0 次或 1 次。

### 保证出现次数的计算规则
一个关键字 $K$ 的"保证出现次数" $C(K)$，是基于以下递归逻辑计算的：
- 首先，统计 $K$ 作为固定关键字出现的次数。
- 然后，遍历模板中的所有抉择结构 `{ A | B | ... }`，如果 $K$ 在每一个选项 $A, B, \dots$ 中都保证会出现（即，递归计算出的保证次数都 $\ge 1$），那么这个抉择结构就为 $C(K)$ 贡献 `+1`。
- 在可选结构 `[...]` 内部的任何关键字，都不被视为"保证出现"。

### 输入与输出
- **输入描述**：输入为一行字符串，代表命令格式模板。由关键字、`{`, `}`, `|`, `[`, `]` 和空格组成，保证格式合法。
- **输出描述**：
  - 第一行：按输入顺序输出所有固定关键字，以单个空格分隔。**（注意：即使有重复的固定关键字，也必须按顺序全部输出，不可去重）**
  - 第二行：对应第一行的每个关键字，输出其保证出现的最小次数，以单个空格分隔。

### 示例
#### 示例 1
* **输入**：`a b { c | d [ e ] } [ f { g | h } ]`
* **输出**：
  ```text
  a b
  1 1
  ```

#### 示例 2
* **输入**：`system log system [ verbose ]`
* **输出**：
  ```text
  system log system
  2 1 2
  ```

## 2. 算法核心思路

本题本质上是 **"模板语法树（AST）构建 + 树形递归计算"** 的组合。整个过程可以清晰地分为三个阶段：

### 阶段一：词法切分 (Tokenization)
为了防止括号、分隔符和字母粘连（例如 `{c|d}` 这种非空格分隔的边界情况），不能简单地使用 `split(" ")`。我们需要按字符流扫描：
- 连续的小写字母合并为一个 `KW`（关键字）Token。
- `{`、`}`、`[`、`]`、`|` 各自切分为独立的控制 Token。
- 忽略所有空格。

### 阶段二：语法解析 (Recursive Descent Parsing)
利用递归下降算法将 Token 流解析为一棵语法树。节点定义如下：
* **`KW`（关键字节点）**：存储具体的字符串值 `word`。
* **`CHOICE`（抉择节点）**：包含一个选项列表 `options`，其中每个选项又是一个子节点序列（`List<List<Node>>`）。
* **`OPT`（可选节点）**：包含其内部的子序列 `inner`（`List<Node>`）。

解析控制流如下：
1. **`parseSeq()`**：解析一个节点序列，直到遇到终结符 `}`、`]` 或 `|` 时返回，将控制权交还给父级。
2. **`parseChoice()`**：当遇到 `{` 时触发。不断调用 `parseSeq()` 收集以 `|` 分隔的选项，直到读取到 `}` 为止。

### 阶段三：递归计算 $C(K)$
对顶层的每一个固定关键字 $K$（即顶层序列中的 `KW` 节点），通过递归函数 `guaranteed(K, seq)` 计算其保证次数：
1. **基础地基**：累加当前 `seq` 中直接属于 `KW` 类型的节点且值等于 $K$ 的数量。
2. **处理抉择**：遍历 `seq` 中的 `CHOICE` 节点。若该抉择节点的**每一个选项** $A_i$ 满足 `guaranteed(K, A_i) >= 1`，则该抉择节点为 $K$ 的保证次数贡献 `+1`。
3. **处理可选**：直接跳过 `OPT` 节点，不深入其内部进行累加，贡献恒为 `0`（因为可选结构可能一次都不出现，无法提供任何下界保证）。

## 3. 易错点与防坑指南

1. **固定关键字绝对不能去重**
   - 题目要求"按输入顺序输出所有固定关键字"。如 `system log system`，在顶层有两个独立的 `system` 关键字节点。
   - 输出第一行必须完整保留 `system log system`。
   - 输出第二行要分别计算每个位置上关键字值的保证次数，得到 `2 1 2`（因为整个模板中，`system` 的保证出现次数为 `2`）。
2. **可选结构内部不要向下递归**
   - 在计算保证次数 `guaranteed(K, seq)` 时，切记不能对 `OPT` 节点的内部成员进行递归计算，因为可选结构即使包含 $K$，最坏情况下也是出现 0 次。
3. **分词边界安全**
   - 必须通过字符级别的扫描来切分 Token，避免因为输入没有严格使用空格隔开括号而导致解析失败。

## 4. 优化后的完整 Java 实现

```java
import java.util.*;

public class Main {
    static final int KW = 0, CHOICE = 1, OPT = 2;
    static String[] tokens;
    static int pos;

    // 语法树节点定义
    static class Node {
        int type;
        String word;
        List<List<Node>> options; // 用于 CHOICE 节点，存储每个分支的序列
        List<Node> inner;         // 用于 OPT 节点，存储可选包围的序列
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String line = sc.hasNextLine() ? sc.nextLine() : "";
        tokens = tokenize(line);
        pos = 0;
        
        // 构建顶层语法序列
        List<Node> top = parseSeq();

        // 收集顶层所有的固定关键字：按输入顺序全部保留，千万不能进行去重（Deduplication）
        List<String> fixed = new ArrayList<>();
        for (Node n : top) {
            if (n.type == KW) {
                fixed.add(n.word);
            }
        }

        // 统一计算每个固定关键字在模板中的最小保证出现次数
        StringBuilder a = new StringBuilder();
        StringBuilder b = new StringBuilder();
        for (String k : fixed) {
            a.append(k).append(' ');
            b.append(guaranteed(k, top)).append(' ');
        }
        
        System.out.println(a.toString().trim());
        System.out.println(b.toString().trim());
    }

    /**
     * 词法分析：将输入流精确切分成独立的 token（关键字或符号）
     */
    static String[] tokenize(String s) {
        List<String> list = new ArrayList<>();
        StringBuilder cur = new StringBuilder();
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c >= 'a' && c <= 'z') {
                cur.append(c);
            } else {
                if (cur.length() > 0) { 
                    list.add(cur.toString()); 
                    cur.setLength(0); 
                }
                if (c == '{' || c == '}' || c == '|' || c == '[' || c == ']') {
                    list.add(String.valueOf(c));
                }
            }
        }
        if (cur.length() > 0) {
            list.add(cur.toString());
        }
        return list.toArray(new String[0]);
    }

    /**
     * 解析一个顺序序列，当遇到属于外层的界定符 '}', ']', '|' 时，中止当前序列的解析
     */
    static List<Node> parseSeq() {
        List<Node> seq = new ArrayList<>();
        while (pos < tokens.length) {
            String t = tokens[pos];
            if (t.equals("}") || t.equals("]") || t.equals("|")) {
                break;
            }
            if (t.equals("{")) {
                pos++; // 跳过 '{'
                Node n = new Node(); 
                n.type = CHOICE; 
                n.options = parseChoice();
                seq.add(n);
            } else if (t.equals("[")) {
                pos++; // 跳过 '['
                Node n = new Node(); 
                n.type = OPT; 
                n.inner = parseSeq();
                if (pos < tokens.length && tokens[pos].equals("]")) {
                    pos++; // 跳过 ']'
                }
                seq.add(n);
            } else {
                Node n = new Node(); 
                n.type = KW; 
                n.word = t;
                seq.add(n); 
                pos++;
            }
        }
        return seq;
    }

    /**
     * 解析抉择结构的大括号内部，以 '|' 分割出不同的候选路径序列
     */
    static List<List<Node>> parseChoice() {
        List<List<Node>> options = new ArrayList<>();
        while (true) {
            options.add(parseSeq());
            if (pos < tokens.length && tokens[pos].equals("|")) {
                pos++;
                continue;
            }
            if (pos < tokens.length && tokens[pos].equals("}")) {
                pos++; // 成功消费匹配的 '}' 结束整个抉择组
            }
            break;
        }
        return options;
    }

    /**
     * 核心递归求值：在给定的 seq 语法树序列下，递归计算关键字 K 保证出现的下界
     */
    static int guaranteed(String K, List<Node> seq) {
        int cnt = 0;
        for (Node n : seq) {
            if (n.type == KW) {
                // 1. 若当前节点为 K，确定保证次数 +1
                if (n.word.equals(K)) {
                    cnt++;
                }
            } else if (n.type == CHOICE) {
                // 2. 抉择结构：只有当所有分支在递归中都能保证出现 K（即次数 >= 1）时，整个抉择结构才能贡献 +1
                boolean allBranchesContain = true;
                for (List<Node> opt : n.options) {
                    if (guaranteed(K, opt) < 1) {
                        allBranchesContain = false;
                        break;
                    }
                }
                if (allBranchesContain) {
                    cnt++;
                }
            }
            // 3. 可选结构 [C] 整体跳过，对最小出现下界贡献恒为 0，不进行递归
        }
        return cnt;
    }
}
```

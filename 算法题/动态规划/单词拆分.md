<!--前提：substring取得左开右闭-->



动态规划，dp[i]的意思就是在i之前(不包括i)的字母都能在dict中匹配上

一开始想不明白为什么要有j，为什么要双循环，i直接从1到n不就完事了，我举个例子



*假如字符串为ababaa，字典中有ab和ababaa，显然直接取第二个就完事了，但是如果按照我刚开始的想法一次遍历，会先取ab，然后再取ab，然后就拼不出来了*



**显然我需要回去再检测一遍，j就是这个作用，所以当dp[j]=true并且从j到i-1的字符串在dict中存在，那么dp[i]=true，这样就可以利用之前的dp[j]，不断的更新dp数组中为true的值，dp数组中true值越多，我们的跳板越多**



```
public class Solution {
    /**
     * @param s: A string
     * @param wordSet: A dictionary of words dict
     * @return: A boolean
     */
    public boolean wordBreak(String s, Set<String> wordSet) {
        // write your code here
        // 为空直接返回true
        if(s==null){
            return true;
        }
        // 视频里有解释为什么+1且为什么dp[0]=true
        boolean[] dp=new boolean[s.length()+1];
        dp[0]=true;
        for(int i=1;i<=s.length();i++){
            for(int j=0;j<=i;j++){
                if(dp[j]&&wordSet.contains(s.substring(j,i))){
                    dp[i]=true;
                    break;
                }
            }
        }
        return dp[s.length()];
    }
}
```

我一开始写的是上面这串代码，但是通不过，超时

进行优化后的代码就是下面的，主要变化在于当第二次循环时，如果我们substring截取的字符串比dict中最长的还要长，那么我们可以直接跳过，但是我一开始写的j是从0->i，感觉不怎么好写，这时反过来，让j从i到0，让第二次循环的条件变成j<=maxLength(dict中最长的字符串)，这时就变成了下面的



```
public class Solution {
    /**
     * @param s: A string
     * @param wordSet: A dictionary of words dict
     * @return: A boolean
     */
    public boolean wordBreak(String s, Set<String> wordSet) {
        // write your code here
        if(s==null){
            return true;
        }
        int maxLength=0;
        for(String str:wordSet){
            maxLength=Math.max(maxLength,str.length());
        }
        boolean[] dp=new boolean[s.length()+1];
        dp[0]=true;
        for(int i=1;i<=s.length();i++){
        	// 这里取等，是因为 当概念中的j变成了i-j，且substring右开时
        	// j=1时，截取到的字符串长度=1，以此类推
            for(int j=1;j<=maxLength;j++){
            	// 防止访问数组过界
                if(j>i){
                    break;
                }
                if(dp[i-j]&&wordSet.contains(s.substring(i-j,i))){
                    dp[i]=true;
                    break;
                }
            }
        }
        return dp[s.length()];
    }
}
```

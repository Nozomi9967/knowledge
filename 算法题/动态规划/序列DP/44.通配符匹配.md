### **LeetCode 44「通配符匹配」是双序列 DP：`dp[i][j]` 表示 `s` 的前 i 个字符与 `p` 的前 j 个字符能否匹配。`?` 匹配任意单字符，`*` 匹配任意长度（含 0）的字符序列——**关键在 `*` 的两种用法：匹配空串（`dp[i][j-1]`）或再吃掉一个字符（`dp[i-1][j]`）**。**

### **一、问题本身**

模式串 `p` 里有两个通配符：

- `?`：匹配**任意单个字符**
- `*`：匹配**任意长度**的字符序列，可以为空

```
s = "adceb", p = "*a*b"  →  true
s = "acdcb", p = "a*c?b" →  false
```

---

### **二、状态与转移**

**状态**：`dp[i][j]` = `s[0..i-1]` 与 `p[0..j-1]` 是否匹配（用 1-based 方便处理空串）。

**转移**分三种情况：

**情况一：`p[j-1]` 是普通字符**
```java
dp[i][j] = (s[i-1] == p[j-1]) && dp[i-1][j-1];
```

**情况二：`p[j-1]` 是 `?`**
```java
dp[i][j] = dp[i-1][j-1];   // 吃掉一个字符，不影响其余
```

**情况三：`p[j-1]` 是 `*`**（这是本题唯一有难度的地方）
```java
dp[i][j] = dp[i][j-1]      // * 匹配空串：模式串少用一个 *
        || dp[i-1][j];     // * 再吃掉 s 的一个字符：模式串的 * 还在
```

**为什么 `*` 的第二个转移是 `dp[i-1][j]` 而不是 `dp[i-1][j-1]`**：因为 `*` 可以匹配多个字符，吃掉 `s[i-1]` 之后 `*` 仍然在模式串当前位置，要继续匹配 `s[i-2]`。这是本题和「10 正则表达式匹配」最大的区别——正则里的 `*` 是"修饰前一个字符"（必须和前一字符绑定），通配符里的 `*` 是独立的、可以匹配任意串。

---

### **三、边界**

```
dp[0][0] = true;                          // 空串匹配空串
dp[i][0] = false (i > 0);                 // 模式串为空，非空 s 不可能匹配
dp[0][j] = dp[0][j-1] && p[j-1] == '*';   // s 为空时，只有全是 * 才匹配
```

第三行最容易漏：`s = ""`、`p = "***"` 应该返回 true，而 `p = "*a*"` 返回 false。

---

### **四、代码**

```java
class Solution {
    public boolean isMatch(String s, String p) {
        int m = s.length(), n = p.length();
        boolean[][] dp = new boolean[m + 1][n + 1];
        dp[0][0] = true;

        // 边界：s 为空时，p 只有全为 * 才能匹配
        for (int j = 1; j <= n; j++) {
            dp[0][j] = dp[0][j - 1] && p.charAt(j - 1) == '*';
        }

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                char pc = p.charAt(j - 1);
                if (pc == '*') {
                    dp[i][j] = dp[i][j - 1] || dp[i - 1][j];
                } else if (pc == '?' || pc == s.charAt(i - 1)) {
                    dp[i][j] = dp[i - 1][j - 1];
                }
                // 否则默认 false
            }
        }
        return dp[m][n];
    }
}
```

### **五、空间优化到一维**

`dp[i][j]` 只依赖 `dp[i][j-1]`（本行左边）、`dp[i-1][j]`（上一行同列）、`dp[i-1][j-1]`（上一行左边）。所以可以压成一维，但**要从左往右遍历**（因为依赖本行左边），且要保存 `dp[i-1][j-1]`：

```java
boolean[] dp = new boolean[n + 1];
dp[0] = true;
for (int j = 1; j <= n; j++) dp[j] = dp[j-1] && p.charAt(j-1) == '*';

for (int i = 1; i <= m; i++) {
    boolean prevDiag = dp[0];    // 保存 dp[i-1][j-1]
    dp[0] = false;               // dp[i][0] = false (i>0)
    for (int j = 1; j <= n; j++) {
        boolean temp = dp[j];    // 存下 dp[i-1][j]，供下一轮当 prevDiag
        char pc = p.charAt(j - 1);
        if (pc == '*') {
            dp[j] = dp[j - 1] || dp[j];
        } else if (pc == '?' || pc == s.charAt(i - 1)) {
            dp[j] = prevDiag;
        } else {
            dp[j] = false;
        }
        prevDiag = temp;
    }
}
return dp[n];
```

**注意 `else` 分支必须显式置 false**：一维数组复用时，如果不清零，会残留上一行的 true。

---

### **六、复杂度与易错点**

| 项 | 复杂度 |
|---|---|
| 时间 | O(m·n) |
| 空间 | O(m·n) / 优化后 O(n) |

**易错点**：

1. **`*` 的转移写成 `dp[i-1][j-1]`**：那是正则的写法，通配符必须是 `dp[i-1][j]`
2. **漏了 `s` 为空时的边界初始化**：`p="***"` 会返回 false
3. **一维优化时忘记清零**：残留 true
4. **把 `?` 和 `*` 搞反**：`?` 是单字符，`*` 是任意长度
5. **和 10 正则匹配混淆**：10 里 `*` 必须跟在某个字符后面（`a*` 表示 0 或多个 a），44 里 `*` 独立存在。两个题面很像，DP 转移完全不同，面试时明确说清区别是加分项

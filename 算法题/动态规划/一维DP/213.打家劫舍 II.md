### **LeetCode 213「打家劫舍 II」把线性问题变成了环形：首尾相邻，所以第一间和最后一间不能同时偷。解法是「拆成两个线性问题取较大值」——要么不偷最后一间（区间 `[0, n-2]`），要么不偷第一间（区间 `[1, n-1]`），两种情况的并集覆盖了所有合法方案。**

### **一、问题本身**

房屋排成一圈，相邻不能同时偷（现在第 1 间和第 n 间也相邻），求最大金额。

```
nums = [2,3,2]
不偷首尾任一间 → 只能偷中间的 3  →  3
（如果按线性算会得到 2+2=4，但首尾在环上相邻，非法）
```

---

### **二、核心思路：环怎么破**

**环形问题的通用套路是"枚举断开点"**。这里首尾只有两种关系：要么不偷第一间，要么不偷最后一间。这两种情况必定覆盖所有合法方案（也可能两种都不偷，被包含在内），所以：

```
答案 = max( robLinear(nums[0..n-2]),  robLinear(nums[1..n-1]) )
```

其中 `robLinear` 就是 198 题的线性版本。

**为什么这样是对的**：任何合法方案要么不包含第 0 间、要么不包含第 n-1 间（否则首尾同时被偷，非法）。所以按"排除谁"分类讨论是完备的。

---

### **三、代码**

```java
class Solution {
    public int rob(int[] nums) {
        int n = nums.length;
        if (n == 1) return nums[0];        // 只有一间，环退化成单点
        if (n == 2) return Math.max(nums[0], nums[1]);
        return Math.max(
            robLinear(nums, 0, n - 2),     // 不偷最后一间
            robLinear(nums, 1, n - 1)      // 不偷第一间
        );
    }

    // 198 题的线性版本，处理闭区间 [l, r]
    private int robLinear(int[] nums, int l, int r) {
        int prev2 = 0;   // dp[i-2]
        int prev1 = 0;   // dp[i-1]
        for (int i = l; i <= r; i++) {
            int cur = Math.max(prev1, prev2 + nums[i]);
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }
}
```

`prev2` 和 `prev1` 初始化成 0 的好处是：不需要单独处理区间长度为 1 的情况，第一次循环自动得到 `max(0, nums[l])`。

---

### **四、边界处理（这题最容易挂的地方）**

**`n == 1` 必须特判**。因为 `n=1` 时两个子问题分别是 `robLinear(0, -1)` 和 `robLinear(1, 0)`，前者是空区间、后者越界，不特判直接崩。

`n == 2` 其实可以不特判（`robLinear(0,0)` 和 `robLinear(1,1)` 都正常），但加上更稳。

| 项 | 复杂度 |
|---|---|
| 时间 | O(n)，两次线性扫描 |
| 空间 | O(1) |

### **六、易错点与延伸**

**易错点**：

1. **忘了 n=1 特判**，数组越界
2. **两个区间写错**：`[0, n-2]` 和 `[1, n-1]`，不是 `[0, n-1]` 和 `[1, n-2]`
3. **想用"记录是否偷了第一间"的状态扩展**：能做但状态变复杂（`dp[i][0/1]` 表示偷没偷第一间），拆两个线性问题更简单
4. **环上有负数**：本题金额非负所以 `max(0, ...)` 没问题；如果有负数，"不偷"必须成为一个合法选项，初始化逻辑要改

**延伸**：337 题「打家劫舍 III」是树形 DP（后序遍历，返回"偷/不偷当前节点"两个值）；这是同一条线的三个难度。

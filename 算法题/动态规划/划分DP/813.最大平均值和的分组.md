### **LeetCode 813「最大平均值和的分组」动态规划解法**

核心思路是**二维划分 DP**：`d[i][j]` 表示前缀 `nums[0..i-1]` 分成最多 `j` 组时的最大分数，通过枚举最后一段的起点完成状态转移，时间复杂度 $O(n^2 \cdot k)$。

---

### **一、问题本身**

给定一个整数数组 `nums` 和一个整数 `k`，需要将数组分成 **k 个非空连续子数组**。每个子数组的分数为该子数组的平均值，总分数为所有子数组分数之和。求**最大可能的总分数**。

> 例如 `nums = [9,1,2,3,9]`，`k = 3`，最优分组为 `[9] | [1,2] | [3,9]`，分数为 `9 + 1.5 + 6 = 16.5`。

---

### **二、DP 解法**

```java
class Solution {
    public double largestSumOfAverages(int[] nums, int k) {
        int n = nums.length;
        // d[i][j]：前 i 个元素分最多 j 份时，构成的最大分数
        double[][] d = new double[n + 1][k + 1];
        for (int i = 0; i < n; i++) {
            double sum = 0;
            int cnt = 1;
            for (int j = i; j >= 0; j--, cnt++) {
                sum += (double) nums[j];
                // 前 j 个元素最多 m 份，1 <= m < k
                for (int m = k - 1; m > 0; m--) {
                    d[i + 1][m + 1] = Math.max(
                        d[i + 1][m + 1], sum / (double) cnt + d[j][m]
                    );
                }
                if (j == 0) d[i + 1][1] = sum / (double) cnt;
            }
        }
        return d[n][k];
    }
}
```

#### **状态定义**

`d[i][j]`：前缀 `nums[0..i-1]`（前 `i` 个元素）分成**最多 `j` 组**时的最大分数。

#### **状态转移**

对于每个位置 `i`（0 到 n-1），枚举最后一段 `nums[j..i]` 的起点 `j`（从 `i` 往左扫）：

- 最后一段 `nums[j..i]` 的平均值为 `sum / cnt`（其中 `sum` 是从 `j` 到 `i` 的累加和，`cnt` 是元素个数）
- 前 `j` 个元素分成最多 `m` 组的最优分数为 `d[j][m]`
- 总共分成最多 `m+1` 组：`d[i+1][m+1] = max(d[i+1][m+1], sum/cnt + d[j][m])`

$$
d[i+1][m+1] = \max_{\substack{0 \le j \le i \\ 1 \le m < k}} \left(\frac{\sum_{p=j}^{i} nums[p]}{i-j+1} + d[j][m]\right)
$$

#### **边界条件**

`d[0][0] = 0`（空数组，0 组，分数 0）。`d[i+1][1]` 在 `j=0` 时赋值，表示整个前缀作为一组的情况。

#### **答案**

`d[n][k]`，即整个数组分成 `k` 组的最大分数。

---

### **三、复杂度分析**

- **时间复杂度**：外层 `i` 走 $n$ 次，中层 `j` 最多走 $n$ 次，内层 `m` 走 $k$ 次。总计 $O(n^2 \cdot k)$。
- **空间复杂度**：`d` 二维数组占 $O(n \cdot k)$。

**优化思路**：内层累加 `sum` 从 `i` 往左扫，避免了预处理前缀和数组，代码更紧凑。如果改成预处理前缀和 `preSum`，则 `sum = preSum[i+1] - preSum[j]`，转移式不变。

### **四、一个具体例子走一遍**

以 `nums = [9,1,2,3,9]`，`k = 3`（`n = 5`）为例：

| i | 枚举 j | 最后一段 nums[j..i] | 平均值 | m | d[i+1][m+1] 更新 | 最终值 |
|---|--------|---------------------|--------|---|-----------------|--------|
| 0 | j=0 | [9] | 9/1=9 | — | d[1][1]=9 | 9 |
| 1 | j=1 | [1] | 1 | m=1 | d[2][2]=9+1=10 | d[2][1]=5 |
|   | j=0 | [9,1] | 5 | — | d[2][1]=5 | |
| 2 | j=2 | [2] | 2 | m=1 | d[3][2]=5+2=7 | |
|   | j=1 | [1,2] | 1.5 | m=1 | d[3][2]=max(7,9+1.5)=10.5 | |
|   | j=0 | [9,1,2] | 4 | — | d[3][1]=4 | 4 |
| 3 | j=3 | [3] | 3 | m=1 | d[4][2]=4+3=7 | |
|   | j=3 | [3] | 3 | m=2 | d[4][3]=10.5+3=13.5 | |
|   | j=2 | [2,3] | 2.5 | m=1 | d[4][2]=max(7,5+2.5)=7.5 | |
|   | j=2 | [2,3] | 2.5 | m=2 | d[4][3]=max(13.5,10.5+2.5)=13.5 | |
|   | j=1 | [1,2,3] | 2 | m=1 | d[4][2]=max(7.5,5+2)=7 | |
|   | j=1 | [1,2,3] | 2 | m=2 | d[4][3]=max(13.5,9+2)=13 | |
|   | j=0 | [9,1,2,3] | 3.75 | — | d[4][1]=3.75 | 3.75 |
| 4 | j=4 | [9] | 9 | m=1 | d[5][2]=3.75+9=12.75 | |
|   | j=4 | [9] | 9 | m=2 | d[5][3]=13.5+9=22.5 | |
|   | j=3 | [3,9] | 6 | m=1 | d[5][2]=max(12.75,4+6)=10 | |
|   | j=3 | [3,9] | 6 | m=2 | d[5][3]=max(22.5,10.5+6)=16.5 | ← **最优** |
|   | j=2 | [2,3,9] | 4.67 | m=1 | d[5][2]=max(10,5+4.67)=9.67 | |
|   | j=2 | [2,3,9] | 4.67 | m=2 | d[5][3]=max(16.5,9+4.67)=13.67 | |
|   | j=1 | [1,2,3,9] | 3.75 | m=1 | d[5][2]=max(9.67,5+3.75)=8.75 | |
|   | j=1 | [1,2,3,9] | 3.75 | m=2 | d[5][3]=max(16.5,9+3.75)=16.5 | |
|   | j=0 | [9,1,2,3,9] | 4.8 | — | d[5][1]=4.8 | 4.8 |

返回 `d[5][3] = 16.5`，对应分组 `[9] | [1,2] | [3,9]`。

### **六、面试话术**

1. **为什么是二维 DP？** — 因为决策有两个维度：前缀到哪个位置（`i`）、用了几个分组（`j`）。如果只用一维，无法区分"用了 2 组"和"用了 3 组"对后续的影响。
2. **"最多 j 组" vs "恰好 j 组"** — 本题用"最多"，因为数组元素为正数时，分组越多分数越高，`d[n][k]` 自然等于恰好 k 组的最优值。如果元素可为负数，"最多"和"恰好"需要区分。
3. **累加 sum 的方向** — `j` 从 `i` 往左递减，`sum` 从 `nums[i]` 开始累加，这样可以在内层循环中增量计算，无需前缀和数组。
4. **与划分 DP 模板的统一** — 和 [[132.分割回文串 II]]、[[2707.字符串中的额外字符]] 一样的"枚举最后一段"思路，只是"合法段"的判断和转移操作不同。

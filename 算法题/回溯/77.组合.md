## 题目

https://leetcode.cn/problems/combinations/description/?envType=study-plan-v2&envId=top-interview-150



## 题解



```java
class Solution {

    void dfs(int index,int k,int n,List<Integer> list,List<List<Integer>> res){
        // 剪枝
        int need=k-list.size();
        if(need>n-index+1) return;
        if(list.size()==k){
            res.add(List.copyOf(list));
            return;
        }
        for(;index<=n;index++){
            list.add(index);
            dfs(index+1,k,n,list,res);
            list.remove(list.size()-1);
        }
        return;

    }

    public List<List<Integer>> combine(int n, int k) {
        List<List<Integer>> res=new ArrayList<>();
        dfs(1,k,n,new ArrayList<Integer>(),res);
        return res;
    }
}
```

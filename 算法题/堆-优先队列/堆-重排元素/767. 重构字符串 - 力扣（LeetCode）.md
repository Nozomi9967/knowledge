给定一个字符串 `s` ，检查是否能重新排布其中的字母，使得两相邻的字符不同。

返回 *`s` 的任意可能的重新排列。若不可行，返回空字符串 `""`* 。

**示例 1:**

```
输入: s = "aab"
输出: "aba"
```

**示例 2:**

```
输入: s = "aaab"
输出: ""
```

**提示:**

- `1 <= s.length <= 500`
- `s` 只包含小写字母

---


## 我的题解

```java
class Solution {

    public String reorganizeString(String s) {

        var pq=new PriorityQueue<int[]>(

            (a,b)->Integer.compare(b[1],a[1])

        );

        int n=s.length();

        int[] cnt=new int[26];

        for(char c:s.toCharArray()){

            cnt[c-'a']++;

        }

        for(int i=0;i<26;i++){

            if(cnt[i]>0) pq.offer(new int[]{i,cnt[i]});

        }

        var sb=new StringBuilder();

        while (pq.size() > 1) {

            int[] first = pq.poll();

            int[] second = pq.poll();

  

            // 两个不同的字符贴在一起，绝对安全

            sb.append((char)('a' + first[0]));

            sb.append((char)('a' + second[0]));

  

            // 用掉一次后，如果还有剩余，再放回队列

            if (--first[1] > 0) pq.offer(first);

            if (--second[1] > 0) pq.offer(second);

        }

  

        // 最后可能还会剩下一个孤零零的字符

        if (!pq.isEmpty()) {

            int[] last = pq.poll();

            if (last[1] > 1) return ""; // 如果这唯一剩下的字符数量大于1，说明前面没匀开，失败

            sb.append((char)('a' + last[0]));

        }

        return sb.toString();

    }

}
```

class Solution {
    public String reorganizeString(String s) {
        int n = s.length();
        Map<Character, Integer> count = new HashMap<>();
        for (char c : s.toCharArray()) {
            count.merge(c, 1, Integer::sum);
        }

        List<Map.Entry<Character, Integer>> a = new ArrayList<>(count.entrySet());
        // 按出现次数从大到小排序
        a.sort((p, q) -> q.getValue() - p.getValue());
        int m = a.get(0).getValue();
        if (m > n - m + 1) {
            return "";
        }

        char[] ans = new char[n];
        int i = 0;
        for (Map.Entry<Character, Integer> entry : a) {
            char ch = entry.getKey();
            int cnt = entry.getValue();
            while (cnt-- > 0) {
                ans[i] = ch;
                i += 2;
                if (i >= n) {
                    i = 1; // 填完偶数填奇数
                }
            }
        }
        return new String(ans);
    }
}

### 🏆 为什么灵神的第一个解法（桶计数+隔位插）更好？

灵神（第一段代码）的思路非常巧妙，他甚至不需要复杂的队列，直接用“隔位填充”的数学思维搞定：

1. **先检查最坏情况**：找出最多的那个字符，看它有没有超过 `(n + 1) / 2`。如果超过了，直接判死刑返回 `""`。
    
2. **偶数位填满，再填奇数位**：因为已经确保了没有任何字符过半，所以他直接从索引 `0, 2, 4, 6...`（偶数位）开始填，填完了再调头从 `1, 3, 5...`（奇数位）填。
    

这种“插空法”非常稳定，只需要一次遍历和简单的数组操作，**时间复杂度是 $O(n)$，而且不需要频繁地对队列进行进出操作**。

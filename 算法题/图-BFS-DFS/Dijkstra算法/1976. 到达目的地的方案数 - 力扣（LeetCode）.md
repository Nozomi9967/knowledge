提示

你在一个城市里，城市由 `n` 个路口组成，路口编号为 `0` 到 `n - 1` ，某些路口之间有 **双向** 道路。输入保证你可以从任意路口出发到达其他任意路口，且任意两个路口之间最多有一条路。

给你一个整数 `n` 和二维整数数组 `roads` ，其中 `roads[i] = [u_i, v_i, time_i]` 表示在路口 `u_i` 和 `v_i` 之间有一条需要花费 `time_i` 时间才能通过的道路。你想知道花费 **最少时间** 从路口 `0` 出发到达路口 `n - 1` 的方案数。

请返回花费 **最少时间** 到达目的地的 **路径数目** 。由于答案可能很大，将结果对 `10^9 + 7` **取余** 后返回。

**示例 1：**

![](https://assets.leetcode.com/uploads/2025/02/14/1976_corrected.png)
```
输入：n = 7, roads = [[0,6,7],[0,1,2],[1,2,3],[1,3,3],[6,3,3],[3,5,1],[6,5,1],[2,5,1],[0,4,5],[4,6,2]]
输出：4
解释：从路口 0 出发到路口 6 花费的最少时间是 7 分钟。
四条花费 7 分钟的路径分别为：
- 0 ➝ 6
- 0 ➝ 4 ➝ 6
- 0 ➝ 1 ➝ 2 ➝ 5 ➝ 6
- 0 ➝ 1 ➝ 3 ➝ 5 ➝ 6
```

**示例 2：**

```
输入：n = 2, roads = [[1,0,10]]
输出：1
解释：只有一条从路口 0 到路口 1 的路，花费 10 分钟。
```

**提示：**

- `1 <= n <= 200`
- `n - 1 <= roads.length <= n * (n - 1) / 2`
- `roads[i].length == 3`
- `0 <= u_i, v_i <= n - 1`
- `1 <= time_i <= 10^9`
- `u_i != v_i`
- 任意两个路口之间至多有一条路。
- 从任意路口出发，你能够到达其他任意路口。

#### **关键改动解释**

在 Dijkstra 的松弛过程中，我额外维护了一个 `ways[]` 数组：当发现一条更短的路径到达 `y` 时，说明之前记录的路径数已经过时，直接把 `ways[y]` 替换为 `ways[x]`；当发现一条距离相等的路径时，说明这是另一条“并列最短”的路线，需要把 `ways[x]` 累加到 `ways[y]` 上，并对 `MOD` 取模防止溢出。

另外把优先队列里的元素类型统一为 `long[]`，是因为距离值可能超过 `int` 范围（题目中边权可以达到 `10^9`，多条边累加后很容易溢出 `int`），这也是原代码里 `int[]` 的一个隐藏风险点。

最后，判断队列里取出的记录是否“过期”（`if (d > dist[x]) continue;`）是 Dijkstra 在不支持删除堆中元素时的标准写法，可以避免对已经确定最短距离的节点重复处理。
```java
import java.util.*;

class Solution {

    public static final long MOD = 1_000_000_007L;

    public int countPaths(int n, int[][] roads) {
        List<long[]>[] adj = new ArrayList[n];
        Arrays.setAll(adj, i -> new ArrayList<long[]>());
        for (int[] road : roads) {
            int x = road[0], y = road[1], t = road[2];
            adj[x].add(new long[]{y, t});
            adj[y].add(new long[]{x, t});
        }

        long[] dist = new long[n];
        Arrays.fill(dist, Long.MAX_VALUE);
        long[] ways = new long[n];

        dist[0] = 0;
        ways[0] = 1;

        // {当前距离, 节点下标}
        PriorityQueue<long[]> pq = new PriorityQueue<>((a, b) -> Long.compare(a[0], b[0]));
        pq.offer(new long[]{0, 0});

        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            long d = cur[0];
            int x = (int) cur[1];
            if (d > dist[x]) continue; // 过期的记录，跳过

            for (long[] next : adj[x]) {
                int y = (int) next[0];
                long w = next[1];
                long newDist = d + w;

                if (newDist < dist[y]) {
                    dist[y] = newDist;
                    ways[y] = ways[x];
                    pq.offer(new long[]{newDist, y});
                } else if (newDist == dist[y]) {
                    ways[y] = (ways[y] + ways[x]) % MOD;
                }
            }
        }

        return (int) (ways[n - 1] % MOD);
    }
}
```

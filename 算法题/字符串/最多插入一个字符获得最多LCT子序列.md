### **LeetCode 3409「插入一个字符后的最大子序列数」**

核心思路是**状态机计数 + 贪心分析插入增益**：先用状态机统计原始字符串中的 LCT 子序列数（`base`），再分析插入 L / C / T 三种策略各能额外产生多少子序列，取三者最大值。最终答案 = `base + max_gain`。

---

### **一、问题本身**

给定一个由 `L`、`C`、`T` 和其他字符组成的字符串 `s`。

1. 首先统计 `s` 中满足 `L` 在 `C` 在 `T` 之前的子序列总数（即 LCT 子序列数）。
2. 允许在 `s` 中**插入恰好一个字符**（可以是 `L`、`C` 或 `T`），求插入后 LCT 子序列数的最大值。

> 例如 `s = "LMCT"`：
> - 原始 LCT = 1（`L(0) C(2) T(3)`）
> - 插入 `C` 在位置 1 → `"LCMCT"`，新增 LCT = 1（`L(0) C(1) T(4)`），总计 2

---

### **二、错误思路：`LCT * 2`**

```java
// 错版
long L, LC, LCT;
L = LC = LCT = 0;
for (char c : arr) {
    if (c == 'L') L++;
    else if (c == 'C') LC += L;
    else if (c == 'T') LCT += LC;
}
return LCT * 2;  // ❌ 错误
```

**为什么错？** 插入一个字符并不是把所有已有子序列翻倍，而是**额外产生**一部分新的 LCT 子序列，具体增益取决于插入什么字符、插在哪里。

反例：`s = "LT"`，原始 LCT = 0（没有 C，无法形成 LCT）。在 L 和 T 之间插入 C → `"LCT"`，产生 1 个 LCT。正确答案 = 0 + 1 = **1**，而 `LCT*2 = 0*2 = 0`。

---

### **三、正确思路：`base + max_gain`**

答案 = **原始 LCT 数量** + **三种插入策略的最大增益**。

三种插入策略的增益分析：

| 插入字符 | 最优位置 | 额外产生的 LCT 数 | 对应统计量 |
|---------|---------|-----------------|-----------|
| 插入 `L` | 字符串**最左边** | 原串中 `CT` 子序列的个数 | `CT` |
| 插入 `T` | 字符串**最右边** | 原串中 `LC` 子序列的个数 | `LC` |
| 插入 `C` | **枚举每个位置**取最大 | 该位置左边 `L` 数 × 右边 `T` 数 | `max(L_left × T_right)` |

---

### **四、状态机统计原始数量 + 插入增益**

```java
class Solution {
    public long numOfSubsequences(String S) {
        char[] s = S.toCharArray();
        int n = s.length;

        // 统计原始子序列数量
        long l = 0, lc = 0, lct = 0;   // L 数、LC 子序列数、LCT 子序列数
        long c = 0, ct = 0;             // C 数、CT 子序列数
        long lt = 0;                    // 插入 C 的最大增益

        // 预处理 T 的总数（用于正向扫描时计算右边 T 数）
        int totalT = 0;
        for (char ch : s) if (ch == 'T') totalT++;

        int remainT = totalT;  // 右边还剩多少个 T
        for (char b : s) {
            if (b == 'L') {
                l++;
            } else if (b == 'C') {
                lc += l;   // 每个 L 和这个 C 组成一个 LC
                c++;
            } else if (b == 'T') {
                lct += lc;  // 每个 LC 和这个 T 组成一个 LCT
                ct += c;    // 每个 C 和这个 T 组成一个 CT
                remainT--;
            }
            // 插入 C 在当前位置的增益 = 左边 L 数 × 右边 T 数
            lt = Math.max(lt, l * remainT);
        }

        long base = lct;
        long maxGain = Math.max(Math.max(ct, lc), lt);
        return base + maxGain;
    }
}
```

#### **状态机含义**

- `l`：扫描过程中累计的 `L` 总数
- `lc`：已形成的 `LC` 子序列数（每个新 C 与之前所有 L 配对）
- `lct`：已形成的 `LCT` 子序列数（每个新 T 与之前所有 LC 配对）
- `c`：累计 `C` 总数
- `ct`：已形成的 `CT` 子序列数（每个新 T 与之前所有 C 配对）
- `lt`：枚举每个位置插入 C 的增益（左边 L 数 × 右边 T 数），取最大值
- `remainT`：右边还剩多少个 T（正向扫描时逐步递减）

### **五、一个具体例子走一遍**

以 `s = "LMCT"` 为例：

**正向扫描：**

| 字符 | l | lc | lct | c | ct | remainT | lt = max(lt, l×remainT) |
|------|---|-----|-----|---|-----|---------|------------------------|
| 初始 | 0 | 0   | 0   | 0 | 0   | 1       | 0                      |
| L    | 1 | 0   | 0   | 0 | 0   | 1       | max(0, 1×1) = **1**    |
| M    | 1 | 0   | 0   | 0 | 0   | 1       | max(1, 1×1) = 1        |
| C    | 1 | 1   | 0   | 1 | 0   | 1       | max(1, 1×1) = 1        |
| T    | 1 | 1   | 1   | 1 | 1   | 0       | max(1, 1×0) = 1        |

`base = lct = 1`，三种增益：`ct=1`（插入 L）、`lc=1`（插入 T）、`lt=1`（插入 C），`max_gain = 1`。

返回 `1 + 1 = 2` ✓

以 `s = "LT"` 为例：

| 字符 | l | lc | lct | c | ct | remainT | lt |
|------|---|-----|-----|---|-----|---------|-----|
| L    | 1 | 0   | 0   | 0 | 0   | 1       | 1   |
| T    | 1 | 0   | 0   | 0 | 0   | 0       | 0   |

`base = 0`，`ct=0`、`lc=0`、`lt=1`，`max_gain = 1`。

返回 `0 + 1 = 1` ✓（插入 C 在 L 和 T 之间）

**例 3：`s = "LCCT"`**

| 字符 | l | lc | lct | c | ct | remainT | lt |
|------|---|-----|-----|---|-----|---------|-----|
| L    | 1 | 0   | 0   | 0 | 0   | 1       | 1   |
| C    | 1 | 1   | 0   | 1 | 0   | 1       | 1   |
| C    | 1 | 2   | 0   | 2 | 0   | 1       | 1   |
| T    | 1 | 2   | 2   | 2 | 2   | 0       | 0   |

`base = 2`，`ct=2`（插入 L 增益 2）、`lc=2`（插入 T 增益 2）、`lt=1`，`max_gain = 2`。

返回 `2 + 2 = 4` ✓

### **六、与 2222 的对比**

| 维度 | [[2222.选择建筑的方案数]] | 本题 |
|------|------------------------|------|
| 问题类型 | 三元组计数（固定 3 个位置） | 子序列计数 + 插入增益 |
| 约束 | 两两不同（010 / 101） | L 在 C 前、C 在 T 前（有序三元组） |
| 解法 | 左右前缀计数，乘积求和 | 状态机计数 + 贪心分析插入位置 |
| 时间复杂度 | $O(n)$ | $O(n)$ |

两者都是"对每个位置统计左右异类字符数"的思路，但本题更复杂——需要维护多层子序列计数（L → LC → LCT），并在扫描过程中同时计算插入 C 的增益。

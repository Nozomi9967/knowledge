## 题目

[49. 字母异位词分组 - 力扣（LeetCode）](https://leetcode.cn/problems/group-anagrams/description/?envType=study-plan-v2&envId=top-interview-150)







## 题解

```java
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        int len=strs.length;
        List<List<String>> list = new LinkedList<>();
        if(len==1){
            List<String> l=new LinkedList<>();
            l.add(strs[0]);
            list.add(l);
            return list;
        }
        Map<String,List<String>> map=new HashMap<>();
        for(int i=0;i<len;i++){
            char[] arr=strs[i].toCharArray();
            Arrays.sort(arr);
            String s=new String(arr);
            List<String> l=map.getOrDefault(s,new LinkedList<String>());
            l.add(strs[i]);
            map.put(s,l);
        }
        for(String s:map.keySet()){
            char [] arr=s.toCharArray();
            Arrays.sort(arr);
            String sorted = new String(arr);
            list.add(map.get(sorted));
        }
        return list;
    }
}
```

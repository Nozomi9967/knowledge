## 题目

https://leetcode.cn/problems/generate-parentheses/?envType=study-plan-v2&envId=top-interview-150



## 题解

```java
class Solution {

    List<String> res=new ArrayList<>();

    void dfs(int n,int left,int index,String s){
        if(left<index-left || left>n) return;
        if(index==2*n){
            res.add(s);
            return;
        }
        dfs(n,left+1,index+1,s+'(');
        dfs(n,left,index+1,s+')');
        return;
    }

    public List<String> generateParenthesis(int n) {
        dfs(n,0,0,new String());
        return res;
    }
}
```

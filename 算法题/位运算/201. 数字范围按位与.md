## 题目

https://leetcode.cn/problems/bitwise-and-of-numbers-range/description/?envType=study-plan-v2&envId=top-interview-150





## 题解

1. 找到两个二进制数从左往右第一个不相同的位置

   例如：10110100

   ​            10110000

   此位的后面相与的话都会变成0，这样的话结果就确定了，以此位置为分界点，前半部分left和right都一样，后半部分都是0

   可以用异或来找到这个位置，异或的结果中第一个为1的位置就是了
   而Integer.numberOfLeadingZeros这个函数的作用是找到32位int数二进制表示的前导零个数
   用32减去异或的结果就是m了

2. 找到m后，接下来就是拼接结果了，由于后半部分都是0，所以找一个二进制数，让它m位及其之后位都是0，之前都是1，再与left相与jiu'xing'l

```java
class Solution {
    public int rangeBitwiseAnd(int left, int right) {
        int m=32-Integer.numberOfLeadingZeros(left^right);
        return left&~((1<<m)-1);
    }
}
```

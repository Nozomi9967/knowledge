## 题解



服了，一开始想错了，以为如果旋转最后一个下标就会变成递减数组

其实情况就只有一个大递增、两个小递增

判断nums[mid]和target是不是在同一段就行了
二分还是选开区间比较好，，，

```java
class Solution {
    public int search(int[] nums, int target) {
        int left=0,right=nums.length-1;
        while(left+1<right){
            int mid=left+(right-left)/2;
            if(nums[mid]>=nums[left]&&target<nums[left]){
                left=mid;
            }else if(nums[mid]<nums[left]&&target>=nums[left]){
                right=mid;
            }else if(target<nums[mid]){
                right=mid;
            }else{
                left=mid;
            }
        }
        return nums[left] == target ? left :
       nums[right] == target ? right : -1;
    }
}
```



```java
class Solution {
    public int search(int[] nums, int target) {
        int last = nums[nums.length - 1];
        int left = -1;
        int right = nums.length - 1; // 开区间 (-1, n-1)
        while (left + 1 < right) { // 开区间不为空
            int mid = (left + right) >>> 1;
            int x = nums[mid];
            if (target > last && x <= last) { // target 在第一段，x 在第二段
                right = mid; // 下轮循环去左边找
            } else if (x > last && target <= last) { // x 在第一段，target 在第二段
                left = mid; // 下轮循环去右边找
            } else if (x >= target) { // 否则，x 和 target 在同一段，这就和方法一的 lowerBound 一样了
                right = mid;
            } else {
                left = mid;
            }
        }
        return nums[right] == target ? right : -1;
    }
}
```

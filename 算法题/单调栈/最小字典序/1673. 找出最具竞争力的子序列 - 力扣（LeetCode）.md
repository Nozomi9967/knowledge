提示

给你一个整数数组 `nums` 和一个正整数 `k` ，返回长度为 `k` 且最具 **竞争力** 的 `nums` 子序列。

数组的子序列是从数组中删除一些元素（可能不删除元素）得到的序列。

在子序列 `a` 和子序列 `b` 第一个不相同的位置上，如果 `a` 中的数字小于 `b` 中对应的数字，那么我们称子序列 `a` 比子序列 `b` （相同长度下）更具 **竞争力** 。 例如， `[1,3,4]` 比 `[1,3,5]` 更具竞争力，在第一个不相同的位置，也就是最后一个位置上， `4` 小于 `5` 。

**示例 1：**

```
输入：nums = [3,5,2,6], k = 2
输出：[2,6]
解释：在所有可能的子序列集合 {[3,5], [3,2], [3,6], [5,2], [5,6], [2,6]} 中，[2,6] 最具竞争力。
```

**示例 2：**

```
输入：nums = [2,4,3,3,5,4,9,6], k = 4
输出：[2,3,3,4]
```

核心思路：从左到右构造一个尽可能小的子序列。遇到比当前末尾更小的数时，如果后面仍然够凑出长度 `k`，就用这个小数替换末尾较大的数。

https://leetcode.cn/problems/find-the-most-competitive-subsequence/solutions/2788312/gen-zhao-wo-guo-yi-bian-shi-li-2ni-jiu-m-36c4/
```java
class Solution {

    public int[] mostCompetitive(int[] nums, int k) {

        var st=new ArrayDeque<Integer>();

        int n=nums.length;

        for(int i=0;i<n;i++){

            int x=nums[i];
			// 最后那个判断很重要
            while(!st.isEmpty()&&x<nums[st.peek()]&&st.size()-1+n-i>=k) st.pop();

  

            st.push(i);

        }

        int[] ans=new int[k];

        for(int i=0;i<k;i++) ans[i]=nums[st.pollLast()];

  

        return ans;

    }

}
```




核心思路：从左到右构造一个尽可能小的子序列。遇到比当前末尾更小的数时，如果后面仍然够凑出长度 `k`，就用这个小数替换末尾较大的数。

这里的 `st` 存的是**数组下标**，不是数值。`ArrayDeque` 用 `push` 把新下标放到队头，因此队头是栈顶，队尾则是最早加入的下标。

### **逐行看代码**

```java
var st = new ArrayDeque<Integer>();
int n = nums.length;

for (int i = 0; i < n; i++) {
    int x = nums[i];

    while (!st.isEmpty()
            && x < nums[st.peek()]
            && st.size() + n - i > k) {
        st.pop();
    }

    st.push(i);
}
```

循环里的三个条件分别表示：

- `!st.isEmpty()`：栈里有元素，才有东西可比较、可弹出。
- `x < nums[st.peek()]`：当前数比栈顶对应的数小。用当前数替换栈顶，可能让子序列字典序更小。
- `st.size() + n - i > k`：弹出栈顶后，剩余的栈元素加上从当前下标 `i` 开始的所有元素，仍然**至少能凑出 `k` 个数**。

最后一个条件是为了避免删得太多，导致剩下的元素不够组成长度为 `k` 的子序列。式子也可以这样理解：弹出一个后，栈里有 `st.size() - 1` 个，当前及之后还有 `n - i` 个；要求总数不少于 `k`：

```text
(st.size() - 1) + (n - i) >= k
```

移项后就是代码里的 `st.size() + n - i > k`。

### **用示例 1 走一遍**

`nums = [3,5,2,6]，k = 2`

| 当前数 | 操作 | 栈中下标对应的数（从底到顶） |
|---|---|---|
| 3 | 入栈 | `[3]` |
| 5 | 5 比 3 大，入栈 | `[3,5]` |
| 2 | 2 比 5 小，且可以弹出，弹出 5 | `[3]` |
| 2 | 2 仍比 3 小，且仍可弹出，弹出 3 | `[]` |
| 2 | 入栈 | `[2]` |
| 6 | 6 比 2 大，入栈 | `[2,6]` |

结果就是 `[2,6]`。

### **为什么最后从 `pollLast()` 取？**

```java
int[] ans = new int[k];
for (int i = 0; i < k; i++) {
    ans[i] = nums[st.pollLast()];
}
```

`push(i)` 会把下标放在队头，栈顶对应较晚加入的元素；但答案要按原数组顺序从前往后取，所以从队尾 `pollLast()`，依次取出最早加入的下标。

循环结束时栈里可能多于 `k` 个元素。因为这些下标按入栈顺序排列，队尾开始取出的前 `k` 个，就是最终答案。

时间复杂度是 `O(n)`：每个下标最多入栈一次、出栈一次。

# 1143.最长公共子序列（LCS，二维 DP）

> [!abstract] 题目
> 给定两个字符串 `text1` 和 `text2`，返回**最长公共子序列**的长度。子序列不要求连续，只要求保持相对顺序。若不存在公共子序列返回 0。

| 参数 | 范围 |
|-----|------|
| text1.length | 1 ~ 1000 |
| text2.length | 1 ~ 1000 |
| 字符集 | 小写英文字母 |

**示例：** `text1 = "abcde"`, `text2 = "ace"` → 输出 3（`"ace"` 是公共子序列，虽不连续但保持相对顺序）。

---

## 核心思路：二维 DP（双序列对齐）

和 [[72.编辑距离]] 同款「双序列前缀对齐」模板：状态由两个串各自「已处理前缀长度」共同决定，天然是 (i, j) 二维网格。

### 状态定义

`d[i][j]` = `text1` 前 `i` 个字符与 `text2` 前 `j` 个字符的最长公共子序列长度。

### 状态转移

看 `text1[i-1]` 与 `text2[j-1]` 是否相等：

| 条件 | 转移 | 含义 |
|------|------|------|
| `a[i-1] == b[j-1]` | `d[i][j] = d[i-1][j-1] + 1` | 最后一个字符能配上，长度 +1，双指针各回退 |
| `a[i-1] != b[j-1]` | `d[i][j] = max(d[i-1][j], d[i][j-1])` | 配不上 → 舍弃 text1 末尾 或 舍弃 text2 末尾，取更大者 |

答案 = `d[m][n]`。

> [!info] 不等分支里的 `d[i-1][j-1]` 是冗余项
> 原写法 `max(d[i-1][j-1], d[i-1][j], d[i][j-1])` 带上了 `d[i-1][j-1]`。由于 DP 表格**单调不减**（`d[i-1][j] ≥ d[i-1][j-1]`、`d[i][j-1] ≥ d[i-1][j-1]`），它一定被另外两个覆盖，写了无害、删了也不影响正确性。标准写法只留 `max(d[i-1][j], d[i][j-1])`。

## 我的写法

```java
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        char[] a=text1.toCharArray();
        char[] b=text2.toCharArray();
        int m=a.length,n=b.length;
        int[][] d=new int[m+1][n+1];
        for(int i=1;i<=m;i++)
        for(int j=1;j<=n;j++){
            if(a[i-1]!=b[j-1]) d[i][j]=Math.max(d[i-1][j-1],Math.max(d[i-1][j],d[i][j-1]));
            else d[i][j]=d[i-1][j-1]+1;
        }
        return d[m][n];
    }
}
```

## 滚动数组优化版（空间 O(n)）

`d[i][j]` 只依赖 `d[i-1][j-1]`（左上角）、`d[i-1][j]`（正上）和 `d[i][j-1]`（左侧），可压缩为一维：

```java
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        char[] a = text1.toCharArray(), b = text2.toCharArray();
        int m = a.length, n = b.length;
        int[] d = new int[n + 1];
        for (int i = 1; i <= m; i++) {
            int prev = 0;          // 相当于 d[i-1][j-1]，每行开头是 d[i-1][0]=0
            for (int j = 1; j <= n; j++) {
                int temp = d[j];   // 先存 d[i-1][j]（下一列的 prev）
                if (a[i - 1] == b[j - 1]) {
                    d[j] = prev + 1;
                } else {
                    d[j] = Math.max(d[j], d[j - 1]); // d[j] 是 d[i-1][j]，d[j-1] 是 d[i][j-1]
                }
                prev = temp;       // 接力传给下一列
            }
        }
        return d[n];
    }
}
```

> ⚠️ 与编辑距离滚动的区别：LCS 相等分支用 `prev + 1`（左上角），不等分支 `Math.max(d[j], d[j-1])` 不需要 `prev`。`prev` 变量同样必须在 `d[j]` 被覆盖前取出，用 `temp` 接力。

- 时间：O(m × n)
- 空间：标准版 O(m × n)，滚动数组 O(n)

## 面试话术

1. **为什么是二维 DP？** → 两个序列的匹配，状态由「已处理前缀长度」(i, j) 共同决定；子序列不要求连续，所以转移只看「这个字符配不配得上」，配不上就在两个串里各丢一个末尾再取 max。
2. **相等一定取 `d[i-1][j-1]+1` 吗？为什么不是 `d[i-1][j]+1`？** → 用上这个公共字符一定是赚的（它可以再多构成一个匹配），且不会劣于丢掉它；取 `d[i-1][j-1]+1` 是 LCS 的经典增配决策。
3. **不等分支为什么是 max 不是 min？** → LCS 要"最长"，配不上时有两条路：丢掉 `text1` 末尾（`d[i-1][j]`）或丢掉 `text2` 末尾（`d[i][j-1]`），取收益更大的一边。
4. **和编辑距离什么关系？** → 编辑距离（只允许删除/插入的特例 583）满足 `minDistance = m + n - 2 × LCS`：两串去掉公共子序列后，剩下的字符全要删/插补齐。LCS 越长，编辑距离越小。
5. **复杂度？** → O(m×n) 时间；空间可滚到 O(n)。两个串长度 1000，10⁶ 次运算完全没问题。

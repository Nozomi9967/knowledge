## 常用命令

### 后端
```bash
# 构建单个模块
mvn -pl Finance -am clean package -DskipTests

# 运行单个模块
mvn spring-boot:run -pl Finance
```

### 前端
```bash
# Vue前端
cd nozomi_house_vue
pnpm install
pnpm run serve          # port 8082
```

### Android
```bash
# 构建APK
cd android/Nozomi-House
.\gradlew.bat :app:assembleDebug --no-daemon

# 安装APK
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

### 部署
```bash
# 上传JAR到生产
scp -i C:\Users\q1948\.ssh\nozomi-ecs <local.jar> root@47.98.57.132:/opt/nozomi-house/jars/
```

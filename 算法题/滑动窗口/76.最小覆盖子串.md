## 题目

https://leetcode.cn/problems/minimum-window-substring/description/?envType=study-plan-v2&envId=top-interview-150



## 题解



滑动窗口

用一个map记录当前窗口是否已经覆盖了子串

如果没有覆盖，r++

否则，l++，直到没有覆盖子串



也就是说，每次r++直到得到一个满足的窗口，紧接着进行l++，缩小窗口直到这个窗口不满足覆盖条件

这是再去寻找下一个满足的窗口

```java
class Solution {
        Map<Character,Integer> map = new HashMap<>();
        Map<Character,Integer> cur = new HashMap<>();

    boolean check(){
        for(Character c:map.keySet()){
            if(!cur.containsKey(c)||cur.get(c)<map.get(c)) return false;
        }
        return true;
    }

    public String minWindow(String s, String t) {
        for(char c:t.toCharArray()) map.put(c,map.getOrDefault(c,0)+1);
        int l=0,r=-1;
        int minLen=Integer.MAX_VALUE,minLeft=-1;
        int sLen=s.length();
        while(r<sLen){
            r++;
            if(r<sLen&&map.containsKey(s.charAt(r))){
                cur.put(s.charAt(r),cur.getOrDefault(s.charAt(r),0)+1);
            }
            // 需要确保在覆盖的状态下，进行窗口缩小，从而得到最小窗口大小
            while(check()&&l<=r){
                if(r-l+1<minLen){
                    minLen=r-l+1;
                    minLeft=l;
                }
                if(map.containsKey(s.charAt(l))){
                    cur.put(s.charAt(l),cur.getOrDefault(s.charAt(l),0)-1);
                }
                l++;
            }
        }
        return minLeft==-1?"":s.substring(minLeft,minLeft+minLen);
    }
}
```

### **LeetCode 394「字符串解码」用两个栈：数字栈存重复次数、字符串栈存"进入括号前已经拼好的前缀"。遇到 `[` 就把当前状态压栈并重置，遇到 `]` 就弹栈把 `前缀 + 倍数×当前串` 拼回去。**

### **一、问题本身**

按规则展开嵌套的编码字符串：`k[encoded]` 表示 `encoded` 重复 `k` 次。

```
"3[a]2[bc]"      → "aaabcbc"
"3[a2[c]]"       → "accaccacc"     （嵌套）
"2[abc]3[cd]ef"  → "abcabccdcdcdef"（后缀）
```

---

### **二、为什么用两个栈**

这本质是**带括号的表达式求值**，只不过运算符是"重复"。表达式求值的通用解法就是栈：

- 需要一个栈存**数字**（重复次数）
- 需要一个栈存**括号外的上下文**（前缀字符串）

为什么字符串也要栈：遇到嵌套 `3[a2[c]]` 时，处理内层 `2[c]` 的中间结果 `cc` 要和外层的 `a` 拼接，而外层的 `a` 在内层处理期间必须暂存起来——这个暂存就是字符串栈。

---

### **三、状态机式遍历**

遍历时维护三个变量：

- `cur`：当前正在构建的字符串
- `num`：当前读到的数字（可能是多位数，要累加）
- 两个栈：`numStack`、`strStack`

四种字符、四种动作：

| 遇到 | 动作 |
|---|---|
| 数字 `0-9` | `num = num * 10 + digit`（处理多位数） |
| `[` | 把 `num` 和 `cur` 分别压栈，然后**清零**（`num=0, cur=""`） |
| `]` | 弹栈：`cur = 弹出的前缀 + 弹出的倍数 × cur` |
| 字母 | `cur += c` |

**`[` 时清零是关键**：因为进入括号了，括号内要重新开始计数和拼接。这个"清零"对应的就是"保存现场 + 重置"的栈操作语义。

---

### **四、代码**

```java
class Solution {
    public String decodeString(String s) {
        Deque<Integer> numStack = new ArrayDeque<>();
        Deque<StringBuilder> strStack = new ArrayDeque<>();
        StringBuilder cur = new StringBuilder();
        int num = 0;

        for (char c : s.toCharArray()) {
            if (c >= '0' && c <= '9') {
                num = num * 10 + (c - '0');
            } else if (c == '[') {
                numStack.push(num);
                strStack.push(cur);
                num = 0;
                cur = new StringBuilder();     // 进入括号，重新开始
            } else if (c == ']') {
                int repeat = numStack.pop();
                StringBuilder prefix = strStack.pop();
                for (int i = 0; i < repeat; i++) {
                    prefix.append(cur);
                }
                cur = prefix;                  // 拼好的结果作为新的当前串
            } else {
                cur.append(c);
            }
        }
        return cur.toString();
    }
}
```

### **五、手动走一遍 `3[a2[c]]`**

```
字符    numStack   strStack        cur
3       0          []              ""
[       3          [""]            ""
a       3          [""]            "a"
2       3          [""]            "a"   num=2
[       3,2        ["", "a"]       ""
c       3,2        ["", "a"]       "c"
]       3          [""]            "a" + "cc" = "acc"
]       -          []              "" + "acc"*3 = "accaccacc"
```

第 7 步弹栈时 `prefix` 是 `"a"`、`repeat` 是 2，`cur` 是 `"c"`，拼成 `"a" + "cc" = "acc"`。这一步是理解嵌套的关键。

---

### **六、复杂度**

| 项 | 复杂度 |
|---|---|
| 时间 | O(结果串长度) —— 每次 append 都是有效产出 |
| 空间 | O(嵌套深度) 栈 + O(结果串长度) 输出 |

注意时间复杂度不能简单写成 O(n)：`3[3[3[a]]]` 的输入只有 8 个字符，输出却有 27 个。

---

### **七、易错点**

1. **多位数处理**：`12[ab]` 要累加 `num = num*10 + digit`，不能只取一位
2. **`[` 时忘记清零 `cur`**：括号内的内容会和前缀混在一起
3. **`]` 时拼接方向错**：是 `prefix + repeat × cur`，不是 `cur + prefix`
4. **用 `String` 而不是 `StringBuilder`**：重复拼接会产生大量临时对象，长输入下会超时
5. **字符串栈存 `String`**：`String` 不可变，`append` 会新建对象，必须用 `StringBuilder`
6. **栈用 `Stack` 类**：与 232 同理，用 `ArrayDeque`

---

### **八、另一种解法：递归下降**

把 `[...]` 当成一个递归结构，写一个 `parse(index)` 返回"解析结果 + 新下标"：

```java
private int[] parse(String s, int i) { ... }   // 返回 [结束位置, ...]
```

递归法和栈法完全等价（栈就是编译器帮你维护的递归栈），但递归法在嵌套很深时有栈溢出风险。**面试写栈法更稳，因为能显式说清"两个栈各存什么"。**

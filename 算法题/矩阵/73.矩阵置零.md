## 题目

https://leetcode.cn/problems/set-matrix-zeroes/?envType=study-plan-v2&envId=top-interview-150

## 题解



```java
class Solution {
    public void setZeroes(int[][] matrix) {
        Set<Integer> r=new HashSet<>();
        Set<Integer> c=new HashSet<>();
        int n=matrix.length;
        int m=matrix[0].length;
        for(int i=0;i<n;i++){
            for(int j=0;j<m;j++){
                if(matrix[i][j]==0){
                    r.add(i);
                    c.add(j);
                }
            }
        }
        for(int row:r){
            for(int j=0;j<m;j++) matrix[row][j]=0;
        }
        for(int col:c){
            for(int i=0;i<n;i++) matrix[i][col]=0;
        }
    }
}
```



## 题目

https://leetcode.cn/problems/find-k-th-smallest-pair-distance/

**原来 - 超时**
```java
class Solution {

    public int smallestDistancePair(int[] nums, int k) {

        int n=nums.length;

        int min=Integer.MAX_VALUE;

        int max=Integer.MIN_VALUE;

        for(int num:nums){

            min=Math.min(min,num);

            max=Math.max(max,num);

        }

        int l=0,r=max-min;

        while(l<=r){

            int m=(r-l)/2+l;

            if(check(m,nums,k)) r=m-1;

            else l=m+1;

        }

        return l;

    }

  

    public boolean check(int m,int[] nums,int k){

        int cnt=0;

        int n=nums.length;

        for(int i=0;i<n;i++){

            int a=nums[i];

            for(int j=i+1;j<n;j++){

                int b=nums[j];

                if(Math.abs(a-b)<=m) cnt++;

                if(cnt>=k) return true;

            }

        }

        return cnt>=k;

    }

}
```


**改进后 - 排序+双指针**
```java
class Solution {

    public int smallestDistancePair(int[] nums, int k) {

        int n=nums.length;

        Arrays.sort(nums);

        int l=0,r=nums[n-1]-nums[0];

        while(l<=r){

            int m=(r-l)/2+l;

            if(check(m,nums,k)) r=m-1;

            else l=m+1;

        }

        return l;

    }

  

    public boolean check(int m,int[] nums,int k){

        int cnt=0;

        int n=nums.length;

        int i=0;

        for(int j=0;j<n;j++){

            while(nums[j]-nums[i]>m){

                 i++;

            }

            cnt+=(j-i);

        }

        return cnt>=k;

    }

}
```


因为数组有序了，**“寻找差值 $\le mx$ 的数对”** 就可以演变成一个**右端点往右挪、左端点同向跟随**的滑动窗口（双指针）：


```java
int i = 0;
for (int j = 0; j < nums.length; j++) {
    while (nums[j] - nums[i] > mx) {
        i++; // 如果差距太大了，左指针右移，缩小差距
    }
    cnt += j - i; // 核心：直接通过下标差值算出以 nums[j] 为右端点的合法数对个数
}
```

**为什么可以直接 `cnt += j - i`？**

假设当前是有序数组 `[1, 3, 4, 7]`，当前 `mx = 4`。

当右指针 `j` 走到 `7`（下标 3），左指针 `i` 在 `3`（下标 1）。因为 $7 - 3 = 4 \le 4$ 满足条件。

此时，不仅 $(3, 7)$ 满足条件，夹在中间的 $(4, 7)$ 也必然满足条件！

所以，以 `7` 为右端点的合法数对有：$(3, 7)$ 和 $(4, 7)$，一共 $3 - 1 = 2$ 个，即 `j - i` 个。我们**根本不需要去遍历中间的数**，直接用下标一减就知道有多少个了。

在整个 `for` 循环里，`j` 在往右走，`i` 也只在往右走（不会倒退）。所以 `check` 函数的复杂度从你的 $O(N^2)$ 降到了惊人的 **$O(N)$**。

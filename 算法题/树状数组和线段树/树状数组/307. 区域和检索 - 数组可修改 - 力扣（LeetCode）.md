[307\. 区域和检索 - 数组可修改](https://leetcode.cn/problems/range-sum-query-mutable/)



给你一个数组 `nums` ，请你完成两类查询。

1. 其中一类查询要求 **更新** 数组 `nums` 下标对应的值
2. 另一类查询要求返回数组 `nums` 中索引 `left` 和索引 `right` 之间（ **包含** ）的nums元素的 **和** ，其中 `left <= right`

实现 `NumArray` 类：

- `NumArray(int[] nums)` 用整数数组 `nums` 初始化对象
- `void update(int index, int val)` 将 `nums[index]` 的值 **更新** 为 `val`
- `int sumRange(int left, int right)` 返回数组 `nums` 中索引 `left` 和索引 `right` 之间（ **包含** ）的nums元素的 **和** （即， `nums[left] + nums[left + 1], ..., nums[right]` ）

**示例 1：**

```
输入：
["NumArray", "sumRange", "update", "sumRange"]
[[[1, 3, 5]], [0, 2], [1, 2], [0, 2]]
输出：
[null, 9, null, 8]

解释：
NumArray numArray = new NumArray([1, 3, 5]);
numArray.sumRange(0, 2); // 返回 1 + 3 + 5 = 9
numArray.update(1, 2);   // nums = [1,2,5]
numArray.sumRange(0, 2); // 返回 1 + 2 + 5 = 8
```

**提示：**

- `1 <= nums.length <= 3 * 10^4`
- `-100 <= nums[i] <= 100`
- `0 <= index < nums.length`
- `-100 <= val <= 100`
- `0 <= left <= right < nums.length`
- 调用 `update` 和 `sumRange` 方法次数不大于 `3 * 10^4`

---



```java

class NumArray {
    private int[] nums;   // 保存当前数组值
    private int[] tree;   // 树状数组，下标从 1 开始
    private int n;

    public NumArray(int[] nums) {
        this.n = nums.length;
        this.nums = new int[n];        // 初始化为 0，使 update 算出的 delta = nums[i]
        this.tree = new int[n + 1];    // 多开一位，下标从 1 开始
        for (int i = 0; i < n; i++) {
            update(i, nums[i]);
        }
    }

    public void update(int index, int val) {
        int delta = val - nums[index]; // 增量
        nums[index] = val;             // 更新原数组
        for (int i = index + 1; i <= n; i += i & -i) {
            tree[i] += delta;          // 跳到下一个包含它的关键区间
        }
    }

    // 计算前缀 [1, i] 的元素和
    private int prefixSum(int i) {
        int s = 0;
        for (; i > 0; i &= i - 1) {    // i &= i-1 等价于 i -= i & -i
            s += tree[i];
        }
        return s;
    }

    public int sumRange(int left, int right) {
        return prefixSum(right + 1) - prefixSum(left);
    }
}

```



# 307. 区域和检索 - 数组可修改 · 树状数组笔记

---

## 一、树状数组是什么

树状数组（Fenwick Tree / Binary Indexed Tree）是一种支持以下两种操作均为 O(log n) 的数据结构：

- **单点修改**：把某个位置的值改掉
- **前缀查询**：查询 [0, i] 的区间和

核心思想是：`tree[i]` 不存单点值，而是存**一段区间的和**，区间长度由 `lowbit(i)` 决定。

---

## 二、lowbit 是什么

```
lowbit(i) = i & -i
```

取出 i 的二进制中**最低位的 1** 所代表的值。

```
i = 6  →  0110  →  lowbit = 0010 = 2
i = 4  →  0100  →  lowbit = 0100 = 4
i = 8  →  1000  →  lowbit = 1000 = 8
```

`tree[i]` 覆盖的区间是 `[i - lowbit(i) + 1, i]`，长度恰好是 `lowbit(i)`：

```
tree[6] 覆盖 [5, 6]，长度 2
tree[4] 覆盖 [1, 4]，长度 4
tree[8] 覆盖 [1, 8]，长度 8
```

---

## 三、下标约定

树状数组**下标必须从 1 开始**，因为 `lowbit(0) = 0`，update 里的 `i += lowbit(i)` 会死循环。

题目数组是 0-based，所以有固定映射：

```
原数组下标 index  →  树中下标 index + 1
```

---

## 四、update 详解

### 为什么用 delta 而不是直接赋值

`update(index, val)` 的语义是**把 index 位置赋值为 val**。

树中每个节点存的是区间和，不是单点值。你无法直接"赋值"一个节点，只能告诉它**变化了多少**，然后把这个变化量传播出去。

```
旧值 nums[index] = 3
新值 val = 7
delta = 7 - 3 = 4   ← 这个区间变大了 4
```

之后让所有"覆盖了 index 的树节点"都 `+= delta` 即可。

### i += i & -i 是什么

修改位置 index 后，需要更新所有**覆盖了该位置的树节点**。

`i += lowbit(i)` 正好是从当前节点跳到**下一个覆盖它的父节点**：

```
修改原数组下标 2，树中起点 i = 3

i=3  →  tree[3] += delta,  i = 3 + lowbit(3) = 3 + 1 = 4
i=4  →  tree[4] += delta,  i = 4 + lowbit(4) = 4 + 4 = 8
i=8  →  tree[8] += delta,  i = 8 + 8 = 16
...  直到 i > n 停止
```

tree[3] 覆盖 [3,3]，tree[4] 覆盖 [1,4]，tree[8] 覆盖 [1,8]，全部包含位置 3，全部需要更新。

### 代码

```java
public void update(int index, int val) {
    int delta = val - nums[index];   // 计算增量
    nums[index] = val;               // 更新原数组
    for (int i = index + 1; i <= n; i += i & -i) {  // index+1 是下标偏移
        tree[i] += delta;            // 向上传播增量
    }
}
```

---

## 五、prefixSum 详解

### i &= i - 1 是什么

`prefixSum(i)` 要把 `[1, i]` 这段前缀拆成若干个不重叠的关键区间累加。

`i -= lowbit(i)`（等价于 `i &= i - 1`）表示**去掉最低位的 1**，跳到下一个需要累加的区间右端点：

```
prefixSum(7)

i=7  →  tree[7] 覆盖 [7,7],   s += tree[7],  i = 7 - lowbit(7) = 7 - 1 = 6
i=6  →  tree[6] 覆盖 [5,6],   s += tree[6],  i = 6 - lowbit(6) = 6 - 2 = 4
i=4  →  tree[4] 覆盖 [1,4],   s += tree[4],  i = 4 - lowbit(4) = 4 - 4 = 0
i=0  →  停止

结果 = [7,7] + [5,6] + [1,4] = [1,7] 的和  ✓
```

### 代码

```java
private int prefixSum(int i) {
    int s = 0;
    for (; i > 0; i &= i - 1) {   // i &= i-1 等价于 i -= lowbit(i)
        s += tree[i];
    }
    return s;
}
```

## 六、sumRange 详解

### 为什么是 prefixSum(right + 1) 而不是 prefixSum(right)

`prefixSum(i)` 的含义是树中 [1, i] 的和，对应**原数组 [0, i-1]**：

```
prefixSum(1) → 原数组 [0, 0]
prefixSum(2) → 原数组 [0, 1]
prefixSum(3) → 原数组 [0, 2]
```

题目要求原数组 `[left, right]` 的和，前缀相减：

```
[left, right] = [0, right] - [0, left-1]
              = prefixSum(right + 1) - prefixSum(left)
                           ↑
                    right 对应树中 right+1，才能把 right 位置包含进去
```

### 反例验证

`nums = [1, 3, 5, 7]`，查询 `sumRange(1, 2)`，期望 = 3 + 5 = 8。

```
正确写法：prefixSum(3) - prefixSum(1) = 9 - 1 = 8  ✓

错误写法：prefixSum(2) - prefixSum(1) = 4 - 1 = 3  ✗  （right=2 没被包含进去）
```

### 代码

```java
public int sumRange(int left, int right) {
    return prefixSum(right + 1) - prefixSum(left);
}
```

## 七、构造函数的巧妙写法

```java
public NumArray(int[] nums) {
    this.n = nums.length;
    this.nums = new int[n];   // 全部初始化为 0
    this.tree = new int[n + 1];
    for (int i = 0; i < n; i++) {
        update(i, nums[i]);   // delta = nums[i] - 0 = nums[i]
    }
}
```

`this.nums` 初始全为 0，第一次 `update(i, nums[i])` 时：

```
delta = nums[i] - 0 = nums[i]
```

delta 恰好就是原值，**复用了 update 的传播逻辑来完成建树**，不需要单独写建树代码。代价是 O(n log n)，相比 O(n) 建树略慢，但写法极简洁。

class NumArray {
    private int[] nums;
    private int[] tree;
    private int n;

    public NumArray(int[] nums) {
        this.n = nums.length;
        this.nums = new int[n];
        this.tree = new int[n + 1];
        for (int i = 0; i < n; i++) {
            update(i, nums[i]);
        }
    }

    public void update(int index, int val) {
        int delta = val - nums[index];
        nums[index] = val;
        for (int i = index + 1; i <= n; i += i & -i) {
            tree[i] += delta;
        }
    }

    private int prefixSum(int i) {
        int s = 0;
        for (; i > 0; i &= i - 1) {
            s += tree[i];
        }
        return s;
    }

    public int sumRange(int left, int right) {
        return prefixSum(right + 1) - prefixSum(left);
    }
}

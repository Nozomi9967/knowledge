给定一个由 `0` 和 `1` 组成的矩阵 `mat` ，请输出一个大小相同的矩阵，其中每一个格子是 `mat` 中对应位置元素到最近的 `0` 的距离。

两个相邻元素间的距离为 `1` 。

**示例 1：**

![](https://pic.leetcode.cn/1626667201-NCWmuP-image.png)

```
输入：mat = [[0,0,0],[0,1,0],[0,0,0]]
输出：[[0,0,0],[0,1,0],[0,0,0]]
```

**示例 2：**

![](https://pic.leetcode.cn/1626667205-xFxIeK-image.png)

```
输入：mat = [[0,0,0],[0,1,0],[1,1,1]]
输出：[[0,0,0],[0,1,0],[1,2,1]]
```

**提示：**

- `m == mat.length`
- `n == mat[i].length`
- `1 <= m, n <= 10^4`
- `1 <= m * n <= 10^4`
- `mat[i][j] is either 0 or 1.`
- `mat` 中至少有一个 `0 `

---




```java
class Solution {

    public int[][] updateMatrix(int[][] mat) {

        int m = mat.length;

        int n = mat[0].length;

        int[][] dist = new int[m][n];

        boolean[][] visited = new boolean[m][n];

        Deque<int[]> queue = new ArrayDeque<>();

  

        // 1. 初始化：将所有 0 加入队列，这些是 BFS 的源头

        for (int i = 0; i < m; i++) {

            for (int j = 0; j < n; j++) {

                if (mat[i][j] == 0) {

                    dist[i][j] = 0;

                    visited[i][j] = true; // 0 已经是最短距离（0）

                    queue.offer(new int[]{i, j});

                }

            }

        }

  

        int[] dx = {0, 0, -1, 1};

        int[] dy = {-1, 1, 0, 0};

  

        // 2. 开始多源 BFS

        while (!queue.isEmpty()) {

            int[] curr = queue.poll();

            int x = curr[0], y = curr[1];

  

            for (int i = 0; i < 4; i++) {

                int nx = x + dx[i];

                int ny = y + dy[i];

  

                // 如果坐标合法且未被访问过

                if (nx >= 0 && nx < m && ny >= 0 && ny < n && !visited[nx][ny]) {

                    // 核心逻辑：相邻格子的距离 = 当前格子距离 + 1

                    dist[nx][ny] = dist[x][y] + 1;

                    visited[nx][ny] = true;

                    queue.offer(new int[]{nx, ny});

                }

            }

        }

  

        return dist;

    }

}
```

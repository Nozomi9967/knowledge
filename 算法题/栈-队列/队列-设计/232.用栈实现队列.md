### **LeetCode 232「用栈实现队列」的核心是「两个栈分工」：`in` 栈只负责 push，`out` 栈只负责 pop/peek。只有当 `out` 为空时才把 `in` 全部倒过去——这样每个元素最多被搬运两次，均摊时间复杂度 O(1)。**

### **一、问题本身**

只允许用两个栈（后进先出）实现队列的四个方法：`push`、`pop`、`peek`、`empty`。

```
push(1), push(2), peek() → 1, pop() → 1, empty() → false
```

---

### **二、为什么需要两个栈**

一个栈是 LIFO，天生和 FIFO 相反。两个栈可以"负负得正"：

```
in 栈：[1, 2, 3]  （3 在栈顶）

把 in 全部弹出压进 out：
out 栈：[3, 2, 1]  （1 在栈顶）

此时 out 的栈顶就是最早进来的元素，pop 出来正是队列语义。
```

**倒一次之后，顺序就反过来了**，这就是核心。

---

### **三、关键设计：什么时候倒**

**只有在 `out` 为空、且需要 pop/peek 时才倒。** 如果每次 push 都倒一次，虽然也对，但会把已经排好的 `out` 顺序打乱，而且每次 O(n)。

正确策略：

- `push(x)`：直接压进 `in`，O(1)
- `pop()`：若 `out` 空，把 `in` 全部倒进 `out`；然后 `out.pop()`
- `peek()`：同 pop，只是不弹出
- `empty()`：两个都空才算空

**为什么均摊 O(1)**：每个元素一生只会被"压进 in → 倒进 out → 从 out 弹出"这三步，总共 O(1) 次操作，所以 n 次操作总代价 O(n)，均摊下来每次 O(1)。

---

### **四、代码**

```java
class MyQueue {
    private Deque<Integer> in;    // 只负责接收
    private Deque<Integer> out;   // 只负责输出

    public MyQueue() {
        in = new ArrayDeque<>();
        out = new ArrayDeque<>();
    }

    public void push(int x) {
        in.push(x);
    }

    public int pop() {
        moveIfNeeded();
        return out.pop();
    }

    public int peek() {
        moveIfNeeded();
        return out.peek();
    }

    public boolean empty() {
        return in.isEmpty() && out.isEmpty();
    }

    private void moveIfNeeded() {
        if (out.isEmpty()) {
            while (!in.isEmpty()) {
                out.push(in.pop());
            }
        }
    }
}
```

**`ArrayDeque` 是首选**：`Stack` 类是遗留类（基于 Vector，有同步开销），`LinkedList` 有节点开销，`ArrayDeque` 性能最好。

---

### **五、复杂度**

| 操作 | 时间复杂度 |
|---|---|
| push | O(1) |
| pop / peek | 均摊 O(1)，单次最坏 O(n) |
| empty | O(1) |

空间 O(n)。

---

### **六、易错点**

1. **每次 push 就倒**：逻辑上可行但复杂且低效，且容易在 `out` 非空时打乱顺序
2. **`moveIfNeeded` 写成无条件倒**：`out` 非空时倒会把顺序搞反
3. **`empty()` 只看一个栈**：必须两个都空
4. **用 `Stack` 类**：遗留类，面试官可能追问"为什么不用"，答"Stack 继承 Vector、每个方法都加锁，单线程场景没必要"
5. **和 225（用队列实现栈）搞反**：那题反过来，核心是"push 时把新元素转到队头"

---

### **七、延伸：用栈实现队列的变体**

如果要求 **push 也 O(1)、pop 也严格 O(1)**（不接受均摊），两个栈做不到，需要更复杂的数据结构。面试一般不追这个，但被问到要能说"两栈方案是均摊 O(1)，严格最坏 O(n)，工程上完全够用"。

# 网络设备与安全概念（笔试速查）

> 这类「网络设备/安全协议」概念笔试常考，往往一句话就能答对，但要能说清**它是干什么的、和谁配合、和谁区分**。全部按"一句定义 + 关键词 + 记忆点"整理。

## ACL — 访问控制列表（Access Control List）

**定义：** 规定"谁可以访问某个资源、能做什么操作"的规则列表。

- **文件 ACL**：给某个文件/资源设定某用户可读写、另一用户只读。
- **网络设备 ACL**：按 **IP、端口、协议** 等规则**允许或拒绝**数据包通过。
- 记忆点：接入数据包 → 逐条比对 ACL 规则 → 匹配则按规则动作（allow/deny）。

> [!note] 别和以下概念混
> - **ACL ≠ 权限模型**（RBAC/ABAC），ACL 是"绑定在资源/接口上的一张清单"。
> - **ACL ≠ 防火墙**，但网络 ACL 常是防火墙/交换机实现访问控制的方式之一。

## MPLS — 多协议标签交换（Multiprotocol Label Switching）

**定义：** 按**标签（Label）**转发数据的技术，路由器不再每跳做完整 IP 最长前缀匹配，而是**看标签转发**。

- **标签**：短小的定长标识（约 20 bit），只在本段链路（local）有意义，**沿途设备可替换**，出口剥离。
- **FEC（转发等价类）**：入口把属于同一流向/目的地/VPN 的包归为一类，打同类标签。
- **LSP（标签交换路径）**：从入口到出口、由标签决定的固定路径。
- 记忆点：**包裹上的"中转指示"**——入口贴标签，沿途按标签转，出口撕掉。
- 用途：指导转发、流量分类、VPN、QoS；标签**不是加密**，也不等于 IP 地址。

> [!warning] 题面常挖的坑
> "标签就代表目的 IP""标签是加密的"——**都不对**。标签只是转发指示，不加密、不是 IP。

## IPsec — 互联网安全协议（SA / SPI / ESP / AH）

**定义：** 给 **IP 层**数据包加保护（加密 + 完整性/身份验证），常用来做 **VPN**。

- **SA（Security Association，安全关联）**：通信双方约定的一份**安全规则**——用什么协议（ESP/AH）、加密/完整性算法、密钥、SPI、有效期。**SA 是单向的**，双向通信要一对。
- **SPI（Security Parameter Index）**：用来**识别/定位 SA 的编号**。收包时根据 SPI 找到对应 SA，再按规则验证/解密。
- **ESP**：**加密** + 完整性校验（主流）。
- **AH**：只做**完整性/身份验证**，**不加密**。
- 记忆点：**IPsec 负责保护，SA 规定怎么保护（单向），SPI 帮忙找到那份 SA**。

> [!note] 和别的安全协议区分
> - **IPsec**：IP 层，常做 VPN。
> - **TLS/HTTPS**：传输层（或者更上），保护 Web/应用层流量。见 [[计网八股#HTTPS解决了HTTP哪些问题？]]。
> - **不是一回事**：IPsec 护的是 IP 包，TLS 护的是应用会话。

## IPSG — IP 源地址保护（IP Source Guard）

**定义：** 交换机上的安全功能，检查终端发出的包，确认**源 IP 是否与该端口绑定的合法 IP 一致**，不一致就丢弃，防**IP 欺骗**。

- **绑定信息来源**：主要来自 **DHCP Snooping（DHCP 侦听）** 记录的 "IP ↔ MAC ↔ 端口" 对应关系；静态 IP 可手动配静态绑定。
- 记忆点：**DHCP Snooping 负责记录对应关系，IPSG 根据记录校验源 IP**，两者常配合使用。
- 注意：这里的"端口"是**交换机物理接口**（如 `GigabitEthernet0/1`），**不是** TCP/UDP 端口号。

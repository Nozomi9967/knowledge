## 题目

https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/description/?envType=study-plan-v2&envId=top-interview-150



## 题解

```java
class Solution {

    int fun(int[] nums,int target){
        int left=-1;
        int right=nums.length;
        // 开区间
        while(left+1<right){
            int mid=left+(right-left)/2;
            if(nums[mid]>=target) right=mid;
            else left=mid;
        }
        return right;
    }

    public int[] searchRange(int[] nums, int target) {
        int start=fun(nums,target);
        if(start==nums.length || nums[start]!=target){
            return new int[]{-1,-1};
        }

        int end=fun(nums,target+1)-1;
        return new int[]{start,end};
    }
}
```







你这个问题本质是：**开区间二分时，不同写法对应的是“找不同边界”**，而不是谁对谁错。

先直接说结论，再帮你拆清楚👇

------

## ✅ 你这段代码在干嘛？

```java
if(nums[mid] <= target) left = mid;
else right = mid;
return left;
```

👉 这是在找：

> **最后一个 ≤ target 的位置（右边界）**

也就是典型的：

- upper_bound - 1

✔ 这是**完全正确的写法**

------

## ❗你说的“只能 nums[mid] >= target 返回 right”其实是另一种问题

那种写法是：

```java
if(nums[mid] >= target) right = mid;
else left = mid;
return right;
```

👉 它找的是：

> **第一个 ≥ target 的位置（左边界）**

------

## 🔥 核心区别（重点！）

| 写法 | 条件                  | 收缩方向   | 找的是什么        | 返回值  |
| ---- | --------------------- | ---------- | ----------------- | ------- |
| 你的 | `nums[mid] <= target` | left 右移  | 最后一个 ≤ target | `left`  |
| 常见 | `nums[mid] >= target` | right 左移 | 第一个 ≥ target   | `right` |

👉 两个是**对称的！都对！**

------

## 🚨 那为什么你会觉得“上面不行”？

一般是因为👇这两种情况：

### ❌ 1. 你用错了返回值

比如你写的是：

```java
if(nums[mid] <= target) left = mid;
else right = mid;
return right; // ❌ 错了
```

👉 那肯定不对，因为你维护的是 `left`

------

### ❌ 2. 你想找的是“左边界”，却用了“右边界写法”

比如数组：

```text
[1,2,2,2,3], target=2
```

- 你的写法返回：**最后一个 2 → index=3**
- 但你如果想要：**第一个 2 → index=1**

👉 就会觉得“错了”

------

## 🧠 记忆口诀（建议你直接背这个）

👉 开区间二分统一模板：

### ✔ 找左边界（第一个 ≥ target）

```java
if(nums[mid] >= target) right = mid;
else left = mid;
return right;
```

------

### ✔ 找右边界（最后一个 ≤ target）

```java
if(nums[mid] <= target) left = mid;
else right = mid;
return left;
```

------

## 💡 再帮你总结一句本质

👉 开区间二分核心不是条件，而是：

> **你想让谁成为答案，就更新谁，并返回谁**

- 想要 left → 就让 left 往答案逼近
- 想要 right → 就让 right 往答案逼近

# 90. 子集 II（Subsets II）

## 题目

https://leetcode.cn/problems/subsets-ii/

给定一个**可能包含重复元素**的整数数组 `nums`，返回所有可能的子集（幂集），解集**不能包含重复子集**。

## 题解：「选或不选」模板 + 去重剪枝

在 [[算法题/回溯/78.子集.md]] 的选或不选模板上加一个剪枝。核心规则一句话：

> **先排序。如果不选 `nums[i]`，那么后面所有和它相等的元素也都不能选。**

```java
class Solution {
    public List<List<Integer>> subsetsWithDup(int[] nums) {
        Arrays.sort(nums); // 去重的前提：相等的元素排在一起
        List<List<Integer>> ans = new ArrayList<>();
        List<Integer> path = new ArrayList<>();
        dfs(0, nums, path, ans);
        return ans;
    }

    private void dfs(int i, int[] nums, List<Integer> path, List<List<Integer>> ans) {
        if (i == nums.length) { // 子集构造完毕
            ans.add(new ArrayList<>(path));
            return;
        }

        // 选 nums[i]
        path.add(nums[i]);
        dfs(i + 1, nums, path, ans);
        path.removeLast();

        // 不选 nums[i]：后面与它相等的元素也一并跳过（都不能选）
        while (i + 1 < nums.length && nums[i + 1] == nums[i]) i++;
        dfs(i + 1, nums, path, ans);
    }
}
```

## 剪枝为什么是对的

以 `nums = [1,2,2]`（排序后）为例，两个 2 是一段相等元素。

一个子集里「值为 2 的元素取了几个」只能是 0、1、2 三种情况，**不该区分取的是前一个 2 还是后一个 2**——`[1,2]` 和 `[1,2]`（取第二个 2）是同一个子集。

剪枝规则把这段相等元素的决策压成合法三种：

- **取 0 个**：第一个 2 走「不选」分支 → while 把第二个 2 也跳过 → 整段一个不取 ✓
- **取 1 个**：第一个 2 走「选」分支，第二个 2 走「不选」分支（后面没有相等的了，随便）✓
- **取 2 个**：两个都走「选」分支 ✓
- **想跳过第一个、只取第二个？** 不可能——第一个 2 一旦不选，while 立刻把第二个 2 也跳过，堵住 ✓

所以每段相等元素只能**从左到右连续取前缀**，`k` 个取法唯一，重复子集被精确剪掉，合法子集一个不少。

**不排序行不行？不行。** 不排序则相等元素不相邻，while 跳不掉，去重失效。这就是「先去重排序，再去重剪枝」这对搭档必须同时出现的原因。

## 复杂度

- 时间 `O(n · 2ⁿ)`：最坏全不相等时退化为 78 题，`2ⁿ` 个叶子 × 拷贝 `O(n)`；有重复时实际节点更少
- 空间 `O(n)`：排序栈外，递归栈 + path（不算输出）
